Exercícios: SELECT

Prática guiada

Liste:

  1. Todos os clientes com email não nulo (id, nome, email).
  2. Os 5 pedidos mais recentes (id, cliente_id, valor_total).
  3. Clientes cujo nome começa com 'D'.
  4. Pedidos com valor_total entre 50 e 200 ordenados descrescente.

Dica

Combine WHERE + ORDER BY + LIMIT para compor consultas idiomáticas.
