Inserção simples e em lote

Inserção simples

INSERT INTO clientes (nome, email)
VALUES ('Ana Silva', 'ana@example.com');

Múltiplas linhas

INSERT INTO clientes (nome, email) VALUES
('Bruno Costa', 'bruno@example.com'),
('Carlos Lima', NULL),
('Diana Souza', 'diana@example.com');

Cuidados

  • Respeite NOT NULL/UNIQUE/FOREIGN KEY.
  • Strings entre aspas simples; evite confundir NULL com ''.
