Prática com SQLite

CLI, .schema, headers e execução

Iniciando

sqlite3 aula.db
.mode box
.headers on
.read setup.sql   -- opcional: arquivo com CREATE/INSERT

Consultando

.schema
SELECT id, nome FROM clientes LIMIT 10;
SELECT * FROM pedidos ORDER BY criado_em DESC LIMIT 5;

Dica

Use .mode column ou .mode box para legibilidade. .tables lista as tabelas.
