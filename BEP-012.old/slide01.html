SELECT, INSERT e DDL

O que é SQL

Definição

SQL (Structured Query Language) é a linguagem padrão para bancos de dados relacionais, utilizada para definir estruturas (DDL), manipular dados (DML) e controlar acesso/transações (DCL/TCL).

DDL

Data Definition Language: CREATE, ALTER, DROP.

DML

Data Manipulation Language: SELECT, INSERT, UPDATE, DELETE.

DCL

Data Control Language: GRANT, REVOKE (varia por SGBD).

TCL

Transaction Control: COMMIT, ROLLBACK, SAVEPOINT.

Onde SQL é usado?

  • APIs de backend (consulta e persistência)
  • ETL/ELT e análise de dados
  • Administração de bancos (migrations, tuning)
