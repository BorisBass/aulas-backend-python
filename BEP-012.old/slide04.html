SELECT Básico

Projeção de colunas, alias e FROM

Projeção

-- Todas as colunas
SELECT * FROM clientes;

-- Colunas específicas
SELECT id, nome, email FROM clientes;

-- Alias de colunas
SELECT id AS codigo, nome AS cliente FROM clientes;

Dicas

  • Evite SELECT * em produção: impacto em rede/planos de execução.
  • Use alias para legibilidade e padronização em relatórios.
