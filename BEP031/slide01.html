BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Setup do Ambiente

Configurando FastAPI e criando a estrutura básica

O que precisamos

  • ✅ FastAPI (framework web rápido e simples)
  • ✅ Uvicorn (servidor ASGI)
  • ✅ Python 3.10+

Instalação

# Instalar FastAPI e Uvicorn
pip install fastapi uvicorn

# Estrutura simples
projeto/
  main.py

Primeiro arquivo: main.py

from fastapi import FastAPI

app = FastAPI(title="API Exemplo")

@app.get("/")
def raiz():
    return {"mensagem": "API funcionando!"}

Executar o servidor

uvicorn main:app --reload

# Acesse:
# http://localhost:8000
# http://localhost:8000/docs  (Swagger)
# http://localhost:8000/redoc (ReDoc)

Dica: O FastAPI já gera documentação automática em /docs.
