Implementação prática de uma API REST básica

🏠 Índice geral

Objetivos da Aula

  • Configurar o ambiente para criar uma API REST
  • Criar rotas simples em uma API
  • Manipular requisições e respostas HTTP
  • Enviar e receber dados em JSON
  • Testar APIs com ferramentas como Postman ou curl

Sobre esta Aula

Esta aula apresenta a implementação prática de uma API REST básica usando FastAPI. Os alunos aprenderão a configurar o ambiente, criar rotas e modelos Pydantic, manipular requisições e respostas HTTP, e testar APIs com ferramentas como Postman ou curl.
