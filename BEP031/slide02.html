BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Criando Rotas Simples

Primeiras rotas GET e POST com FastAPI

Rota GET

from fastapi import FastAPI

app = FastAPI()

@app.get("/usuarios")
def listar_usuarios():
    return [
        {"id": 1, "nome": "João"},
        {"id": 2, "nome": "Maria"}
    ]

Rota POST

from fastapi import FastAPI
from pydantic import BaseModel

class Usuario(BaseModel):
    nome: str
    email: str

@app.post("/usuarios")
def criar_usuario(usuario: Usuario):
    return {"id": 3, **usuario.dict()}

Observações

  • ✅ @app.get e @app.post definem o método HTTP
  • ✅ FastAPI valida automaticamente os dados (Pydantic)
  • ✅ Respostas JSON são geradas automaticamente
  • ✅ Documentação aparece em /docs
