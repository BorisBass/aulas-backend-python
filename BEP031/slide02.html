BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Criando Rotas Simples

Primeiras rotas GET e POST com FastAPI

Rota GET

from fastapi import FastAPI

app = FastAPI()

@app.get("/usuarios")
def listar_usuarios():
    return [
        {"id": 1, "nome": "João"},
        {"id": 2, "nome": "Maria"}
    ]

Rota POST

from fastapi import Body, FastAPI, HTTPException

@app.post("/usuarios")
def criar_usuario(usuario: dict = Body(...)):
    nome = usuario.get("nome")
    email = usuario.get("email")
    if not nome or not isinstance(nome, str):
        raise HTTPException(status_code=400, detail="Campo 'nome' obrigatorio.")
    if not email or not isinstance(email, str):
        raise HTTPException(status_code=400, detail="Campo 'email' obrigatorio.")
    return {"id": 3, "nome": nome, "email": email}

Validação básica manual

  • ✅ O corpo da requisição chega como dict
  • ✅ Verificamos nome e email com if
  • ✅ Em caso de erro, retornamos 400 com mensagem clara

Observações

  • ✅ @app.get e @app.post definem o método HTTP
  • ✅ Você pode validar os dados manualmente (com if)
  • ✅ Respostas JSON são geradas automaticamente
  • ✅ Documentação aparece em /docs

Como testar na prática

GET no navegador

http://localhost:8000/usuarios

POST com Python (requests)

import requests

novo = {
  "nome": "Ana",
  "email": "ana@email.com"
}

resposta = requests.post("http://localhost:8000/usuarios", json=novo)
print(resposta.status_code)
print(resposta.json())

Dica: Você também pode testar pelo /docs, clicando em Try it out.
