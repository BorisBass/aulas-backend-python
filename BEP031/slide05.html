BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Testes com Python

Roteiro rápido com requests

Iniciar servidor

uvicorn main:app --reload

# API rodando em:
# http://localhost:8000

Testando GET

import requests

resposta = requests.get("http://localhost:8000/produtos")
print(resposta.status_code)
print(resposta.json())

Testando POST

import requests

novo = {
    "nome": "Livro Python",
    "preco": 79.9,
    "categoria": "livros"
}

resposta = requests.post("http://localhost:8000/produtos", json=novo)
print(resposta.status_code)
print(resposta.json())

Dicas

  • ✅ Veja a documentação em /docs
  • ✅ Verifique o status code
  • ✅ Teste erros (dados inválidos)
  • ✅ Compare respostas com o esperado
