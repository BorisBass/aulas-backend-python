BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Testando com Postman

Como testar APIs com ferramentas

Iniciar servidor

uvicorn main:app --reload

# API rodando em:
# http://localhost:8000

Testando GET

  1. Selecione método GET
  2. URL: http://localhost:8000/usuarios
  3. Clique em Send

Testando POST

  1. Selecione método POST
  2. URL: http://localhost:8000/usuarios
  3. Body → raw → JSON
  4. Exemplo de JSON:
{
  "nome": "João Silva",
  "email": "joao@exemplo.com"
}

Alternativa: curl

# GET
curl http://localhost:8000/usuarios

# POST
curl -X POST http://localhost:8000/usuarios \
  -H "Content-Type: application/json" \
  -d '{"nome": "João", "email": "joao@exemplo.com"}'

Dicas

  • ✅ Veja a documentação em /docs
  • ✅ Verifique o status code
  • ✅ Teste erros (dados inválidos)
  • ✅ Compare respostas com o esperado
