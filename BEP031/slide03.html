BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Manipulando Requisições

Lendo dados de requisições HTTP

Body (JSON)

Recebendo o JSON como dict e validando manualmente:

from fastapi import Body, FastAPI, HTTPException

app = FastAPI()

@app.post("/produtos")
def criar_produto(produto: dict = Body(...)):
    nome = produto.get("nome")
    preco = produto.get("preco")
    if not nome:
        raise HTTPException(status_code=400, detail="Campo 'nome' obrigatorio.")
    if preco is None:
        raise HTTPException(status_code=400, detail="Campo 'preco' obrigatorio.")
    return {"id": 1, "nome": nome, "preco": preco}

Query Params

Parâmetros na URL para filtro e busca:

@app.get("/produtos")
def listar_produtos(categoria=None, preco_max=None):

    if categoria:
        itens = [p for p in itens if p.get("categoria") == categoria]
    if preco_max is not None:
        try:
            preco_max = float(preco_max)
            itens = [p for p in itens if p["preco"] <= preco_max]
        except ValueError:
            raise HTTPException(status_code=400, detail="preco_max deve ser numero.")
    return {
        "categoria": categoria,
        "preco_max": preco_max,
        "itens": itens
    }

# Exemplo:
# /produtos?categoria=eletronicos&preco_max=1000

Path Params

Parâmetros na rota para identificar recursos:

@app.get("/produtos/{produto_id}")
def buscar_produto(produto_id: int):
    return {"id": produto_id, "nome": "Produto X"}

Exemplo prático

GET com query params

http://localhost:8000/produtos?categoria=livros&preco_max=80

POST com JSON

POST http://localhost:8000/produtos
Content-Type: application/json

{
  "nome": "Livro Python",
  "preco": 79.9
}

Observação: aqui validamos com if e retornamos HTTPException quando faltar dados.
