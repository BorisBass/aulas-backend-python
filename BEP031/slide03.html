BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Manipulando Requisições

Lendo dados de requisições HTTP

Body (JSON) com Pydantic

from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()

class Produto(BaseModel):
    nome: str
    preco: float
    categoria: str | None = None

@app.post("/produtos")
def criar_produto(produto: Produto):
    return {"id": 1, **produto.dict()}

Query Params

Parâmetros na URL para filtro e busca:

@app.get("/produtos")
def listar_produtos(categoria: str | None = None, preco_max: float | None = None):
    return {
        "categoria": categoria,
        "preco_max": preco_max
    }

# Exemplo:
# /produtos?categoria=eletronicos&preco_max=1000

Path Params

Parâmetros na rota para identificar recursos:

@app.get("/produtos/{produto_id}")
def buscar_produto(produto_id: int):
    return {"id": produto_id, "nome": "Produto X"}

Validação Automática

  • ✅ Tipos inválidos geram erro 422 automaticamente
  • ✅ Campos obrigatórios são validados
  • ✅ Mensagens de erro já vêm no formato JSON
