BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Enviando Respostas JSON

Formatando e enviando respostas em JSON

Resposta padrão

Em FastAPI, retornar um dict já gera JSON:

@app.get("/status")
def status():
    return {"ok": True, "mensagem": "API online"}

Status Code

from fastapi import status

@app.post("/usuarios", status_code=status.HTTP_201_CREATED)
def criar_usuario(usuario: Usuario):
    return {"id": 1, **usuario.dict()}

Erros com HTTPException

from fastapi import HTTPException

@app.get("/usuarios/{user_id}")
def buscar_usuario(user_id: int):
    if user_id != 1:
        raise HTTPException(status_code=404, detail="Usuário não encontrado")
    return {"id": 1, "nome": "João"}

Boas práticas

  • ✅ Use status codes corretos
  • ✅ Respostas consistentes (mesma estrutura)
  • ✅ Mensagens claras para erros
  • ✅ Aproveite a documentação automática
