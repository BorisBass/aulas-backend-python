BEP-031: Criando uma API REST Simples

Implementação prática de uma API REST básica

Documentação Automática

Swagger e ReDoc gerados pelo FastAPI

O que é gerado automaticamente?

  • ✅ Lista de endpoints (rotas)
  • ✅ Métodos HTTP (GET, POST, etc.)
  • ✅ Parâmetros de rota e query
  • ✅ Body de requisicao (campos do JSON)
  • ✅ Respostas e exemplos

Endereços

http://localhost:8000/docs   # Swagger UI (interativo)
http://localhost:8000/redoc  # ReDoc (leitura organizada)

Diferença: Swagger permite testar requisições. ReDoc é melhor para leitura.

Como funciona

O FastAPI cria um schema OpenAPI automaticamente e usa esse schema para montar as duas páginas.

  • ✅ Qualquer rota criada aparece na documentação
  • ✅ Quanto mais detalhes na rota, melhor a documentação
  • ✅ É possível ocultar rotas com include_in_schema=False
