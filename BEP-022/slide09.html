BEP-022: Tratamento de Exceções em POO

Melhorando a segurança e robustez do código

Boas Práticas

Dicas e melhores práticas para tratamento de exceções

✅ 1. Seja Específico

❌ Evite

try:
    # código
except:  # Muito genérico!
    print("Erro!")

✅ Prefira

try:
    # código
except ValueError:
    print("Erro de valor!")
except ZeroDivisionError:
    print("Divisão por zero!")

✅ 2. Ordene do Específico para o Genérico

try:
    # código
except SaldoInsuficienteError:  # Mais específica
    pass
except ErroBancario:             # Mais genérica
    pass
except Exception:                # Mais genérica ainda
    pass

✅ 3. Use Exceções Customizadas

Crie exceções específicas para seu domínio:

class SaldoInsuficienteError(Exception):
    """Erro quando saldo é insuficiente"""
    pass

# Mais claro que ValueError genérico!

✅ 4. Não Ignore Exceções Silenciosamente

❌ Evite

try:
    arquivo.read()
except:
    pass  # Ignora erro silenciosamente!

✅ Prefira

try:
    arquivo.read()
except FileNotFoundError as e:
    print(f"Erro: {e}")
    # Ou log, ou relance, mas não ignore!

✅ 5. Use Finally para Limpeza

try:
    arquivo = open("dados.txt", "r")
    # processar...
except FileNotFoundError:
    print("Arquivo não encontrado!")
finally:
    if 'arquivo' in locals():
        arquivo.close()  # Sempre fecha!

✅ 6. Adicione Informações Úteis

class SaldoInsuficienteError(Exception):
    def __init__(self, saldo, valor):
        self.saldo = saldo
        self.valor = valor
        super().__init__(
            f"Saldo insuficiente! "
            f"Disponível: R$ {saldo:.2f}, "
            f"Solicitado: R$ {valor:.2f}"
        )

✅ 7. Documente Exceções

def sacar(self, valor):
    """
    Saca um valor da conta.
    
    Raises:
        ValorInvalidoError: Se valor for <= 0
        SaldoInsuficienteError: Se saldo for insuficiente
    """
    if valor <= 0:
        raise ValorInvalidoError(valor)
    # ...

Resumo

  • ✅ Seja específico nas exceções
  • ✅ Ordene do específico para o genérico
  • ✅ Use exceções customizadas
  • ✅ Não ignore erros silenciosamente
  • ✅ Use finally para limpeza
  • ✅ Adicione informações úteis
  • ✅ Documente as exceções
