BEP-022: Tratamento de Exceções em POO

Melhorando a segurança e robustez do código

Exceções Customizadas

Por que criar exceções próprias?

Por que Criar?

Às vezes, as exceções padrão do Python não são suficientes para expressar erros específicos do nosso domínio.

Vantagens:
  • ✅ Mensagens mais claras
  • ✅ Erros específicos do domínio
  • ✅ Melhor organização
  • ✅ Facilita tratamento

Quando Usar?

Use exceções customizadas quando:

  • Erros específicos do seu sistema
  • Precisa de informações adicionais
  • Quer categorizar erros
  • Melhorar legibilidade do código

📝 Exemplo: Problema com Exceções Padrão

class ContaBancaria:
    def sacar(self, valor):
        if valor > self.saldo:
            raise ValueError("Saldo insuficiente!")
        # Mas ValueError também pode ser usado para outros erros...
        # Como diferenciar?

✅ Solução: Exceção Customizada

# Exceção customizada
class SaldoInsuficienteError(Exception):
    """Exceção lançada quando saldo é insuficiente"""
    pass

class ContaBancaria:
    def sacar(self, valor):
        if valor > self.saldo:
            raise SaldoInsuficienteError(
                f"Saldo insuficiente! Disponível: R$ {self.saldo:.2f}"
            )
        self.saldo -= valor

# Agora é mais claro!
try:
    conta.sacar(1000)
except SaldoInsuficienteError as e:
    print(f"❌ Erro bancário: {e}")
except ValueError as e:
    print(f"❌ Erro de valor: {e}")

🎯 Exemplos de Exceções Customizadas

💳 Sistema Bancário

  • SaldoInsuficienteError
  • ContaNaoEncontradaError
  • LimiteExcedidoError

🛒 E-commerce

  • ProdutoIndisponivelError
  • EstoqueInsuficienteError
  • DescontoInvalidoError

👤 Sistema de Usuários

  • UsuarioNaoEncontradoError
  • SenhaInvalidaError
  • EmailJaCadastradoError

📚 Sistema Educacional

  • AlunoNaoMatriculadoError
  • NotaInvalidaError
  • TurmaLotadaError

Convenção de Nomenclatura

Sempre termine o nome da exceção customizada com "Error" ou "Exception" para seguir as convenções do Python e facilitar a identificação.
