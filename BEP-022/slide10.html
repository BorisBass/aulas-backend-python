BEP-022: Tratamento de Exceções em POO

Melhorando a segurança e robustez do código

Exercícios Práticos I

Tratamento básico de exceções

Exercício 1: Calculadora Segura

  1. Crie a classe Calculadora com métodos somar(), subtrair(), multiplicar() e dividir().
  2. Implemente tratamento de exceções para:
    • Divisão por zero
    • Valores não numéricos
    • Operações inválidas
  3. Retorne mensagens claras para o usuário.

Exercício 2: Validador de Dados

  1. Crie a classe Validador com métodos:
    • validar_idade() - deve ser entre 0 e 150
    • validar_email() - deve conter @ e domínio
    • validar_telefone() - deve ter pelo menos 10 dígitos
  2. Use try-except para tratar valores inválidos.
  3. Retorne True/False ou lance exceções apropriadas.

Exercício 3: Gerenciador de Arquivos

  1. Crie a classe GerenciadorArquivo com métodos:
    • ler_arquivo() - lê conteúdo do arquivo
    • escrever_arquivo() - escreve no arquivo
    • copiar_arquivo() - copia arquivo
  2. Trate exceções:
    • FileNotFoundError
    • PermissionError
    • IOError
  3. Use finally para garantir que arquivos sejam fechados.

Dicas

  • Use exceções específicas (ValueError, ZeroDivisionError, etc.)
  • Ordene os except do mais específico para o mais genérico
  • Retorne valores apropriados (True/False, None, ou dados)
  • Use finally para limpeza de recursos
  • Mensagens de erro devem ser claras e amigáveis
