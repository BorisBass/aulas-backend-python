Exceções customizadas e sistemas completos

Exercício 4: Sistema Bancário com Exceções Customizadas

  1. Crie exceções customizadas:
    • SaldoInsuficienteError
    • ValorInvalidoError
    • ContaNaoEncontradaError
  2. Crie a classe ContaBancaria com métodos que lançam essas exceções.
  3. Implemente tratamento adequado em cada método.
  4. Crie uma hierarquia de exceções (exceção base + específicas).

Exercício 5: Sistema de E-commerce

  1. Crie exceções customizadas:
    • ProdutoIndisponivelError
    • EstoqueInsuficienteError
    • DescontoInvalidoError
  2. Crie a classe Produto e Carrinho.
  3. Implemente métodos que validam e lançam exceções apropriadas.
  4. Trate exceções ao adicionar produtos ao carrinho e calcular total.

Exercício 6: Sistema de Usuários

  1. Crie exceções customizadas:
    • EmailInvalidoError
    • SenhaFracaError
    • UsuarioNaoEncontradoError
    • EmailJaCadastradoError
  2. Crie a classe Usuario e SistemaUsuarios.
  3. Implemente validações que lançam exceções apropriadas.
  4. Use try-except ao cadastrar, buscar e autenticar usuários.

Checklist para Resolver

  • ✅ Crie exceções customizadas com nomes descritivos
  • ✅ Adicione informações úteis nas exceções
  • ✅ Crie hierarquia de exceções quando apropriado
  • ✅ Use try-except em métodos que podem falhar
  • ✅ Ordene except do específico para o genérico
  • ✅ Use finally para limpeza quando necessário
  • ✅ Teste todos os cenários de erro
  • ✅ Mensagens de erro devem ser claras
