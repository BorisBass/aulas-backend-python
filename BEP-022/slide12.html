Confirme seu domínio dos conceitos

Resumo dos Conceitos

Try-Except

  • Captura exceções durante execução
  • Permite tratamento de erros
  • Mantém programa funcionando
  • Ordem: específico → genérico
  • Finally: sempre executa
  • Else: executa se não houver erro

Exceções Customizadas

  • Herda de Exception
  • Mensagens específicas do domínio
  • Melhor organização
  • Facilita tratamento
  • Pode criar hierarquia
  • Adiciona informações úteis

Pergunta-Chave

"O que acontece se este código falhar?"

  • Se pode falhar → Use try-except
  • Se erro é específico → Crie exceção customizada
  • Se precisa limpar → Use finally
