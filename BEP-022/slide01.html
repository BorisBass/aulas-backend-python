BEP-022: Tratamento de Exceções em POO

Melhorando a segurança e robustez do código

Introdução: O que são Exceções?

Conceito e importância do tratamento de exceções

Definição

Exceção é um evento que ocorre durante a execução de um programa e interrompe o fluxo normal de instruções.

Exemplos comuns:
  • Dividir por zero
  • Acessar índice inválido em lista
  • Abrir arquivo que não existe
  • Converter string para número inválido

O Problema

Sem tratamento, exceções interrompem o programa e mostram mensagens confusas para o usuário.

Exemplo sem tratamento: 
numero = int(input("Digite um número: "))
# Se digitar "abc" → ValueError!
# Programa para e mostra erro técnico

A Solução: Tratamento de Exceções

Com tratamento adequado, podemos:

✅ Capturar erros

Interceptar exceções antes que interrompam o programa

✅ Tratar adequadamente

Executar código alternativo quando erro ocorre

✅ Informar o usuário

Mostrar mensagens claras e amigáveis

✅ Manter o programa rodando

Continuar execução mesmo após erros

Exemplo: Sem Tratamento

# Programa sem tratamento de exceções
def dividir(a, b):
    return a / b

# Se b for 0, programa para com erro!
resultado = dividir(10, 0)
print(resultado)  # Nunca será executado
Saída: ZeroDivisionError: division by zero

Exemplo: Com Tratamento

# Programa com tratamento de exceções
def dividir(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        print("❌ Erro: Não é possível dividir por zero!")
        return None

# Agora o programa continua mesmo com erro!
resultado = dividir(10, 0)
if resultado:
    print(f"Resultado: {resultado}")
Saída: ❌ Erro: Não é possível dividir por zero!

Programa continua executando normalmente!

Benefícios do Tratamento

  • ✅ Robustez: Programa não quebra facilmente
  • ✅ Experiência do usuário: Mensagens claras e amigáveis
  • ✅ Debugging: Mais fácil identificar e corrigir problemas
  • ✅ Profissionalismo: Código mais maduro e confiável
  • ✅ Segurança: Previne falhas que podem ser exploradas
