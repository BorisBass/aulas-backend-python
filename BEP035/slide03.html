Compreender o framework Django e sua arquitetura

Estrutura do Projeto

Arquivos principais e suas funcoes

Estrutura inicial

meu_projeto/
├─ manage.py
└─ meu_projeto/
   ├─ __init__.py
   ├─ settings.py
   ├─ urls.py
   ├─ wsgi.py
   └─ asgi.py

Para que serve cada arquivo

manage.py: comandos do projeto
settings.py: configuracoes gerais
urls.py: mapeamento de rotas
wsgi.py: deploy em servidores WSGI (HTTP tradicional, síncrono)
asgi.py: deploy com ASGI (HTTP + async, suporte a web sockets)
