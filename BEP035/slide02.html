BEP-035: Introdução ao Django

Compreender o framework Django e sua arquitetura

Instalação e Ambiente

Preparando o ambiente com venv e Django

Criar e ativar venv

# criar venv
python -m venv .venv

# ativar no Linux
source .venv/bin/activate

# ativar no Windows (prompt de comando)
.venv\Scripts\activate

# ativar no Windows (PowerShell)
.venv\Scripts\Activate.ps1

Instalar Django

# instalar
pip install django

# conferir versao
django-admin --version

Criar projeto

# criar projeto
django-admin startproject meu_projeto

# entrar na pasta
cd meu_projeto

# rodar servidor
python manage.py runserver

O servidor roda em http://127.0.0.1:8000.
