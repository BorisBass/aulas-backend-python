## Exercicios - BEP035: Introducao ao Django

### Exercicio 1: Projeto e ambiente
Crie um projeto Django chamado `meu_projeto`.

- Use venv.
- Instale o Django.
- Rode o servidor.

### Exercicio 2: Entendendo a estrutura
Explique com suas palavras para que servem:

- `manage.py`
- `settings.py`
- `urls.py`
- `wsgi.py` e `asgi.py`

### Exercicio 3: Criar um app
Crie um app chamado `core` e registre no `INSTALLED_APPS`.

### Exercicio 4: Primeira view
Crie uma view que retorne o texto: `Ola Django!`.

### Exercicio 5: Mapeamento de rotas
Configure a URL raiz (`/`) para chamar a view criada.

### Exercicio 6: Teste final
Execute o servidor e confirme se a mensagem aparece no navegador.
