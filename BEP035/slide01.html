BEP-035: Introdução ao Django

Compreender o framework Django e sua arquitetura

O que é Django?

Framework web completo e produtivo para Python

Por que usar Django?

Produtividade: muitas soluções prontas
Segurança: proteção contra ataques comuns
Organização: estrutura clara de projeto
Escalabilidade: cresce com o projeto

Arquitetura MTV

Django usa o padrão MTV, parecido com MVC.

# M = Model (dados)
# T = Template (tela)
# V = View (regra/controle)

Fluxo: Usuário → View → Model → View → Template → Usuário

MTV x MVC

No Django, a View faz o papel do Controller e o Template é a camada de apresentação.
