Formatos de Dados: XML

Estrutura e uso do formato XML em WebServices

O que é XML?

XML (eXtensible Markup Language) é uma linguagem de marcação que permite estruturar dados de forma hierárquica e legível. É amplamente usado em WebServices, especialmente em SOAP.

Características:

  • ✅ Legível por humanos: Fácil de ler e entender
  • ✅ Estruturado: Organiza dados de forma hierárquica
  • ✅ Extensível: Permite criar suas próprias tags
  • ✅ Padronizado: Segue padrões bem definidos

Estrutura Básica do XML

<?xml version="1.0" encoding="UTF-8"?>
<usuario>
    <id>123</id>
    <nome>João Silva</nome>
    <email>joao@exemplo.com</email>
    <idade>30</idade>
</usuario>

Elementos:

  • Declaração XML: <?xml version="1.0" encoding="UTF-8"?>
  • Elemento raiz: <usuario> (contém todos os outros elementos)
  • Elementos filhos: <id>, <nome>, <email>, <idade>
  • Tags de fechamento: Cada tag de abertura tem uma de fechamento

XML com Estrutura Complexa

<?xml version="1.0" encoding="UTF-8"?>
<usuarios>
    <usuario id="1">
        <nome>João Silva</nome>
        <email>joao@exemplo.com</email>
        <endereco>
            <rua>Rua das Flores, 123</rua>
            <cidade>Salvador</cidade>
            <estado>BA</estado>
        </endereco>
    </usuario>
    <usuario id="2">
        <nome>Maria Santos</nome>
        <email>maria@exemplo.com</email>
    </usuario>
</usuarios>

Recursos Demonstrados:

  • ✅ Atributos: id="1" (informações sobre o elemento)
  • ✅ Elementos aninhados: <endereco> dentro de <usuario>
  • ✅ Múltiplos elementos: Vários <usuario> dentro de <usuarios>

XML em WebServices (SOAP)

<?xml version="1.0" encoding="UTF-8"?>
<soap:Envelope xmlns:soap="http://schemas.xmlsoap.org/soap/envelope/">
    <soap:Body>
        <getUsuarioResponse>
            <usuario>
                <id>123</id>
                <nome>João Silva</nome>
                <email>joao@exemplo.com</email>
            </usuario>
        </getUsuarioResponse>
    </soap:Body>
</soap:Envelope>

Em WebServices SOAP, todas as mensagens são formatadas em XML, seguindo uma estrutura específica com envelope, cabeçalho e corpo.

Vantagens do XML

Legibilidade

Fácil de ler e entender, mesmo sem ferramentas especiais.

Flexibilidade

Permite estruturas complexas e hierárquicas.

Validação

Pode ser validado usando DTD ou XSD.

Padrão

Amplamente aceito e suportado.

Desvantagens do XML

  • ⚠️ Verboso: Requer mais caracteres que JSON
  • ⚠️ Processamento: Pode ser mais lento para processar
  • ⚠️ Tamanho: Arquivos XML tendem a ser maiores
  • ⚠️ Complexidade: Pode ser mais complexo para estruturas simples

Quando Usar XML?

  • ✅ WebServices SOAP: Padrão obrigatório
  • ✅ Documentos estruturados: Quando precisa de validação rigorosa
  • ✅ Integração com sistemas legados: Muitos sistemas antigos usam XML
  • ✅ Quando precisa de metadados: XML suporta atributos e namespaces
