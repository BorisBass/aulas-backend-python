Plano de Ensino - Back End com Python

Estrutura completa do curso com 48 aulas

🏠 Índice Geral

Estrutura Completa do Curso

🎯 Objetivo Geral

Desenvolver competências completas em programação Python para desenvolvimento de aplicações backend, incluindo fundamentos, estruturas de dados, algoritmos, frameworks web, banco de dados e boas práticas de desenvolvimento.

Importante

Este plano de ensino foi baseado no documento oficial "PLANO DE ENSINO - Back End com Python - BEP.pdf" que contém 48 aulas completas. As 10 aulas BEP-001 a BEP-010 implementadas representam a primeira parte do curso (fundamentos de Python).

📚 Módulos Implementados (Fundamentos)

BEP-001: Introdução ao Python

Objetivo: Apresentar a linguagem, características e escrever os primeiros programas.

Conteúdo: O que é Python, ambiente de desenvolvimento, primeiro programa, sintaxe básica, comentários, variáveis simples, entrada de dados.

Slides: 12 slides

BEP-002: Variáveis e Tipos de Dados

Objetivo: Dominar os tipos de dados básicos e operações com variáveis.

Conteúdo: Tipos de dados (int, float, str, bool), operações aritméticas, conversão de tipos, manipulação de strings.

Slides: 15 slides

BEP-003: Operadores

Objetivo: Dominar operadores aritméticos, relacionais e lógicos.

Conteúdo: Operadores aritméticos, relacionais e lógicos, precedência de operadores.

Slides: 7 slides

BEP-004: Estruturas Condicionais

Objetivo: Aprender a usar estruturas condicionais para tomar decisões.

Conteúdo: if, elif, else, condicionais aninhadas.

Slides: 7 slides

BEP-005: Estruturas de Repetição

Objetivo: Aprender a usar estruturas de repetição para automatizar tarefas.

Conteúdo: for, while, controle de loops (break, continue), loops aninhados.

Slides: 7 slides

BEP-006: Listas

Objetivo: Aprender a trabalhar com listas para armazenar coleções de dados.

Conteúdo: Criação e acesso a listas, métodos de listas, operações com listas.

Slides: 6 slides

BEP-007: Tuplas e Dicionários

Objetivo: Dominar estruturas de dados avançadas.

Conteúdo: Tuplas (imutáveis), dicionários (pares chave-valor), operações e métodos.

Slides: 19 slides

BEP-008: Funções

Objetivo: Aprender a criar e usar funções para organizar código.

Conteúdo: Definição de funções, parâmetros, retorno, escopo de variáveis.

Slides: 15 slides

BEP-009: Manipulação de Strings

Objetivo: Trabalhar com textos de maneira eficiente.

Conteúdo: Operações básicas com strings, métodos úteis (lower, upper, strip, split, join), formatação de strings.

Slides: 15 slides

BEP-010: Tratamento de Erros e Exceções

Objetivo: Ensinar como identificar, capturar e tratar erros para tornar programas robustos.

Conteúdo: O que são exceções, bloco try-except, lançando exceções com raise, tratamento de exceções comuns, uso de finally.

Slides: 6 slides
