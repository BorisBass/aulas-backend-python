BEP-038: URLs e Rotas no Django

Configurar rotas e URLs no Django

Namespaces

Namespaces evitam conflitos quando múltiplos apps têm URLs com o mesmo nome.

O que é namespace?

Namespace é um "prefixo" que identifica de qual app uma URL pertence. Isso evita confusão quando dois apps têm rotas com o mesmo nome (ex: ambos têm lista).

Definindo namespace no include

# meu_projeto/urls.py
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include(('core.urls', 'core'), namespace='core')),
    path('produtos/', include(('produtos.urls', 'produtos'), namespace='produtos')),
]

Sintaxe: include((urls_module, app_name), namespace='nome')

O primeiro elemento da tupla é o módulo de URLs, o segundo é o nome do app.

Definindo app_name no urls.py do app

# core/urls.py
from django.urls import path
from .views import lista, criar

app_name = 'core'  # define o nome do app

urlpatterns = [
    path('', lista, name='home'),      # nome da rota: 'home'
    path('lista/', lista, name='lista'),
    path('criar/', criar, name='criar'),
]

app_name: Define o nome do app para uso com namespaces.

name: Dá um nome único para cada rota dentro do app.

Usando namespace em templates


<a href="{% url 'core:lista' %}">Lista de Tarefas</a>
<a href="{% url 'produtos:lista' %}">Lista de Produtos</a>

Sintaxe: {% url 'namespace:nome_da_rota' %}

Isso gera a URL correta mesmo que ambos os apps tenham uma rota chamada lista.
