BEP-038: URLs e Rotas no Django

Configurar rotas e URLs no Django

Incluindo múltiplos apps

Um projeto Django pode ter vários apps, cada um com suas próprias URLs.

Estrutura de exemplo

Suponha que temos dois apps: core (tarefas) e produtos (produtos).

meu_projeto/
├── manage.py
├── meu_projeto/
│   ├── urls.py          # URLs principais
│   └── settings.py
├── core/
│   ├── urls.py          # URLs do app core
│   └── views.py
└── produtos/
    ├── urls.py          # URLs do app produtos
    └── views.py

URLs do projeto (raiz)

# meu_projeto/urls.py
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),
    path('', include('core.urls')),        # URLs do app core
    path('produtos/', include('produtos.urls')),  # URLs do app produtos
]

include(): Inclui todas as URLs definidas em outro arquivo urls.py. O prefixo 'produtos/' será adicionado antes de todas as URLs do app produtos.

URLs do app core

# core/urls.py
from django.urls import path
from .views import lista, criar

urlpatterns = [
    path('', lista),           # / (raiz)
    path('lista/', lista),      # /lista/
    path('criar/', criar),     # /criar/
]

URLs do app produtos

# produtos/urls.py
from django.urls import path
from .views import listar_produtos, detalhar_produto

urlpatterns = [
    path('', listar_produtos),              # /produtos/
    path('<int:id>/', detalhar_produto),  # /produtos/1/
]

Resultado:

  • / → view lista do core
  • /lista/ → view lista do core
  • /produtos/ → view listar_produtos
  • /produtos/1/ → view detalhar_produto com id=1
