BEP-038: URLs e Rotas no Django

Configurar rotas e URLs no Django

O que é URLConf?

URLConf (URL Configuration) é o sistema do Django que mapeia URLs para views.

Conceito

URLConf é um arquivo Python que define padrões de URL e suas views correspondentes. Quando o Django recebe uma requisição, ele verifica o arquivo urls.py para encontrar qual view deve ser executada.

Estrutura básica

# meu_projeto/urls.py (raiz do projeto)
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path('admin/', admin.site.urls),  # rota do admin
    path('', include('core.urls')),   # inclui URLs do app core
]

path(): Define uma rota. Recebe dois parâmetros principais:

  • Primeiro: padrão da URL (ex: 'admin/')
  • Segundo: view ou include() para incluir outras URLs

Fluxo de requisição

1. Usuário acessa http://localhost:8000/lista/

2. Django verifica meu_projeto/urls.py

3. Encontra path('', include('core.urls'))

4. Verifica core/urls.py

5. Encontra path('lista/', lista)

6. Executa a função lista da view
