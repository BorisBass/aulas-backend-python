Configurar rotas e URLs no Django

Exercícios Práticos

Pratique os conceitos aprendidos nesta aula.

Exercícios Propostos

  1. Configurar URLs: Crie rotas para listar, criar, editar e deletar tarefas
  2. Múltiplos Apps: Crie um app produtos e configure suas URLs
  3. Namespaces: Configure namespaces para evitar conflitos
  4. Reverse: Use reverse() e {% url %} nos templates
  5. Parâmetros: Crie rotas com parâmetros dinâmicos (<int:id>)

Materiais

📘 Ver Exercícios  |  ✅ Ver Soluções

Dicas

  • Sempre use name nas rotas para facilitar manutenção
  • Use namespaces quando tiver múltiplos apps
  • Prefira reverse() e {% url %} em vez de URLs hardcoded
  • Organize URLs por app para manter o código limpo
