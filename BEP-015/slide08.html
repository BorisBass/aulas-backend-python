Exercício 1: INNER JOIN - Solução

Objetivo: Mostrar livros com informações do autor e categoria

SELECT 
    l.titulo,
    a.nome as autor,
    c.nome as categoria,
    l.ano,
    l.preco
FROM livros l
INNER JOIN autores a ON l.autor_id = a.id
INNER JOIN categorias c ON l.categoria_id = c.id;

Resultado:

Título Autor Categoria Ano Preço
Python para Iniciantes João Silva Programação 2023 R$ 50
Banco de Dados Maria Santos Programação 2024 R$ 60
Algoritmos João Silva Algoritmos 2022 R$ 45
História do Brasil Carlos Lima História 2021 R$ 35

Exercício 2: LEFT JOIN - Solução

Objetivo: Mostrar TODOS os autores, mesmo os sem livros

SELECT 
    a.nome as autor,
    a.nacionalidade,
    l.titulo
FROM autores a
LEFT JOIN livros l ON a.id = l.autor_id;

Resultado:

Autor Nacionalidade Título
João Silva Brasileiro Python para Iniciantes
João Silva Brasileiro Algoritmos
Maria Santos Brasileira Banco de Dados
Carlos Lima Brasileiro História do Brasil

Exercício 3: Subconsulta - Solução

Objetivo: Encontrar livros com preço acima da média

Média dos preços: (50 + 60 + 45 + 35) ÷ 4 = R$ 47,50

SELECT 
    l.titulo,
    l.preco,
    a.nome as autor
FROM livros l
INNER JOIN autores a ON l.autor_id = a.id
WHERE l.preco > (
    SELECT AVG(preco) 
    FROM livros
);

Resultado:

Título Preço Autor
Banco de Dados R$ 60 Maria Santos

Exercício 4: GROUP BY - Solução

Objetivo: Calcular estatísticas por categoria

SELECT 
    c.nome as categoria,
    COUNT(*) as total_livros,
    AVG(l.preco) as preco_medio,
    SUM(l.preco) as preco_total
FROM livros l
INNER JOIN categorias c ON l.categoria_id = c.id
GROUP BY c.nome;

Resultado:

Categoria Total Livros Preço Médio Preço Total
Programação 2 R$ 55,00 R$ 110
Algoritmos 1 R$ 45,00 R$ 45
História 1 R$ 35,00 R$ 35

Exercício 5: ORDER BY - Solução

Objetivo: Mostrar livros ordenados por preço (maior para menor)

SELECT 
    l.titulo,
    l.preco,
    a.nome as autor
FROM livros l
INNER JOIN autores a ON l.autor_id = a.id
ORDER BY l.preco DESC;

Resultado:

Título Preço Autor
Banco de Dados R$ 60 Maria Santos
Python para Iniciantes R$ 50 João Silva
Algoritmos R$ 45 João Silva
História do Brasil R$ 35 Carlos Lima

Exercício 6: Combinado - Solução

Objetivo: Mostrar autores com mais livros, ordenados por quantidade

SELECT 
    a.nome as autor,
    COUNT(*) as quantidade_livros,
    AVG(l.preco) as preco_medio
FROM autores a
INNER JOIN livros l ON a.id = l.autor_id
GROUP BY a.nome
ORDER BY quantidade_livros DESC;

Resultado:

Autor Quantidade Livros Preço Médio
João Silva 2 R$ 47,50
Maria Santos 1 R$ 60,00
Carlos Lima 1 R$ 35,00

Resumo do que Aprendemos

INNER JOIN

Conecta tabelas mostrando apenas registros com correspondência

LEFT JOIN

Mostra todos os registros da tabela da esquerda

RIGHT JOIN

Mostra todos os registros da tabela da direita

Subconsultas

Consultas dentro de outras consultas para filtros complexos

ORDER BY

Organiza os resultados em ordem específica

GROUP BY

Agrupa registros e permite cálculos (SUM, AVG, COUNT)
