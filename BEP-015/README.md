# BEP-015: Joins e Consultas Avançadas

## 📋 Descrição do Módulo

Este módulo aborda conceitos fundamentais de integração de dados em bancos de dados relacionais, focando em JOINs e consultas avançadas que permitem combinar informações de múltiplas tabelas de forma eficiente.

## 🎯 Objetivos de Aprendizagem

Ao final deste módulo, o aluno será capaz de:

- Compreender o conceito e importância dos JOINs
- Implementar INNER JOIN para conectar tabelas com correspondências
- Utilizar LEFT JOIN para incluir todos os registros da tabela da esquerda
- Aplicar RIGHT JOIN para incluir todos os registros da tabela da direita
- Criar subconsultas para filtros complexos
- Ordenar resultados com ORDER BY
- Agrupar dados e fazer cálculos com GROUP BY
- Resolver problemas práticos combinando diferentes técnicas
