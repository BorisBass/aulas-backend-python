Comando SELECT - Seleção de Dados

O que é o SELECT?

O comando SELECT é usado para consultar e recuperar dados de uma ou mais tabelas. É o comando mais usado em SQL.

Sintaxe Básica do SELECT

SELECT coluna1, coluna2, coluna3
FROM nome_da_tabela;

Exemplo Prático

Imagine uma tabela de clientes:

id nome email cidade
1 João Silva joao@email.com Salvador
2 Maria Santos maria@email.com Feira de Santana
3 Pedro Costa pedro@email.com Salvador

Exemplos de SELECT

Selecionar Todas as Colunas

SELECT * FROM clientes;

Retorna todas as colunas e registros

Selecionar Colunas Específicas

SELECT nome, email FROM clientes;

Retorna apenas nome e email

Resultado dos Exemplos

SELECT * FROM clientes;

id nome email cidade
1 João Silva joao@email.com Salvador
2 Maria Santos maria@email.com Feira de Santana
3 Pedro Costa pedro@email.com Salvador

SELECT nome, email FROM clientes;

nome email
João Silva joao@email.com
Maria Santos maria@email.com
Pedro Costa pedro@email.com

Dicas Importantes

SELECT *

Retorna todas as colunas. Use com cuidado em tabelas grandes.

Colunas Específicas

Selecione apenas as colunas que você precisa.

FROM

Sempre especifique a tabela de onde virão os dados.

Ponto e Vírgula

Termine sempre os comandos SQL com ponto e vírgula (;).

Mais Exemplos

-- Selecionar apenas uma coluna
SELECT nome FROM clientes;

-- Selecionar duas colunas
SELECT nome, cidade FROM clientes;

-- Selecionar com espaçamento (mais legível)
SELECT 
    nome,
    email,
    cidade
FROM clientes;

Cuidados

SELECT *

Pode ser lento em tabelas com muitas colunas

Nomes

Nomes de colunas são sensíveis a maiúsculas/minúsculas

Tabela

A tabela deve existir no banco de dados

Resumo

O comando SELECT permite:

  • ✅ Consultar dados de tabelas
  • ✅ Selecionar todas as colunas (*)
  • ✅ Escolher colunas específicas
  • ✅ Recuperar informações do banco
