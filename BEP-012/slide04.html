Comando INSERT - Inserir Dados

O que é o INSERT?

O comando INSERT é usado para adicionar novos registros (linhas) em uma tabela do banco de dados.

Sintaxe Básica do INSERT

INSERT INTO nome_da_tabela (coluna1, coluna2, coluna3)
VALUES (valor1, valor2, valor3);

Exemplo: Tabela de Clientes

Imagine uma tabela de clientes vazia:

id nome email cidade
(vazio) (vazio) (vazio) (vazio)

Inserir um Cliente

INSERT INTO clientes (nome, email, cidade)
VALUES ('João Silva', 'joao@email.com', 'Salvador');

Resultado: Tabela com Dados

id nome email cidade
1 João Silva joao@email.com Salvador

Inserir Múltiplos Registros

INSERT INTO clientes (nome, email, cidade)
VALUES 
    ('Maria Santos', 'maria@email.com', 'Feira de Santana'),
    ('Pedro Costa', 'pedro@email.com', 'Salvador'),
    ('Ana Lima', 'ana@email.com', 'Vitória da Conquista');

Importante

  • INSERT INTO: Especifica a tabela onde inserir
  • Colunas: Lista as colunas que receberão valores
  • VALUES: Lista os valores correspondentes
  • Ordem: Os valores devem estar na mesma ordem das colunas
  • Tipos: Os valores devem ser compatíveis com os tipos das colunas
