Exercícios Práticos

Vamos praticar consultas SELECT com diferentes níveis de dificuldade.

Exercício 1: Básico

Tarefa: Liste todos os clientes com nome e email.

-- Sua solução aqui:
SELECT nome, email FROM clientes;

Exercício 2: Com Filtro

Tarefa: Mostre apenas os clientes de Salvador.

-- Sua solução aqui:
SELECT nome, email, cidade FROM clientes WHERE cidade = 'Salvador';

Exercício 3: Com Ordenação

Tarefa: Liste os produtos ordenados por preço (mais caro primeiro).

-- Sua solução aqui:
SELECT nome, preco FROM produtos ORDER BY preco DESC;

Exercício 4: Com Limite

Tarefa: Mostre apenas os 3 primeiros clientes.

-- Sua solução aqui:
SELECT nome, email FROM clientes LIMIT 3;

Exercício 5: Combinado

Tarefa: Mostre produtos com preço menor que 200, ordenados por nome.

-- Sua solução aqui:
SELECT nome, preco FROM produtos 
WHERE preco < 200 
ORDER BY nome;

Dicas

  • Leia com atenção: Entenda o que cada exercício pede
  • Teste: Execute cada consulta e veja o resultado
  • Experimente: Modifique os filtros e veja as mudanças
  • Pratique: Crie suas próprias consultas
