Exercícios: SELECT

Aquecimento → Intermediário → Desafio

Aquecimento

  1. Liste id, nome, email dos 5 primeiros clientes.
  2. Selecione clientes cujo nome começa com 'A', ordenando por nome.
SELECT id, nome, email FROM clientes ORDER BY id LIMIT 5;
SELECT id, nome FROM clientes WHERE nome LIKE 'A%' ORDER BY nome ASC;

Intermediário

  1. Pedidos com valor_total entre 50 e 200, ordenados desc.
  2. Clientes com email não nulo, paginando (LIMIT 5 OFFSET 5).
SELECT id, cliente_id, valor_total FROM pedidos
WHERE valor_total BETWEEN 50 AND 200
ORDER BY valor_total DESC;

SELECT id, nome FROM clientes
WHERE email IS NOT NULL
ORDER BY nome ASC, id ASC
LIMIT 5 OFFSET 5;

Desafio

Crie coluna derivada “faixa” por CASE (>=200 alto, senão baixo) e ordene por valor_total desc.

SELECT id, valor_total,
CASE WHEN valor_total >= 200 THEN 'alto' ELSE 'baixo' END AS faixa
FROM pedidos
ORDER BY valor_total DESC;
