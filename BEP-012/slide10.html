Exercícios: INSERT

Testando constraints e atomicidade

Tarefas

  1. Insira 3 clientes (misture email NULL e não NULL).
  2. Insira 2 pedidos para um cliente existente.
  3. Tente inserir pedido com cliente_id inexistente (observe o erro).
  4. Transação: 2 INSERTs em pedidos e depois ROLLBACK (verifique ausência dos registros).

Exemplos base

INSERT INTO clientes (nome, email) VALUES
('Isabela Ponte', 'isa@example.com'),
('João Pedro', 'joaop@example.com'),
('Kelly Dias', NULL);

-- Violação de FK (espera erro)
INSERT INTO pedidos (cliente_id, valor_total) VALUES (9999, 10.00);

-- Transação
BEGIN;
INSERT INTO pedidos (cliente_id, valor_total) VALUES (1, 888.00);
INSERT INTO pedidos (cliente_id, valor_total) VALUES (1, 250.00);
ROLLBACK;

Checklist

  • NOT NULL, UNIQUE e FK respeitados.
  • Strings corretas (aspas simples), NULL não é ''.
  • Transação confere atomicidade e consistência.
