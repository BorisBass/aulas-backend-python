Exercícios: INSERT

Exercícios Práticos

Vamos praticar inserção de dados com diferentes cenários.

Exercício 1: Inserir Cliente

Tarefa: Insira um novo cliente com nome, email e cidade.

-- Sua solução aqui:
INSERT INTO clientes (nome, email, cidade) 
VALUES ('Ana Costa', 'ana@email.com', 'Vitória da Conquista');

Exercício 2: Inserir Múltiplos Clientes

Tarefa: Insira 3 clientes de uma vez.

-- Sua solução aqui:
INSERT INTO clientes (nome, email, cidade) VALUES
('Carlos Silva', 'carlos@email.com', 'Camaçari'),
('Lucia Santos', 'lucia@email.com', 'Ilhéus'),
('Roberto Lima', 'roberto@email.com', 'Salvador');

Exercício 3: Inserir Produto

Tarefa: Insira um novo produto com nome, preço e estoque.

-- Sua solução aqui:
INSERT INTO produtos (nome, preco, estoque) 
VALUES ('Tablet Samsung', 1200.00, 8);

Exercício 4: Cliente sem Email

Tarefa: Insira um cliente que não tem email (use NULL).

-- Sua solução aqui:
INSERT INTO clientes (nome, email, cidade) 
VALUES ('Maria Silva', NULL, 'Feira de Santana');

Exercício 5: Verificar Inserção

Tarefa: Verifique se os dados foram inseridos corretamente.

-- Sua solução aqui:
SELECT * FROM clientes;
SELECT * FROM produtos;

Dicas

  • Aspas simples: Use ' ' para strings
  • NULL: Use NULL para valores ausentes
  • Verifique: Use SELECT para confirmar inserções
  • Ordem: Os valores devem estar na ordem das colunas
