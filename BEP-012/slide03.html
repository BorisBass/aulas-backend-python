Comandos CREATE, ALTER e DROP

Comandos CREATE, ALTER e DROP

DDL - Data Definition Language

Os comandos CREATE, ALTER e DROP são usados para gerenciar a estrutura do banco de dados (schemas, tabelas, colunas, etc.).

CREATE SCHEMA - Criar Esquema

O comando CREATE SCHEMA é usado para criar um novo esquema (namespace) no banco de dados.

-- Criar um esquema para o projeto
CREATE SCHEMA loja;

-- Usar o esquema criado
USE loja;

ALTER SCHEMA - Modificar Esquema

O comando ALTER SCHEMA permite modificar propriedades de um esquema existente.

-- Renomear um esquema
ALTER SCHEMA loja RENAME TO ecommerce;

DROP SCHEMA - Excluir Esquema

O comando DROP SCHEMA remove completamente um esquema e todos os seus objetos.

-- Excluir um esquema (CUIDADO: remove todos os objetos!)
DROP SCHEMA loja CASCADE;

CREATE TABLE - Criar Tabelas

O comando CREATE TABLE é usado para criar novas tabelas no banco de dados.

-- Criar uma tabela de clientes
CREATE TABLE clientes (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    email TEXT,
    telefone TEXT,
    cidade TEXT
);

ALTER TABLE - Modificar Tabelas

O comando ALTER TABLE permite modificar a estrutura de uma tabela existente.

-- Adicionar uma nova coluna
ALTER TABLE loja.clientes ADD COLUMN data_cadastro DATE;

-- Remover uma coluna (SQLite não suporta DROP COLUMN diretamente)
-- Em outros SGBDs: ALTER TABLE loja.clientes DROP COLUMN telefone;

DROP TABLE - Excluir Tabelas

O comando DROP TABLE remove completamente uma tabela e todos os seus dados.

-- Excluir uma tabela (CUIDADO: remove todos os dados!)
DROP TABLE loja.clientes;

Importante

  • SCHEMA: Organiza objetos do banco (tabelas, views, etc.)
  • CREATE: Cria novas estruturas (schemas, tabelas, índices, etc.)
  • ALTER: Modifica estruturas existentes
  • DROP: Remove estruturas completamente
  • Cuidado: DROP remove dados permanentemente!
  • Hierarquia: SCHEMA → TABLE → COLUMNS
