Esquema e Tipos Essenciais

Affinities do SQLite, datas/horários e valores monetários

Modelo de exemplo

CREATE TABLE clientes (
  id INTEGER PRIMARY KEY,
  nome TEXT NOT NULL,
  email TEXT UNIQUE
);

CREATE TABLE pedidos (
  id INTEGER PRIMARY KEY,
  cliente_id INTEGER NOT NULL,
  valor_total REAL NOT NULL, -- Postgres/MySQL: DECIMAL(10,2)
  criado_em DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (cliente_id) REFERENCES clientes(id)
);

Datas/Horários

Armazene UTC quando aplicável; converta na borda. Em SQLite, TIMESTAMP é texto/real/integer conforme affinity.

Monetário

Use DECIMAL(10,2) em Postgres/MySQL. Em SQLite, REAL com cuidado a arredondamentos.

NULL ≠ ''

Trate NULL como ausência de valor. WHERE e agregações mudam com NULL.

Integridade

PK, FK, UNIQUE, CHECK e DEFAULT reduzem erros na aplicação.
