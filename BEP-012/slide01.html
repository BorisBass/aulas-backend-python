BEP-012: Introdução a SQL – Comandos Básicos

SELECT, INSERT e comandos básicos de estrutura

O que é SQL?

Definição

SQL (Structured Query Language) é a linguagem padrão para trabalhar com bancos de dados relacionais. É uma linguagem declarativa que permite:

Principais Funções do SQL

Consultar Dados

Buscar informações nas tabelas

Inserir Dados

Adicionar novos registros

Modificar Dados

Alterar informações existentes

Remover Dados

Excluir registros

Exemplo Prático

Imagine que você tem uma tabela de clientes:

ID Nome Email Cidade
1 João Silva joao@email.com Salvador
2 Maria Santos maria@email.com Feira de Santana

Com SQL você pode:

  • Buscar: "Mostre todos os clientes de Salvador"
  • Adicionar: "Insira um novo cliente"
  • Modificar: "Altere o email do João"
  • Remover: "Exclua o cliente ID 2"

Tipos de Comandos SQL

DDL

Data Definition Language
CREATE, ALTER, DROP
(Criar, alterar, excluir estruturas)

DML

Data Manipulation Language
SELECT, INSERT, UPDATE, DELETE
(Consultar e modificar dados)

Exemplo de Comando SQL

-- Buscar todos os clientes
SELECT * FROM clientes;

-- Buscar apenas nome e email
SELECT nome, email FROM clientes;

-- Buscar clientes de Salvador
SELECT nome, email FROM clientes 
WHERE cidade = 'Salvador';

Características do SQL

Padrão

Funciona na maioria dos bancos de dados

Declarativo

Você diz o que quer, não como fazer

Fácil de Aprender

Sintaxe simples e intuitiva

Seguro

Controle de acesso e integridade

Resumo

SQL é a linguagem que permite:

  • ✅ Consultar dados (SELECT)
  • ✅ Inserir dados (INSERT)
  • ✅ Modificar dados (UPDATE)
  • ✅ Excluir dados (DELETE)
  • ✅ Criar estruturas (CREATE)
