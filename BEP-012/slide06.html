Comando INSERT - Inserir Dados

O que é o INSERT?

O comando INSERT é usado para adicionar novos registros (linhas) em uma tabela do banco de dados.

Sintaxe Básica do INSERT

INSERT INTO nome_da_tabela (coluna1, coluna2, coluna3)
VALUES (valor1, valor2, valor3);

Exemplo: Tabela de Clientes

Imagine uma tabela de clientes vazia:

id nome email cidade
(vazio) (vazio) (vazio) (vazio)

Inserir um Registro

-- Inserir um novo cliente
INSERT INTO clientes (nome, email, cidade)
VALUES ('João Silva', 'joao@email.com', 'Salvador');

Resultado: Tabela com Dados

id nome email cidade
1 João Silva joao@email.com Salvador

Cliente inserido com sucesso!

Inserir Múltiplos Registros

-- Inserir vários clientes de uma vez
INSERT INTO clientes (nome, email, cidade) VALUES
('Maria Santos', 'maria@email.com', 'Feira de Santana'),
('Pedro Costa', 'pedro@email.com', 'Salvador'),
('Ana Lima', 'ana@email.com', 'Vitória da Conquista');

Resultado: Tabela com Múltiplos Dados

id nome email cidade
1 João Silva joao@email.com Salvador
2 Maria Santos maria@email.com Feira de Santana
3 Pedro Costa pedro@email.com Salvador
4 Ana Lima ana@email.com Vitória da Conquista

Regras Importantes

Aspas

Use aspas simples para texto: 'João Silva'

Números

Números não precisam de aspas: 25, 100.50

Ordem

A ordem dos valores deve seguir a ordem das colunas

NOT NULL

Colunas marcadas como NOT NULL são obrigatórias

Mais Exemplos

-- Inserir apenas nome e cidade (email pode ser NULL)
INSERT INTO clientes (nome, cidade)
VALUES ('Carlos Oliveira', 'Camaçari');

-- Inserir com ID específico (se a coluna permitir)
INSERT INTO clientes (id, nome, email, cidade)
VALUES (10, 'Lucia Ferreira', 'lucia@email.com', 'Ilhéus');

Cuidados

Chave Primária

IDs são gerados automaticamente (AUTO_INCREMENT)

Aspas

Não esqueça as aspas em textos

Colunas

Verifique se as colunas existem na tabela

Commit

As alterações são salvas automaticamente

Resumo

O comando INSERT permite:

  • ✅ Adicionar novos registros
  • ✅ Inserir um registro por vez
  • ✅ Inserir múltiplos registros
  • ✅ Especificar quais colunas preencher
