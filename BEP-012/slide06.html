Filtros: WHERE, ORDER BY e LIMIT

Refinando Consultas

Os comandos WHERE, ORDER BY e LIMIT permitem filtrar, ordenar e limitar os resultados das consultas.

WHERE - Filtrar Dados

O comando WHERE é usado para filtrar registros que atendem a uma condição específica.

-- Sintaxe básica
SELECT colunas
FROM tabela
WHERE condição;

Exemplo: Tabela de Clientes

id nome email cidade
1 João Silva joao@email.com Salvador
2 Maria Santos maria@email.com Feira de Santana
3 Pedro Costa pedro@email.com Salvador

Exemplos de WHERE

-- Clientes de Salvador
SELECT * FROM clientes WHERE cidade = 'Salvador';

-- Cliente com ID específico
SELECT * FROM clientes WHERE id = 2;

-- Clientes com nome que contém 'João'
SELECT * FROM clientes WHERE nome LIKE '%João%';

ORDER BY - Ordenar Dados

O comando ORDER BY é usado para ordenar os resultados por uma ou mais colunas.

-- Ordenar por nome (A-Z)
SELECT * FROM clientes ORDER BY nome;

-- Ordenar por nome (Z-A)
SELECT * FROM clientes ORDER BY nome DESC;

-- Ordenar por cidade, depois por nome
SELECT * FROM clientes ORDER BY cidade, nome;

LIMIT - Limitar Resultados

O comando LIMIT é usado para limitar o número de registros retornados.

-- Mostrar apenas os 2 primeiros clientes
SELECT * FROM clientes LIMIT 2;

-- Mostrar os 3 primeiros clientes ordenados por nome
SELECT * FROM clientes ORDER BY nome LIMIT 3;

Exemplo Combinado

-- Clientes de Salvador, ordenados por nome, limitado a 2
SELECT nome, email FROM clientes 
WHERE cidade = 'Salvador' 
ORDER BY nome 
LIMIT 2;

Importante

  • WHERE: Filtra registros por condições
  • ORDER BY: Ordena os resultados (ASC = crescente, DESC = decrescente)
  • LIMIT: Limita o número de registros retornados
  • Ordem: WHERE → ORDER BY → LIMIT
  • Operadores: =, !=, <, >, <=, >=, LIKE
