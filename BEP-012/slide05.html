SELECT, INSERT e comandos básicos de estrutura

Filtros: WHERE, ORDER BY e LIMIT

Refinando Consultas

Os comandos WHERE, ORDER BY e LIMIT permitem filtrar, ordenar e limitar os resultados das consultas.

WHERE - Filtrar Dados

O comando WHERE é usado para filtrar registros que atendem a uma condição específica.

-- Sintaxe básica
SELECT colunas
FROM tabela
WHERE condição;

Exemplo: Tabela de Clientes

id nome email cidade idade
1 João Silva joao@email.com Salvador 25
2 Maria Santos maria@email.com Feira de Santana 30
3 Pedro Costa pedro@email.com Salvador 22
4 Ana Lima ana@email.com Vitória da Conquista 28

Exemplos de WHERE

Igualdade

-- Clientes de Salvador
SELECT nome, email 
FROM clientes 
WHERE cidade = 'Salvador';

Maior que

-- Clientes com mais de 25 anos
SELECT nome, idade 
FROM clientes 
WHERE idade > 25;

ORDER BY - Ordenar Dados

O comando ORDER BY é usado para ordenar os resultados por uma ou mais colunas.

-- Ordenar por nome (A-Z)
SELECT nome, cidade 
FROM clientes 
ORDER BY nome;

-- Ordenar por idade (maior para menor)
SELECT nome, idade 
FROM clientes 
ORDER BY idade DESC;

LIMIT - Limitar Resultados

O comando LIMIT é usado para limitar o número de registros retornados.

-- Mostrar apenas os 3 primeiros clientes
SELECT nome, cidade 
FROM clientes 
LIMIT 3;

-- Mostrar os 2 clientes mais velhos
SELECT nome, idade 
FROM clientes 
ORDER BY idade DESC 
LIMIT 2;

Resultados dos Exemplos

WHERE cidade = 'Salvador'

nome email
João Silva joao@email.com
Pedro Costa pedro@email.com

ORDER BY idade DESC LIMIT 2

nome idade
Maria Santos 30

Combinando Comandos

-- Clientes de Salvador, ordenados por nome, limitado a 2
SELECT nome, email, cidade
FROM clientes
WHERE cidade = 'Salvador'
ORDER BY nome
LIMIT 2;

Dicas Importantes

Texto

Use aspas simples para texto: 'Salvador'

Ordem

ASC = crescente (padrão), DESC = decrescente

LIMIT

Resumo

ORDER BY

Ordena os resultados

LIMIT

Limita o número de registros
