1. Configuração Inicial

Conceito: Antes de trabalhar com SQL, precisamos importar as bibliotecas e estabelecer uma conexão com o banco de dados.

Prática: Vamos usar SQLite em memória para não precisar salvar arquivos.

Comandos: sqlite3.connect(':memory:') cria conexão em memória, cursor = conn.cursor() cria cursor para executar comandos.

Célula 1: Configuração

import sqlite3

# Criar conexão com banco em memória
conn = sqlite3.connect(':memory:')
cursor = conn.cursor()
print("Conexão com SQLite estabelecida!")

2. DDL - Criar Tabelas (CREATE TABLE)

Conceito: DDL (Data Definition Language) é usado para definir a estrutura do banco. CREATE TABLE cria novas tabelas.

Prática: Vamos criar duas tabelas: clientes e produtos, definindo suas colunas e tipos de dados.

Célula 2: Criar Tabelas

# Criar tabela de clientes
cursor.execute('''
CREATE TABLE clientes (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    email TEXT,
    telefone TEXT,
    cidade TEXT
)
''')
print("Tabela 'clientes' criada!")

# Criar tabela de produtos
cursor.execute('''
CREATE TABLE produtos (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    preco REAL,
    estoque INTEGER
)
''')
print("Tabela 'produtos' criada!")

3. DDL - Modificar Tabela (ALTER TABLE)

Conceito: ALTER TABLE permite modificar a estrutura de uma tabela existente, como adicionar colunas.

Prática: Vamos adicionar uma coluna de data de cadastro à tabela de clientes.

Comandos: PRAGMA table_info(tabela) mostra informações sobre as colunas de uma tabela.

Célula 3: Alterar Tabela

# Adicionar coluna data_cadastro
cursor.execute('''
ALTER TABLE clientes ADD COLUMN data_cadastro DATE
''')
print("Coluna 'data_cadastro' adicionada!")

# Verificar estrutura da tabela
cursor.execute("PRAGMA table_info(clientes)")
colunas = cursor.fetchall()
print("Estrutura da tabela 'clientes':")
for coluna in colunas:
    print(f"  - {coluna[1]} ({coluna[2]})")

4. DML - Inserir Dados (INSERT INTO)

Conceito: DML (Data Manipulation Language) é usado para manipular dados. INSERT INTO adiciona novos registros.

Prática: Vamos inserir dados de exemplo nas tabelas para depois consultá-los.

Comandos: cursor.executemany() executa o mesmo comando para múltiplos registros, conn.commit() salva as alterações.

Célula 4: Inserir Clientes

# Inserir clientes
clientes = [
    ('João Silva', 'joao@email.com', '(71) 99999-1111', 'Salvador', '2024-01-15'),
    ('Maria Santos', 'maria@email.com', '(71) 99999-2222', 'Feira de Santana', '2024-01-20'),
    ('Pedro Costa', 'pedro@email.com', '(71) 99999-3333', 'Salvador', '2024-01-25'),
    ('Ana Lima', 'ana@email.com', '(71) 99999-4444', 'Vitória da Conquista', '2024-02-01'),
    ('Carlos Oliveira', 'carlos@email.com', '(71) 99999-5555', 'Camaçari', '2024-02-05')
]

cursor.executemany('''
INSERT INTO clientes (nome, email, telefone, cidade, data_cadastro)
VALUES (?, ?, ?, ?, ?)
''', clientes)
print(f"{len(clientes)} clientes inseridos!")

Célula 5: Inserir Produtos

# Inserir produtos
produtos = [
    ('Notebook Dell', 2500.00, 15),
    ('Mouse Logitech', 89.90, 50),
    ('Teclado Mecânico', 199.90, 25),
    ('Monitor 24"', 800.00, 10),
    ('Webcam HD', 150.00, 30)

cursor.executemany('''
INSERT INTO produtos (nome, preco, estoque)
VALUES (?, ?, ?)
''', produtos)
print(f"{len(produtos)} produtos inseridos!")

5. DML - Consultar Dados (SELECT)

Conceito: SELECT é o comando mais usado em SQL para recuperar dados das tabelas. Podemos selecionar todas as colunas (*) ou colunas específicas.

Prática: Agora que temos dados, vamos consultá-los usando SELECT.

Comandos: cursor.fetchall() retorna todos os resultados da consulta como uma lista de tuplas.

Célula 6: SELECT Básico

# SELECT * (todos os dados)
cursor.execute("SELECT * FROM clientes")
clientes = cursor.fetchall()
print("Todos os clientes:")
for cliente in clientes:
    print(f"  ID: {cliente[0]}, Nome: {cliente[1]}, Cidade: {cliente[4]}")

# SELECT com colunas específicas
cursor.execute("SELECT nome, email FROM clientes")
clientes = cursor.fetchall()
print("\nNome e email dos clientes:")
for cliente in clientes:
    print(f"  {cliente[0]} - {cliente[1]}")

6. DML - Filtros (WHERE, ORDER BY, LIMIT)

Conceito: WHERE filtra registros por condições, ORDER BY ordena os resultados, LIMIT limita o número de registros retornados.

Prática: Vamos aplicar filtros para buscar dados específicos e organizados.

Célula 7: Filtros

# WHERE - Clientes de Salvador
cursor.execute("SELECT nome, email, cidade FROM clientes WHERE cidade = 'Salvador'")
clientes_salvador = cursor.fetchall()
print("Clientes de Salvador:")
for cliente in clientes_salvador:
    print(f"  {cliente[0]} - {cliente[1]}")

# ORDER BY - Produtos por preço
cursor.execute("SELECT nome, preco FROM produtos ORDER BY preco DESC")
produtos_ordenados = cursor.fetchall()
print("\nProdutos ordenados por preço (maior para menor):")
for produto in produtos_ordenados:
    print(f"  {produto[0]} - R$ {produto[1]:.2f}")

# LIMIT - Primeiros 3 clientes
cursor.execute("SELECT nome, cidade FROM clientes LIMIT 3")
primeiros_clientes = cursor.fetchall()
print("\nOs 3 primeiros clientes:")
for cliente in primeiros_clientes:
    print(f"  {cliente[0]} - {cliente[1]}")
