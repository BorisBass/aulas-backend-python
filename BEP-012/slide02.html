Tipos de Dados Básicos

Os tipos de dados definem que tipo de informação pode ser armazenada em cada coluna da tabela.

INTEGER - Números Inteiros

Armazena números inteiros (positivos, negativos ou zero).

-- Exemplos de INTEGER
id INTEGER PRIMARY KEY,        -- 1, 2, 3, 100, -5
idade INTEGER,                 -- 25, 30, 18
quantidade INTEGER             -- 0, 1, 10, 1000

TEXT - Texto

Armazena texto de qualquer tamanho (nomes, descrições, etc.).

-- Exemplos de TEXT
nome TEXT NOT NULL,            -- "João Silva"
email TEXT,                    -- "joao@email.com"
descricao TEXT                 -- "Produto de alta qualidade"

REAL - Números Decimais

Armazena números com casas decimais (preços, medidas, etc.).

-- Exemplos de REAL
preco REAL,                    -- 25.99, 100.50, 0.99
peso REAL,                     -- 1.5, 2.75, 0.25
altura REAL                    -- 1.75, 0.50, 2.10

DATE - Datas

Armazena datas no formato YYYY-MM-DD.

-- Exemplos de DATE
data_nascimento DATE,          -- "1990-05-15"
data_cadastro DATE,            -- "2024-01-20"
data_vencimento DATE           -- "2024-12-31"

Exemplo: Tabela com Diferentes Tipos

CREATE TABLE produtos (
    id INTEGER PRIMARY KEY,           -- Número inteiro
    nome TEXT NOT NULL,               -- Texto
    preco REAL,                       -- Número decimal
    data_lancamento DATE,             -- Data
    ativo INTEGER                     -- 1 (sim) ou 0 (não)
);

Importante

  • INTEGER: Para números inteiros (contadores, IDs)
  • TEXT: Para qualquer texto (nomes, descrições)
  • REAL: Para números decimais (preços, medidas)
  • DATE: Para datas (nascimento, cadastro)
  • NOT NULL: Campo obrigatório (não pode ficar vazio)
