Comandos CREATE, ALTER e DROP

DDL - Data Definition Language

Os comandos CREATE, ALTER e DROP são usados para gerenciar a estrutura do banco de dados (tabelas, colunas, etc.).

CREATE - Criar Tabelas

O comando CREATE TABLE é usado para criar novas tabelas no banco de dados.

-- Criar uma tabela de clientes
CREATE TABLE clientes (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    email TEXT,
    telefone TEXT,
    cidade TEXT
);

ALTER - Modificar Tabelas

O comando ALTER TABLE é usado para modificar a estrutura de uma tabela existente.

-- Adicionar uma nova coluna
ALTER TABLE clientes ADD COLUMN data_cadastro DATE;

-- Renomear uma coluna (SQLite não suporta, mas outros SGBDs sim)
ALTER TABLE clientes RENAME COLUMN telefone TO telefone_contato;

-- Remover uma coluna (SQLite não suporta, mas outros SGBDs sim)
ALTER TABLE clientes DROP COLUMN telefone;

DROP - Excluir Tabelas

O comando DROP TABLE é usado para excluir uma tabela completamente do banco de dados.

-- Excluir uma tabela
DROP TABLE clientes;

-- Excluir uma tabela (se existir)
DROP TABLE IF EXISTS clientes;

Cuidados Importantes

DROP TABLE

ATENÇÃO: Exclui a tabela e todos os dados permanentemente!

ALTER TABLE

Algumas modificações podem afetar dados existentes

Backup

Sempre faça backup antes de alterações importantes

Teste

Teste os comandos em ambiente de desenvolvimento primeiro

Tipos de Dados Básicos

INTEGER

Números inteiros (1, 2, 100, -5)

TEXT

Texto (nomes, descrições)

DATE

Datas (2024-01-15)

REAL

Números decimais (10.50, 99.99)

Exemplo Completo

-- 1. Criar tabela
CREATE TABLE produtos (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL,
    preco REAL,
    estoque INTEGER
);

-- 2. Adicionar coluna
ALTER TABLE produtos ADD COLUMN categoria TEXT;

-- 3. Excluir tabela (cuidado!)
DROP TABLE produtos;

Resumo

CREATE

Cria novas tabelas e estruturas

ALTER

Modifica estruturas existentes

DROP

Exclui estruturas permanentemente
