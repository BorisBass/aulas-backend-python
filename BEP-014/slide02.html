BEP-014: Modelagem e Normalização de Dados

Estruturando dados de forma eficiente para evitar redundância e inconsistência

1ª Forma Normal (1FN)

Definição da 1ª Forma Normal

Uma tabela está na 1ª Forma Normal (1FN) quando:

  • ✅ Todos os valores em cada coluna são atômicos (indivisíveis)
  • ✅ Não há grupos repetitivos ou arrays em uma única coluna
  • ✅ Cada célula contém apenas um valor
  • ✅ Não há colunas com múltiplos valores separados por vírgulas

Valores Atômicos vs Grupos Repetitivos

Ambos violam a 1FN, mas são problemas diferentes: um é sobre o conteúdo da célula, o outro sobre a estrutura da tabela.

Tipo de violação Exemplo ruim (NÃO 1FN) Correção (1FN)
Valores não atômicos
Vários valores em uma mesma célula 		Telefones: "(71) 99999-1111, (71) 3333-2222"
Cursos: "Python, Java, SQL" 		Uma linha por valor:
Telefone = "(71) 99999-1111"
Telefone = "(71) 3333-2222"
Grupos repetitivos
Múltiplas colunas para o mesmo atributo 		Telefone1, Telefone2, Telefone3
Curso1, Curso2, Curso3 		Uma única coluna (Telefone) e várias linhas
Uma única coluna (Curso) e várias linhas

Dica

Atômico foca no conteúdo da célula; grupo repetitivo foca na estrutura (colunas). A solução de ambos é normalizar em linhas (e possivelmente em tabelas auxiliares).

Exemplo: Tabela NÃO Normalizada

Esta tabela NÃO está na 1FN:

ID Nome Telefones Cursos
1 João Silva (71) 99999-1111, (71) 3333-2222 Python, Java, SQL
2 Maria Santos (75) 88888-3333 JavaScript, React

Problemas Identificados:

  • Coluna "Telefones": Múltiplos valores separados por vírgula
  • Coluna "Cursos": Múltiplos valores separados por vírgula
  • Não atômico: Cada célula contém mais de um valor

Exemplo: Tabela na 1ª Forma Normal

Esta tabela ESTÁ na 1FN:

ID Nome Telefone Curso
1 João Silva (71) 99999-1111 Python
1 João Silva (71) 3333-2222 Java
1 João Silva (71) 99999-1111 SQL
2 Maria Santos (75) 88888-3333 JavaScript
2 Maria Santos (75) 88888-3333 React

Características da 1FN:

  • Valores atômicos: Cada célula contém apenas um valor
  • Sem grupos repetitivos: Não há múltiplos valores em uma coluna
  • Estrutura simples: Fácil de consultar e manipular

Como Aplicar a 1ª Forma Normal

1. Identificar

Encontrar colunas com múltiplos valores

2. Separar

Dividir valores em linhas individuais

3. Verificar

Confirmar que cada célula tem um valor

4. Aplicar

Implementar a nova estrutura

Importante!

A 1ª Forma Normal é a base para todas as outras formas normais. Sem ela, não é possível aplicar a 2FN ou 3FN. É o primeiro passo obrigatório na normalização de dados.
