BEP-014: Modelagem e Normalização de Dados

Estruturando dados de forma eficiente para evitar redundância e inconsistência

🏠 Índice geral

Objetivos da Aula

  • Compreender os conceitos fundamentais de modelagem de dados.
  • Aplicar a 1ª, 2ª e 3ª formas normais em tabelas.
  • Identificar problemas de redundância e inconsistência.
  • Normalizar tabelas de banco de dados de forma eficiente.
  • Avaliar o impacto da modelagem na performance e integridade.
  • Resolver exercícios práticos de normalização.
