BEP-039: Formulários e Validação de Dados

Manipular formulários com segurança no Django

Limpeza de Dados

Limpeza (cleaning) normaliza e valida dados de forma customizada.

O que é limpeza?

Limpeza é o processo de normalizar e validar dados de um campo específico ou do formulário inteiro. Use métodos clean_<campo>() para campos individuais e clean() para validações que envolvem múltiplos campos.

clean_<campo>() - Validação de Campo

# core/forms.py
from django import forms
from django.core.exceptions import ValidationError

class TarefaForm(forms.Form):
    descricao = forms.CharField(max_length=200)
    prioridade = forms.ChoiceField(choices=[('alta', 'Alta'), ('media', 'Média'), ('baixa', 'Baixa')])
    
    def clean_descricao(self):
        descricao = self.cleaned_data.get('descricao')
        if descricao and len(descricao.strip()) < 5:
            raise ValidationError('A descrição deve ter pelo menos 5 caracteres.')
        return descricao.strip()  # remove espaços extras e retorna

clean_descricao(): Método chamado automaticamente para validar o campo descricao.

self.cleaned_data.get('descricao'): Acessa o valor já validado do campo.

ValidationError: Exceção lançada quando a validação falha.

return: Retorna o valor limpo/normalizado.

clean() - Validação do Formulário

# core/forms.py
class TarefaForm(forms.Form):
    descricao = forms.CharField(max_length=200)
    data_inicio = forms.DateField()
    data_fim = forms.DateField()
    
    def clean(self):
        cleaned_data = super().clean()  # chama limpeza padrão
        data_inicio = cleaned_data.get('data_inicio')
        data_fim = cleaned_data.get('data_fim')
        
        # validação que envolve múltiplos campos
        if data_inicio and data_fim:
            if data_fim < data_inicio:
                raise ValidationError({
                    'data_fim': 'A data de fim deve ser posterior à data de início.'
                })
        
        return cleaned_data  # retorna todos os dados limpos

clean(): Valida o formulário inteiro, útil para validações entre campos.

super().clean(): Chama a limpeza padrão do Django primeiro.

ValidationError com dicionário: Associa erro a um campo específico.

Exemplo: Validação de E-mail Único

# core/forms.py
from django import forms
from django.core.exceptions import ValidationError
from .models import Usuario

class UsuarioForm(forms.Form):
    email = forms.EmailField()
    nome = forms.CharField(max_length=100)
    
    def clean_email(self):
        email = self.cleaned_data.get('email')
        if Usuario.objects.filter(email=email).exists():
            raise ValidationError('Este e-mail já está cadastrado.')
        return email

Este exemplo verifica se o e-mail já existe no banco antes de permitir o cadastro.
