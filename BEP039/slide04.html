BEP-039: Formulários e Validação de Dados

Manipular formulários com segurança no Django

Exibindo Mensagens de Erro

Django Forms facilita a exibição de erros nos templates.

Template Básico com Erros


<form method="post">
    {% csrf_token %}  <!-- obrigatório para segurança -->
    
    <!-- Erros gerais do formulário -->
    {% if form.non_field_errors %}
        <div class="erros">
            {{ form.non_field_errors }}
        </div>
    {% endif %}
    
    <!-- Campo descricao -->
    <div>
        {{ form.descricao.label_tag }}
        {{ form.descricao }}
        {% if form.descricao.errors %}
            <div class="erro-campo">
                {{ form.descricao.errors }}
            </div>
        {% endif %}
    </div>
    
    <!-- Campo prioridade -->
    <div>
        {{ form.prioridade.label_tag }}
        {{ form.prioridade }}
        {% if form.prioridade.errors %}
            <div class="erro-campo">
                {{ form.prioridade.errors }}
            </div>
        {% endif %}
    </div>
    
    <button type="submit">Salvar</button>
</form>

{% csrf_token %}: Token de segurança obrigatório em formulários POST.

form.non_field_errors: Erros que não estão associados a um campo específico.

form.campo.errors: Lista de erros do campo específico.

Template Simplificado


<form method="post">
    {% csrf_token %}
    
    <!-- Renderiza todos os campos automaticamente -->
    {{ form.as_p }}  <!-- como parágrafos -->
    <!-- ou -->
    {{ form.as_table }}  <!-- como tabela -->
    <!-- ou -->
    {{ form.as_ul }}  <!-- como lista -->
    
    <button type="submit">Salvar</button>
</form>

form.as_p: Renderiza campos como parágrafos (<p>), incluindo erros.

form.as_table: Renderiza como tabela HTML.

form.as_ul: Renderiza como lista não ordenada.

Nota: Esses métodos incluem os erros automaticamente.

Template Customizado com Loop


<form method="post">
    {% csrf_token %}
    
    {% for field in form %}
        <div class="campo">
            {{ field.label_tag }}
            {{ field }}
            {% if field.errors %}
                <ul class="erros">
                    {% for error in field.errors %}
                        <li>{{ error }}</li>
                    {% endfor %}
                </ul>
            {% endif %}
            {% if field.help_text %}
                <small>{{ field.help_text }}</small>
            {% endif %}
        </div>
    {% endfor %}
    
    <button type="submit">Salvar</button>
</form>

{% for field in form %}: Itera sobre todos os campos do formulário.

field.help_text: Texto de ajuda do campo (se definido no form).

Este método oferece mais controle sobre o layout.

Estilizando Erros

<style>
    .erro-campo {
        color: red;
        font-size: 0.9em;
        margin-top: 5px;
    }
    .erro-campo ul {
        list-style: none;
        padding: 0;
        margin: 0;
    }
</style>
