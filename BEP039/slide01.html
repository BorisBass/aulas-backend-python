BEP-039: Formulários e Validação de Dados

Manipular formulários com segurança no Django

O que são Django Forms?

Django Forms é um sistema que facilita a criação, validação e processamento de formulários HTML.

Por que usar Django Forms?

  • Segurança: Proteção automática contra CSRF
  • Validação: Validação automática de dados
  • HTML automático: Gera HTML dos campos
  • Limpeza: Limpa e normaliza dados

Criando um Form

# core/forms.py
from django import forms

class TarefaForm(forms.Form):
    descricao = forms.CharField(
        max_length=200,
        label='Descrição',
        widget=forms.TextInput(attrs={'class': 'form-control'})
    )
    prioridade = forms.ChoiceField(
        choices=[('alta', 'Alta'), ('media', 'Média'), ('baixa', 'Baixa')],
        label='Prioridade'
    )
    status = forms.IntegerField(
        min_value=0,
        max_value=100,
        initial=0,
        label='Status (%)'
    )

forms.Form: Classe base para criar formulários.

widget: Define como o campo será renderizado no HTML.

attrs: Atributos HTML adicionais (ex: classes CSS).

Tipos de campo: Documentação Django – Form fields (CharField, IntegerField, ChoiceField, etc.)

Usando o Form na View

# core/views.py
from django.shortcuts import render, redirect
from .forms import TarefaForm
from .models import Tarefa

def criar_tarefa(request):
    if request.method == 'POST':
        form = TarefaForm(request.POST)  # cria form com dados do POST
        if form.is_valid():  # valida os dados
            descricao = form.cleaned_data['descricao']  # dados limpos
            prioridade = form.cleaned_data['prioridade']
            status = form.cleaned_data['status']
            Tarefa.objects.create(descricao=descricao, prioridade=prioridade, status=status)
            return redirect('core:lista')
    else:
        form = TarefaForm()  # form vazio para GET
    
    return render(request, 'criar_tarefa.html', {'form': form})

request.POST: Dados enviados pelo formulário.

is_valid(): Valida todos os campos do formulário.

cleaned_data: Dicionário com dados validados e limpos.

Template criar_tarefa.html


<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Criar tarefa</title>
</head>
<body>
    <h1>Nova tarefa</h1>
    <form method="post">
        {% csrf_token %}
        {{ form.as_p }}  <!-- renderiza todos os campos do form -->
        <button type="submit">Salvar</button>
    </form>
    <p><a href="{% url 'core:lista' %}">Voltar para lista</a></p>
</body>
</html>

criar_tarefa.html é o template chamado pela view criar_tarefa.

{{ form.as_p }} renderiza automaticamente os campos do TarefaForm.

O link usa {% url 'core:lista' %} para voltar para a lista de tarefas (como no projeto de exemplo).
