Exercícios Propostos

  1. Criar Form: Crie um formulário para cadastrar tarefas
  2. Validação: Adicione validações para campos obrigatórios
  3. Limpeza: Implemente clean_descricao() para validar tamanho mínimo
  4. Template: Crie template que exibe erros de validação
  5. View: Implemente view que processa o formulário

Dicas

  • Sempre use {% csrf_token %} em formulários POST
  • Use form.is_valid() antes de acessar cleaned_data
  • Customize mensagens de erro usando ValidationError
  • Use clean() para validações entre múltiplos campos
