BEP-039: Formulários e Validação de Dados

Manipular formulários com segurança no Django

Validação de Dados

Django Forms valida automaticamente os dados antes de processá-los.

Validação Automática

Quando você chama form.is_valid(), o Django valida:

  • Tipo: Se o valor corresponde ao tipo do campo
  • Obrigatoriedade: Se campos obrigatórios foram preenchidos
  • Limites: max_length, min_value, max_value, etc.
  • Formato: Email, URL, etc.

Campos com Validação

# core/forms.py
from django import forms

class ContatoForm(forms.Form):
    nome = forms.CharField(
        max_length=100,
        required=True,  # campo obrigatório
        label='Nome'
    )
    email = forms.EmailField(
        required=True,
        label='E-mail'
    )
    idade = forms.IntegerField(
        min_value=18,
        max_value=120,
        required=True,
        label='Idade'
    )
    telefone = forms.CharField(
        max_length=15,
        required=False,  # campo opcional
        label='Telefone'
    )

required=True: Campo obrigatório (padrão).

required=False: Campo opcional.

EmailField: Valida formato de e-mail automaticamente.

Verificando Validação

# core/views.py
def criar_tarefa(request):
    if request.method == 'POST':
        form = TarefaForm(request.POST)
        if form.is_valid():
            # dados válidos - processar
            descricao = form.cleaned_data['descricao']
            # ... salvar no banco ...
            return redirect('core:lista')
        else:
            # dados inválidos - form.errors contém os erros
            # o template mostrará os erros automaticamente
            pass
    
    else:
        form = TarefaForm()
    
    return render(request, 'criar_tarefa.html', {'form': form})

form.is_valid(): Retorna True se todos os campos são válidos.

form.errors: Dicionário com erros de validação por campo.

Se is_valid() retornar False, o template pode exibir os erros.

Mensagens de Erro Padrão

Django fornece mensagens de erro em português se configurado:

  • Campo obrigatório: "Este campo é obrigatório."
  • E-mail inválido: "Informe um endereço de e-mail válido."
  • Valor muito grande: "Certifique-se de que este valor seja menor ou igual a X."
