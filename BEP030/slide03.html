BEP-030: RESTful Web Services e Métodos HTTP

Princípios REST e métodos HTTP para manipulação de recursos

Métodos HTTP: GET

Buscar e recuperar recursos

O que é GET?

O método GET é usado para buscar e recuperar informações de um recurso. É o método mais comum e usado para leitura de dados.

Características:

  • ✅ Idempotente: Múltiplas requisições retornam o mesmo resultado
  • ✅ Seguro: Não modifica dados no servidor
  • ✅ Cacheável: Respostas podem ser armazenadas em cache
  • ✅ Sem corpo: Não envia dados no corpo da requisição

Exemplos de Uso

// Buscar todos os usuários
GET /api/usuarios HTTP/1.1
Host: exemplo.com
Accept: application/json

// Resposta
HTTP/1.1 200 OK
Content-Type: application/json

{
  "usuarios": [
    {"id": 1, "nome": "João"},
    {"id": 2, "nome": "Maria"}
  ]
}

// Buscar um usuário específico
GET /api/usuarios/123 HTTP/1.1
Host: exemplo.com

// Resposta
HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": 123,
  "nome": "João Silva",
  "email": "joao@exemplo.com"
}

Quando Usar GET?

Use GET para:

  • Buscar lista de recursos
  • Buscar um recurso específico
  • Filtrar e pesquisar dados
  • Operações de leitura

NÃO use GET para:

  • Criar novos recursos
  • Atualizar dados
  • Deletar recursos
  • Operações que modificam dados

GET com Parâmetros

GET pode usar parâmetros de query string para filtrar, paginar ou buscar dados:

// Buscar com filtros
GET /api/usuarios?nome=João&idade=25 HTTP/1.1

// Buscar com paginação
GET /api/usuarios?page=1&limit=10 HTTP/1.1

// Buscar com ordenação
GET /api/usuarios?sort=nome&order=asc HTTP/1.1
