Sobre esta Aula

Esta aula apresenta os conceitos fundamentais de REST (Representational State Transfer) e os métodos HTTP utilizados para manipular recursos em APIs. Os alunos aprenderão sobre os princípios REST, os métodos HTTP (GET, POST, PUT, DELETE, PATCH), os códigos de status HTTP e como estruturar URLs RESTful. A aula também inclui exercícios práticos de modelagem de recursos REST.

Estrutura pedagógica: A aula começa com uma introdução aos conceitos REST, depois apresenta cada método HTTP em detalhes, explica os códigos de status e mostra como estruturar URLs. Por fim, inclui exercícios práticos para fixar o aprendizado.
