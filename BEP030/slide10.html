BEP-030: RESTful Web Services e Métodos HTTP

Princípios REST e métodos HTTP para manipulação de recursos

Consumindo APIs Públicas

Exemplos simples de requisições GET

Exemplo 1: JSONPlaceholder

API pública de testes para simular recursos.

# Listar posts
GET https://jsonplaceholder.typicode.com/posts

# Buscar post específico
GET https://jsonplaceholder.typicode.com/posts/1

# Filtrar por usuário
GET https://jsonplaceholder.typicode.com/posts?userId=1

Documentação: https://jsonplaceholder.typicode.com/guide/

Exemplo 2: ViaCEP

API pública brasileira para consulta de CEP.

# Consultar CEP
GET https://viacep.com.br/ws/01001000/json/

# Consultar por endereço
GET https://viacep.com.br/ws/BA/Salvador/Barra/json/

Documentação: https://viacep.com.br/

Consumo no Python (GET + print)

import requests

# JSONPlaceholder
resp = requests.get("https://jsonplaceholder.typicode.com/posts/1")
print(resp.json())

# ViaCEP
resp = requests.get("https://viacep.com.br/ws/01001000/json/")
print(resp.json())

Instalação: pip install requests

Boas práticas no Python

import requests

url = "https://jsonplaceholder.typicode.com/posts/1"

try:
    resp = requests.get(url, timeout=5)
    print("Status:", resp.status_code)
    if resp.status_code == 200:
        print(resp.json())
    else:
        print("Erro HTTP:", resp.text)
except requests.exceptions.Timeout:
    print("Timeout ao acessar a API")
except requests.exceptions.RequestException as e:
    print("Erro de rede:", e)
  • ✅ Verifique o status code antes de usar o JSON
  • ✅ Trate erros de rede e timeouts
  • ✅ Leia a documentação da API
