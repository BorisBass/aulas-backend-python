Os 6 princípios fundamentais do REST

Os 6 Princípios REST

Interface Uniforme

Padrão consistente para todas as APIs. URLs representam recursos, métodos HTTP representam ações.

Stateless

Cada requisição é independente. Servidor não mantém estado entre requisições.

Cacheable

Respostas podem ser armazenadas em cache para melhorar performance.

Cliente-Servidor

Separação clara entre cliente e servidor. Cada um pode evoluir independentemente.

Sistema em Camadas

Arquitetura pode ter múltiplas camadas (proxy, balanceador, cache) sem afetar comunicação.

Código Sob Demanda (Opcional)

Servidor pode enviar código executável ao cliente quando necessário.
