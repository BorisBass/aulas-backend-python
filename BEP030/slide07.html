BEP-030: RESTful Web Services e Métodos HTTP

Princípios REST e métodos HTTP para manipulação de recursos

Status HTTP

Códigos de status HTTP comuns

Categorias de Status

Os códigos de status HTTP são divididos em 5 categorias:

1xx - Informativo

Requisição recebida, processando...

2xx - Sucesso

Requisição processada com sucesso

3xx - Redirecionamento

Requisição precisa de ação adicional

4xx - Erro do Cliente

Erro na requisição do cliente

5xx - Erro do Servidor

Erro no processamento do servidor

Status 2xx - Sucesso

200 OK

Requisição bem-sucedida. Usado em GET, PUT, PATCH.

201 Created

Recurso criado com sucesso. Usado em POST.

204 No Content

Sucesso sem conteúdo na resposta. Usado em DELETE.

Status 4xx - Erro do Cliente

400 Bad Request

Requisição inválida. Dados mal formatados ou faltando.

401 Unauthorized

Não autenticado. Precisa fazer login.

403 Forbidden

Sem permissão. Autenticado mas sem acesso.

404 Not Found

Recurso não encontrado.

409 Conflict

Conflito. Recurso já existe ou estado inválido.

Status 5xx - Erro do Servidor

500 Internal Server Error

Erro interno do servidor. Erro não tratado.

502 Bad Gateway

Servidor recebeu resposta inválida de outro servidor.

503 Service Unavailable

Serviço temporariamente indisponível.

Resumo dos Status Mais Comuns

GET    /api/usuarios/123    → 200 OK (encontrado) ou 404 Not Found
POST   /api/usuarios        → 201 Created (criado) ou 400 Bad Request
PUT    /api/usuarios/123    → 200 OK (atualizado) ou 404 Not Found
PATCH  /api/usuarios/123    → 200 OK (atualizado) ou 404 Not Found
DELETE /api/usuarios/123    → 204 No Content (deletado) ou 404 Not Found
