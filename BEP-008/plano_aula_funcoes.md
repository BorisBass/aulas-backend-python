# Plano de Aula: Funções em Python

## Informações Gerais
- **Disciplina**: Programação Python
- **Tema**: Funções em Python
- **Duração**: 3 horas (180 minutos)
- **Nível**: Iniciante
- **Objetivo Geral**: Ensinar como organizar o código em blocos reutilizáveis (funções)

## Objetivos Específicos
Ao final da aula, o aluno será capaz de:
1. Compreender o conceito de funções e sua importância na programação
2. Definir e chamar funções em Python
3. Trabalhar com argumentos e parâmetros
4. Entender o retorno de valores das funções
5. Compreender o escopo de variáveis
6. Aplicar funções em situações práticas
7. Desenvolver habilidades para organizar código em funções reutilizáveis

## Conteúdo Programático

### 1. Introdução às Funções (30 minutos)
- **Conceito**: O que são funções e por que usar
- **Analogia**: Funções como "receitas" ou "máquinas"
- **Vantagens**: Reutilização, organização, manutenção
- **Sintaxe básica**: def, nome, parênteses, dois pontos
- **Exemplos práticos**: Funções simples sem parâmetros

### 2. Definição e Chamada de Funções (40 minutos)

#### 2.1 Sintaxe Básica (15 minutos)
- **Estrutura**: def nome_funcao():
- **Indentação**: Importância da indentação em Python
- **Chamada**: Como executar uma função
- **Exemplos**: Funções de saudação e cálculos simples

#### 2.2 Primeiros Exemplos (25 minutos)
- **Função sem parâmetros**: print("Olá!")
- **Função com código**: Cálculos básicos
- **Múltiplas chamadas**: Reutilização
- **Demonstração prática**: Criando e testando funções

### 3. Argumentos e Parâmetros (50 minutos)

#### 3.1 Parâmetros Simples (20 minutos)
- **Conceito**: Diferença entre parâmetro e argumento
- **Um parâmetro**: Funções que recebem um valor
- **Múltiplos parâmetros**: Funções com vários parâmetros
- **Ordem dos parâmetros**: Importância da sequência

#### 3.2 Tipos de Parâmetros (30 minutos)
- **Parâmetros posicionais**: Ordem importa
- **Parâmetros nomeados**: Especificar o nome do parâmetro
- **Valores padrão**: Parâmetros opcionais
- **Misturando tipos**: Posicionais e nomeados juntos

### 4. Retorno de Valores (40 minutos)

#### 4.1 Comando return (20 minutos)
- **Conceito**: Retornar valores das funções
- **Sintaxe**: return valor
- **Múltiplos returns**: return em diferentes condições
- **Sem return**: Funções que não retornam (None)

#### 4.2 Aplicações Práticas (20 minutos)
- **Funções de cálculo**: Soma, média, máximo
- **Funções de validação**: Verificar condições
- **Funções de formatação**: Preparar dados para exibição
- **Exemplos progressivos**: Do simples ao complexo

### 5. Escopo de Variáveis (30 minutos)

#### 5.1 Conceito de Escopo (15 minutos)
- **Variáveis locais**: Dentro da função
- **Variáveis globais**: Fora da função
- **Regra LEGB**: Local, Enclosing, Global, Built-in
- **Exemplos práticos**: Demonstração visual

#### 5.2 Boas Práticas (15 minutos)
- **Evitar variáveis globais**: Quando possível
- **Parâmetros vs globais**: Preferir parâmetros
- **Nomes descritivos**: Funções e variáveis claras
- **Documentação**: Comentários explicativos

### 6. Aplicações Práticas (20 minutos)
- **Projeto integrador**: Calculadora com funções
- **Exercícios guiados**: Resolução em conjunto
- **Dúvidas e esclarecimentos**: Momento de perguntas
- **Resumo dos conceitos**: Consolidação do aprendizado
