BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

Escopo de Variáveis

🔍 Conceito de Escopo

O escopo define onde uma variável pode ser acessada no código.

# Variável global
nome_global = "João"

def minha_funcao():
    # Variável local
    nome_local = "Maria"
    print(f"Local: {nome_local}")
    print(f"Global: {nome_global}")

# Chamando a função
minha_funcao()
print(f"Fora da função - Global: {nome_global}")
# print(f"Fora da função - Local: {nome_local}")  # Erro! Variável local não existe aqui

🌍 Variáveis Globais

Variáveis definidas fora de qualquer função. Podem ser acessadas de qualquer lugar.

# Variáveis globais
contador = 0
nome = "Python"

def incrementar():
    global contador  # Indica que vamos modificar a variável global
    contador += 1
    print(f"Contador: {contador}")

def mostrar_nome():
    print(f"Nome: {nome}")  # Pode acessar variável global

# Testando as funções
incrementar()
incrementar()
mostrar_nome()
print(f"Contador final: {contador}")

🏠 Variáveis Locais

Variáveis definidas dentro de uma função. Só existem dentro da função.

def calcular_media(nota1, nota2, nota3):
    # Variáveis locais
    soma = nota1 + nota2 + nota3
    media = soma / 3
    print(f"Soma: {soma}")
    print(f"Média: {media:.2f}")
    return media

# Chamando a função
resultado = calcular_media(8, 9, 7)
print(f"Resultado: {resultado}")

# As variáveis 'soma' e 'media' não existem aqui
# print(soma)  # Erro! Variável local não existe

🔄 Regra LEGB

Python procura variáveis nesta ordem:

  • Local: Dentro da função
  • Enclosing: Função que contém a função
  • Global: No módulo principal
  • Built-in: Funções e variáveis do Python
# Variável global
nome = "Global"

def funcao_externa():
    nome = "Externa"
    
    def funcao_interna():
        nome = "Interna"
        print(f"Local: {nome}")
    
    funcao_interna()
    print(f"Externa: {nome}")

funcao_externa()
print(f"Global: {nome}")

⚠️ Modificando Variáveis Globais

# Variável global
contador = 0

def incrementar_global():
    global contador  # Indica que vamos modificar a variável global
    contador += 1
    print(f"Contador: {contador}")

def incrementar_local():
    contador = 0  # Cria uma nova variável local
    contador += 1
    print(f"Contador local: {contador}")

# Testando as funções
print(f"Contador inicial: {contador}")
incrementar_global()
print(f"Contador após global: {contador}")
incrementar_local()
print(f"Contador após local: {contador}")

🎯 Boas Práticas

# ✅ Boa prática: Usar parâmetros em vez de variáveis globais
def calcular_media(notas):
    return sum(notas) / len(notas)

# ✅ Boa prática: Função pura (não modifica variáveis externas)
def somar(a, b):
    return a + b

# ❌ Evitar: Modificar variáveis globais
contador = 0

def incrementar_mal():
    global contador
    contador += 1
    return contador

# ✅ Melhor: Passar valores como parâmetros
def incrementar_bem(valor):
    return valor + 1

Cuidados Importantes

  • Evite globais: Use parâmetros quando possível
  • Nomes claros: Use nomes descritivos para variáveis
  • Funções puras: Prefira funções que não modificam variáveis externas
  • Documentação: Documente quando usar variáveis globais
