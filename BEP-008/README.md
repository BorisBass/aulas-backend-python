# BEP-008: Funções em Python

## 📖 Descrição

Material didático completo sobre **Funções em Python**, desenvolvido para estudantes iniciantes. Este módulo faz parte do curso de programação Python do IFBA CEPEDI e aborda como organizar o código em blocos reutilizáveis.

## 🎯 Objetivos

### Objetivo Geral
Ensinar como organizar o código em blocos reutilizáveis (funções), desenvolvendo competências para criar, usar e gerenciar funções em Python.

### Objetivos Específicos
- Compreender o conceito de funções e sua importância na programação
- Definir e chamar funções em Python
- Trabalhar com argumentos e parâmetros
- Entender o retorno de valores das funções
- Compreender o escopo de variáveis
- Aplicar funções em situações práticas
- Desenvolver habilidades para organizar código em funções reutilizáveis

## 🚀 Como Usar

### 1. Navegação pelos Slides
- Abra `index.html` em um navegador
- Clique em qualquer slide para abrir
- Use as setas do teclado para navegar

### 2. Exercícios Práticos
- Abra `exercicios_funcoes_colab.py` no Google Colab
