BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

Boas Práticas

📝 Nomenclatura

Use nomes descritivos e claros para suas funções.

# ✅ Boa nomenclatura def calcular_media_notas(notas): return sum(notas) / len(notas) def verificar_aprovacao(media): return media >= 7.0 def obter_nome_completo(nome, sobrenome): return f"{nome} {sobrenome}" # ❌ Nomenclatura ruim def calc(n): return sum(n) / len(n) def check(m): return m >= 7.0 def get(n, s): return f"{n} {s}"

🎯 Responsabilidade Única

Cada função deve ter uma única responsabilidade.

# ✅ Boa prática: Funções com responsabilidade única def calcular_media(notas): return sum(notas) / len(notas) def verificar_aprovacao(media): return media >= 7.0 def mostrar_resultado(media, aprovado): print(f"Média: {media:.2f}") print(f"Status: {'Aprovado' if aprovado else 'Reprovado'}") # ❌ Má prática: Função com múltiplas responsabilidades def processar_tudo(notas): media = sum(notas) / len(notas) aprovado = media >= 7.0 print(f"Média: {media:.2f}") print(f"Status: {'Aprovado' if aprovado else 'Reprovado'}") return media, aprovado

📏 Tamanho das Funções

Mantenha suas funções pequenas e focadas.

# ✅ Boa prática: Função pequena e focada def verificar_idade(idade): if idade < 0: return "Idade inválida" elif idade < 18: return "Menor de idade" else: return "Maior de idade" # ❌ Má prática: Função muito longa def processar_aluno_completo(nome, idade, notas, endereco, telefone): # Validação de dados if len(nome) < 2: return "Nome inválido" if idade < 0: return "Idade inválida" if len(notas) == 0: return "Sem notas" # Cálculo da média media = sum(notas) / len(notas) # Verificação de aprovação if media >= 7.0: status = "Aprovado" else: status = "Reprovado" # Criação do relatório relatorio = f"Nome: {nome}\n" relatorio += f"Idade: {idade}\n" relatorio += f"Média: {media:.2f}\n" relatorio += f"Status: {status}\n" relatorio += f"Endereço: {endereco}\n" relatorio += f"Telefone: {telefone}\n" return relatorio

🔄 Funções Puras

Prefira funções que não modificam variáveis externas.

# ✅ Boa prática: Função pura def somar(a, b): return a + b def calcular_media(notas): return sum(notas) / len(notas) # ❌ Má prática: Função com efeitos colaterais contador = 0 def somar_com_contador(a, b): global contador contador += 1 return a + b # ✅ Melhor: Função pura com contador como parâmetro def somar_pura(a, b, contador): return a + b, contador + 1

📋 Documentação

Documente suas funções com comentários claros.

# ✅ Boa prática: Função bem documentada def calcular_media(notas): """ Calcula a média de uma lista de notas. Args: notas (list): Lista de números representando as notas Returns: float: Média das notas Raises: ValueError: Se a lista estiver vazia """ if len(notas) == 0: raise ValueError("Lista de notas não pode estar vazia") return sum(notas) / len(notas) # ❌ Má prática: Função sem documentação def calc(n): return sum(n) / len(n)

⚠️ Tratamento de Erros

# ✅ Boa prática: Tratamento de erros def dividir(a, b): if b == 0: return None # ou raise ValueError("Divisão por zero") return a / b def calcular_raiz_quadrada(numero): if numero < 0: return None # ou raise ValueError("Não é possível calcular raiz de número negativo") return numero ** 0.5 # ✅ Melhor: Usando exceções def dividir_seguro(a, b): try: return a / b except ZeroDivisionError: return None def calcular_raiz_segura(numero): try: return numero ** 0.5 except ValueError: return None

🎯 Parâmetros e Retorno

# ✅ Boa prática: Parâmetros claros e retorno consistente def processar_notas(notas, peso_avaliacao=1.0): """ Processa uma lista de notas com peso opcional. Args: notas (list): Lista de notas peso_avaliacao (float): Peso da avaliação (padrão: 1.0) Returns: dict: Dicionário com estatísticas das notas """ if len(notas) == 0: return {"erro": "Lista vazia"} media = sum(notas) / len(notas) media_ponderada = media * peso_avaliacao return { "media": media, "media_ponderada": media_ponderada, "quantidade": len(notas), "maior": max(notas), "menor": min(notas) } # ❌ Má prática: Parâmetros confusos e retorno inconsistente def processar(n, p=1): if len(n) == 0: return "erro" return sum(n) / len(n) * p

Resumo das Boas Práticas

  • Nomes claros: Use nomes descritivos
  • Responsabilidade única: Uma função, uma tarefa
  • Tamanho adequado: Funções pequenas e focadas
  • Funções puras: Evite efeitos colaterais
  • Documentação: Comente suas funções
  • Tratamento de erros: Valide entradas e trate erros
