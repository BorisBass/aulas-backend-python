BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

Vantagens das Funções

🔄 Reutilização de Código

Escreva uma vez, use várias vezes. Evite repetir o mesmo código.

# Sem função (repetitivo)
print("Olá, João!")
print("Olá, Maria!")
print("Olá, Pedro!")

# Com função (reutilizável)
def cumprimentar(nome):
    print(f"Olá, {nome}!")

cumprimentar("João")
cumprimentar("Maria")
cumprimentar("Pedro")

🧹 Organização do Código

Divida seu programa em partes menores e mais gerenciáveis.

# Código desorganizado (tudo junto)
print("Calculando média...")
nota1 = 8.5
nota2 = 7.0
nota3 = 9.2
media = (nota1 + nota2 + nota3) / 3
print(f"Média: {media:.2f}")

# Código organizado (com funções)
def calcular_media(nota1, nota2, nota3):
    return (nota1 + nota2 + nota3) / 3

def mostrar_resultado(media):
    print(f"Média: {media:.2f}")

media = calcular_media(8.5, 7.0, 9.2)
mostrar_resultado(media)

🔧 Facilidade de Manutenção

Corrija ou melhore o código em um só lugar.

# Se precisar mudar o cálculo da média
def calcular_media(nota1, nota2, nota3):
    # Mudança aqui afeta todo o programa
    return (nota1 + nota2 + nota3) / 3

👥 Trabalho em Equipe

Diferentes pessoas podem trabalhar em funções diferentes.

# Pessoa A: Função de entrada
def ler_notas():
    nota1 = float(input("Nota 1: "))
    nota2 = float(input("Nota 2: "))
    nota3 = float(input("Nota 3: "))
    return nota1, nota2, nota3

# Pessoa B: Função de cálculo
def calcular_media(nota1, nota2, nota3):
    return (nota1 + nota2 + nota3) / 3

# Pessoa C: Função de saída
def mostrar_resultado(media):
    print(f"Média: {media:.2f}")

Benefícios das Funções

  • Modularidade: Código dividido em módulos
  • Testabilidade: Teste cada função separadamente
  • Legibilidade: Código mais fácil de entender
  • Escalabilidade: Fácil de expandir e modificar
💡 Analogia: Funções como Ferramentas

Imagine uma caixa de ferramentas:

  • Martelo: Função para pregar
  • Chave de fenda: Função para apertar parafusos
  • Furadeira: Função para fazer furos

Cada ferramenta tem uma função específica e pode ser reutilizada!
