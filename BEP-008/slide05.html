BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

Parâmetros e Argumentos

🔍 Diferença Conceitual

  • Parâmetro: Variável na definição da função
  • Argumento: Valor passado na chamada da função
# Parâmetro (na definição) def cumprimentar(nome): # 'nome' é o parâmetro print(f"Olá, {nome}!") # Argumento (na chamada) cumprimentar("João") # "João" é o argumento cumprimentar("Maria") # "Maria" é o argumento

📝 Sintaxe com Parâmetros

def nome_da_funcao(parametro1, parametro2): # Código da função print(f"Parâmetro 1: {parametro1}") print(f"Parâmetro 2: {parametro2}") # Chamada da função nome_da_funcao("valor1", "valor2")

🎯 Exemplos Práticos

# Função com um parâmetro def cumprimentar_pessoa(nome): print(f"Olá, {nome}!") # Função com múltiplos parâmetros def somar_numeros(a, b): resultado = a + b print(f"{a} + {b} = {resultado}") # Função com parâmetros de diferentes tipos def mostrar_pessoa(nome, idade, cidade): print(f"Nome: {nome}") print(f"Idade: {idade}") print(f"Cidade: {cidade}") # Chamando as funções cumprimentar_pessoa("Ana") somar_numeros(5, 3) mostrar_pessoa("João", 25, "Salvador")

⚠️ Erros Comuns

# ❌ Erro: Número incorreto de argumentos def somar(a, b): return a + b somar(5) # Erro! Precisa de 2 argumentos somar(5, 3, 2) # Erro! Muitos argumentos # ✅ Correto somar(5, 3) # 2 argumentos para 2 parâmetros

🔄 Ordem dos Parâmetros

# Função com parâmetros em ordem específica def calcular_media(nota1, nota2, nota3): return (nota1 + nota2 + nota3) / 3 # Chamada correta (ordem importa) media = calcular_media(8.5, 7.0, 9.2) print(f"Média: {media:.2f}") # 8.23 # Chamada com ordem diferente (mesmo resultado!) media = calcular_media(9.2, 8.5, 7.0) # 8.23 (mesmo resultado) print(f"Média: {media:.2f}") # 8.23 # Exemplo onde ordem REALMENTE importa def criar_pessoa(nome, idade, cidade): return f"{nome}, {idade} anos, de {cidade}" pessoa1 = criar_pessoa("João", 25, "Salvador") pessoa2 = criar_pessoa("Salvador", 25, "João") # Resultado diferente! print(pessoa1) # João, 25 anos, de Salvador print(pessoa2) # Salvador, 25 anos, de João

Dicas Importantes

  • Número: Argumentos devem corresponder aos parâmetros
  • Ordem: Argumentos são passados na ordem dos parâmetros
  • Significado: A ordem importa quando os parâmetros têm significados diferentes
  • Tipos: Python não verifica tipos automaticamente
💡 Exemplo Prático
# Função para calcular área de retângulo def calcular_area_retangulo(largura, altura): area = largura * altura print(f"Área do retângulo: {area}") # Diferentes retângulos calcular_area_retangulo(5, 3) # 15 calcular_area_retangulo(10, 7) # 70 calcular_area_retangulo(4, 4) # 16 (quadrado)
