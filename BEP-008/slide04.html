BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

Sintaxe Básica

📝 Estrutura Fundamental

def nome_da_funcao():
    # Código da função aqui
    print("Esta é uma função")
    return "resultado"  # Opcional

🔧 Componentes Obrigatórios

  • def: Palavra-chave para definir função
  • nome_da_funcao: Nome único da função
  • (): Parênteses (vazios se sem parâmetros)
  • : Dois pontos após os parênteses
  • Indentação: Código da função deve estar indentado

📋 Regras de Nomenclatura

# ✅ Nomes válidos
def calcular_media():
def verificar_idade():
def mostrar_resultado():
def funcao123():

# ❌ Nomes inválidos
def 123funcao():  # Não pode começar com número
def função():     # Não pode ter acentos
def minha-funcao(): # Não pode ter hífen
def def():        # Não pode usar palavra-chave

🎯 Exemplos Práticos

# Função simples
def cumprimentar():
    print("Olá, mundo!")

# Função com múltiplas linhas
def mostrar_informacoes():
    print("Nome: João Silva")
    print("Idade: 25 anos")
    print("Cidade: Salvador")

# Função com retorno
def obter_data():
    return "15/03/2024"

# Chamando as funções
cumprimentar()
mostrar_informacoes()
data = obter_data()
print(f"Data: {data}")

⚠️ Erros Comuns

# ❌ Erro: Esqueceu os dois pontos
def minha_funcao()  # Falta :
    print("Erro!")

# ❌ Erro: Indentação incorreta
def minha_funcao():
print("Erro!")  # Deve estar indentado

# ❌ Erro: Nome inválido
def 2funcao():  # Não pode começar com número
    print("Erro!")

# ✅ Correto
def minha_funcao():
    print("Correto!")

Dicas Importantes

  • Indentação: Use 4 espaços ou 1 tab consistentemente
  • Nomes: Use letras, números e underscore
  • Dois pontos: Sempre após os parênteses
  • Chamada: Use o nome da função + ()
💡 Exemplo Completo
# Definindo a função
def calcular_area_retangulo():
    largura = 5
    altura = 3
    area = largura * altura
    print(f"Área: {area}")

# Chamando a função
calcular_area_retangulo()
calcular_area_retangulo()  # Pode chamar várias vezes
