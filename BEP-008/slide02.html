BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

O que são Funções?

🔍 Definição

Uma função é um bloco de código que executa uma tarefa específica e pode ser reutilizado várias vezes.

# Exemplo de função simples def cumprimentar(): print("Olá, mundo!") # Chamando a função cumprimentar()

🏗️ Anatomia de uma Função

def nome_da_funcao(): # Definição da função # Código da função print("Esta é uma função") return "resultado" # Retorno (opcional) # Chamada da função resultado = nome_da_funcao()

📋 Componentes

  • def: Palavra-chave para definir função
  • nome_da_funcao: Nome único da função
  • (): Parênteses para parâmetros (opcionais)
  • : Dois pontos obrigatórios
  • Indentação: Código da função deve estar indentado

Regras Importantes

  • Nomes: Use letras, números e underscore
  • Indentação: Use 4 espaços ou 1 tab
  • Dois pontos: Sempre após os parênteses
  • Chamada: Use o nome da função + ()
💡 Exemplo Prático
# Função para mostrar data def mostrar_data(): print("Hoje é 15 de março de 2024") print("Dia da semana: Sexta-feira") # Chamando a função mostrar_data() mostrar_data() # Pode chamar várias vezes
