BEP-008: Funções em Python

Organize seu código em blocos reutilizáveis

Tipos de Parâmetros

📍 Parâmetros Posicionais

Argumentos são passados na ordem dos parâmetros.

def criar_pessoa(nome, idade, cidade):
    return f"{nome}, {idade} anos, de {cidade}"

# Chamada posicional
pessoa1 = criar_pessoa("João", 25, "Salvador")
print(pessoa1)  # João, 25 anos, de Salvador

# Ordem importa!
pessoa2 = criar_pessoa("Salvador", 25, "João")  # Resultado diferente!
print(pessoa2)  # Salvador, 25 anos, de João

🏷️ Parâmetros Nomeados

Especifique o nome do parâmetro na chamada.

def criar_pessoa(nome, idade, cidade):
    return f"{nome}, {idade} anos, de {cidade}"

# Chamada nomeada (ordem não importa)
pessoa1 = criar_pessoa(idade=25, nome="João", cidade="Salvador")
print(pessoa1)  # João, 25 anos, de Salvador

# Misturando posicional e nomeado
pessoa2 = criar_pessoa("Maria", cidade="Rio de Janeiro", idade=30)
print(pessoa2)  # Maria, 30 anos, de Rio de Janeiro

🔧 Valores Padrão

Parâmetros opcionais com valores padrão.

# Função com valor padrão
def multiplicar(a, b=2):
    return a * b

# Chamadas diferentes
resultado1 = multiplicar(5, 3)  # 5 * 3 = 15
resultado2 = multiplicar(5)    # 5 * 2 = 10 (usa padrão)
resultado3 = multiplicar(5, b=4)  # 5 * 4 = 20

print(f"Resultado 1: {resultado1}")
print(f"Resultado 2: {resultado2}")
print(f"Resultado 3: {resultado3}")

🎯 Exemplos com Valores Padrão

# Função de saudação com título padrão
def cumprimentar(nome, titulo="Sr."):
    return f"Olá, {titulo} {nome}!"

# Diferentes chamadas
print(cumprimentar("João"))                    # Olá, Sr. João!
print(cumprimentar("Maria", "Sra."))          # Olá, Sra. Maria!
print(cumprimentar("Pedro", "Dr."))           # Olá, Dr. Pedro!

# Função de cálculo com operação padrão
def calcular(a, b, operacao="+"):
    if operacao == "+":
        return a + b
    elif operacao == "-":
        return a - b
    elif operacao == "*":
        return a * b
    elif operacao == "/":
        return a / b

print(calcular(10, 5))        # 15 (soma padrão)
print(calcular(10, 5, "-"))   # 5 (subtração)
print(calcular(10, 5, "*"))   # 50 (multiplicação)

⚠️ Regras dos Valores Padrão

# ✅ Correto: parâmetros com padrão no final
def funcao_correta(a, b, c=10):
    return a + b + c

# ❌ Erro: parâmetro sem padrão após parâmetro com padrão
def funcao_errada(a, b=10, c):  # Erro!
    return a + b + c

# ✅ Correto: todos os parâmetros com padrão
def funcao_todos_padrao(a=1, b=2, c=3):
    return a + b + c

Cuidados Importantes

  • Ordem: Parâmetros sem padrão devem vir antes dos com padrão
  • Valores padrão: São calculados uma vez na definição
  • Mutabilidade: Evite usar listas ou dicionários como padrão
  • Clareza: Use nomes descritivos para parâmetros
💡 Exemplo Prático
# Função para formatar texto
def formatar_texto(texto, maiusculo=False, tamanho=50):
    if maiusculo:
        texto = texto.upper()
    
    # Centralizar texto
    texto_formatado = texto.center(tamanho)
    return texto_formatado

# Diferentes formatações
print(formatar_texto("Python"))
print(formatar_texto("Python", maiusculo=True))
print(formatar_texto("Python", tamanho=30))
print(formatar_texto("Python", maiusculo=True, tamanho=30))
