Checklist de deploy e exercícios

Checklist de produção

Segurança

  • DEBUG desativado.
  • SECRET_KEY em variável de ambiente.
  • ALLOWED_HOSTS configurado.
  • HTTPS habilitado (certificado TLS).

Banco de dados e arquivos

  • Banco de dados de produção configurado (PostgreSQL, por exemplo).
  • Migrações aplicadas (python manage.py migrate).
  • Arquivos estáticos coletados (python manage.py collectstatic).
  • Configuração para arquivos de mídia (uploads) definida.

Observabilidade

  • Logs de erro e acesso disponíveis.
  • Alguma forma de monitorar se a aplicação está no ar.
  • Plano básico de backup para o banco de dados.

Exercício final

Escolha um projeto Django que você já criou e monte um plano de deploy completo para ele, utilizando uma das plataformas vistas em aula. Mesmo que você não execute o deploy real agora, descreva cada passo e valide se seu código está pronto para produção.
