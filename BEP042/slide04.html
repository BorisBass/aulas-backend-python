BEP-042: Deploy de Aplicações Django

Plataformas de deploy gratuito

Heroku, Render e similares

Plataformas como Heroku e Render simplificam o deploy, cuidando de servidor, banco de dados e logs.

Conceitos em comum

  • Você conecta o repositório Git (GitHub, GitLab, etc.).
  • A plataforma instala as dependências e roda o comando de start.
  • Variáveis de ambiente são configuradas via painel.

Exemplo de Procfile

web: gunicorn meu_projeto.wsgi --log-file -

Limitações de planos gratuitos

  • Tempo de uso limitado ou "sleep" após inatividade.
  • Menos recursos (CPU, memória, disco).
  • Possível ausência de banco de dados persistente gratuito.
