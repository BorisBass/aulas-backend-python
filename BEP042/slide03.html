Usando Nginx como servidor web reverso

Papel do Nginx

O Nginx atua como servidor web reverso, recebendo as requisições HTTP e encaminhando para o Gunicorn.

Proxy reverso para Gunicorn

# Exemplo simplificado de configuração de site no Nginx
server {
    listen 80;
    server_name meu-dominio.com;

    location /static/ {
        alias /caminho/para/staticfiles/;
    }

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

O Nginx serve arquivos estáticos diretamente e encaminha o restante para o Gunicorn.

Segurança e performance

  • Suporte eficiente a muitas conexões simultâneas.
  • Integração com HTTPS (TLS) por meio de certificados.
  • Cache e compressão de respostas.
