Usando Gunicorn como servidor de aplicação

O que é o Gunicorn?

Gunicorn é um servidor WSGI que executa a sua aplicação Django em produção.

Instalação

pip install gunicorn

Rodando o Gunicorn

# Dentro do diretório do projeto
gunicorn meu_projeto.wsgi:application --bind 0.0.0.0:8000
  • meu_projeto.wsgi:application aponta para o objeto WSGI do seu projeto Django.
  • --bind define o endereço e a porta onde o servidor vai escutar.

Configuração básica

# gunicorn_config.py (exemplo)
workers = 3
timeout = 120
bind = "0.0.0.0:8000"

O número de workers depende dos recursos do servidor e da carga da aplicação.
