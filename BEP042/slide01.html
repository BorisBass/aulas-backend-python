BEP-042: Deploy de Aplicações Django

Diferenças entre desenvolvimento e produção

Dev x Produção

Em desenvolvimento, priorizamos velocidade; em produção, priorizamos segurança, estabilidade e performance.

DEBUG

# settings.py
DEBUG = False  # Sempre False em produção
  • Com DEBUG = True, Django mostra páginas de erro detalhadas (perigoso em produção).
  • Com DEBUG = False, erros são escondidos do usuário final.

ALLOWED_HOSTS

# settings.py
ALLOWED_HOSTS = ["meu-dominio.com", "meu-ip-publico"]

Define quais domínios/IPs podem servir a aplicação. Em produção, nunca deixe vazio.

SECRET_KEY e variáveis de ambiente

import os

SECRET_KEY = os.environ.get("DJANGO_SECRET_KEY")
  • Nunca commitar a SECRET_KEY de produção no repositório.
  • Use variáveis de ambiente (.env, painel da plataforma, etc.).

Arquivos estáticos em produção

# settings.py (exemplo)
STATIC_URL = "/static/"
STATIC_ROOT = BASE_DIR / "staticfiles"

# Coletar estáticos
python manage.py collectstatic

Em produção, os arquivos estáticos são servidos por um servidor web (como Nginx) ou pela própria plataforma.
