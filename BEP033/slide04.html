BEP-033: Manipulação de Erros e Logs

Tratamento de erros e registro de logs em APIs

Ferramentas de Logging

Logging em Python e FastAPI

Logging padrão do Python

import logging

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s [%(levelname)s] %(message)s'
)

logger = logging.getLogger("api")
logger.info("API iniciada")
logger.error("Erro ao processar")

Middleware de Logging (FastAPI)

from fastapi import FastAPI, Request
import time
import logging

app = FastAPI()
logger = logging.getLogger("api")

@app.middleware("http")
async def log_requests(request: Request, call_next):
    start = time.time()
    response = await call_next(request)
    duration = time.time() - start
    logger.info(f"{request.method} {request.url.path} - {response.status_code} - {duration:.2f}s")
    return response

Boas práticas

  • ✅ Use níveis corretos (INFO, WARNING, ERROR)
  • ✅ Não logue dados sensíveis
  • ✅ Registre método, URL e status
  • ✅ Monitore erros 5xx
