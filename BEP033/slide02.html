BEP-033: Manipulação de Erros e Logs

Tratamento de erros e registro de logs em APIs

Respostas de Erro Padronizadas

Como estruturar respostas de erro de forma consistente

Estrutura Padrão de Erro

{
  "erro": "Descrição geral do erro",
  "detalhes": {
    "campo": "Mensagem específica"
  },
  "codigo": "CODIGO_ERRO",
  "timestamp": "2025-01-15T10:30:00Z"
}

Implementação em FastAPI

from fastapi import FastAPI, HTTPException
from datetime import datetime

app = FastAPI()

def resposta_erro(mensagem, detalhes=None, codigo=None, status_code=400):
    return {
        "erro": mensagem,
        "detalhes": detalhes or {},
        "codigo": codigo,
        "timestamp": datetime.now().isoformat()
    }, status_code

@app.post("/usuarios")
def criar_usuario(dados: dict):
    erros = {}
    if not dados.get("nome"):
        erros["nome"] = "Nome é obrigatório"
    if erros:
        corpo, status_code = resposta_erro(
            "Dados inválidos", erros, "VALIDACAO_ERRO", 400
        )
        raise HTTPException(status_code=status_code, detail=corpo)
    return {"ok": True}

Use sempre o mesmo formato para facilitar o consumo da API.
