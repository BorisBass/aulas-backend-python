BEP-020: Herança e Polimorfismo

Reutilização e extensão de código através de herança e polimorfismo

Vantagens da Herança

Reutilização de código e organização

Principais Vantagens

1. Reutilização de Código

Evita duplicação. Atributos e métodos comuns são definidos uma vez na classe pai e herdados por todas as subclasses.

2. Organização Hierárquica

Cria uma estrutura lógica e organizada. Facilita entender relacionamentos entre classes e a hierarquia do sistema.

3. Facilita Manutenção

Mudanças na classe pai se propagam automaticamente para todas as subclasses. Corrigir um bug uma vez beneficia toda a hierarquia.

4. Extensibilidade

Fácil adicionar novas funcionalidades. Crie novas subclasses sem modificar a classe pai, seguindo o princípio "aberto para extensão, fechado para modificação".

5. Consistência

Garante que todas as subclasses sigam o mesmo padrão. Comportamentos comuns são padronizados na classe pai.

Quando Usar Herança?

  • Relacionamento "é um": Se você pode dizer "Carro É UM Veiculo", use herança
  • Código compartilhado: Quando várias classes têm muito código em comum
  • Hierarquia natural: Quando existe uma relação hierárquica clara entre classes
  • Extensão futura: Quando você prevê que precisará criar variações da classe

Não use herança: Apenas para reutilizar código sem relação conceitual. Prefira composição nesses casos.
