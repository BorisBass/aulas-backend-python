BEP-020: Herança e Polimorfismo

Reutilização e extensão de código através de herança e polimorfismo

Checklist de Revisão

Confirme seu domínio dos conceitos

Você consegue:

  • Explicar o que é herança e suas vantagens
  • Criar uma classe pai (superclasse) com atributos e métodos comuns
  • Criar subclasses que herdam de uma classe pai
  • Usar super() para acessar métodos da classe pai
  • Usar super().__init__() no construtor da subclasse
  • Sobrescrever métodos herdados (override)
  • Explicar o que é polimorfismo
  • Reconhecer polimorfismo em código
  • Criar código que usa polimorfismo para tratar objetos diferentes uniformemente
  • Identificar quando usar herança vs composição
  • Projetar hierarquias de classes apropriadas
  • Aplicar herança e polimorfismo em exercícios práticos

Próximos Passos

Após dominar estes conceitos, você estará pronto para:

  • Herança múltipla (múltiplas classes pai)
  • Classes abstratas e métodos abstratos
  • Interfaces e protocolos
  • Métodos de classe e métodos estáticos
  • Design Patterns (padrões de projeto)
  • Frameworks e bibliotecas que usam herança extensivamente

Dica de Estudo

Pratique criando hierarquias de classes para entidades do seu dia a dia. Pense em relações "é um": um Carro É UM Veiculo, um Cachorro É UM Animal, um Gerente É UM Funcionario. Quanto mais você praticar, mais natural se tornará identificar oportunidades de usar herança e polimorfismo!
