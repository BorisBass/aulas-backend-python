BEP-020: Herança e Polimorfismo

Reutilização e extensão de código através de herança e polimorfismo

O que é Polimorfismo?

Métodos com comportamentos diferentes

Definição

Polimorfismo (do grego: "muitas formas") permite que objetos de diferentes classes respondam ao mesmo método de formas diferentes.

  • Mesmo nome de método
  • Comportamentos diferentes
  • Baseado no tipo do objeto
  • Facilita código genérico

Analogia

Pense em "desenhar":

  • Desenhar um Círculo → traça um círculo
  • Desenhar um Quadrado → traça um quadrado
  • Desenhar um Triângulo → traça um triângulo

Todos "desenham", mas cada um de forma diferente!

Exemplo Conceitual

class Animal:
    def fazer_som(self):
        return "Fazendo algum som..."

class Cachorro(Animal):
    def fazer_som(self):
        return "Au au!"

class Gato(Animal):
    def fazer_som(self):
        return "Miau!"

class Vaca(Animal):
    def fazer_som(self):
        return "Muuu!"

# Polimorfismo em ação
animais = [
    Cachorro(),
    Gato(),
    Vaca()
]

# Mesmo método, comportamentos diferentes
for animal in animais:
    print(animal.fazer_som())
# Saída:
# Au au!
# Miau!
# Muuu!

Todos os animais têm o método fazer_som(), mas cada um se comporta de forma diferente!

Vantagens do Polimorfismo

  • Código genérico: Pode tratar objetos diferentes de forma uniforme
  • Flexibilidade: Fácil adicionar novos tipos sem modificar código existente
  • Manutenibilidade: Código mais limpo e fácil de entender
  • Extensibilidade: Novas classes podem ser adicionadas facilmente
