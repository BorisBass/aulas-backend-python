Acessando Métodos da Classe Pai

Usando super() para chamar métodos herdados

O que é super()?

super() é uma função especial que retorna uma referência à classe pai (superclasse).

  • Permite acessar métodos da classe pai
  • Usado principalmente no __init__
  • Evita duplicar código
  • Garante que a inicialização da classe pai aconteça

Sintaxe

class Pai:
    def __init__(self, atributo_pai):
        self.atributo_pai = atributo_pai

class Filha(Pai):
    def __init__(self, atributo_pai, atributo_filha):
        super().__init__(atributo_pai)
        self.atributo_filha = atributo_filha

super().__init__() chama o construtor da classe pai.

Exemplo Completo

class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade
    
    def apresentar(self):
        return f"Sou {self.nome}, tenho {self.idade} anos"

class Estudante(Pessoa):
    def __init__(self, nome, idade, matricula):
        super().__init__(nome, idade)  # Chama __init__ da classe Pai
        self.matricula = matricula
    
    def apresentar(self):
        # Chama o método da classe pai e adiciona informação
        info_pai = super().apresentar()
        return f"{info_pai} e minha matrícula é {self.matricula}"

# Uso
est = Estudante("Ana", 20, "2025A001")
print(est.nome)  # Herdado de Pessoa
print(est.idade)  # Herdado de Pessoa
print(est.matricula)  # Próprio de Estudante
print(est.apresentar())  # Método sobrescrito

Importante sobre super()

  • No __init__: Sempre chame super().__init__() antes de inicializar atributos próprios
  • Em outros métodos: Use super().metodo() para chamar versão da classe pai
  • Ordem importa: Chame super() primeiro para garantir que a classe pai seja inicializada corretamente
  • Python 3: super() funciona automaticamente, não precisa passar argumentos
