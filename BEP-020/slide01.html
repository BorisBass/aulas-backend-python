BEP-020: Herança e Polimorfismo

Reutilização e extensão de código através de herança e polimorfismo

O que é Herança?

Conceito fundamental e analogia do mundo real

Definição

Herança é um mecanismo que permite criar uma nova classe baseada em uma classe existente.

  • Classe Pai (Superclasse): A classe original que é herdada
  • Classe Filha (Subclasse): A nova classe que herda da classe pai
  • Herança: A subclasse "herda" todos os atributos e métodos da superclasse

Analogia do Mundo Real

Pense em Veículos:

  • Veiculo (classe pai): características comuns a todos
  • Carro (subclasse): herda de Veiculo + características próprias
  • Moto (subclasse): herda de Veiculo + características próprias
  • Caminhao (subclasse): herda de Veiculo + características próprias

Todos são veículos, mas cada um tem particularidades.

Exemplo Conceitual

Sem herança (repetição de código):

class Carro:
    def __init__(self, marca, modelo):
        self.marca = marca
        self.modelo = modelo
        self.rodas = 4  # Repetido
    
    def acelerar(self):
        return "Acelerando..."  # Repetido

class Moto:
    def __init__(self, marca, modelo):
        self.marca = marca
        self.modelo = modelo
        self.rodas = 2  # Repetido
    
    def acelerar(self):
        return "Acelerando..."  # Repetido

Com herança (código reutilizado):

class Veiculo:  # Classe pai
    def __init__(self, marca, modelo):
        self.marca = marca
        self.modelo = modelo
    
    def acelerar(self):
        return "Acelerando..."

class Carro(Veiculo):  # Herda de Veiculo
    def __init__(self, marca, modelo):
        super().__init__(marca, modelo)
        self.rodas = 4

class Moto(Veiculo):  # Herda de Veiculo
    def __init__(self, marca, modelo):
        super().__init__(marca, modelo)
        self.rodas = 2
