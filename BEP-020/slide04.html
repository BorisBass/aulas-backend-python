BEP-020: Herança e Polimorfismo

Reutilização e extensão de código através de herança e polimorfismo

Exemplo: Animal e Subclasses

Primeiro exemplo prático de herança

Classe Pai: Animal

class Animal:
    def __init__(self, nome, especie):
        self.nome = nome
        self.especie = especie
    
    def fazer_som(self):
        return f"{self.nome} faz um som"
    
    def mover(self):
        return f"{self.nome} está se movendo"
    
    def informacoes(self):
        return f"{self.nome} é um(a) {self.especie}"

Esta classe define características e comportamentos comuns a todos os animais.

Subclasses: Cachorro e Gato

class Cachorro(Animal):
    def __init__(self, nome, raca):
        super().__init__(nome, "Cachorro")
        self.raca = raca
    
    def latir(self):
        return f"{self.nome}: Au au!"

class Gato(Animal):
    def __init__(self, nome, cor):
        super().__init__(nome, "Gato")
        self.cor = cor
    
    def miar(self):
        return f"{self.nome}: Miau!"

# Uso
rex = Cachorro("Rex", "Labrador")
mimi = Gato("Mimi", "Branco")

print(rex.informacoes())  # Herdado de Animal
print(rex.latir())        # Próprio de Cachorro
print(mimi.mover())       # Herdado de Animal
print(mimi.miar())        # Próprio de Gato

Análise do Código

  • super().__init__(): Chama o construtor da classe pai para inicializar nome e especie
  • Herança: Cachorro e Gato herdam fazer_som(), mover() e informacoes()
  • Extensão: Cada subclasse adiciona métodos próprios (latir(), miar())
  • Atributos próprios: Cada subclasse tem atributos específicos (raca, cor)
