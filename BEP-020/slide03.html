BEP-020: Herança e Polimorfismo

Reutilização e extensão de código através de herança e polimorfismo

Sintaxe de Herança

Como criar classes pai e subclasses em Python

Sintaxe Básica

Para criar uma subclasse, coloque o nome da classe pai entre parênteses:

class ClassePai:
    # atributos e métodos da classe pai
    pass

class ClasseFilha(ClassePai):
    # atributos e métodos da classe filha
    # herda tudo da ClassePai
    pass

A classe filha herda todos os atributos e métodos da classe pai.

Exemplo Simples

class Animal:
    def __init__(self, nome):
        self.nome = nome
    
    def fazer_som(self):
        return "Fazendo algum som..."

class Cachorro(Animal):
    def latir(self):
        return f"{self.nome}: Au au!"

# Uso
c = Cachorro("Rex")
print(c.nome)  # Herdado de Animal
print(c.fazer_som())  # Herdado de Animal
print(c.latir())  # Próprio de Cachorro

Cachorro herda nome e fazer_som() de Animal.

Pontos Importantes

  • Herança simples: Python suporta herança múltipla, mas começamos com herança simples
  • Herança automática: Todos os métodos e atributos são herdados automaticamente
  • Extensão: A subclasse pode adicionar novos métodos e atributos
  • Modificação: A subclasse pode sobrescrever métodos da classe pai (veremos depois)
  • super(): Usado para acessar métodos da classe pai (veremos no próximo slide)
