Sobrescrita de Métodos (Override)

Personalizando comportamentos nas subclasses

O que é Override?

Sobrescrita (Override) é quando uma subclasse redefine um método herdado da classe pai.

  • A subclasse cria um método com o mesmo nome
  • O método da subclasse substitui o da classe pai
  • Permite personalizar comportamento
  • Mantém a mesma assinatura (nome e parâmetros)

Exemplo Simples

class Animal:
    def fazer_som(self):
        return "Fazendo algum som..."

class Cachorro(Animal):
    def fazer_som(self):  # Sobrescreve o método
        return "Au au!"

class Gato(Animal):
    def fazer_som(self):  # Sobrescreve o método
        return "Miau!"

c = Cachorro()
g = Gato()
print(c.fazer_som())  # "Au au!"
print(g.fazer_som())  # "Miau!"

Exemplo Completo: Extendendo e Sobrescrevendo

class Veiculo:
    def __init__(self, marca, modelo):
        self.marca = marca
        self.modelo = modelo
        self.velocidade = 0
    
    def acelerar(self, incremento=10):
        self.velocidade += incremento
        return f"{self.modelo} acelerou para {self.velocidade} km/h"
    
    def frear(self):
        self.velocidade = max(0, self.velocidade - 10)
        return f"{self.modelo} freou para {self.velocidade} km/h"
    
    def informacoes(self):
        return f"{self.marca} {self.modelo} - {self.velocidade} km/h"

class Carro(Veiculo):
    def __init__(self, marca, modelo, portas):
        super().__init__(marca, modelo)
        self.portas = portas
    
    def acelerar(self, incremento=15):  # Sobrescreve: acelera mais rápido
        self.velocidade += incremento
        return f"{self.modelo} acelerou rapidamente para {self.velocidade} km/h"
    
    def informacoes(self):  # Sobrescreve: adiciona informação sobre portas
        info_base = super().informacoes()
        return f"{info_base} - {self.portas} portas"

class Moto(Veiculo):
    def __init__(self, marca, modelo, cilindradas):
        super().__init__(marca, modelo)
        self.cilindradas = cilindradas
    
    def acelerar(self, incremento=20):  # Sobrescreve: acelera ainda mais
        self.velocidade += incremento
        return f"{self.modelo} acelerou muito rápido para {self.velocidade} km/h"

# Uso
carro = Carro("Toyota", "Corolla", 4)
moto = Moto("Honda", "CB600", 600)

print(carro.acelerar())  # Usa versão sobrescrita
print(moto.acelerar())   # Usa versão sobrescrita
print(carro.informacoes())  # Versão estendida

Quando Sobrescrever?

  • Comportamento diferente: Quando a subclasse precisa de comportamento específico
  • Extensão: Quando quer adicionar funcionalidade além da classe pai (usando super())
  • Otimização: Quando a subclasse pode implementar de forma mais eficiente
  • Especialização: Quando a subclasse representa um caso específico
