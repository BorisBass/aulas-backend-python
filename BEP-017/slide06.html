Introdução aos conceitos básicos de Programação Orientada a Objetos

Mini-projeto

ContaBancaria: depósito, saque e saldo

Requisitos

  • Atributos: titular e saldo.
  • Métodos: depositar(valor), sacar(valor), ver_saldo().
  • Sem conceitos novos além de classe, atributos e métodos.

Implementação

class ContaBancaria:
    def __init__(self, titular, saldo_inicial=0):
        self.titular = titular
        self.saldo = float(saldo_inicial)

    def depositar(self, valor):
        if valor > 0:
            self.saldo += valor
        # se valor for inválido, não altera (mantemos simples e explícito)

    def sacar(self, valor):
        if 0 <= valor <= self.saldo:
            self.saldo -= valor
        # se valor maior que saldo, não altera (sem exceções aqui, por simplicidade)

    def ver_saldo(self):
        return round(self.saldo, 2)

c = ContaBancaria("Ana")
c.depositar(100)
c.sacar(30)
print(c.titular, c.ver_saldo())  # Ana 70.0
