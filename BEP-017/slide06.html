BEP-017: Fundamentos de POO

Introdução aos conceitos básicos de Programação Orientada a Objetos

Mini-projeto

ContaBancaria: depósito, saque e saldo

Requisitos

Vamos criar uma classe simples para representar uma conta bancária:

  • Atributos: titular (nome) e saldo (valor)
  • Métodos:
    • depositar(valor) - adiciona dinheiro
    • sacar(valor) - retira dinheiro
    • ver_saldo() - mostra o saldo atual

Implementação

class ContaBancaria:
    def __init__(self, titular, saldo_inicial=0):
        self.titular = titular
        self.saldo = float(saldo_inicial)

    def depositar(self, valor):
        if valor > 0:
            self.saldo += valor

    def sacar(self, valor):
        if 0 <= valor <= self.saldo:
            self.saldo -= valor

    def ver_saldo(self):
        return round(self.saldo, 2)

# Criando e usando objetos
conta_ana = ContaBancaria("Ana")
conta_ana.depositar(100)
conta_ana.sacar(30)
print(f"{conta_ana.titular}: R$ {conta_ana.ver_saldo():.2f}")

Este exemplo mostra como POO organiza dados (titular, saldo) e comportamentos (depositar, sacar) juntos.
