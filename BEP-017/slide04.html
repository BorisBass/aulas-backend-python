Métodos e __init__

Entendendo self, construtor e comportamento

O que é um método?

class Aluno:
    def __init__(self, nome, matricula):
        self.nome = nome
        self.matricula = matricula

    def apresentar(self):
        return f"Sou {self.nome}, matrícula {self.matricula}."

a = Aluno("Ana", "2025A001")
print(a.apresentar())

Método é uma função da classe. Recebe self, que representa o próprio objeto.

O que é __init__?

class Produto:
    def __init__(self, nome, preco):
        # chamado automaticamente quando criamos o objeto
        self.nome = nome
        self.preco = float(preco)

    def aplicar_desconto(self, percentual):
        fator = 1 - (percentual / 100)
        self.preco = round(self.preco * fator, 2)

p = Produto("Caderno", 20)
p.aplicar_desconto(10)
print(p.preco)

__init__ é o construtor: define como iniciar o estado do objeto.
