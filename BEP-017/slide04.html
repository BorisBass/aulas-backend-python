Métodos e __init__

Entendendo self, construtor e comportamento

O que é um método?

Método é uma função que pertence a uma classe. Define o comportamento dos objetos.

  • Métodos são ações que o objeto pode realizar
  • Sempre recebem self como primeiro parâmetro
  • Podem acessar e modificar atributos do objeto
  • Exemplos: acelerar(), calcular(), apresentar()

O que é __init__?

__init__ é o construtor: método especial que inicializa o objeto.

  • Chamado automaticamente ao criar um objeto
  • Define os valores iniciais dos atributos
  • Prepara o objeto para uso
  • É como "configurar" o objeto na criação

Exemplo Simples

class Animal:
    def __init__(self, nome, especie):
        self.nome = nome        # atributo
        self.especie = especie  # atributo
    
    def fazer_som(self):        # método
        return f"{self.nome} faz um som!"

gato = Animal("Mimi", "Gato")
print(gato.fazer_som())  # Mimi faz um som!
