Introdução aos conceitos básicos de Programação Orientada a Objetos

Procedural vs Orientado a Objetos

Mesmo problema resolvido de duas maneiras

Abordagem Procedural

# dados e funções separados
nome = "Caderno"
preco = 20.00

def aplicar_desconto(preco, percentual):
    fator = 1 - (percentual / 100)
    return round(preco * fator, 2)

preco = aplicar_desconto(preco, 10)
print(nome, preco)

Vantagens: simples para começar. Limitações: conforme cresce, fica difícil organizar dados e comportamentos relacionados.

Abordagem Orientada a Objetos

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

    def aplicar_desconto(self, percentual):
        fator = 1 - (percentual / 100)
        self.preco = round(self.preco * fator, 2)

p = Produto("Caderno", 20.00)
p.aplicar_desconto(10)
print(p.nome, p.preco)

Vantagens: dados e comportamentos juntos; facilita evolução, reuso e manutenção.

Quando usar OO?

  • Quando objetos do seu domínio possuem estado e comportamentos claros.
  • Quando o projeto tende a crescer e precisa de organização.
