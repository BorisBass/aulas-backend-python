Introdução aos conceitos básicos de Programação Orientada a Objetos

Classe e Objeto

Construção gradual sem surpresas

1) Definindo uma classe

class Aluno:
    pass  # classe vazia por enquanto

Acima criamos apenas o "molde". Ainda não há atributos nem métodos.

2) Criando um objeto (instância)

a = Aluno()
print(type(a))  # <class '__main__.Aluno'>

Agora temos um objeto do tipo Aluno. Sem atributos, ainda não guarda dados.

3) Adicionando atributos e lendo valores

class Aluno:
    def __init__(self, nome, matricula):
        self.nome = nome
        self.matricula = matricula

a = Aluno("Ana", "2025A001")
print(a.nome)
print(a.matricula)

Agora o objeto tem estado: nome e matrícula. O método __init__ será explicado no próximo slide.
