BEP-017: Fundamentos de POO

Introdução aos conceitos básicos de Programação Orientada a Objetos

O que é POO?

Entendendo objeto, classe, atributo e método com um exemplo simples

Conceitos

  • Objeto: entidade com estado e comportamento.
  • Classe: molde que define objetos.
  • Atributo: dado que compõe o estado do objeto.
  • Método: função da classe/objeto (comportamento).

Exemplo (explicado)

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome      # atributo
        self.preco = preco    # atributo

    def aplicar_desconto(self, percentual):  # método
        fator = 1 - (percentual / 100)
        self.preco = round(self.preco * fator, 2)

# uso explicado (sem novos conceitos ocultos):
p = Produto("Caderno", 20.00)  # cria objeto a partir da classe
print(p.nome, p.preco)
p.aplicar_desconto(10)
print(p.preco)

Acima usamos apenas o que foi definido: classe, atributos, método e criação de objeto. Nenhum recurso novo é usado sem explicação.

Procedural vs Orientado a Objetos

  • Procedural: foco em funções e dados separados.
  • OO: dados + comportamentos agrupados em objetos, favorecendo organização e reuso.
