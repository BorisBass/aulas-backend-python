Exercício 1: Classe Aluno

  1. Crie a classe Aluno com atributos nome e nota.
  2. Adicione o método aprovado() que retorna True se nota >= 6.
  3. Crie dois objetos e teste o método.
class Aluno:
    def __init__(self, nome, nota):
        self.nome = nome
        self.nota = float(nota)

    def aprovado(self):
        return self.nota >= 6

a1 = Aluno("Ana", 7.5)
a2 = Aluno("Bruno", 5.8)
print(a1.nome, a1.aprovado())
print(a2.nome, a2.aprovado())

Exercício 2: Produto com reajuste

  1. Crie classe Produto com nome e preco.
  2. Adicione método reajustar(percentual) para aumentar o preço.
  3. Teste com diferentes percentuais.
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = float(preco)

    def reajustar(self, percentual):
        fator = 1 + (percentual / 100)
        self.preco = round(self.preco * fator, 2)

p = Produto("Caderno", 20)
p.reajustar(10)
print(p.preco)
