BEP-002: Variáveis e Tipos de Dados

Armazene e manipule dados em Python

Entrada de Dados (input)

⌨️ Lendo dados

nome = input("Seu nome: ")
idade = int(input("Sua idade: "))
print(f"Olá, {nome}! Você tem {idade} anos.")

🧮 Exemplo: IMC

peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))
imc = peso / (altura ** 2)
print(f"IMC: {imc:.2f}")
