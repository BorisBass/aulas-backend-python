BEP-036: Modelos e Migrations

Modelar dados com Django ORM

Consultas básicas

CRUD simples usando o ORM do Django.

Onde executar?

Use o Django shell para testar:

python manage.py shell

Depois, importe o model:

from core.models import Tarefa
# criar
Tarefa.objects.create(descricao="Estudar Django", prioridade="alta")

# listar tudo
tarefas = Tarefa.objects.all()

# filtrar
altas = Tarefa.objects.filter(prioridade="alta")

# pegar por id
t = Tarefa.objects.get(id=1)

# atualizar
t.status = 50
t.save()

# remover
t.delete()

Ver o resultado no terminal

# imprimir lista filtrada
print(altas)

# melhor: mostrar item por item
for t in altas:
    print(t)

# mostrar campos
for t in altas:
    print(t.id, t.descricao, t.prioridade, t.status)
