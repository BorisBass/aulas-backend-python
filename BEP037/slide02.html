BEP-037: Views e Templates

Criar páginas dinâmicas utilizando views e templates

Template HTML com DTL

Django Template Language (DTL) permite dados dinamicos.

O que é DTL?

DTL é a linguagem de templates do Django. Ela permite inserir variáveis e usar estruturas como {% for %} e {% if %} no HTML.

Onde criar o template?

core/
├─ templates/
│  └─ home.html

<!DOCTYPE html>
<html>
<head>
  <meta charset="utf-8">
  <title>Pagina inicial</title>
</head>
<body>
  <h1>Ola, {{ nome }}!</h1>
  <p>Hoje e {{ data }}</p>
</body>
</html>
