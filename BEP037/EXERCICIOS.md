## Exercicios - BEP037: Views e Templates

### Exercicio 1: View basica
Crie uma view que retorne "Pagina inicial".

### Exercicio 2: Template simples
Crie um template `home.html` com:
- Um titulo
- Um paragrafo com `{{ nome }}`

### Exercicio 3: Contexto
Passe um dicionario com `nome` e `data` para o template.

### Exercicio 4: Lista no template
Mostre uma lista de tarefas usando `{% for %}`.

### Exercicio 5: Renderizacao
Use `render()` para ligar view e template.
