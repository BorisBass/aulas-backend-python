BEP-037: Views e Templates

Criar páginas dinâmicas utilizando views e templates

Contexto

Contexto e um dicionario com dados para o template.

Template usado

O arquivo abaixo fica em core/templates/home.html.

# core/views.py
from django.shortcuts import render
from datetime import date

def home(request):
    contexto = {
        "nome": "Joao",
        "data": date.today(),
    }
    return render(request, "home.html", contexto)
