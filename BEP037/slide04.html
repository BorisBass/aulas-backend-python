BEP-037: Views e Templates

Criar páginas dinâmicas utilizando views e templates

render() e DTL

Renderiza HTML com dados dinamicos.

View que busca no banco

# core/views.py
from django.shortcuts import render
from .models import Tarefa

def lista(request):
    tarefas = Tarefa.objects.all()  # SELECT no banco
    contexto = {"tarefas": tarefas}
    return render(request, "lista.html", contexto)

URL da view

A URL liga o caminho do navegador com a funcao de view.

# core/urls.py
from django.urls import path
from .views import lista

urlpatterns = [
    path("lista/", lista),  # /lista/
]

Template lista.html


<h2>Tarefas</h2>
<ul>
{% for t in tarefas %}
  <li>{{ t.descricao }} - {{ t.prioridade }} - {{ t.status }}%</li>
{% empty %}
  <li>Nenhuma tarefa cadastrada.</li>
{% endfor %}
</ul>
