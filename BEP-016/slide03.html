Tratamento de Erros e Boas Práticas

Tratamento de Erros

Por que Tratar Erros?

Quando trabalhamos com bancos de dados, vários problemas podem ocorrer. O tratamento de erros garante que nosso programa continue funcionando mesmo quando algo dá errado.

Tipos de Erros Comuns

Erros de Conexão

  • Arquivo de banco corrompido
  • Permissões insuficientes
  • Disco cheio

Erros de Integridade

  • Email duplicado
  • Chave primária repetida
  • Violação de constraints

Erros de SQL

  • Comando SQL inválido
  • Tabela não existe
  • Coluna não encontrada

Erros de Entrada

  • Dados inválidos
  • Campos obrigatórios vazios
  • Tipos incorretos

Tratamento Básico de Erros

import sqlite3

def conectar_banco_seguro():
    """Conecta ao banco com tratamento de erros"""
    try:
        conn = sqlite3.connect('exemplo.db')
        cursor = conn.cursor()
        print("✅ Conectado com sucesso!")
        return conn, cursor
    except sqlite3.Error as e:
        print(f"❌ Erro ao conectar: {e}")
        return None, None
    except Exception as e:
        print(f"❌ Erro inesperado: {e}")
        return None, None

def inserir_dados_seguro(cursor, conn):
    """Insere dados com tratamento de erros"""
    try:
        nome = input("Nome: ")
        email = input("Email: ")
        
        # Validar dados
        if not nome:
            print("❌ Nome é obrigatório!")
            return
        
        # Tentar inserir
        cursor.execute('''
            INSERT INTO usuarios (nome, email)
            VALUES (?, ?)
        ''', (nome, email))
        
        conn.commit()
        print("✅ Dados inseridos com sucesso!")
        
    except sqlite3.IntegrityError:
        print("❌ Erro: Email já existe!")
    except sqlite3.Error as e:
        print(f"❌ Erro no banco: {e}")
    except ValueError as e:
        print(f"❌ Erro de valor: {e}")
    except Exception as e:
        print(f"❌ Erro inesperado: {e}")

Boas Práticas

Sempre Fechar Conexão

Use try/finally ou with statement para garantir que a conexão seja fechada

Commit das Transações

Salve as alterações com commit() após operações de escrita

Validação de Dados

Verifique os dados antes de enviar para o banco

Prepared Statements

Use ? para evitar SQL injection

Exemplo com With Statement

import sqlite3

def exemplo_with_statement():
    """Exemplo usando with statement"""
    try:
        with sqlite3.connect('exemplo.db') as conn:
            cursor = conn.cursor()
            
            # Criar tabela
            cursor.execute('''
                CREATE TABLE IF NOT EXISTS produtos (
                    id INTEGER PRIMARY KEY,
                    nome TEXT NOT NULL,
                    preco REAL
                )
            ''')
            
            # Inserir dados
            cursor.execute('''
                INSERT INTO produtos (nome, preco)
                VALUES (?, ?)
            ''', ('Notebook', 2500.00))
            
            # Consultar dados
            cursor.execute("SELECT * FROM produtos")
            produtos = cursor.fetchall()
            
            for produto in produtos:
                print(f"ID: {produto[0]}, Nome: {produto[1]}, Preço: R$ {produto[2]}")
            
            # Conexão é fechada automaticamente
            print("✅ Operações concluídas!")
            
    except sqlite3.Error as e:
        print(f"❌ Erro: {e}")
    except Exception as e:
        print(f"❌ Erro inesperado: {e}")

Erros Específicos do SQLite

sqlite3.Error

Erro geral do SQLite

sqlite3.IntegrityError

Violação de integridade (duplicatas, etc.)

sqlite3.OperationalError

Erro operacional (tabela não existe, etc.)

sqlite3.DatabaseError

Erro relacionado ao banco de dados
