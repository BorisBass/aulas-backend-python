BEP-016: Conectando a Banco de Dados

Biblioteca SQLite3 - Instalação e Uso Básico

Biblioteca SQLite3

O que é SQLite3?

SQLite3 é uma biblioteca Python que permite conectar e trabalhar com bancos de dados SQLite. É uma biblioteca nativa do Python, ou seja, já vem instalada!

Verificação de Instalação

Para verificar se o SQLite3 está disponível, execute:

Verificar SQLite3

import sqlite3
print(sqlite3.version)
print(sqlite3.sqlite_version)

Resultado esperado: Versão da biblioteca Python e versão do SQLite

Conectando ao Banco

Conceito: Para trabalhar com SQLite, primeiro precisamos estabelecer uma conexão.

Conexão Básica

import sqlite3

# Conectar ao banco (cria se não existir)
conn = sqlite3.connect('meu_banco.db')
print("✅ Conectado ao banco de dados!")

# Criar cursor para executar comandos
cursor = conn.cursor()
print("✅ Cursor criado!")

# Fechar conexão
conn.close()
print("🔒 Conexão fechada!")

Criando Tabelas

Conceito: Tabelas são estruturas que organizam os dados em linhas e colunas.

Criar Tabela de Alunos

import sqlite3

# Conectar ao banco
conn = sqlite3.connect('escola.db')
cursor = conn.cursor()

# Criar tabela
cursor.execute('''
    CREATE TABLE alunos (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        nome TEXT NOT NULL,
        idade INTEGER,
        curso TEXT,
        nota REAL
    )
''')

# Salvar alterações
conn.commit()
print("✅ Tabela 'alunos' criada com sucesso!")

# Fechar conexão
conn.close()

Inserindo Dados

Conceito: INSERT adiciona novos registros na tabela.

Inserir Alunos

import sqlite3

# Conectar ao banco
conn = sqlite3.connect('escola.db')
cursor = conn.cursor()

# Inserir um aluno
cursor.execute('''
    INSERT INTO alunos (nome, idade, curso, nota)
    VALUES ('João Silva', 20, 'Python', 8.5)
''')

# Inserir outro aluno
cursor.execute('''
    INSERT INTO alunos (nome, idade, curso, nota)
    VALUES ('Maria Santos', 22, 'Python', 9.0)
''')

# Salvar alterações
conn.commit()
print("✅ Alunos inseridos com sucesso!")

# Fechar conexão
conn.close()

Consultando Dados

Conceito: SELECT recupera dados da tabela.

Consultar Alunos

import sqlite3

# Conectar ao banco
conn = sqlite3.connect('escola.db')
cursor = conn.cursor()

# Consultar todos os alunos
cursor.execute("SELECT * FROM alunos")
alunos = cursor.fetchall()

print("📋 LISTA DE ALUNOS:")
print("-" * 50)
for aluno in alunos:
    print(f"ID: {aluno[0]}, Nome: {aluno[1]}, Idade: {aluno[2]}, Curso: {aluno[3]}, Nota: {aluno[4]}")

# Fechar conexão
conn.close()

Pontos Importantes

  • Sempre feche a conexão: Use conn.close() para liberar recursos
  • Commit as alterações: Use conn.commit() para salvar mudanças
  • Tratamento de erros: Use try/except para capturar erros
  • Arquivo do banco: SQLite cria um arquivo .db no diretório atual

Teste Prático

  1. Execute o código de conexão para criar o banco
  2. Crie a tabela alunos com os campos especificados
  3. Insira alguns alunos com dados diferentes
  4. Consulte os dados para verificar se foram salvos
  5. Verifique o arquivo escola.db criado no diretório
