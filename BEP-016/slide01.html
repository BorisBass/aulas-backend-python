BEP-016: Conectando a Banco de Dados

Integração de Python com bancos de dados

O que é Conectar a Banco de Dados?

Definição

Conectar a banco de dados significa estabelecer uma comunicação entre sua aplicação Python e um sistema de gerenciamento de banco de dados para armazenar, consultar e manipular dados de forma persistente.

Analogia: Biblioteca

Biblioteca Física

Você vai até a biblioteca, pede um livro ao bibliotecário, ele busca na estante e te entrega

Banco de Dados

Seu programa Python "vai" até o banco, pede dados ao sistema, ele busca no armazenamento e retorna

Exemplo Prático: Sistema de Cadastro

Imagine que você quer criar um sistema para cadastrar alunos:

Sem Banco de Dados

  • Dados ficam na memória
  • Perdidos quando programa fecha
  • Sem persistência
  • Limitado a uma sessão

Com Banco de Dados

  • Dados salvos permanentemente
  • Persistem entre sessões
  • Múltiplos usuários
  • Consultas eficientes

Componentes da Conexão

Aplicação Python

Seu programa que precisa dos dados

Driver/Connector

Biblioteca que faz a comunicação

Banco de Dados

Sistema que armazena os dados

Protocolo

Linguagem comum para comunicação

Tipos de Banco de Dados

Banco de Dados Servidor

  • MySQL, PostgreSQL
  • Servidor separado
  • Múltiplos usuários
  • Mais complexo

Banco de Dados Embarcado

  • SQLite
  • Arquivo local
  • Simples de usar
  • Ideal para iniciantes

Por que SQLite?

Vantagens

  • Já vem com Python
  • Não precisa instalar servidor
  • Arquivo único
  • Fácil de aprender
  • Perfeito para projetos pequenos

Características

  • Banco de dados relacional
  • Suporte completo a SQL
  • Transações ACID
  • Zero configuração
  • Cross-platform
