# BEP-016: Conectando a Banco de Dados

## Descrição
Esta aula introduz os alunos à integração de linguagens de programação com bancos de dados, focando especificamente no uso da biblioteca SQLite3 do Python.

## Objetivos
- Introduzir os alunos à integração de linguagens de programação com bancos de dados
- Compreender o conceito de banco de dados embarcado
- Conhecer a biblioteca SQLite3 e seu uso básico
- Aprender a criar tabelas, inserir e consultar dados
- Implementar operações CRUD completas
- Desenvolver sistemas com persistência de dados
