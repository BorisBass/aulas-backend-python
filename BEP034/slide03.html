Comunicação bidirecional em tempo real com WebSockets

Implementação Básica

Como criar um WebSocket simples com FastAPI

O que acontece no WebSocket?

A rota WebSocket fica aberta depois do accept(). A partir disso, o servidor e o cliente podem enviar mensagens a qualquer momento, sem precisar abrir uma nova requisicao HTTP.

WebSocket básico

Fluxo: aceitar conexao, receber mensagem, enviar resposta.

from fastapi import FastAPI, WebSocket

app = FastAPI()  # cria a aplicacao

@app.websocket("/ws")
async def websocket_endpoint(ws: WebSocket):
    await ws.accept()  # aceita a conexao
    while True:
        data = await ws.receive_text()  # recebe mensagem
        await ws.send_text(f"Echo: {data}")  # devolve resposta

Broadcast com Gerenciador

Um gerenciador guarda as conexoes ativas e envia mensagem para todos. Isso permite criar um chat.

from fastapi import WebSocket

class ConnectionManager:
    def __init__(self):
        self.active = []  # lista de conexoes

    async def connect(self, ws: WebSocket):
        await ws.accept()  # aceita a conexao
        self.active.append(ws)  # guarda cliente

    def disconnect(self, ws: WebSocket):
        self.active.remove(ws)  # remove cliente

    async def broadcast(self, message: str):
        for ws in self.active:  # envia para todos
            await ws.send_text(message)  # mensagem

manager = ConnectionManager()

@app.websocket("/ws/chat")
async def chat(ws: WebSocket):
    await manager.connect(ws)  # conecta cliente
    try:
        while True:
            msg = await ws.receive_text()  # recebe mensagem
            await manager.broadcast(msg)  # envia para todos
    except:
        manager.disconnect(ws)  # desconecta

Metodos mais usados

Metodo Para que serve
await ws.accept() Aceita a conexao WebSocket
await ws.receive_text() Recebe mensagem em texto
await ws.send_text(msg) Envia mensagem em texto
await ws.receive_bytes() Recebe dados binarios
await ws.send_bytes(data) Envia dados binarios
await ws.receive_json() Recebe mensagem JSON
await ws.send_json(obj) Envia mensagem JSON
await ws.close() Fecha a conexao
ws.client Acessa IP e porta do cliente

Cliente Python (websockets)

Este cliente abre a conexao, envia uma mensagem e recebe o retorno.

# pip install websockets
import asyncio
import websockets

async def cliente():
    try:
        async with websockets.connect("ws://localhost:8000/ws") as ws:
            await ws.send("Ola WebSocket!")  # envia mensagem
            resposta = await ws.recv()  # espera resposta
            print("Recebido:", resposta)  # mostra no terminal
    except Exception as e:
        print("Erro no cliente:", e)  # trata erro

asyncio.run(cliente())
