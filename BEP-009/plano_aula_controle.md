# Plano de Aula: Estruturas de Controle Avançadas em Python (BEP-009)

## Informações Gerais

- **Disciplina:** Back End com Python
- **Aula:** BEP-009
- **Tema:** Estruturas de Controle Avançadas
- **Duração:** 3 horas
- **Público-alvo:** Estudantes de programação com conhecimentos básicos em Python

## Objetivo Geral

Dominar estruturas de controle avançadas em Python, especificamente loops (for e while), break, continue e else, desenvolvendo competências para criar programas mais dinâmicos e eficientes.

## Objetivos Específicos

Ao final desta aula, o aluno será capaz de:

1. Utilizar loops `for` para iterar sobre sequências
2. Aplicar loops `while` para repetições condicionais
3. Controlar o fluxo de execução com `break` e `continue`
4. Usar `else` em loops para execução condicional
5. Implementar loops aninhados para estruturas complexas
6. Aplicar funções úteis como `enumerate()`, `zip()` e `reversed()`
7. Tratar erros em loops usando `try-except`
8. Resolver problemas práticos usando estruturas de controle

## Exercícios Propostos

### Exercícios Básicos

1. **Contador Inteligente:** Conte de 1 a 100, pulando números divisíveis por 3 e parando em números divisíveis por 7
2. **Busca em Lista:** Procure um número específico em uma lista e informe sua posição
3. **Tabuada Personalizada:** Crie uma tabuada que pare quando o resultado for maior que 50

### Exercícios Intermediários

4. **Sistema de Login:** Implemente um sistema de login com tentativas limitadas
5. **Processamento de Dados:** Processe uma lista de números e pare quando encontrar um número negativo
6. **Gerador de Padrões:** Crie padrões de asteriscos usando loops aninhados

### Exercícios Avançados

7. **Validador de Senha:** Verifique se uma senha atende a múltiplos critérios
8. **Calculadora de Estatísticas:** Calcule estatísticas de uma lista de números
9. **Jogo da Forca:** Implemente um jogo da forca simplificado
10. **Gerador de Matriz:** Crie uma matriz com padrões específicos
