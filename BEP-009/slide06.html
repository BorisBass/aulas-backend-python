BEP-009: Manipulação de Strings

Trabalhe com textos de maneira eficiente

Formatação com f-strings

✨ f-strings (Python 3.6+)

Formatação moderna e intuitiva de strings

# F-strings básicas
nome = "João"
idade = 25
print(f"Olá, {nome}! Você tem {idade} anos.")

# F-strings com expressões
a = 10
b = 20
print(f"A soma de {a} + {b} = {a + b}")

🎯 Formatação de Números

# Formatação de decimais
preco = 19.99
print(f"Preço: R$ {preco:.2f}")  # Preço: R$ 19.99

# Formatação de inteiros
numero = 42
print(f"Número: {numero:03d}")  # Número: 042

# Formatação de percentual
taxa = 0.15
print(f"Taxa: {taxa:.1%}")  # Taxa: 15.0%

📊 Alinhamento e Preenchimento

# Alinhamento à esquerda
texto = "Python"
print(f"'{texto:<10}'")  # 'Python    '
# Alinhamento à direita
print(f"'{texto:>10}'")  # '    Python'
# Centralizado
print(f"'{texto:^10}'")  # '  Python  '
# Com preenchimento
print(f"'{texto:*^10}'")  # '**Python**'

Dica

f-strings são a forma mais moderna e eficiente de formatar strings em Python!
