Validação de Strings

✅ Métodos de Validação

Verificar características de strings

# Verificar se é alfabético texto1 = "Python" texto2 = "Python123" print(texto1.isalpha()) # True print(texto2.isalpha()) # False # Verificar se é numérico numero1 = "123" numero2 = "12.3" print(numero1.isdigit()) # True print(numero2.isdigit()) # False

🔍 Métodos de Verificação

  • isalpha(): Apenas letras
  • isdigit(): Apenas dígitos
  • isalnum(): Letras e números
  • isspace(): Apenas espaços
  • islower(): Apenas minúsculas
  • isupper(): Apenas maiúsculas
# Exemplos de validação texto = "Python123" print(f"É alfanumérico: {texto.isalnum()}") # True print(f"É alfabético: {texto.isalpha()}") # False print(f"É numérico: {texto.isdigit()}") # False

🎯 Aplicação Prática

💡 Validador de Senha
# Validar senha senha = input("Digite sua senha: ") if len(senha) < 8: print("Senha deve ter pelo menos 8 caracteres") elif not any(c.isupper() for c in senha): print("Senha deve ter pelo menos uma letra maiúscula") elif not any(c.islower() for c in senha): print("Senha deve ter pelo menos uma letra minúscula") elif not any(c.isdigit() for c in senha): print("Senha deve ter pelo menos um número") else: print("Senha válida!")
