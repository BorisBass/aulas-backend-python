Operações Básicas com Strings

🔤 Concatenação de Strings

Juntar duas ou mais strings usando o operador +

# Concatenação simples
nome = "João"
sobrenome = "Silva"
nome_completo = nome + " " + sobrenome
print(nome_completo)  # João Silva

# Concatenação com variáveis
saudacao = "Olá, " + nome + "!"
print(saudacao)  # Olá, João!

🔄 Repetição de Strings

Repetir uma string usando o operador *

# Repetir string
linha = "-" * 20
print(linha)  # --------------------

# Repetir com variável
quantidade = 5
asteriscos = "*" * quantidade
print(asteriscos)  # *****

📍 Indexação e Fatiamento

Acessar caracteres individuais e partes da string

texto = "Python"

# Acessar caracteres
print(texto[0])    # P
print(texto[-1])   # n

# Fatiamento
print(texto[0:3])  # Pyt
print(texto[2:])   # thon
print(texto[:4])   # Pyth

Dica

Strings em Python são indexadas começando do 0. Use índices negativos para acessar do final!
