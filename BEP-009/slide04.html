Método strip()

✂️ strip() - Remover Espaços

Remove espaços em branco do início e fim da string

# Remover espaços texto = " Python é incrível " texto_limpo = texto.strip() print(f"'{texto_limpo}'") # 'Python é incrível' # Comparação com e sem strip nome1 = "João" nome2 = " João " print(nome1 == nome2) # False print(nome1 == nome2.strip()) # True

🔧 Variações do strip()

  • strip(): Remove espaços dos dois lados
  • lstrip(): Remove espaços da esquerda
  • rstrip(): Remove espaços da direita
texto = " Python " print(f"'{texto.strip()}'") # 'Python' print(f"'{texto.lstrip()}'") # 'Python ' print(f"'{texto.rstrip()}'") # ' Python'

🎯 Aplicação Prática

💡 Validação de Entrada
# Limpar entrada do usuário email = input("Digite seu email: ").strip() senha = input("Digite sua senha: ").strip() if email and senha: print("Dados válidos!") else: print("Por favor, preencha todos os campos!")

Dica

Sempre use strip() ao processar entrada do usuário para evitar problemas com espaços extras!
