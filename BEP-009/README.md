# BEP-009: Estruturas de Controle Avançadas em Python

## 📚 Visão Geral

Este módulo do curso Back End com Python (BEP) ensina estruturas de controle avançadas em Python, focando em loops (for e while), break, continue, else em loops, loops aninhados e funções úteis para iteração.

## 🎯 Objetivos de Aprendizagem

Ao concluir este módulo, você será capaz de:

- ✅ Utilizar loops `for` para iterar sobre sequências
- ✅ Aplicar loops `while` para repetições condicionais
- ✅ Controlar o fluxo de execução com `break` e `continue`
- ✅ Usar `else` em loops para execução condicional
- ✅ Implementar loops aninhados para estruturas complexas
- ✅ Aplicar funções úteis como `enumerate()`, `zip()` e `reversed()`
- ✅ Tratar erros em loops usando `try-except`
- ✅ Resolver problemas práticos usando estruturas de controle

## 🚀 Como Usar

### Visualizar Slides

1. Abra o arquivo `index.html` no navegador
2. Clique no slide desejado
3. Use as setas do teclado ou botões na tela para navegar
4. Pressione `←` para voltar e `→` para avançar

### Fazer Exercícios

1. Abra o arquivo `exercicios_controle_colab.py` no Google Colab ou em seu editor favorito
2. Leia as instruções de cada exercício
3. Implemente sua solução
4. Teste com diferentes valores
5. Compare com as soluções fornecidas
