📊 Processamento de Dados

Manipulação de grandes volumes de texto

# Processar arquivo de texto
def processar_arquivo(nome_arquivo):
    with open(nome_arquivo, 'r', encoding='utf-8') as arquivo:
        conteudo = arquivo.read()
    
    # Estatísticas básicas
    linhas = conteudo.split('\n')
    palavras = conteudo.split()
    
    print(f"Linhas: {len(linhas)}")
    print(f"Palavras: {len(palavras)}")
    print(f"Caracteres: {len(conteudo)}")
    
    # Palavra mais frequente
    contador = {}
    for palavra in palavras:
        palavra = palavra.lower().strip('.,!?')
        contador[palavra] = contador.get(palavra, 0) + 1
    
    palavra_mais_frequente = max(contador, key=contador.get)
    print(f"Palavra mais frequente: {palavra_mais_frequente}")

Explicação da função processar_arquivo()

  • with open(): Abre arquivo de forma segura (fecha automaticamente)
  • encoding='utf-8': Suporta acentos e caracteres especiais
  • split('\n'): Divide texto em linhas (quebras de linha)
  • split(): Divide texto em palavras (espaços como separador)
  • strip('.,!?'): Remove pontuação das palavras
  • contador.get(): Retorna 0 se chave não existir
  • max(contador, key=contador.get): Encontra chave com maior valor

🔍 Análise de Texto

# Analisar sentimento básico
def analisar_sentimento(texto):
    palavras_positivas = ['bom', 'ótimo', 'excelente', 'maravilhoso']
    palavras_negativas = ['ruim', 'terrível', 'horrível', 'péssimo']
    
    texto_lower = texto.lower()
    positivas = sum(1 for palavra in palavras_positivas if palavra in texto_lower)
    negativas = sum(1 for palavra in palavras_negativas if palavra in texto_lower)
    
    if positivas > negativas:
        return "Positivo"
    elif negativas > positivas:
        return "Negativo"
    else:
        return "Neutro"

Explicação da função analisar_sentimento()

  • texto.lower(): Converte para minúsculas (busca case-insensitive)
  • sum(1 for palavra in lista if condição): Conta quantas palavras da lista estão no texto
  • Lista de compreensão: Gera 1 para cada palavra encontrada, 0 para não encontrada
  • Comparação simples: Mais palavras positivas = sentimento positivo
  • Análise básica: Versão simplificada de análise de sentimento

🎯 Aplicação: Sistema de Busca

# Sistema de busca simples
def buscar_texto(texto, termo):
    texto_lower = texto.lower()
    termo_lower = termo.lower()
    
    if termo_lower in texto_lower:
        posicao = texto_lower.find(termo_lower)
        return f"Termo encontrado na posição {posicao}"
    else:
        return "Termo não encontrado"

Explicação da função buscar_texto()

  • texto.lower() e termo.lower(): Busca case-insensitive (ignora maiúsculas/minúsculas)
  • in operador: Verifica se termo existe no texto (retorna True/False)
  • find(): Retorna posição da primeira ocorrência (ou -1 se não encontrar)
  • Busca simples: Encontra apenas a primeira ocorrência
  • Retorno informativo: Mostra posição exata onde foi encontrado
💡 Exemplo de uso das funções
# Exemplo de uso
texto = "Python é uma linguagem excelente para programação!"

# Análise de sentimento
sentimento = analisar_sentimento(texto)
print(f"Sentimento: {sentimento}")  # Positivo

# Busca de texto
resultado = buscar_texto(texto, "Python")
print(resultado)  # Termo encontrado na posição 0
