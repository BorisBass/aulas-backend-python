BEP-009: Manipulação de Strings

Trabalhe com textos de maneira eficiente

Métodos split() e join()

✂️ split() - Dividir String

Divide uma string em uma lista de substrings

# Dividir por espaços (padrão) frase = "Python é uma linguagem incrível" palavras = frase.split() print(palavras) # ['Python', 'é', 'uma', 'linguagem', 'incrível'] # Dividir por caractere específico data = "15/03/2025" partes = data.split("/") print(partes) # ['15', '03', '2025']

🔗 join() - Juntar Lista

Une elementos de uma lista em uma string

# Juntar lista em string palavras = ["Python", "é", "incrível"] frase = " ".join(palavras) print(frase) # Python é incrível # Juntar com separador específico numeros = ["1", "2", "3", "4"] linha = "-".join(numeros) print(linha) # 1-2-3-4

🎯 Aplicação Prática

💡 Processamento de Texto
# Contar palavras em um texto texto = input("Digite um texto: ") palavras = texto.split() numero_palavras = len(palavras) print(f"O texto tem {numero_palavras} palavras") # Inverter ordem das palavras palavras_invertidas = " ".join(reversed(palavras)) print(f"Texto invertido: {palavras_invertidas}")

Dica

split() e join() são muito úteis para processar dados separados por delimitadores!
