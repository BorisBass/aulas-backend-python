BEP-009: Manipulação de Strings

Trabalhe com textos de maneira eficiente

Formatação com %

📊 Formatação com % (Estilo C)

Formatação clássica usando o operador %

# Formatação básica
nome = "João"
idade = 25
print("Olá, %s! Você tem %d anos." % (nome, idade))

# Formatação de decimais
preco = 19.99
print("Preço: R$ %.2f" % preco)

🔤 Especificadores de Formato

  • %s: String
  • %d: Inteiro
  • %f: Decimal
  • %e: Notação científica
  • %x: Hexadecimal
# Diferentes tipos
numero = 42
decimal = 3.14159
texto = "Python"

print("Inteiro: %d" % numero)
print("Decimal: %.2f" % decimal)
print("String: %s" % texto)
print("Hexadecimal: %x" % numero)  # 2a

📏 Formatação com Largura

# Largura fixa
texto = "Python"
print("'%10s'" % texto)    # '    Python'
print("'%-10s'" % texto)   # 'Python    '

# Decimal com largura
numero = 3.14159
print("'%8.2f'" % numero)  # '    3.14'

Dica

Embora funcional, a formatação com % é considerada legada. Prefira f-strings ou format()!
