BEP-009: Manipulação de Strings

Trabalhe com textos de maneira eficiente

Métodos lower() e upper()

🔤 lower() - Minúsculas

Converte todos os caracteres para minúsculas

texto = "PYTHON É INCRÍVEL" texto_minusculo = texto.lower() print(texto_minusculo) # python é incrível # Aplicação prática nome = input("Digite seu nome: ") nome_minusculo = nome.lower() print(f"Olá, {nome_minusculo}!")

🔤 upper() - Maiúsculas

Converte todos os caracteres para maiúsculas

texto = "python é incrível" texto_maiusculo = texto.upper() print(texto_maiusculo) # PYTHON É INCRÍVEL # Aplicação prática resposta = input("Digite 'sim' ou 'não': ") if resposta.upper() == "SIM": print("Você confirmou!")

Dica

Use lower() ou upper() para comparações que não devem ser sensíveis a maiúsculas/minúsculas!
