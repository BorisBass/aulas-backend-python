Crie um programa que formate um CPF no padrão XXX.XXX.XXX-XX.

# Sua solução aqui cpf = input("Digite o CPF (apenas números): ").strip() if len(cpf) == 11 and cpf.isdigit(): cpf_formatado = f"{cpf[:3]}.{cpf[3:6]}.{cpf[6:9]}-{cpf[9:]}" print(f"CPF formatado: {cpf_formatado}") else: print("CPF inválido!")

Crie um programa que conte o número de vogais em um texto.

# Sua solução aqui texto = input("Digite um texto: ").lower() vogais = "aeiou" contador = 0 for letra in texto: if letra in vogais: contador += 1 print(f"Número de vogais: {contador}")

🎯 Exercício 6: Gerador de Senha

Crie um programa que gere uma senha aleatória com letras e números.

# Sua solução aqui import random import string tamanho = int(input("Digite o tamanho da senha: ")) caracteres = string.ascii_letters + string.digits senha = ''.join(random.choice(caracteres) for _ in range(tamanho)) print(f"Senha gerada: {senha}")

Explicação dos Módulos e Funções

  • string.ascii_letters: Contém todas as letras (a-z, A-Z)
  • string.digits: Contém todos os dígitos (0-9)
  • random.choice(): Escolhe um elemento aleatório de uma lista
💡 Explicação da Linha Complexa

senha = ''.join(random.choice(caracteres) for _ in range(tamanho))

🔍 Quebrando a linha em partes:

# 1. range(tamanho) - cria uma sequência de números # Exemplo: range(5) = [0, 1, 2, 3, 4] # 2. for _ in range(tamanho) - loop que executa 'tamanho' vezes # O _ significa "não me importo com o valor da variável" # 3. random.choice(caracteres) - escolhe um caractere aleatório # Executado a cada iteração do loop # 4. Lista de compreensão completa: # [random.choice(caracteres) for _ in range(tamanho)] # Resultado: ['A', 'b', '3', 'X', '9'] (exemplo para tamanho=5) # 5. ''.join() - junta todos os elementos da lista em uma string # ''.join(['A', 'b', '3', 'X', '9']) = "Ab3X9"

Versão Mais Simples (para entender)

# Versão passo a passo (mais fácil de entender) import random import string tamanho = int(input("Digite o tamanho da senha: ")) caracteres = string.ascii_letters + string.digits senha = "" for i in range(tamanho): caractere_aleatorio = random.choice(caracteres) senha += caractere_aleatorio print(f"Senha gerada: {senha}")
