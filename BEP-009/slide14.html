BEP-009: Manipulação de Strings

Trabalhe com textos de maneira eficiente

Boas Práticas

💡 Dicas para Manipulação de Strings

  • Use f-strings: Mais legível e eficiente
  • Valide entrada: Sempre use strip() e validações
  • Trate erros: Verifique se strings existem antes de usar
  • Seja consistente: Use o mesmo estilo em todo o código

🔧 Performance

# ✅ Bom - Use f-strings
nome = "João"
idade = 25
print(f"Olá, {nome}! Você tem {idade} anos.")

# ❌ Ruim - Concatenação com +
print("Olá, " + nome + "! Você tem " + str(idade) + " anos.")

🛡️ Segurança

# Validação de entrada
def validar_entrada(texto):
    if not texto or not texto.strip():
        return False
    
    # Remover caracteres perigosos
    texto_limpo = texto.strip()
    
    # Verificar tamanho
    if len(texto_limpo) > 1000:
        return False
    
    return True
