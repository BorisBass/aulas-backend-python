BEP-009: Manipulação de Strings

Trabalhe com textos de maneira eficiente

Busca e Substituição

🔍 Método find()

Encontra a posição de uma substring na string

# Buscar substring texto = "Python é incrível" posicao = texto.find("incrível") print(posicao) # 10 # Buscar com início posicao = texto.find("é", 5) print(posicao) # 7 # Substring não encontrada posicao = texto.find("Java") print(posicao) # -1

🔄 Método replace()

Substitui uma substring por outra

# Substituição simples texto = "Python é incrível" novo_texto = texto.replace("incrível", "fantástico") print(novo_texto) # Python é fantástico # Substituição múltipla texto = "Java é bom, mas Python é melhor" novo_texto = texto.replace("Java", "C++").replace("Python", "JavaScript") print(novo_texto) # C++ é bom, mas JavaScript é melhor

🎯 Aplicação Prática

💡 Limpeza de Texto
# Limpar texto de entrada texto = input("Digite um texto: ") texto_limpo = texto.strip().lower() # Remove todos os espaços duplos while " " in texto_limpo: texto_limpo = texto_limpo.replace(" ", " ") print(f"Texto original: '{texto}'") print(f"Texto limpo: '{texto_limpo}'")

Dica

Use find() para verificar se uma substring existe antes de usar replace()!
