Sistema Gerenciador de Banco de Dados (SGBD)

O que é um SGBD?

Um Sistema Gerenciador de Banco de Dados (SGBD) é um software que gerencia, organiza e controla o acesso aos dados armazenados em um banco de dados.

Funções do SGBD

Gerenciamento

Cria, modifica e remove bancos de dados e tabelas

Segurança

Controla acesso, permissões e autenticação

Integridade

Garante consistência e confiabilidade dos dados

Performance

Otimiza consultas e operações

Analogia: SGBD como Biblioteca

Biblioteca (SGBD)

  • Organiza os livros (dados)
  • Controla empréstimos (acesso)
  • Mantém catálogo (índices)
  • Garante segurança

Usuário

  • Faz pedidos (consultas)
  • Recebe livros (resultados)
  • Devolve livros (transações)
  • Segue regras (permissões)

Recursos de Segurança

Autenticação

Verifica identidade do usuário

Autorização

Controla o que cada usuário pode fazer

Auditoria

Registra todas as operações

Criptografia

Protege dados sensíveis

Controle de Transações

Atomicidade

Toda operação é executada completamente ou não é executada

Consistência

Dados sempre em estado válido

Isolamento

Transações não interferem umas nas outras

Durabilidade

Mudanças permanecem mesmo após falhas

Vantagens do SGBD

Segurança

Controle de acesso e backup automático

Compartilhamento

Múltiplos usuários acessam simultaneamente

Performance

Otimização automática de consultas

Integridade

Garante consistência dos dados

Tipos de SGBD

Desktop

Para aplicações locais (SQLite, Access)

Servidor

Para aplicações corporativas (MySQL, PostgreSQL)

Cloud

Hospedado na nuvem (AWS RDS, Google Cloud SQL)

Mobile

Para aplicações móveis (SQLite, Realm)
