Exercícios Práticos

Exercícios de Reconhecimento

Vamos praticar identificando conceitos em tabelas simples!

Exercício 1: Identifique os Componentes

Analise a tabela abaixo e identifique:

ID Nome Idade Cidade
1 Ana Silva 25 Salvador
2 Carlos Santos 30 São Paulo
🔍 Perguntas:
  • Qual é a chave primária?
  • Quantas colunas existem?
  • Quantos registros existem?
  • Quais são os tipos de dados de cada coluna?

Exercício 2: Relacionamentos

Analise as duas tabelas e identifique o relacionamento:

📚 Tabela: Livros
ID Título Autor_ID
1 Python para Iniciantes 1
2 Banco de Dados 2
👤 Tabela: Autores
ID Nome
1 João Silva
2 Maria Santos
🔍 Perguntas:
  • Qual é a chave estrangeira na tabela Livros?
  • Que tipo de relacionamento existe?
  • Quantos livros o autor "João Silva" escreveu?

Exercício 3: Modelagem

Imagine um sistema de biblioteca e identifique:

  • 📚 Entidades: Quais objetos existem?
  • 🔗 Relacionamentos: Como se conectam?
  • 🔑 Chaves: O que identifica cada entidade?
💡 Dica:

Pense em: Livros, Autores, Usuários, Empréstimos

Respostas dos Exercícios

Exercício 1:
  • Chave primária: ID
  • Colunas: 4 (ID, Nome, Idade, Cidade)
  • Registros: 2
  • Tipos: ID (INT), Nome (VARCHAR), Idade (INT), Cidade (VARCHAR)
Exercício 2:
  • Chave estrangeira: Autor_ID
  • Relacionamento: Muitos para Um (N:1)
  • João Silva: 1 livro
