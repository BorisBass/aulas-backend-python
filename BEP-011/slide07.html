Respostas dos Exercícios

Exercício 1:
  • Chave primária: ID
  • Colunas: 4 (ID, Nome, Idade, Cidade)
  • Registros: 2
  • Tipos: ID (INT), Nome (VARCHAR), Idade (INT), Cidade (VARCHAR)
Exercício 2:
  • Chave estrangeira: Autor_ID
  • Relacionamento: Muitos para Um (N:1)
  • João Silva: 1 livro

Laboratório prático (online)

Vamos fazer um teste rápido e gratuito em uma ferramenta online. Você pode escolher:

  • 🔹 Google Colab (Python + SQLite) — recomendado
  • 🔹 SQLiteOnline — roda SQL direto no navegador

Passo a passo no Google Colab
  1. Abra o link do Colab acima (cria um notebook novo).
  2. Copie e execute os blocos de código abaixo, na ordem.
  3. Observe os resultados no output de cada célula.
1) Criar banco e tabela (SQLite via Python)
import sqlite3

# cria (ou abre) um banco em memória: ideal para testes
connection = sqlite3.connect(":memory:")
cursor = connection.cursor()

# cria a tabela Clientes
cursor.execute(
    """
    CREATE TABLE clientes (
        id INTEGER PRIMARY KEY,
        nome TEXT NOT NULL,
        email TEXT UNIQUE,
        idade INTEGER
    );
    """
)

connection.commit()
print("Tabela criada!")
2) Inserir alguns registros
dados = [
    (1, "Ana Silva", "ana@example.com", 25),
    (2, "Carlos Santos", "carlos@example.com", 30),
    (3, "João Souza", "joao@example.com", 22),
]

cursor.executemany(
    "INSERT INTO clientes (id, nome, email, idade) VALUES (?, ?, ?, ?);",
    dados,
)
connection.commit()
print("Registros inseridos!")
3) Fazer consultas simples (prévia da próxima aula)
# listar todos os clientes
for row in cursor.execute("SELECT id, nome, email, idade FROM clientes;"):
    print(row)

# filtrar por idade >= 25
print("\nMaiores ou iguais a 25:")
for row in cursor.execute("SELECT nome, idade FROM clientes WHERE idade >= 25;"):
    print(row)
