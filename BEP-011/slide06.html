Sistemas Gerenciadores de BD (SGBD)

O que é um SGBD?

Um Sistema Gerenciador de Banco de Dados (SGBD) é um software que gerencia o armazenamento, recuperação e segurança dos dados.

Funções de um SGBD

  • Armazenamento: Salva dados de forma organizada
  • Recuperação: Busca dados rapidamente
  • Segurança: Controla acesso aos dados
  • Integridade: Mantém dados consistentes
  • Backup: Cria cópias de segurança

SGBDs Populares

MySQL
  • ✅ Gratuito e open source
  • ✅ Muito popular
  • ✅ Boa performance
  • ✅ Fácil de usar
PostgreSQL
  • ✅ Muito robusto
  • ✅ Recursos avançados
  • ✅ Gratuito
  • ✅ Padrão SQL completo
SQLite
  • ✅ Muito leve
  • ✅ Arquivo único
  • ✅ Sem servidor
  • ✅ Ideal para iniciantes

Comparação de SGBDs

Característica MySQL PostgreSQL SQLite
Complexidade Média Alta Baixa
Performance Excelente Excelente Boa
Uso Web, aplicações Aplicações complexas Aplicações simples
Instalação Servidor Servidor Arquivo

Para Iniciantes

Recomendação: Comece com SQLite (em Colab) e avance para PostgreSQL quando precisar de recursos avançados (tipos, extensões).

Mini prática adicional (Colab)

Importe um CSV e consulte:

import pandas as pd
import sqlite3

connection = sqlite3.connect(":memory:")
cursor = connection.cursor()

pd.read_csv("https://raw.githubusercontent.com/BorisBass/aulas-backend-python/main/BEP-011/dados_clientes.csv") \
  .to_sql("clientes", connection, index=False, if_exists="replace")

for row in cursor.execute("SELECT nome, idade FROM clientes WHERE idade >= 25 ORDER BY idade DESC;"):
    print(row)
