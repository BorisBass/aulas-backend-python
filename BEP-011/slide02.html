Conceitos fundamentais de bancos de dados relacionais

Bancos Relacionais vs Não Relacionais

Tipos de Bancos de Dados

Existem dois tipos principais de bancos de dados:

Bancos Relacionais (SQL)

  • Estrutura: Dados organizados em tabelas
  • Relacionamentos: Tabelas conectadas por chaves
  • Consistência: Dados sempre válidos
  • Exemplos: MySQL, PostgreSQL, SQLite

Bancos Não Relacionais (NoSQL)

  • Estrutura: Dados em documentos, grafos, chave-valor
  • Flexibilidade: Estrutura pode variar
  • Escalabilidade: Crescimento horizontal
  • Exemplos: MongoDB, Redis, Neo4j

Comparação Prática

Característica Relacional Não Relacional
Estrutura Tabelas fixas Flexível
Consistência Alta Variável
Escalabilidade Vertical Horizontal
Uso Sistemas tradicionais Big Data, IoT

Situações do mundo real

  • E-commerce: relacional para pedidos/estoque; NoSQL para cache e sessões.
  • Analytics: NoSQL para ingestão massiva; relacional para relatórios consistentes.
  • Chat/app móvel: NoSQL para mensagens; relacional para billing/assinaturas.

Perguntas guiadas

  • Quais dados do seu projeto exigem integridade estrita (PK/FK)?
  • Existe parte do seu domínio que variará muito de estrutura?
  • Qual consulta crítica não pode falhar nem retornar dados inconsistentes?

Quando usar cada tipo?

Relacional: Sistemas bancários, e-commerce, CRM

Não Relacional: Redes sociais, IoT, análise de dados

Foco do Curso

Neste curso, focaremos em bancos relacionais porque:

  • ✅ Mais utilizados no mercado
  • ✅ Base para aprender outros tipos
  • ✅ Excelente para iniciantes
  • ✅ Padrão da indústria
