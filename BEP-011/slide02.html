BEP-011: Introdução a Banco de Dados Relacionais

Conceitos fundamentais de bancos de dados relacionais

Banco de Dados Relacional vs Não Relacional

Dois Tipos Principais

Existem duas grandes categorias de bancos de dados, cada uma com suas características e aplicações específicas.

Banco de Dados Relacional

Estrutura

Dados organizados em tabelas com linhas e colunas bem definidas

Relacionamentos

Tabelas conectadas através de chaves (primárias e estrangeiras)

Esquema Fixo

Estrutura pré-definida e consistente

Linguagem

Usa SQL (Structured Query Language)

Exemplo Visual: Banco Relacional

Tabela: Clientes

ID Nome Email
1 João joao@email.com
2 Maria maria@email.com

Tabela: Pedidos

ID Cliente_ID Produto
101 1 Notebook
102 2 Mouse

Relacionamento: Cliente_ID na tabela Pedidos conecta com ID na tabela Clientes

Banco de Dados Não Relacional (NoSQL)

Estrutura Flexível

Dados em formatos variados: documentos, chave-valor, grafos

Escalabilidade

Fácil expansão horizontal (mais servidores)

Esquema Dinâmico

Estrutura pode mudar conforme necessário

Performance

Otimizado para grandes volumes de dados

Exemplo Visual: Banco Não Relacional

Documento JSON

{
  "_id": "1",
  "nome": "João",
  "email": "joao@email.com",
  "pedidos": [
    {
      "produto": "Notebook",
      "data": "2024-01-15"
    }
  ]
}

Chave-Valor

Chave: "usuario:123"

Valor: "João Silva, joao@email.com"


Chave: "produto:456"

Valor: "Notebook Dell, R$ 2.500"

Comparação Rápida

Relacional

  • ✅ Estrutura consistente
  • ✅ Relacionamentos claros
  • ✅ Padrão SQL
  • ❌ Menos flexível
  • ❌ Escalabilidade limitada

Não Relacional

  • ✅ Muito flexível
  • ✅ Escalabilidade alta
  • ✅ Performance otimizada
  • ❌ Menos padronizado
  • ❌ Relacionamentos complexos

Quando Usar Cada Um?

Use Relacional Para:

  • Sistemas financeiros
  • E-commerce tradicional
  • Sistemas com relacionamentos complexos
  • Aplicações que precisam de consistência

Use Não Relacional Para:

  • Redes sociais
  • Sistemas de IoT
  • Análise de big data
  • Aplicações que crescem rapidamente
