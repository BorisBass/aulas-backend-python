BEP-011: Introdução a Banco de Dados Relacionais

Conceitos fundamentais de bancos de dados relacionais

Conceitos Básicos: Tabela, Linha e Coluna

A Estrutura Fundamental

Os bancos de dados relacionais organizam os dados em tabelas, que são como planilhas com estrutura bem definida.

Tabela (Table)

Definição

Uma tabela é uma estrutura que armazena dados relacionados em linhas e colunas

Nome

Cada tabela tem um nome único que a identifica no banco de dados

Exemplos

clientes, produtos, pedidos, funcionários, departamentos

Exemplo Visual: Tabela "Clientes"

ID Nome Email Telefone Cidade
1 João Silva joao@email.com (71) 99999-1111 Salvador
2 Maria Santos maria@email.com (71) 99999-2222 Feira de Santana
3 Pedro Costa pedro@email.com (71) 99999-3333 Vitória da Conquista

Nome da Tabela: clientes

Coluna (Column/Field)

Definição

Uma coluna representa um atributo ou característica específica dos dados

Nome

Cada coluna tem um nome único dentro da tabela

Tipo de Dados

Cada coluna tem um tipo específico (texto, número, data, etc.)

Exemplo

Na tabela clientes: ID, Nome, Email, Telefone, Cidade

Exemplo Visual: Colunas da Tabela

Coluna: ID

  • Tipo: Número inteiro
  • Função: Identificador único
  • Exemplo: 1, 2, 3

Coluna: Nome

  • Tipo: Texto
  • Função: Nome do cliente
  • Exemplo: "João Silva"

Coluna: Email

  • Tipo: Texto
  • Função: Endereço de email
  • Exemplo: "joao@email.com"

Coluna: Telefone

  • Tipo: Texto
  • Função: Número de telefone
  • Exemplo: "(71) 99999-1111"

Linha (Row/Record)

Definição

Uma linha representa um registro completo com todos os dados de uma entidade

Conteúdo

Cada linha contém um valor para cada coluna da tabela

Unicidade

Cada linha representa uma entidade única (um cliente, um produto, etc.)

Exemplo Visual: Linhas da Tabela

Linha 1: Cliente João

  • ID: 1
  • Nome: João Silva
  • Email: joao@email.com
  • Telefone: (71) 99999-1111
  • Cidade: Salvador

Linha 2: Cliente Maria

  • ID: 2
  • Nome: Maria Santos
  • Email: maria@email.com
  • Telefone: (71) 99999-2222
  • Cidade: Feira de Santana

Analogia com Planilha

Planilha Excel

  • Abas: Como tabelas
  • Cabeçalhos: Como colunas
  • Linhas: Como registros
  • Células: Como valores

Banco de Dados

  • Tabelas: Como abas
  • Colunas: Como cabeçalhos
  • Linhas: Como linhas de dados
  • Valores: Como conteúdo das células

Resumo dos Conceitos

Tabela

Estrutura que organiza dados relacionados

Coluna

Atributo ou característica dos dados

Linha

Registro completo de uma entidade
