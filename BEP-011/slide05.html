Modelo Entidade-Relacionamento (ER)

O que é o Modelo ER?

O Modelo Entidade-Relacionamento é uma ferramenta visual para representar a estrutura e os relacionamentos de um banco de dados de forma gráfica e intuitiva.

Entidade (Entity)

Definição

Uma entidade representa um objeto, pessoa, lugar ou conceito do mundo real

Símbolo

ENTIDADE

Exemplos

  • Cliente
  • Produto
  • Funcionário
  • Departamento
  • Pedido

Exemplo Visual: Entidades

Relacionamento (Relationship)

Definição

Um relacionamento representa uma associação entre duas ou mais entidades

Símbolo

RELACIONAMENTO

Exemplos

  • Cliente FAZ Pedido
  • Pedido CONTÉM Produto
  • Funcionário TRABALHA_EM Departamento
  • Aluno FREQUENTA Curso

Exemplo Visual: Relacionamentos

FAZ
PEDIDO

Um CLIENTE FAZ um PEDIDO

Atributo (Attribute)

Definição

Um atributo é uma propriedade ou característica de uma entidade

Símbolo

Atributo

Exemplos

  • Cliente: nome, email, telefone
  • Produto: nome, preço, categoria
  • Pedido: data, valor, status

Chave Primária no Modelo ER

Definição

Atributo que identifica unicamente cada instância de uma entidade

Símbolo

🔑 ID

Exemplos

  • Cliente: ID_Cliente
  • Produto: ID_Produto
  • Pedido: ID_Pedido

Vantagens do Modelo ER

Visualização

Representa o banco de dados de forma gráfica e intuitiva

Comunicação

Facilita a comunicação entre desenvolvedores e usuários

Planejamento

Ajuda no planejamento e design do banco de dados

Validação

Permite identificar problemas antes da implementação

Resumo dos Elementos

Entidade

Objeto do mundo real (retângulo)

Relacionamento

Associação entre entidades (losango)

Atributo

Propriedade da entidade (elipse)

Chave Primária

Identificador único (sublinhado)
