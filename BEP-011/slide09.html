Exercícios de Reconhecimento de Tabelas

Objetivo

Identificar e analisar estruturas de tabelas, reconhecendo colunas, tipos de dados e relacionamentos.

Exercício 1: Tabela de Funcionários

ID_Funcionario Nome Cargo Salario Data_Admissao
1 João Silva Desenvolvedor 5000.00 2023-01-15
2 Maria Santos Analista 4500.00 2023-03-20
3 Pedro Costa Gerente 8000.00 2022-11-10

Perguntas:

  1. Qual é o nome da tabela?
  2. Quantas colunas tem a tabela?
  3. Qual é a chave primária?
  4. Quantos registros (linhas) existem?
  5. Quais são os tipos de dados das colunas?

Respostas:

  1. Funcionários
  2. 5 colunas
  3. ID_Funcionario
  4. 3 registros
  5. Número, Texto, Texto, Decimal, Data

Exercício 2: Tabela de Produtos

Codigo Nome_Produto Categoria Preco Estoque
P001 Notebook Dell Informática 2500.00 15
P002 Mouse Logitech Acessórios 89.90 50
P003 Teclado Mecânico Acessórios 199.90 25

Perguntas:

  1. Qual é a chave primária desta tabela?
  2. Quantos produtos há em estoque?
  3. Qual produto tem o maior preço?
  4. Quantas categorias diferentes existem?
  5. Qual é o valor total do estoque?

Respostas:

  1. Codigo
  2. 90 unidades (15+50+25)
  3. Notebook Dell (R$ 2.500,00)
  4. 2 categorias (Informática, Acessórios)
  5. R$ 37.500,00 + R$ 4.495,00 + R$ 4.997,50

Perguntas:

  1. Quantos clientes são de Salvador?
  2. Qual cliente foi cadastrado primeiro?
  3. Quantos clientes têm telefone com DDD 71?

Dicas para Análise de Tabelas

Observe

  • Nome da tabela
  • Número de colunas
  • Nomes das colunas
  • Tipos de dados
  • Chave primária

Analise

  • Quantidade de registros
  • Padrões nos dados
  • Relacionamentos possíveis
  • Integridade dos dados
  • Consistência
