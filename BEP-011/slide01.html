BEP-011: Introdução a Banco de Dados Relacionais

Conceitos fundamentais de bancos de dados relacionais

O que é um Banco de Dados?

Definição

Um banco de dados é uma coleção organizada e estruturada de informações que são armazenadas, gerenciadas e acessadas eletronicamente por um sistema computacional.

Exemplos do Dia a Dia

Agenda do Celular

Nomes, telefones, emails organizados em contatos

Lista de Compras

Produtos, quantidades, preços em uma lista organizada

Biblioteca Pessoal

Títulos, autores, gêneros catalogados

Calendário

Eventos, datas, horários organizados por tempo

Exemplo: Sistema de Biblioteca

Imagine uma biblioteca que precisa organizar:

Livros

  • Título
  • Autor
  • ISBN
  • Ano de publicação
  • Gênero

Usuários

  • Nome
  • CPF
  • Email
  • Telefone
  • Endereço

Empréstimos

  • Data do empréstimo
  • Data de devolução
  • Status (ativo/devolvido)
  • Multa (se houver)

Características de um Banco de Dados

Organização

Dados estruturados de forma lógica e consistente

Persistência

Informações mantidas permanentemente no armazenamento

Acesso Eficiente

Consulta e modificação rápida dos dados

Integridade

Consistência e confiabilidade das informações

Banco de Dados vs Arquivo Simples

Arquivo Simples

  • Dados desorganizados
  • Sem relacionamentos
  • Difícil de consultar
  • Sem controle de acesso

Banco de Dados

  • Estrutura organizada
  • Relacionamentos definidos
  • Consultas eficientes
  • Controle de acesso
