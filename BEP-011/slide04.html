Chave Primária e Chave Estrangeira

O que são Chaves?

As chaves são elementos fundamentais que permitem identificar registros únicos e estabelecer relacionamentos entre tabelas.

Chave Primária (Primary Key)

Definição

Uma chave primária é uma coluna (ou conjunto de colunas) que identifica unicamente cada linha de uma tabela

Características

  • Não pode ser nula (NULL)
  • Deve ser única
  • Não pode ser alterada
  • Uma por tabela

Símbolo

🔑

Exemplo Visual: Chave Primária

🔑 ID Nome Email Telefone
1 João Silva joao@email.com (71) 99999-1111
2 Maria Santos maria@email.com (71) 99999-2222
3 Pedro Costa pedro@email.com (71) 99999-3333

A coluna ID é a chave primária - cada valor é único!

Chave Estrangeira (Foreign Key)

Definição

Uma chave estrangeira é uma coluna que referencia a chave primária de outra tabela

Função

Estabelece relacionamentos entre tabelas diferentes

Símbolo

🔗

Exemplo Visual: Chave Estrangeira

Tabela: Clientes

🔑 ID Nome
1 João
2 Maria

Tabela: Pedidos

ID 🔗 Cliente_ID Produto
101 1 Notebook
102 2 Mouse
103 1 Teclado

A coluna Cliente_ID é chave estrangeira - referencia ID da tabela Clientes!

Relacionamento Visual

Clientes
🔑 ID: 1, 2
↔️
Pedidos
🔗 Cliente_ID: 1, 2, 1

O pedido 101 e 103 pertencem ao cliente 1 (João)
O pedido 102 pertence ao cliente 2 (Maria)

Regras das Chaves

Chave Primária

  • ✅ Deve ser única
  • ✅ Não pode ser nula
  • ✅ Não pode ser alterada
  • ✅ Uma por tabela

Chave Estrangeira

  • ✅ Deve existir na tabela referenciada
  • ✅ Pode ser nula (dependendo do caso)
  • ✅ Pode ser alterada
  • ✅ Pode ter várias por tabela

Analogia do Mundo Real

RG (Chave Primária)

  • Cada pessoa tem um RG único
  • Não pode ser nulo
  • Identifica a pessoa
  • Não muda

Endereço (Chave Estrangeira)

  • Referencia um CEP existente
  • Pode ser nulo (sem endereço)
  • Conecta pessoa com localização
  • Pode mudar

Resumo

Chave Primária

Identifica unicamente cada linha da tabela

Chave Estrangeira

Conecta tabelas através de relacionamentos
