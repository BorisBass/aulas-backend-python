BEP-011: Introdução a Banco de Dados Relacionais

Conceitos fundamentais de bancos de dados relacionais

Chaves Primárias e Estrangeiras

Chaves Primárias (Primary Key)

Uma chave primária é um campo (ou conjunto de campos) que identifica unicamente cada linha de uma tabela.

Exemplo: Chave Primária

🔑 ID Nome Email
1 João Silva joao@email.com
2 Maria Santos maria@email.com

ID é a chave primária - cada cliente tem um ID único!

Chaves Estrangeiras (Foreign Key)

Uma chave estrangeira é um campo que referencia a chave primária de outra tabela.

Exemplo: Relacionamento entre Tabelas

📋 Tabela: Clientes
🔑 ID Nome
1 João
2 Maria
🛒 Tabela: Pedidos
🔑 ID 🔗 Cliente_ID Produto
101 1 Notebook
102 2 Mouse

Cliente_ID é a chave estrangeira - conecta pedidos aos clientes!

Regras das Chaves

  • Chave Primária: Única, não nula, imutável
  • Chave Estrangeira: Deve existir na tabela referenciada
  • Integridade: Impede dados órfãos
  • Relacionamentos: Conecta tabelas logicamente

Por que usar Chaves?

  • ✅ Identificação única: Cada registro é único
  • ✅ Relacionamentos: Conecta dados entre tabelas
  • ✅ Integridade: Dados consistentes
  • ✅ Performance: Busca mais rápida
