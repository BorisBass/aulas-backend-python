Exercícios de Interpretação de Relacionamentos

Objetivo

Identificar relacionamentos entre tabelas, reconhecer chaves primárias e estrangeiras, e interpretar cardinalidades.

Exercício 1: Sistema de Biblioteca

Tabela: Usuarios

ID_Usuario Nome Email
1 João joao@email.com
2 Maria maria@email.com

Tabela: Livros

ID_Livro Titulo Autor
101 Python para Iniciantes Silva
102 Banco de Dados Santos

Tabela: Emprestimos

ID_Emprestimo ID_Usuario ID_Livro Data_Emprestimo
201 1 101 2024-01-15
202 2 102 2024-01-20

Perguntas:

  1. Qual é a chave primária de cada tabela?
  2. Quais são as chaves estrangeiras na tabela Emprestimos?
  3. Que tipo de relacionamento existe entre Usuarios e Emprestimos?
  4. Que tipo de relacionamento existe entre Livros e Emprestimos?
  5. Qual é a cardinalidade geral do sistema?

Respostas:

  1. ID_Usuario, ID_Livro, ID_Emprestimo
  2. ID_Usuario e ID_Livro
  3. 1:N (Um usuário pode ter vários empréstimos)
  4. 1:N (Um livro pode ser emprestado várias vezes)
  5. N:N (Usuários ↔ Livros através de Emprestimos)

Exercício 2: Sistema de Vendas

Tabela: Clientes

ID_Cliente Nome Cidade
1 Ana Salvador
2 Carlos Feira

Tabela: Pedidos

ID_Pedido ID_Cliente Data Valor
301 1 2024-01-10 150.00
302 1 2024-01-15 200.00
303 2 2024-01-20 100.00

Perguntas:

  1. Qual cliente fez mais pedidos?
  2. Qual é o valor total dos pedidos da Ana?
  3. Que tipo de relacionamento existe entre Clientes e Pedidos?
  4. Quantos pedidos foram feitos em janeiro de 2024?
  5. Qual é a chave estrangeira na tabela Pedidos?

Respostas:

  1. Ana (2 pedidos)
  2. R$ 350,00 (150 + 200)
  3. 1:N (Um cliente pode fazer vários pedidos)
  4. 3 pedidos
  5. ID_Cliente

Dicas para Interpretar Relacionamentos

Chaves

  • Identifique a chave primária
  • Localize as chaves estrangeiras
  • Verifique as referências
  • Analise a integridade

Cardinalidades

  • Conte quantos registros se relacionam
  • Identifique padrões 1:1, 1:N, N:N
  • Analise tabelas intermediárias
  • Verifique a lógica do negócio
