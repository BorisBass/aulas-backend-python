BEP-041: Testes Automatizados

Executar testes e interpretar resultados

Rodando a suíte de testes

Comandos principais

# Rodar todos os testes com o framework padrão do Django
python manage.py test

# Rodar testes de um app específico
python manage.py test core

# Usando pytest
pytest
pytest core/

Interpretando a saída

  • . (ponto) – teste passou.
  • F – falha (assert falhou).
  • E – erro (exceção não tratada).
  • Ao final, é exibido um resumo com a quantidade de testes executados.

Cobertura de testes

# Instalar o coverage
pip install coverage

# Rodar testes com coverage
coverage run manage.py test

# Gerar relatório no terminal
coverage report

# Gerar relatório HTML
coverage html

Próximos passos

  • Adicionar testes sempre que criar uma funcionalidade importante.
  • Criar testes de regressão sempre que um bug for corrigido.
  • Integrar a suíte de testes ao pipeline de CI (GitHub Actions, GitLab CI etc.).
