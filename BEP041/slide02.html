BEP-041: Testes Automatizados

Tipos de testes em aplicações web

Testes unitários, integração e funcionais

Cada tipo de teste olha para o sistema em um nível diferente de detalhe.

Testes unitários

  • Testam unidades pequenas de código (funções, métodos, classes).
  • São rápidos e fáceis de isolar.
  • Exemplo: testar um método que calcula desconto.

Testes de integração

  • Verificam se módulos diferentes funcionam bem juntos.
  • Envolvem banco de dados, serviços externos, etc.
  • Exemplo: salvar um pedido e gerar uma notificação.

Testes funcionais (end-to-end)

  • Simulam o uso do sistema como um usuário real.
  • Costumam usar ferramentas como Selenium ou Playwright.
  • Exemplo: abrir o navegador, fazer login e criar um registro.

Pirâmide de testes

  • Base larga: muitos testes unitários.
  • Meio: testes de integração.
  • Topo: poucos testes funcionais (mais caros e lentos).

Na prática, começamos pela base: garantir uma boa cobertura com testes unitários.
