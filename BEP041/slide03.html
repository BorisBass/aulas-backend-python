BEP-041: Testes Automatizados

Frameworks de teste no Django

unittest, Django TestCase e pytest

Django já vem com uma estrutura de testes baseada em unittest, e podemos integrar o pytest para um fluxo mais moderno.

Testes com unittest / Django TestCase

# core/tests.py
from django.test import TestCase
from django.urls import reverse
from core.models import Tarefa


class TarefaViewsTest(TestCase):
    def test_lista_tarefas_retorna_200(self):
        url = reverse("core:lista_tarefas")
        response = self.client.get(url)
        self.assertEqual(response.status_code, 200)

    def test_criacao_tarefa(self):
        url = reverse("core:criar_tarefa")
        response = self.client.post(url, data={"titulo": "Estudar testes"})
        self.assertEqual(response.status_code, 302)  # redirect
        self.assertTrue(Tarefa.objects.filter(titulo="Estudar testes").exists())

TestCase já configura um banco de dados de teste isolado para cada método.

Rodando testes com manage.py test

# Rodar todos os testes
python manage.py test

# Rodar testes de um app específico
python manage.py test core

# Rodar um caso de teste específico
python manage.py test core.tests.TarefaViewsTest

Introdução ao pytest

# Instalação
pip install pytest pytest-django

# pytest.ini
[pytest]
DJANGO_SETTINGS_MODULE = meu_projeto.settings

# tests_pytest.py
import pytest
from core.models import Tarefa


@pytest.mark.django_db
def test_criacao_tarefa():
    tarefa = Tarefa.objects.create(titulo="Usar pytest")
    assert tarefa.id is not None

pytest permite usar funções simples de teste com assert e possui uma saída mais amigável.
