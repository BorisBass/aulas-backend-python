Sobre esta Aula

Esta aula introduz conceitos de testes automatizados no contexto de aplicações Django. Você verá por que testar é fundamental, tipos de testes que existem, como usar o framework de testes padrão do Django e como integrar o pytest ao seu fluxo de trabalho.

No final, você será capaz de escrever testes básicos para suas views, models e formulários, rodar a suíte de testes e interpretar os resultados para corrigir bugs com segurança.
