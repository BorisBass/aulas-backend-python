BEP-041: Testes Automatizados

Criando testes simples para models, views e forms

Escrevendo seus primeiros testes

Testando models

from django.test import TestCase
from core.models import Tarefa


class TarefaModelTest(TestCase):
    def test_str_retorna_titulo(self):
        tarefa = Tarefa.objects.create(titulo="Estudar testes")
        self.assertEqual(str(tarefa), "Estudar testes")

Comece testando comportamentos simples, como o método __str__ ou propriedades calculadas.

Testando views

from django.urls import reverse
from django.test import TestCase


class ListaTarefasViewTest(TestCase):
    def test_status_code_e_template(self):
        url = reverse("core:lista_tarefas")
        response = self.client.get(url)
        self.assertEqual(response.status_code, 200)
        self.assertTemplateUsed(response, "core/lista_tarefas.html")

Testando formulários

from django.test import TestCase
from core.forms import TarefaForm


class TarefaFormTest(TestCase):
    def test_form_valido(self):
        form = TarefaForm(data={"titulo": "Estudar Django"})
        self.assertTrue(form.is_valid())

    def test_form_invalido_sem_titulo(self):
        form = TarefaForm(data={"titulo": ""})
        self.assertFalse(form.is_valid())

Dicas práticas

  • Comece testando as regras de negócio mais importantes.
  • Evite depender de serviços externos (e-mails, APIs) nos testes básicos.
  • Use setUp() para criar dados comuns usados em vários testes.
