BEP-041: Testes Automatizados

Introduzir o conceito de testes e sua importância

Por que escrever testes?

Testes automatizados ajudam a garantir que o código funciona hoje e continuará funcionando após mudanças.

Problemas sem testes

  • Alterar uma parte do código e quebrar outra sem perceber.
  • Medo de refatorar por não saber o que pode quebrar.
  • Bugs reaparecendo porque não há verificação automática.

Benefícios dos testes automatizados

  • Detectam regressões rapidamente (algo que funcionava e parou de funcionar).
  • Permitem refatorar com mais segurança.
  • Servem como documentação viva do comportamento esperado do sistema.
  • Reduzem o tempo gasto testando manualmente cada funcionalidade.

Teste manual x teste automatizado

# Teste manual (exemplo)
1. Abrir o navegador
2. Acessar /tarefas/
3. Clicar em "Nova tarefa"
4. Preencher o formulário
5. Conferir se a tarefa aparece na lista

# Teste automatizado (exemplo)
def test_criar_tarefa(self):
    response = self.client.post("/tarefas/nova/", data={"titulo": "Estudar testes"})
    self.assertEqual(response.status_code, 302)
    self.assertTrue(Tarefa.objects.filter(titulo="Estudar testes").exists())

O teste automatizado faz o trabalho repetitivo para você, sempre da mesma forma.
