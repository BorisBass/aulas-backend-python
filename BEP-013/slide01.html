BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Introdução ao UPDATE e DELETE

O que vamos aprender?

Nesta aula, vamos explorar os comandos SQL que permitem modificar e remover dados existentes em tabelas de banco de dados.

Comandos que Estudaremos

UPDATE

Atualizar registros existentes

DELETE

Remover registros da tabela

WHERE

Selecionar registros específicos

Boas Práticas

Evitar perda de dados

Importância da Cláusula WHERE

A cláusula WHERE é fundamental nos comandos UPDATE e DELETE, pois:

  • Especifica quais registros serão modificados ou removidos
  • Evita alterações acidentais em todos os registros
  • Permite operações precisas e controladas
  • É obrigatória na maioria dos casos práticos

Operações CRUD Completas

Agora que já conhecemos CREATE e READ, vamos completar o conjunto CRUD:

CREATE - Criar (INSERT)
READ - Ler (SELECT)
UPDATE - Atualizar (UPDATE)
DELETE - Deletar (DELETE)
