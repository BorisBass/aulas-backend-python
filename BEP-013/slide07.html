BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Boas Práticas

Por que seguir boas práticas?

As boas práticas em UPDATE e DELETE são essenciais para manter a integridade dos dados e evitar perdas acidentais. Elas garantem operações seguras e previsíveis.

Checklist de Segurança

WHERE Obrigatório

Sempre especificar quais registros

Verificar Primeiro

SELECT antes de UPDATE/DELETE

Backup

Fazer backup antes de operações críticas

Transações

Usar BEGIN/COMMIT/ROLLBACK

Padrões de Código

UPDATE Padrão:

-- 1. Verificar registros que serão afetados
SELECT id, nome, email FROM clientes
WHERE cidade = 'Salvador';
-- 2. Executar UPDATE
UPDATE clientes
SET categoria = 'VIP'
WHERE cidade = 'Salvador';
-- 3. Verificar resultado
SELECT COUNT(*) FROM clientes
WHERE categoria = 'VIP';

DELETE Padrão:

-- 1. Contar registros que serão deletados
SELECT COUNT(*) FROM logs
WHERE data_log < '2023-01-01';
-- 2. Ver alguns exemplos
SELECT * FROM logs
WHERE data_log < '2023-01-01'
LIMIT 5;
-- 3. Executar DELETE
DELETE FROM logs
WHERE data_log < '2023-01-01';

Operações em Lote

Para grandes volumes de dados, processe em lotes:

-- Processar 1000 registros por vez
DELETE FROM logs
WHERE data_log < '2023-01-01'
LIMIT 1000;
-- Repetir até não haver mais registros

Validações Importantes

Verificar Dependências

Antes de deletar, verificar se há registros relacionados

Validar Datas

Confirmar se as datas estão corretas

Confirmar IDs

Verificar se os IDs existem na tabela

Testar Relacionamentos

Verificar integridade referencial

Dicas Finais

  • Use nomes descritivos para variáveis e comentários
  • Teste em ambiente de desenvolvimento primeiro
  • Documente operações importantes para referência futura
  • Monitore performance em operações grandes
  • Tenha sempre um plano B para recuperação
