Exercícios: UPDATE

Contexto dos Exercícios

Vamos usar a tabela clientes com os seguintes dados:

CREATE TABLE clientes (
  id INTEGER PRIMARY KEY,
  nome TEXT,
  email TEXT,
  telefone TEXT,
  cidade TEXT,
  idade INTEGER,
  categoria TEXT
);
