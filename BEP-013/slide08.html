BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Exercícios: UPDATE

Preparação do Ambiente

Primeiro, vamos criar a tabela e inserir dados de exemplo:

-- 1. Criar tabela
CREATE TABLE clientes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome TEXT NOT NULL,
    email TEXT UNIQUE,
    telefone TEXT,
    cidade TEXT,
    idade INTEGER,
    categoria TEXT DEFAULT 'Normal'
);
-- 2. Inserir dados de exemplo
INSERT INTO clientes (nome, email, telefone, cidade, idade, categoria) VALUES
('João Silva', 'joao@email.com', '(71) 99999-1111', 'Salvador', 30, 'Normal'),
('Maria Santos', 'maria@email.com', '(71) 99999-2222', 'Feira de Santana', 25, 'Premium'),
('Pedro Costa', 'pedro@email.com', NULL, 'Salvador', 35, 'Normal'),
('Ana Oliveira', 'ana@email.com', '(71) 99999-4444', 'Camaçari', 28, 'VIP'),
('Carlos Lima', 'carlos@email.com', '(71) 99999-5555', 'Salvador', 22, 'Normal');

Exercício 1: Atualização Simples

Objetivo: Atualizar o email do cliente com ID 3 para "novo.email@exemplo.com"

-- 1. Verificar o cliente atual
SELECT * FROM clientes WHERE id = 3;
-- 2. Executar UPDATE
UPDATE clientes SET email = 'novo.email@exemplo.com' WHERE id = 3;
-- 3. Verificar resultado
SELECT * FROM clientes WHERE id = 3;

Exercício 2: Múltiplas Colunas

Objetivo: Atualizar telefone e categoria do cliente "João Silva"

-- 1. Verificar cliente atual
SELECT * FROM clientes WHERE nome = 'João Silva';
-- 2. Atualizar múltiplas colunas
UPDATE clientes
SET telefone = '(71) 99999-7777', categoria = 'Premium'
WHERE nome = 'João Silva';
-- 3. Verificar resultado
SELECT * FROM clientes WHERE nome = 'João Silva';

Exercício 3: Atualização Condicional

Objetivo: Atualizar categoria para "VIP" de todos os clientes de Salvador com mais de 25 anos

-- 1. Verificar quantos serão afetados
SELECT COUNT(*) FROM clientes WHERE cidade = 'Salvador' AND idade > 25;
-- 2. Ver quais clientes serão atualizados
SELECT * FROM clientes WHERE cidade = 'Salvador' AND idade > 25;
-- 3. Executar UPDATE
UPDATE clientes SET categoria = 'VIP'
WHERE cidade = 'Salvador' AND idade > 25;
-- 4. Verificar resultado
SELECT * FROM clientes WHERE categoria = 'VIP';

Exercício 4: Atualização com Cálculo

Objetivo: Aumentar a idade de todos os clientes em 1 ano

-- 1. Verificar idades atuais
SELECT nome, idade FROM clientes;
-- 2. Atualizar todas as idades
UPDATE clientes SET idade = idade + 1;
-- 3. Verificar resultado
SELECT nome, idade FROM clientes;

Exercício 5: Atualização com LIKE

Objetivo: Atualizar categoria para "Especial" de todos os clientes cujo nome começa com "Maria"

-- 1. Verificar clientes que serão afetados
SELECT * FROM clientes WHERE nome LIKE 'Maria%';
-- 2. Atualizar categoria
UPDATE clientes SET categoria = 'Especial'
WHERE nome LIKE 'Maria%';
-- 3. Verificar resultado
SELECT * FROM clientes WHERE categoria = 'Especial';
