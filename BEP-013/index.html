BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

🏠 Índice geral

Objetivos da Aula

  • Entender como atualizar registros existentes com UPDATE.
  • Dominar a cláusula WHERE para seleção precisa de registros.
  • Aprender a remover dados com o comando DELETE.
  • Conhecer cuidados e boas práticas para evitar perda de dados.
  • Completar exercícios da BEP-012 com UPDATE e DELETE.
  • Praticar operações seguras de modificação de dados.
