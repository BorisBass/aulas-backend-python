BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Prática no Google Colab

O que vamos praticar?

Vamos criar um ambiente completo para praticar UPDATE e DELETE com SQLite3 no Google Colab. Você poderá copiar e colar o código diretamente.

Configuração Inicial

Primeiro, vamos configurar o ambiente e criar as tabelas de exemplo:

# Configuração inicial
import sqlite3
from datetime import datetime, timedelta
# Conectar ao banco em memória
conn = sqlite3.connect(':memory:')
cursor = conn.cursor()

Criar Tabelas de Exemplo

Vamos criar tabelas com dados realistas para praticar:

# Criar tabela de clientes
cursor.execute('''
CREATE TABLE clientes (
id INTEGER PRIMARY KEY,
nome TEXT NOT NULL,
email TEXT UNIQUE,
telefone TEXT,
cidade TEXT,
idade INTEGER,
categoria TEXT DEFAULT 'Normal',
data_cadastro DATE DEFAULT CURRENT_DATE
)'''

Vamos inserir dados para praticar UPDATE e DELETE:

Praticar UPDATE

Vamos praticar diferentes tipos de UPDATE:

# 1. UPDATE simples - atualizar telefone
# Verificar antes
cursor.execute("SELECT id, nome, telefone FROM clientes WHERE id = 3")
print("Antes:", cursor.fetchone())
# Executar UPDATE
cursor.execute("UPDATE clientes SET telefone = '(71) 99999-3333' WHERE id = 3")
# Verificar depois
cursor.execute("SELECT id, nome, telefone FROM clientes WHERE id = 3")
print("Depois:", cursor.fetchone())

UPDATE com Múltiplas Condições

# 2. UPDATE com múltiplas condições
# Atualizar categoria de clientes de Salvador com mais de 25 anos
cursor.execute("SELECT COUNT(*) FROM clientes WHERE cidade = 'Salvador' AND idade > 25")
print("Clientes que serão atualizados:", cursor.fetchone()[0])
cursor.execute("UPDATE clientes SET categoria = 'VIP' WHERE cidade = 'Salvador' AND idade > 25")
# Verificar resultado
cursor.execute("SELECT nome, cidade, idade, categoria FROM clientes WHERE cidade = 'Salvador'")
for row in cursor.fetchall():
    print(row)

Praticar DELETE

Vamos praticar DELETE de forma segura:

# 3. DELETE seguro - remover clientes sem telefone
# Verificar quantos serão removidos
cursor.execute("SELECT COUNT(*) FROM clientes WHERE telefone IS NULL")
print("Clientes sem telefone:", cursor.fetchone()[0])
# Ver quais serão removidos
cursor.execute("SELECT id, nome FROM clientes WHERE telefone IS NULL")
print("Serão removidos:", cursor.fetchall())
# Executar DELETE
cursor.execute("DELETE FROM clientes WHERE telefone IS NULL")
# Verificar resultado
cursor.execute("SELECT COUNT(*) FROM clientes")
print("Clientes restantes:", cursor.fetchone()[0])

Transações Seguras

Vamos praticar operações com transações:

# 4. Operação com transação
try:
    cursor.execute("BEGIN")
    # Atualizar idade de todos os clientes
    cursor.execute("UPDATE clientes SET idade = idade + 1")
    # Verificar se está correto
    cursor.execute("SELECT nome, idade FROM clientes LIMIT 3")
    print("Idades atualizadas:", cursor.fetchall())
    # Confirmar transação
    cursor.execute("COMMIT")
    print("Transação confirmada!")
except Exception as e:
    cursor.execute("ROLLBACK")
    print(f"Erro: {e}. Transação desfeita.")

Visualizar Resultados

Vamos ver os resultados finais:

# Visualizar todos os clientes
cursor.execute("SELECT * FROM clientes")
clientes = cursor.fetchall()
for cliente in clientes:
    print(f"ID: {cliente[0]}, Nome: {cliente[1]}, Email: {cliente[2]}, Cidade: {cliente[4]}")
# Fechar conexão
conn.close()
