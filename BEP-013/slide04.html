UPDATE, DELETE e boas práticas para modificação de dados

Comando DELETE

O que é o DELETE?

O comando DELETE é usado para remover registros de uma tabela. É uma operação irreversível - uma vez deletado, o dado é perdido permanentemente (a menos que você tenha backup).

Sintaxe Básica

                        

                            DELETE FROM nome_da_tabela
WHERE condição;

Componentes do DELETE

DELETE FROM tabela

Especifica de qual tabela remover

WHERE condição

Seleciona quais registros remover

Exemplos Práticos

Remover cliente específico:

                        

                            -- Remover cliente com ID 10
DELETE FROM clientes
WHERE id = 10;

Remover registros antigos:

                        

                            -- Remover pedidos de 2020
DELETE FROM pedidos
WHERE data_pedido < '2021-01-01';

Remover registros com valor NULL:

                        

                            -- Remover clientes sem telefone
DELETE FROM clientes
WHERE telefone IS NULL;

CUIDADO EXTREMO!

DELETE é PERIGOSO! Sem WHERE, você remove TODOS os registros:

                        

                            -- ⚠️ PERIGOSO! Remove TODOS os clientes
DELETE FROM clientes;
-- ❌ SEM WHERE = TABELA VAZIA!

Proteção: Sempre Verifique Primeiro

NUNCA execute DELETE sem testar com SELECT:

                        

                            -- 1. PRIMEIRO: Veja o que será deletado
SELECT * FROM clientes
WHERE telefone IS NULL;
-- 2. Se estiver correto, execute o DELETE
DELETE FROM clientes
WHERE telefone IS NULL;

Diferença: DELETE vs DROP

DELETE

Remove registros (dados)

A tabela continua existindo

DROP TABLE

Remove a tabela inteira

Tabela e dados são perdidos
