BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Exercícios Combinados

Cenário Completo

Vamos trabalhar com um sistema de e-commerce que tem as tabelas clientes, produtos e pedidos. Você precisa realizar operações que combinam SELECT, UPDATE e DELETE.

Preparação do Ambiente

Primeiro, vamos criar as tabelas e inserir dados de exemplo:

                        

                            -- 1. Criar tabelas
CREATE TABLE clientes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome TEXT NOT NULL,
    email TEXT UNIQUE,
    telefone TEXT,
    cidade TEXT,
    idade INTEGER,
    categoria TEXT DEFAULT 'Normal',
    data_cadastro DATE DEFAULT CURRENT_DATE
);
                        

                            CREATE TABLE produtos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome TEXT NOT NULL,
    preco REAL,
    categoria TEXT,
    estoque INTEGER DEFAULT 0,
    data_cadastro DATE DEFAULT CURRENT_DATE
);
                        

                            CREATE TABLE pedidos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    cliente_id INTEGER,
    produto_id INTEGER,
    quantidade INTEGER,
    valor_total REAL,
    data_pedido DATE,
    status TEXT DEFAULT 'pendente',
    FOREIGN KEY (cliente_id) REFERENCES clientes(id),
    FOREIGN KEY (produto_id) REFERENCES produtos(id)
);

Exercício 1: Análise e Atualização

Objetivo: Identificar clientes inativos e atualizar sua categoria

                        

                            -- 1. Encontrar clientes sem pedidos nos últimos 6 meses
SELECT * FROM clientes
WHERE id NOT IN (SELECT cliente_id FROM pedidos WHERE data_pedido > date('now', '-6 months'));
-- 2. Atualizar categoria para 'Inativo'
UPDATE clientes SET categoria = 'Inativo'
WHERE id NOT IN (SELECT cliente_id FROM pedidos WHERE data_pedido > date('now', '-6 months'));
-- 3. Verificar quantos foram atualizados
SELECT COUNT(*) FROM clientes WHERE categoria = 'Inativo';

Exercício 2: Limpeza de Dados

Objetivo: Limpar dados inconsistentes

                        

                            -- 1. Encontrar produtos sem preço ou com preço zero
SELECT * FROM produtos WHERE preco IS NULL OR preco = 0;
-- 2. Atualizar preço para NULL
UPDATE produtos SET preco = NULL WHERE preco = 0;
-- 3. Remover produtos sem preço há mais de 1 ano
DELETE FROM produtos WHERE preco IS NULL AND data_cadastro < date('now', '-1 year');

Exercício 3: Manutenção de Pedidos

Objetivo: Gerenciar pedidos antigos

                        

                            -- 1. Atualizar status de pedidos antigos para 'Arquivado'
UPDATE pedidos SET status = 'Arquivado'
WHERE data_pedido < date('now', '-2 years');
-- 2. Remover pedidos cancelados de 2018
DELETE FROM pedidos WHERE status = 'cancelado' AND data_pedido < '2019-01-01';
-- 3. Verificar resultado final
SELECT status, COUNT(*) FROM pedidos GROUP BY status;

Exercício 4: Migração de Dados

Objetivo: Migrar dados de uma estrutura antiga

                        

                            -- 1. Encontrar clientes com telefone no formato antigo
SELECT * FROM clientes WHERE telefone LIKE '71%';
-- 2. Atualizar formato do telefone
UPDATE clientes SET telefone = '(71) ' || telefone
WHERE telefone LIKE '71%';
-- 3. Remover clientes duplicados (mesmo email)
DELETE FROM clientes WHERE id NOT IN (SELECT MIN(id) FROM clientes GROUP BY email);

Exercício 5: Relatório e Ação

Objetivo: Gerar relatório e tomar ações baseadas nele

                        

                            -- 1. Contar clientes por cidade
SELECT cidade, COUNT(*) FROM clientes GROUP BY cidade;
-- 2. Atualizar categoria para 'Premium' em cidades com +100 clientes
UPDATE clientes SET categoria = 'Premium'
WHERE cidade IN (SELECT cidade FROM clientes GROUP BY cidade HAVING COUNT(*) > 100);
-- 3. Remover clientes de cidades com menos de 5 clientes
DELETE FROM clientes WHERE cidade IN (SELECT cidade FROM clientes GROUP BY cidade HAVING COUNT(*) < 5);

Exercício 6: Operação Segura

Objetivo: Realizar operação crítica com segurança

                        

                            -- 1. Fazer backup dos dados que serão alterados
CREATE TABLE backup_produtos AS SELECT * FROM produtos;
-- 2. Usar transação (BEGIN/COMMIT/ROLLBACK)
BEGIN;
-- 3. Atualizar preços de produtos com aumento de 10%
UPDATE produtos SET preco = preco * 1.1;
-- 4. Verificar se tudo está correto antes de confirmar
SELECT AVG(preco) FROM produtos;

Desafio Final

Objetivo: Implementar sistema de limpeza automática

                        

                            -- Criar um script que:
-- 1. Identifica dados inconsistentes
SELECT 'Clientes sem pedidos', COUNT(*) FROM clientes WHERE id NOT IN (SELECT cliente_id FROM pedidos);
-- 2. Corrige automaticamente quando possível
UPDATE clientes SET categoria = 'Inativo' WHERE id NOT IN (SELECT cliente_id FROM pedidos);
-- 3. Remove dados obsoletos
DELETE FROM pedidos WHERE data_pedido < date('now', '-5 years');
-- 4. Gera relatório das ações realizadas
SELECT 'Limpeza concluída', datetime('now') AS data_limpeza;

Dicas para Resolver

  • Sempre comece com SELECT para entender os dados
  • Use transações para operações críticas
  • Teste em pequenos lotes antes de operações grandes
  • Documente cada passo para referência futura
  • Valide resultados após cada operação
