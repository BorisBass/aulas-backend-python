BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Exercícios: DELETE

Contexto dos Exercícios

Vamos usar as tabelas clientes e pedidos:

CREATE TABLE pedidos (
  id INTEGER PRIMARY KEY,
  cliente_id INTEGER,
  produto TEXT,
  valor REAL,
  data_pedido DATE,
  status TEXT
);

Objetivo: Remover o cliente com ID 5 (verificar se não tem pedidos primeiro)

Exercício 2: Remoção por Condição

Objetivo: Remover todos os clientes sem telefone

-- Condição: telefone IS NULL

Exercício 3: Remoção por Data

Objetivo: Remover pedidos antigos (anteriores a 2020)

-- Condição: data_pedido < '2020-01-01'

Exercício 4: Remoção por Status

Objetivo: Remover todos os pedidos cancelados

-- Condição: status = 'cancelado'

Exercício 5: Remoção com Múltiplas Condições

Objetivo: Remover pedidos cancelados de 2019

-- Condições:
-- - status = 'cancelado'
-- - data_pedido BETWEEN '2019-01-01' AND '2019-12-31'

Objetivo: Remover logs antigos processando 100 por vez

-- Usar LIMIT para processar em lotes
-- Repetir até não haver mais registros
