BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Comando UPDATE

O que é o UPDATE?

O comando UPDATE é usado para modificar dados existentes em uma tabela. Ele permite alterar valores de colunas específicas em registros que atendem a determinadas condições.

Sintaxe Básica

                        

                            UPDATE nome_da_tabela
SET coluna1 = novo_valor1, coluna2 = novo_valor2
WHERE condição;

Componentes do UPDATE

UPDATE tabela

Especifica qual tabela será modificada

SET coluna = valor

Define quais colunas e novos valores

WHERE condição

Seleciona quais registros modificar

Exemplo Prático

Vamos atualizar o email de um cliente específico:

                        

                            -- Atualizar email do cliente com ID 1
UPDATE clientes
SET email = 'novo.email@exemplo.com'
WHERE id = 1;

Múltiplas Colunas

Podemos atualizar várias colunas ao mesmo tempo:

                        

                            UPDATE clientes
SET email = 'novo@email.com',
    telefone = '(71) 99999-9999'
WHERE id = 1;

Cuidado Importante!

SEMPRE use WHERE no UPDATE! Sem a cláusula WHERE, TODOS os registros da tabela serão atualizados:

                        

                            -- PERIGOSO! Atualiza TODOS os clientes
UPDATE clientes
SET email = 'mesmo@email.com';
-- ❌ SEM WHERE = TODOS os registros alterados!
