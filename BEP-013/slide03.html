BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Cláusula WHERE em UPDATE

Por que WHERE é essencial?

A cláusula WHERE é o coração do comando UPDATE. Ela determina exatamente quais registros serão modificados, evitando alterações acidentais em dados que não deveriam ser tocados.

Tipos de Condições WHERE

Igualdade

WHERE id = 1

Comparação

WHERE idade > 18

LIKE

WHERE nome LIKE 'João%'

IN

WHERE cidade IN ('Salvador', 'Feira')

Exemplos Práticos

Atualizar por ID específico:

UPDATE clientes
SET telefone = '(71) 99999-8888'
WHERE id = 5;

Atualizar por cidade:

UPDATE clientes
SET cidade = 'Salvador'
WHERE cidade = 'SSA';

Atualizar por data:

UPDATE produtos
SET preco = preco * 1.1
WHERE data_cadastro < '2024-01-01';

Condições Múltiplas

Podemos combinar várias condições usando AND e OR:

-- Atualizar clientes de Salvador com mais de 25 anos
UPDATE clientes
SET categoria = 'VIP'
WHERE cidade = 'Salvador'
    AND idade > 25;

Verificação Antes de Atualizar

Sempre teste sua condição WHERE com SELECT primeiro:

-- 1. Primeiro, veja quais registros serão afetados
SELECT * FROM clientes
WHERE cidade = 'Salvador' AND idade > 25;
-- 2. Se estiver correto, execute o UPDATE
UPDATE clientes
SET categoria = 'VIP'
WHERE cidade = 'Salvador' AND idade > 25;
