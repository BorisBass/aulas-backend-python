BEP-013: Comandos de Atualização e Remoção

UPDATE, DELETE e boas práticas para modificação de dados

Cláusula WHERE em DELETE

WHERE é CRÍTICO no DELETE

No comando DELETE, a cláusula WHERE é ainda mais importante que no UPDATE. Sem ela, você pode perder TODOS os dados da tabela de uma vez!

Condições Comuns em DELETE

Por ID

WHERE id = 5

Por Data

WHERE data < '2020-01-01'

Por NULL

WHERE campo IS NULL

Por Lista

WHERE id IN (1,2,3)

Exemplos Práticos

Remover por ID específico:

-- Remover cliente específico
DELETE FROM clientes
WHERE id = 15;

Remover registros antigos:

-- Remover logs antigos (mais de 1 ano)
DELETE FROM logs
WHERE data_log < '2023-01-01';

Remover registros inválidos:

-- Remover produtos sem preço
DELETE FROM produtos
WHERE preco IS NULL
    OR preco <= 0;

Condições Múltiplas

Combine condições para ser mais específico:

-- Remover pedidos cancelados de 2020
DELETE FROM pedidos
WHERE status = 'cancelado'
    AND data_pedido < '2021-01-01';

Processo Seguro de DELETE

SEMPRE siga estes passos:

1. Verificar

SELECT para ver o que será deletado

2. Backup

Fazer backup se necessário

3. Executar

DELETE com WHERE específico

4. Confirmar

Verificar se funcionou corretamente

Exemplo de Processo Seguro

-- PASSO 1: Verificar o que será deletado
SELECT COUNT(*) FROM clientes
WHERE telefone IS NULL;
-- Resultado: 3 registros serão deletados
-- PASSO 2: Ver os registros específicos
SELECT id, nome FROM clientes
WHERE telefone IS NULL;
-- PASSO 3: Executar DELETE
DELETE FROM clientes
WHERE telefone IS NULL;
