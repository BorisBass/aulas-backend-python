BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Comparação: Representação de Dados

Tuplas vs Objetos - Como os dados são armazenados

📦 Versão 1: Tuplas

# Dados retornados como tupla
cursor.execute("SELECT * FROM alunos")
aluno = cursor.fetchone()
# aluno = (1, "João", 20, "Python", 9.5, "2025-01-15")

# Acesso aos dados
id_aluno = aluno[0]      # Por índice
nome = aluno[1]
idade = aluno[2]

# Problema: difícil lembrar índices
# aluno[3] é o quê mesmo?

🎯 Versão 2: Objetos

# Dados retornados como objeto
aluno = repository.buscar_por_id(1)
# aluno é uma instância de Aluno

# Acesso aos dados
id_aluno = aluno.id      # Por propriedade
nome = aluno.nome
idade = aluno.idade

# Vantagem: código mais legível
# aluno.curso é claro e autodocumentado

Exemplo Prático: Trabalhar com Dados

Versão 1: Tupla

# Buscar aluno
cursor.execute("SELECT * FROM alunos WHERE id = 1")
aluno = cursor.fetchone()

# Verificar se nota é maior que 8
if aluno[4] and aluno[4] > 8:
    print(f"{aluno[1]} tem nota {aluno[4]}")

# Atualizar nota
cursor.execute(
    "UPDATE alunos SET nota = ? WHERE id = ?",
    (9.0, aluno[0])
)

Versão 2: Objeto

# Buscar aluno
aluno = repository.buscar_por_id(1)

# Verificar se nota é maior que 8
if aluno.nota and aluno.nota > 8:
    print(f"{aluno.nome} tem nota {aluno.nota}")

# Atualizar nota
aluno.nota = 9.0
repository.atualizar(aluno)

Comparação

Aspecto Versão 1 (Tuplas) Versão 2 (Objetos)
Legibilidade ❌ Índices numéricos confusos ✅ Nomes descritivos claros
Manutenção ❌ Mudar ordem quebra código ✅ Mudanças isoladas na classe
Validação ❌ Manual em cada função ✅ Automática na classe
Documentação ❌ Precisa comentar índices ✅ Código autodocumentado
