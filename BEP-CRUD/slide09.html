BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Comparação: Reutilização

Funções vs Classes - Qual é mais reutilizável?

Versão 1: Reutilização de Funções

# Função pode ser importada
from crud_sistema.crud_operations import cadastrar_aluno

# Mas precisa passar cursor e conn toda vez
conn, cursor = conectar_banco()
cadastrar_aluno(cursor, conn)

# Problema: dependência explícita de cursor/conn
# Difícil usar em outros contextos

Limitação: Funções dependem de parâmetros externos (cursor, conn)

Versão 2: Reutilização de Classes

# Classe pode ser instanciada e reutilizada
from crud_sistema_v2 import Aluno, AlunoRepository, DatabaseManager

# Configurar uma vez
db = DatabaseManager('meu_banco.db')
db.conectar()
repo = AlunoRepository(db)

# Usar em qualquer lugar
aluno = Aluno(nome="João", idade=20)
repo.criar(aluno)

# Vantagem: estado encapsulado, fácil reutilizar

Vantagem: Classes encapsulam estado, mais fácil reutilizar em diferentes contextos

Exemplo: Usar em Outro Projeto

# Versão 2: Fácil reutilizar
from crud_sistema_v2 import Aluno, AlunoRepository, DatabaseManager

# Em um script diferente, API, etc.
db = DatabaseManager('outro_banco.db')
repo = AlunoRepository(db)

# Mesma classe, contexto diferente
aluno = Aluno(nome="Maria", curso="Python")
repo.criar(aluno)

# Versão 1: Mais difícil
# Precisa importar funções e gerenciar cursor/conn manualmente
