BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Exemplo Prático: Cadastrar Aluno

Comparação lado a lado do mesmo código

Versão 1: Procedural

# crud_operations.py
def cadastrar_aluno(cursor, conn):
    """Cadastra um novo aluno"""
    try:
        nome = input("Nome completo: ").strip()
        if not nome:
            print("❌ Nome é obrigatório!")
            return
        
        idade = input("Idade: ").strip()
        if idade:
            try:
                idade = int(idade)
            except ValueError:
                print("❌ Idade deve ser um número!")
                return
        
        curso = input("Curso: ").strip()
        
        nota = input("Nota (0-10): ").strip()
        if nota:
            try:
                nota = float(nota)
                if nota < 0 or nota > 10:
                    print("❌ Nota deve estar entre 0 e 10!")
                    return
            except ValueError:
                print("❌ Nota deve ser um número!")
                return
        
        # Inserir no banco
        cursor.execute('''
            INSERT INTO alunos (nome, idade, curso, nota)
            VALUES (?, ?, ?, ?)
        ''', (nome, idade, curso, nota))
        
        conn.commit()
        print(f"✅ Aluno '{nome}' cadastrado com sucesso!")
        
    except sqlite3.Error as e:
        print(f"❌ Erro no banco: {e}")

Versão 2: Orientada a Objetos

# sistema.py
def _cadastrar_aluno(self):
    """Cadastra um novo aluno"""
    self._menu.exibir_cabecalho("📝 CADASTRO DE NOVO ALUNO")
    
    try:
        nome = input("Nome completo: ").strip()
        if not nome:
            raise DadosInvalidosError("nome", motivo="Nome é obrigatório")
        
        idade_str = input("Idade: ").strip()
        idade = int(idade_str) if idade_str else None
        
        curso = input("Curso: ").strip() or None
        
        nota_str = input("Nota (0-10): ").strip()
        nota = float(nota_str) if nota_str else None
        
        # Criar objeto Aluno (validação automática)
        aluno = Aluno(nome=nome, idade=idade, curso=curso, nota=nota)
        
        # Salvar no banco
        aluno_criado = self._repository.criar(aluno)
        print(f"✅ Aluno '{aluno_criado.nome}' cadastrado! (ID: {aluno_criado.id})")
    
    except ValueError as e:
        raise DadosInvalidosError("dados", motivo=f"Formato inválido: {e}")
    except DadosInvalidosError:
        raise

Diferenças Principais

Aspecto Versão 1 Versão 2
Validação Manual em cada campo Automática no construtor de Aluno
Parâmetros Recebe cursor e conn Usa self._repository
Dados Tupla (nome, idade, curso, nota) Objeto Aluno
Exceções Genéricas (sqlite3.Error) Customizadas (DadosInvalidosError)
Linhas de código ~50 linhas ~30 linhas

Onde está a Validação na Versão 2?

A validação está na classe Aluno (models.py):

class Aluno:
    def __init__(self, nome, idade=None, curso=None, nota=None):
        # Validação automática
        self._validar_nome(nome)
        self._validar_idade(idade)
        self._validar_nota(nota)
        
        self._nome = nome
        self._idade = idade
        # ...
    
    def _validar_nota(self, nota):
        if nota is not None and (nota < 0 or nota > 10):
            raise DadosInvalidosError("nota", nota, "Nota deve estar entre 0 e 10")

Vantagem: Validação centralizada, reutilizável em qualquer lugar!
