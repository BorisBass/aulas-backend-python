BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Vantagens e Desvantagens

Quando usar cada abordagem

Versão 1: Procedural

✅ Vantagens

  • Simples: Fácil de entender para iniciantes
  • Direto: Código linear, sem abstrações
  • Rápido: Menos overhead, execução mais direta
  • Adequado: Para scripts pequenos e médios

❌ Desvantagens

  • Código duplicado: Validações repetidas
  • Difícil manutenção: Mudanças em vários lugares
  • Sem proteção: Dados podem ser modificados incorretamente
  • Limitado: Difícil escalar para sistemas grandes

Versão 2: Orientada a Objetos

✅ Vantagens

  • Organizado: Código bem estruturado
  • Reutilizável: Classes podem ser usadas em outros contextos
  • Extensível: Fácil adicionar funcionalidades
  • Protegido: Encapsulamento garante integridade
  • Profissional: Adequado para sistemas grandes

❌ Desvantagens

  • Complexo: Mais conceitos para aprender
  • Overhead: Mais código, mais abstrações
    • Over-engineering: Pode ser excessivo para projetos simples

Quando Usar Cada Uma?

Situação Versão 1 (Procedural) Versão 2 (OO)
Scripts simples ✅ Ideal ❌ Desnecessário
Projetos pequenos ✅ Adequado ⚠️ Pode ser excessivo
Projetos médios ⚠️ Funciona, mas... ✅ Recomendado
Projetos grandes ❌ Não recomendado ✅ Essencial
Equipe grande ❌ Difícil coordenar ✅ Facilita colaboração
