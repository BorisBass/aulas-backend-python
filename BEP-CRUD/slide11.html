Conceitos Utilizados

BEP-001 a BEP-010: Python Básico

  • ✅ Variáveis e tipos: Strings, inteiros, floats
  • ✅ Estruturas condicionais: if/elif/else para validações
  • ✅ Estruturas de repetição: while para menu principal
  • ✅ Funções: Organização do código em funções
  • ✅ Tratamento de erros: try/except básico

BEP-011 a BEP-016: Banco de Dados

  • ✅ SQLite: Banco de dados embutido
  • ✅ Conexão: sqlite3.connect()
  • ✅ Cursor: Execução de queries SQL
  • ✅ CRUD: CREATE, READ, UPDATE, DELETE
  • ✅ Módulos: Organização em arquivos separados
  • ✅ if __name__ == "__main__": Execução controlada

Exemplo: Aplicação dos Conceitos

# BEP-001 a BEP-010: Python básico
def cadastrar_aluno(cursor, conn):
    # Variáveis e tipos (BEP-002)
    nome = input("Nome: ").strip()  # String
    idade = input("Idade: ").strip()  # String
    
    # Estruturas condicionais (BEP-004)
    if not nome:
        print("❌ Nome é obrigatório!")
        return
    
    # Tratamento de erros (BEP-010)
    try:
        idade = int(idade)  # Conversão de tipo
    except ValueError:
        print("❌ Idade inválida!")
        return
    
    # BEP-011 a BEP-016: Banco de dados
    cursor.execute('''
        INSERT INTO alunos (nome, idade)
        VALUES (?, ?)
    ''', (nome, idade))
    conn.commit()  # Salvar no banco
