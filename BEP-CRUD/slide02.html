BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Versão 1: Estrutura Procedural

Como o sistema foi organizado na versão 1

Estrutura de Arquivos

crud_sistema/
├── __init__.py          # Inicialização do pacote
├── database.py          # Funções de conexão
├── crud_operations.py   # Funções CRUD
├── menu.py              # Funções de interface
└── main.py              # Programa principal

Características Principais

📦 Organização por Funções

  • database.py: conectar_banco(), fechar_conexao()
  • crud_operations.py: cadastrar_aluno(), listar_alunos(), etc.
  • menu.py: exibir_menu(), formatar_aluno()
  • main.py: Orquestra tudo com if/elif

Exemplo: database.py

# Versão 1: Funções simples
def conectar_banco():
    """Conecta ao banco de dados"""
    try:
        conn = sqlite3.connect('alunos.db')
        cursor = conn.cursor()
        # Criar tabela...
        return conn, cursor
    except sqlite3.Error as e:
        print(f"❌ Erro: {e}")
        return None, None

def fechar_conexao(conn):
    """Fecha conexão"""
    if conn:
        conn.close()
Características: Funções independentes, retornam tuplas, tratamento básico de erros

Exemplo: crud_operations.py

# Versão 1: Funções que recebem cursor e conn
def cadastrar_aluno(cursor, conn):
    """Cadastra um novo aluno"""
    nome = input("Nome: ").strip()
    if not nome:
        print("❌ Nome é obrigatório!")
        return
    
    # Validação manual
    idade = input("Idade: ").strip()
    if idade:
        try:
            idade = int(idade)
        except ValueError:
            print("❌ Idade inválida!")
            return
    
    # Inserir no banco
    cursor.execute('''
        INSERT INTO alunos (nome, idade, curso, nota)
        VALUES (?, ?, ?, ?)
    ''', (nome, idade, curso, nota))
    conn.commit()
Características: Validação manual em cada função, recebe cursor/conn como parâmetros

Pontos Fortes da Versão 1

  • ✅ Simples: Fácil de entender para iniciantes
  • ✅ Direto: Código linear e previsível
  • ✅ Modular: Funções organizadas em arquivos
  • ✅ Adequado: Para projetos pequenos e médios
