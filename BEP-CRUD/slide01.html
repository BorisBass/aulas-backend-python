BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Introdução: Duas Versões do Mesmo Sistema

Apresentação das duas versões do CRUD

Contexto

Durante o curso, desenvolvemos um Sistema CRUD de Gerenciamento de Alunos que evoluiu junto com nosso aprendizado:

  • ✅ BEP-001 a BEP-010: Aprendemos Python básico
  • ✅ BEP-011 a BEP-016: Aprendemos banco de dados e criamos o CRUD (Versão 1)
  • ✅ BEP-017 a BEP-022: Aprendemos POO e refatoramos o CRUD (Versão 2)

Versão 1: Procedural

Localização: BEP-016/crud_sistema/

  • ✅ Funções organizadas em módulos
  • ✅ Dados em tuplas e dicionários
  • ✅ Validação manual
  • ✅ Conceitos: BEP-001 a BEP-016

Paradigma: Programação Procedural

Versão 2: Orientada a Objetos

Localização: BEP-016/crud_sistema_v2/

  • ✅ Classes e objetos
  • ✅ Dados encapsulados em objetos
  • ✅ Validação automática
  • ✅ Conceitos: BEP-017 a BEP-022

Paradigma: Programação Orientada a Objetos

Por que Comparar?

🎯 Objetivos da Comparação:

  • Ver os mesmos conceitos aplicados de formas diferentes
  • Entender vantagens e desvantagens de cada abordagem
  • Compreender quando usar cada paradigma
  • Consolidar o aprendizado das BEP's

📚 O que Vamos Comparar:

  • Estrutura e organização do código
  • Representação de dados
  • Validação e encapsulamento
  • Tratamento de exceções
  • Reutilização e manutenção

Importante

Nenhuma versão é "melhor" que a outra! Cada uma tem seu lugar:

  • ✅ Procedural: Simples, direto, fácil de entender para iniciantes
  • ✅ OO: Organizado, extensível, adequado para sistemas maiores
  • ✅ Escolha: Depende do contexto, tamanho do projeto e equipe
