BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Comparação: Organização do Código

Módulos vs Classes - Estrutura e responsabilidades

Versão 1: Organização por Módulos

crud_sistema/
├── database.py          # Funções de BD
│   ├── conectar_banco()
│   └── fechar_conexao()
├── crud_operations.py   # Funções CRUD
│   ├── cadastrar_aluno()
│   ├── listar_alunos()
│   └── ...
├── menu.py              # Funções de interface
│   └── exibir_menu()
└── main.py              # Orquestração

Características: Funções agrupadas por responsabilidade, mas sem estado compartilhado

Versão 2: Organização por Classes

crud_sistema_v2/
├── models.py            # Entidades
│   └── class Aluno
├── database.py          # Gerenciamento de BD
│   └── class DatabaseManager
├── repository.py        # Operações CRUD
│   └── class AlunoRepository
├── menu.py              # Interface
│   └── class Menu
└── sistema.py           # Orquestrador
    └── class SistemaAlunos

Características: Classes com responsabilidades bem definidas, estado encapsulado

Comparação de Responsabilidades

Responsabilidade Versão 1 Versão 2
Representar Aluno Tupla genérica Classe Aluno
Gerenciar BD Funções em database.py Classe DatabaseManager
Operações CRUD Funções em crud_operations.py Classe AlunoRepository
Interface Funções em menu.py Classe Menu
Orquestração main.py com if/elif Classe SistemaAlunos
