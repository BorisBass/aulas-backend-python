Sobre esta Aula

Esta aula compara duas versões do mesmo sistema CRUD de gerenciamento de alunos. A versão 1 foi desenvolvida usando programação procedural (BEP-001 a BEP-016), enquanto a versão 2 foi refatorada usando programação orientada a objetos (BEP-017 a BEP-022). Através desta comparação, os alunos podem ver na prática como os mesmos conceitos podem ser implementados de formas diferentes, entender as vantagens e desvantagens de cada abordagem, e aprender quando usar cada paradigma. A metodologia combina análise comparativa detalhada com exemplos práticos lado a lado, permitindo uma compreensão clara das diferenças entre programação procedural e orientada a objetos.
