BEP-CRUD: Comparação entre Versões do Sistema CRUD

Procedural vs Orientado a Objetos

Versão 2: Estrutura Orientada a Objetos

Como o sistema foi reorganizado na versão 2

Estrutura de Arquivos

crud_sistema_v2/
├── __init__.py          # Inicialização do pacote
├── models.py            # Classe Aluno (entidade)
├── database.py          # Classe DatabaseManager
├── repository.py        # Classe AlunoRepository
├── menu.py              # Classe Menu
├── sistema.py           # Classe SistemaAlunos
└── exceptions.py        # Exceções customizadas

Características Principais

📦 Organização por Classes

  • models.py: Classe Aluno (entidade com validação)
  • database.py: Classe DatabaseManager (gerencia conexões)
  • repository.py: Classe AlunoRepository (operações CRUD)
  • menu.py: Classe Menu (interface)
  • sistema.py: Classe SistemaAlunos (orquestrador)

Exemplo: database.py

# Versão 2: Classe com métodos
class DatabaseManager:
    def __init__(self, db_name='alunos_v2.db'):
        self._db_name = db_name
        self._connection = None
    
    def conectar(self):
        """Conecta ao banco"""
        if not self._connection:
            self._connection = sqlite3.connect(self._db_name)
            self._criar_tabela()
        return self._connection
    
    @contextmanager
    def get_cursor(self):
        """Context manager para cursor"""
        yield self._connection.cursor()
        self._connection.commit()
Características: Estado encapsulado, context manager, tratamento de erros com exceções customizadas

Exemplo: models.py

# Versão 2: Classe com encapsulamento
class Aluno:
    def __init__(self, nome, idade=None, curso=None, nota=None):
        # Validação automática
        self._validar_nome(nome)
        self._validar_nota(nota)
        
        # Atributos privados
        self._nome = nome
        self._idade = idade
        self._nota = nota
    
    @property
    def nome(self):
        return self._nome
    
    @nome.setter
    def nome(self, valor):
        self._validar_nome(valor)
        self._nome = valor
Características: Encapsulamento, validação automática, propriedades com getters/setters

Pontos Fortes da Versão 2

  • ✅ Organizado: Responsabilidades bem definidas
  • ✅ Encapsulado: Dados protegidos e validados
  • ✅ Extensível: Fácil adicionar funcionalidades
  • ✅ Reutilizável: Classes podem ser usadas em outros contextos
  • ✅ Profissional: Adequado para sistemas maiores
