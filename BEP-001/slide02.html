BEP-001: Introdução ao Python

Seu primeiro contato com a linguagem Python

O que é Python?

🐍 História do Python

Python foi criado por Guido van Rossum em 1991. O nome vem do grupo de comédia britânico "Monty Python's Flying Circus".

# Python 1.0 - 1994 # Python 2.0 - 2000 # Python 3.0 - 2008 (versão atual)

📝 Características Principais

  • Linguagem interpretada: Código executado linha por linha
  • Linguagem de alto nível: Próxima à linguagem humana
  • Multiplataforma: Windows, Mac, Linux
  • Open source: Gratuito e código aberto
  • Orientada a objetos: Suporte completo a OOP

Curiosidade

Python é usado por empresas como Google, Netflix, Instagram, Spotify e NASA!

🎯 Por que Python é Popular?

  • Sintaxe simples: Fácil de ler e escrever
  • Grande comunidade: Muitos recursos e ajuda
  • Bibliotecas ricas: Milhares de módulos disponíveis
  • Versatilidade: Múltiplas aplicações
💡 Exemplo: Python vs Outras Linguagens
# Python (simples) print("Hello World") # Java (mais complexo) System.out.println("Hello World"); # C++ (ainda mais complexo) cout << "Hello World" << endl;
