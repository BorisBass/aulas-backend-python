💬 Comentários em Python

Comentários são textos que explicam o código e são ignorados pelo Python.

# Este é um comentário de linha única print("Hello World") # Comentário no final da linha """ Este é um comentário de múltiplas linhas usando três aspas """

📝 Tipos de Comentários

  • # - Comentário de linha única
  • """ - Comentário de múltiplas linhas
  • ''' - Comentário de múltiplas linhas (alternativo)
