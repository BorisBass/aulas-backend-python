Seu primeiro contato com a linguagem Python

Exercícios Práticos

🎯 Exercício 1: Apresentação Pessoal

Solicite nome, idade e cidade, e mostre uma mensagem formatada.

nome = input("Nome: ")
idade = input("Idade: ")
cidade = input("Cidade: ")
print(f"Olá! Meu nome é {nome}, tenho {idade} anos e moro em {cidade}.")

🎯 Exercício 2: Calculadora Simples

Some dois números digitados pelo usuário.

a = float(input("Primeiro número: "))
b = float(input("Segundo número: "))
print(f"Soma: {a + b}")

🎯 Exercício 3: Conversor de Temperatura

Converta °C para °F usando F = C * 9/5 + 32.

c = float(input("Temperatura em °C: "))
f = c * 9/5 + 32
print(f"{c}°C = {f}°F")
