Seu primeiro contato com a linguagem Python

Variáveis Simples

🏷️ O que são Variáveis?

Variáveis são "caixas" que armazenam dados na memória do computador.

# Criando variáveis
nome = "Maria"
idade = 25
altura = 1.65
ativo = True

# Exibindo variáveis
print(nome)
print(idade)
print(altura)
print(ativo)

📊 Tipos de Dados Básicos

  • str (string): Texto - "Olá mundo"
  • int (inteiro): 42
  • float (decimal): 3.14
  • bool (booleano): True ou False
💡 Exemplo Prático
# Informações pessoais
nome = "Ana Silva"
idade = 30
salario = 5000.50
ativo = True

print(f"Nome: {nome}")
print(f"Idade: {idade} anos")
print(f"Salário: R$ {salario}")
print(f"Ativo: {ativo}")

Dica

Python determina automaticamente o tipo da variável baseado no valor atribuído!
