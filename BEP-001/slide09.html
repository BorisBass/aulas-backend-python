Entrada de Dados

⌨️ Função input()

A função input() lê texto digitado pelo usuário.

# Entrada de texto nome = input("Digite seu nome: ") print(f"Olá, {nome}!") # Entrada de número (conversão de tipo) idade = int(input("Digite sua idade: ")) altura = float(input("Digite sua altura (m): ")) print(f"Idade: {idade}, Altura: {altura}")

🔄 Conversão de Tipos

  • int(): para inteiros
  • float(): para decimais
  • str(): para string
  • bool(): para booleano
💡 Exemplo Prático
# Calculadora de IMC print("=== Calculadora de IMC ===") peso = float(input("Peso (kg): ")) altura = float(input("Altura (m): ")) imc = peso / (altura ** 2) print(f"Seu IMC é: {imc:.2f}")

Dica

input() sempre retorna string. Converta para o tipo correto quando necessário.
