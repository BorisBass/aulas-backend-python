Seu primeiro contato com a linguagem Python

Dicas e Boas Práticas

💡 Dicas para Programar em Python

  • Nomes descritivos: use idade_usuario ao invés de i
  • Comente com moderação: explique o porquê
  • Teste com frequência: rode o código a cada mudança
  • Consistência: mantenha o mesmo estilo

📝 Exemplos

# ✅ Bom
nome_completo = "João Silva"
idade = 25
print(f"Nome: {nome_completo}, Idade: {idade}")

# ❌ Ruim
n = "João Silva"
i = 25
print("Nome:", n, "Idade:", i)
