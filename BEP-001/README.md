# BEP-001: Introdução ao Python

## 📚 Visão Geral
Este módulo apresenta a linguagem Python para iniciantes, cobrindo conceitos básicos, ambiente de desenvolvimento e primeiros programas.

## 🎯 Objetivos de Aprendizagem
- ✅ Compreender o que é Python e sua história
- ✅ Identificar vantagens e aplicações do Python
- ✅ Configurar ambiente de desenvolvimento
- ✅ Escrever primeiro programa em Python
- ✅ Conhecer sintaxe básica e comentários
- ✅ Trabalhar com variáveis e entrada de dados

## 📂 Estrutura do Projeto
```
BEP-001/
├── index.html                       # Página inicial
├── slide01-12.html                  # Slides da aula
├── style.css                        # Estilos
├── script.js                        # Navegação
├── exercicios_introducao_colab.py   # Exercícios práticos
├── plano_aula_introducao.md         # Plano de aula
└── README.md                        # Este arquivo
```

## 🚀 Como Usar
1. Abra `index.html` no navegador
2. Navegue pelos slides
3. Faça os exercícios no Google Colab
4. Consulte o plano de aula
