BEP-001: Introdução ao Python

Seu primeiro contato com a linguagem Python

Primeiro Programa

👋 Hello World em Python

Todo programador começa com um "Hello World". Vamos fazer o nosso!

# Meu primeiro programa em Python
print("Hello World!")
print("Olá, mundo!")
print("Bem-vindo ao Python!")

📝 Explicando o Código

  • # - Comentário (ignorado pelo Python)
  • print() - Função que exibe texto na tela
  • "texto" - String (texto entre aspas)
  • ; - Não é obrigatório em Python
💡 Teste Você Mesmo

Abra o Google Colab e digite:

print("Meu nome é [seu nome]")
print("Estou aprendendo Python!")
print("Python é incrível!")

Dica

No Python, a indentação (espaços no início da linha) é muito importante. Vamos aprender isso em breve!

Cuidado

Use aspas duplas (") ou simples (') para strings, mas seja consistente!
