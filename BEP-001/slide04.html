BEP-001: Introdução ao Python

Seu primeiro contato com a linguagem Python

Ambiente de Desenvolvimento

🛠️ Google Colab

O Google Colab é uma plataforma gratuita que permite executar código Python diretamente no navegador.

Vantagens do Colab

  • Não precisa instalar nada
  • Execução na nuvem
  • Compartilhamento fácil
  • Bibliotecas pré-instaladas
  • Interface amigável

📱 Outras Opções

  • IDEs: PyCharm, VS Code, Spyder
  • Editores: Sublime Text, Atom
  • Jupyter Notebook: Similar ao Colab
  • Terminal: Python interativo

Dica

Para iniciantes, recomendamos começar com Google Colab. É gratuito, fácil de usar e não requer instalação!

💡 Como Acessar o Google Colab
  1. Acesse: colab.research.google.com
  2. Faça login com sua conta Google
  3. Clique em "Novo notebook"
  4. Comece a programar!
