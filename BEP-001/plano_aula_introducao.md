# Plano de Aula: Introdução ao Python (BEP-001)

## Informações Gerais
- **Disciplina:** Back End com Python
- **Aula:** BEP-001
- **Tema:** Introdução ao Python
- **Duração:** 2 horas
- **Público-alvo:** Iniciantes em programação

## Objetivo Geral
Apresentar a linguagem Python, suas características principais, aplicações e preparar o ambiente de desenvolvimento.

## Objetivos Específicos
1. Compreender o que é Python e sua história
2. Identificar as vantagens e aplicações do Python
3. Configurar ambiente de desenvolvimento (Google Colab)
4. Escrever o primeiro programa em Python
5. Conhecer sintaxe básica e comentários
6. Trabalhar com variáveis simples e entrada de dados

## Conteúdo Programático
1. **Introdução (15 min)** - Apresentação e objetivos
2. **O que é Python (20 min)** - História e características
3. **Por que Python (20 min)** - Vantagens e aplicações
4. **Ambiente de Desenvolvimento (20 min)** - Google Colab
5. **Primeiro Programa (20 min)** - Hello World
6. **Sintaxe Básica (15 min)** - Estrutura do código
7. **Comentários (10 min)** - Documentação do código
8. **Variáveis Simples (15 min)** - Armazenamento de dados
9. **Entrada de Dados (15 min)** - Interação com usuário
10. **Exercícios Práticos (30 min)** - Atividades hands-on
11. **Dicas e Boas Práticas (10 min)** - Recomendações
12. **Resumo (10 min)** - Revisão e próximos passos
