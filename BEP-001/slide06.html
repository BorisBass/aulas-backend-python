Seu primeiro contato com a linguagem Python

Sintaxe Básica

📝 Regras de Sintaxe do Python

  • Indentação: Espaços no início da linha são importantes
  • Comentários: Use # para comentários de linha
  • Strings: Texto entre aspas simples ou duplas
  • Case sensitive: Maiúsculas e minúsculas importam
# Comentário de linha nome = "Python" # Variável print(nome) # Função # Indentação é importante if True: print("Dentro do if") print("Também dentro")

🔤 Nomes de Variáveis

  • Podem conter letras, números e _
  • Não podem começar com número
  • Não podem usar palavras reservadas
  • Use nomes descritivos
💡 Exemplos de Nomes Válidos
# Válidos nome = "João" idade = 25 nota_final = 8.5 contador = 0 # Inválidos # 2nome = "João" # Erro! # if = 5 # Erro!

Dica Importante

Python usa indentação para definir blocos de código. Use 4 espaços ou 1 tab, mas seja consistente!
