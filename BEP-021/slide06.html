BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Exemplo: Composição - Carro e Motor

Primeiro exemplo prático de composição

Cenário

Vamos modelar um sistema onde:

  • Um Carro possui um Motor
  • O motor não pode existir sem o carro
  • O motor é criado quando o carro é criado
  • Se o carro é destruído, o motor também é
Pergunta-chave: Motor pode existir sem Carro? NÃO → É Composição!

Implementação Completa

class Motor:
    def __init__(self, potencia, tipo_combustivel):
        self.potencia = potencia  # em CV
        self.tipo_combustivel = tipo_combustivel
        self.ligado = False
    
    def ligar(self):
        if not self.ligado:
            self.ligado = True
            return f"Motor {self.potencia}CV ({self.tipo_combustivel}) ligado!"
        return "Motor já está ligado!"
    
    def desligar(self):
        if self.ligado:
            self.ligado = False
            return "Motor desligado!"
        return "Motor já está desligado!"
    
    def __str__(self):
        return f"Motor {self.potencia}CV - {self.tipo_combustivel}"

class Carro:
    def __init__(self, marca, modelo, potencia_motor, tipo_combustivel):
        self.marca = marca
        self.modelo = modelo
        # COMPOSIÇÃO: Motor é criado DENTRO do Carro
        self.motor = Motor(potencia_motor, tipo_combustivel)
        # Motor não pode existir sem Carro!
    
    def ligar(self):
        """Liga o carro (que liga o motor)"""
        return self.motor.ligar()
    
    def desligar(self):
        """Desliga o carro (que desliga o motor)"""
        return self.motor.desligar()
    
    def info(self):
        """Mostra informações do carro"""
        print(f"Carro: {self.marca} {self.modelo}")
        print(f"Motor: {self.motor}")
        print(f"Status: {'Ligado' if self.motor.ligado else 'Desligado'}")

# ===== USO =====

# Criar carro (motor é criado automaticamente)
carro1 = Carro("Toyota", "Corolla", 150, "Flex")
carro2 = Carro("Honda", "Civic", 180, "Gasolina")

# O motor já existe como parte do carro
carro1.info()
# Carro: Toyota Corolla
# Motor: Motor 150CV - Flex
# Status: Desligado

# Ligar o carro (que liga o motor)
print(carro1.ligar())
# Motor 150CV (Flex) ligado!

# Acessar o motor diretamente
print(carro1.motor.potencia)  # 150
print(carro1.motor.tipo_combustivel)  # Flex

# Motor não pode existir separadamente
# Se tentarmos criar um motor sozinho:
# motor_solo = Motor(200, "Diesel")  # Técnicamente possível,
# mas conceitualmente errado! Motor deveria ser parte de algo.

# Se o carro for destruído (del carro1),
# o motor também é destruído automaticamente

Características Observadas

  • ✅ Motor criado dentro do Carro: O motor é instanciado no construtor do carro
  • ✅ Dependência forte: O motor não pode existir sem o carro
  • ✅ Ciclo de vida conjunto: Se o carro é destruído, o motor também é
  • ✅ Propriedade: O carro é dono do motor
  • ✅ Relação permanente: Não podemos "desmatricular" o motor do carro

Importante

Em Python, tecnicamente você pode criar um Motor separadamente:

motor_solo = Motor(200, "Diesel")  # Funciona tecnicamente

Mas conceitualmente, isso não faz sentido no contexto de composição. O motor deveria sempre ser parte de algo (carro, caminhão, etc.).

Dica: A composição é mais sobre design conceitual do que sobre restrições técnicas da linguagem.
