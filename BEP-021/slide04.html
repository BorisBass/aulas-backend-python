BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Diferença: Associação vs Composição

Comparação detalhada e quando usar cada uma

Associação

  • Relação: "Tem um" (flexível)
  • Independência: Objetos são independentes
  • Existência: Podem existir separadamente
  • Criação: Objetos criados separadamente
  • Destruição: Um pode ser destruído sem afetar o outro
  • Exemplo: Aluno ↔ Curso

Composição

  • Relação: "É parte de" (forte)
  • Dependência: Objeto parte depende do todo
  • Existência: Parte não existe sem o todo
  • Criação: Parte criada dentro do todo
  • Destruição: Se o todo é destruído, a parte também é
  • Exemplo: Motor → Carro

Tabela Comparativa

Característica Associação Composição
Força da relação Fraca (flexível) Forte (permanente)
Independência ✅ Objetos independentes ❌ Parte depende do todo
Criação Separada Conjunta (dentro do todo)
Destruição Independente Conjunta (se todo é destruído)
Compartilhamento ✅ Pode ser compartilhado ❌ Não pode ser compartilhado
Pergunta-chave "Pode existir sem?" → SIM "Pode existir sem?" → NÃO

Como Decidir?

Faça a pergunta-chave:

"O objeto parte pode existir sem o objeto todo?"

  • SIM → Use Associação
  • NÃO → Use Composição

Exemplos de Decisão:

  • Aluno e Curso: Aluno pode existir sem curso? SIM → Associação
  • Carro e Motor: Motor pode existir sem carro? NÃO → Composição
  • Professor e Disciplina: Professor pode existir sem disciplina? SIM → Associação
  • Livro e Página: Página pode existir sem livro? NÃO → Composição

Comparação de Código

Associação (Aluno ↔ Curso)

# Objetos criados separadamente
aluno = Aluno("João")
curso = Curso("Python")

# Associação criada depois
aluno.curso = curso

# Podem existir separadamente
aluno.curso = None  # OK!
# aluno e curso ainda existem

Composição (Carro → Motor)

# Motor criado DENTRO do Carro
carro = Carro("Toyota", 150)
# carro.motor já existe!

# Motor não pode existir sozinho
# Se carro for destruído,
# motor também é destruído
