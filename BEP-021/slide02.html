BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

O que é Associação?

Conceito e características da associação

Definição

Associação é um relacionamento entre duas classes onde os objetos são independentes e podem existir separadamente.

É uma relação de "usa" ou "tem referência a".

Características da Associação

1. Independência

Os objetos podem existir separadamente. A destruição de um não necessariamente destrói o outro.

2. Relação Flexível

A relação pode ser criada, modificada ou removida durante a execução do programa.

3. Múltiplas Relações

Um objeto pode estar associado a múltiplos objetos do mesmo tipo ou de tipos diferentes.

4. Relação "Tem um"

Geralmente expressa como "tem um" ou "usa". Exemplo: "Aluno tem um Curso" ou "Professor usa Sala".

Analogia do Mundo Real

Exemplo 1: Aluno e Curso

  • Um Aluno pode estar matriculado em um Curso
  • O aluno pode existir sem estar em um curso
  • O curso pode existir sem alunos
  • É uma relação flexível

Exemplo 2: Professor e Disciplina

  • Um Professor pode lecionar várias Disciplinas
  • Uma disciplina pode ter vários professores
  • Ambos podem existir independentemente
  • É uma relação múltipla

Implementação em Python

Associação é implementada através de referências entre objetos:

class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.curso = None  # Referência ao objeto Curso
    
    def matricular(self, curso):
        self.curso = curso  # Associação criada!
        print(f"{self.nome} matriculado em {curso.nome}")

class Curso:
    def __init__(self, nome):
        self.nome = nome

# Criar objetos independentes
aluno = Aluno("João")
curso = Curso("Python")

# Criar associação
aluno.matricular(curso)  # João matriculado em Python

# Objetos ainda são independentes
# Podemos remover a associação:
aluno.curso = None  # Associação removida, mas objetos ainda existem
