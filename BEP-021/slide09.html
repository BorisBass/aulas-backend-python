BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Exemplo: Sistema de E-commerce

Modelagem completa com múltiplas relações

Cenário

Vamos modelar um sistema de e-commerce com:

  • Produto: Tem itens (Composição) e pode estar em pedidos (Associação)
  • Item: É parte de um produto (Composição)
  • Cliente: Pode fazer pedidos (Associação)
  • Pedido: Contém produtos (Associação) e tem endereço (Composição)
  • Endereco: É parte de um pedido (Composição)

Implementação

# ===== COMPOSIÇÃO: Item é parte de Produto =====
class Item:
    def __init__(self, nome, quantidade):
        self.nome = nome
        self.quantidade = quantidade

class Produto:
    def __init__(self, nome, preco, itens_info):
        self.nome = nome
        self.preco = preco
        # COMPOSIÇÃO: Itens são criados dentro do Produto
        self.itens = [Item(nome, qtd) for nome, qtd in itens_info]
    
    def __str__(self):
        return f"{self.nome} - R$ {self.preco:.2f}"

# ===== COMPOSIÇÃO: Endereco é parte de Pedido =====
class Endereco:
    def __init__(self, rua, numero, cidade):
        self.rua = rua
        self.numero = numero
        self.cidade = cidade
    
    def __str__(self):
        return f"{self.rua}, {self.numero} - {self.cidade}"

# ===== ASSOCIAÇÃO: Pedido contém Produtos =====
class Pedido:
    def __init__(self, numero, endereco_info):
        self.numero = numero
        # COMPOSIÇÃO: Endereco é criado dentro do Pedido
        self.endereco = Endereco(*endereco_info)
        self.produtos = []  # ASSOCIAÇÃO: lista de Produtos
        self.cliente = None  # ASSOCIAÇÃO: referência ao Cliente
    
    def adicionar_produto(self, produto, quantidade):
        """Cria associação com Produto"""
        self.produtos.append((produto, quantidade))
    
    def calcular_total(self):
        total = sum(produto.preco * qtd for produto, qtd in self.produtos)
        return total
    
    def info(self):
        print(f"Pedido #{self.numero}")
        print(f"Endereço: {self.endereco}")
        if self.cliente:
            print(f"Cliente: {self.cliente.nome}")
        print("Produtos:")
        for produto, qtd in self.produtos:
            print(f"  - {produto.nome} x{qtd} = R$ {produto.preco * qtd:.2f}")
        print(f"Total: R$ {self.calcular_total():.2f}")

# ===== ASSOCIAÇÃO: Cliente faz Pedidos =====
class Cliente:
    def __init__(self, nome, email):
        self.nome = nome
        self.email = email
        self.pedidos = []  # ASSOCIAÇÃO: lista de Pedidos
    
    def fazer_pedido(self, pedido):
        """Cria associação com Pedido"""
        pedido.cliente = self  # Bidirecional
        self.pedidos.append(pedido)
        print(f"Pedido #{pedido.numero} criado para {self.nome}")
    
    def listar_pedidos(self):
        print(f"\nPedidos de {self.nome}:")
        for pedido in self.pedidos:
            print(f"  Pedido #{pedido.numero} - Total: R$ {pedido.calcular_total():.2f}")

# ===== USO =====

# Criar produtos (itens são criados automaticamente - COMPOSIÇÃO)
produto1 = Produto("Notebook", 2500.00, [("Tela", 1), ("Teclado", 1), ("Bateria", 1)])
produto2 = Produto("Mouse", 50.00, [("Botão esquerdo", 1), ("Botão direito", 1)])

# Criar cliente
cliente = Cliente("João Silva", "joao@email.com")

# Criar pedido (endereco é criado automaticamente - COMPOSIÇÃO)
pedido1 = Pedido(1001, ("Rua A", 123, "Salvador"))
pedido1.adicionar_produto(produto1, 1)  # ASSOCIAÇÃO
pedido1.adicionar_produto(produto2, 2)   # ASSOCIAÇÃO

# Cliente faz pedido (ASSOCIAÇÃO)
cliente.fazer_pedido(pedido1)

# Mostrar informações
pedido1.info()
cliente.listar_pedidos()

Relações Identificadas

Composição:

  • Produto → Itens: Itens são criados dentro do produto
  • Pedido → Endereco: Endereco é criado dentro do pedido

Associação:

  • Pedido ↔ Produtos: Pedido contém produtos (múltiplos)
  • Cliente ↔ Pedidos: Cliente faz pedidos (múltiplos, bidirecional)
