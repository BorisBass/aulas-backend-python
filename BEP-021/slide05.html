BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Exemplo: Associação - Aluno e Curso

Primeiro exemplo prático de associação

Cenário

Vamos modelar um sistema onde:

  • Um Aluno pode estar matriculado em um Curso
  • Um aluno pode existir sem estar em um curso
  • Um curso pode existir sem alunos
  • A relação pode ser criada, modificada ou removida
Pergunta-chave: Aluno pode existir sem Curso? SIM → É Associação!

Implementação Completa

class Curso:
    def __init__(self, nome, codigo):
        self.nome = nome
        self.codigo = codigo
    
    def __str__(self):
        return f"{self.nome} ({self.codigo})"

class Aluno:
    def __init__(self, nome, matricula):
        self.nome = nome
        self.matricula = matricula
        self.curso = None  # Associação: referência ao Curso
    
    def matricular(self, curso):
        """Cria associação com um curso"""
        if self.curso is not None:
            print(f"{self.nome} já está matriculado em {self.curso.nome}")
        else:
            self.curso = curso  # Associação criada!
            print(f"{self.nome} matriculado em {curso.nome}")
    
    def desmatricular(self):
        """Remove associação com o curso"""
        if self.curso is not None:
            curso_anterior = self.curso.nome
            self.curso = None  # Associação removida!
            print(f"{self.nome} desmatriculado de {curso_anterior}")
        else:
            print(f"{self.nome} não está matriculado em nenhum curso")
    
    def info(self):
        """Mostra informações do aluno"""
        print(f"Aluno: {self.nome} (Matrícula: {self.matricula})")
        if self.curso:
            print(f"Curso: {self.curso}")
        else:
            print("Curso: Não matriculado")

# ===== USO =====

# Criar objetos independentes
curso_python = Curso("Python para Iniciantes", "PYT001")
curso_java = Curso("Java Avançado", "JAV002")

aluno1 = Aluno("João Silva", "2024001")
aluno2 = Aluno("Maria Santos", "2024002")

# Criar associações
aluno1.matricular(curso_python)
# João Silva matriculado em Python para Iniciantes (PYT001)

aluno2.matricular(curso_java)
# Maria Santos matriculado em Java Avançado (JAV002)

# Mostrar informações
aluno1.info()
# Aluno: João Silva (Matrícula: 2024001)
# Curso: Python para Iniciantes (PYT001)

# Modificar associação (trocar de curso)
aluno1.desmatricular()
# João Silva desmatriculado de Python para Iniciantes (PYT001)

aluno1.matricular(curso_java)
# João Silva matriculado em Java Avançado (JAV002)

# Objetos ainda existem independentemente
print(curso_python)  # Python para Iniciantes (PYT001)
print(aluno2.nome)   # Maria Santos

Características Observadas

  • ✅ Objetos criados separadamente: Aluno e Curso são criados independentemente
  • ✅ Associação criada depois: A relação é estabelecida através do método matricular()
  • ✅ Associação pode ser removida: O método desmatricular() remove a relação
  • ✅ Objetos continuam existindo: Mesmo sem associação, os objetos ainda existem
  • ✅ Relação flexível: Um aluno pode trocar de curso facilmente
