BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Resumo e Checklist

Confirme seu domínio dos conceitos

Resumo dos Conceitos

Associação

  • Relação flexível
  • Objetos independentes
  • Podem existir separadamente
  • Relação pode ser criada/removida
  • Implementação: referências
  • Exemplo: Aluno ↔ Curso

Composição

  • Relação forte
  • Objeto parte depende do todo
  • Parte não existe sem o todo
  • Relação permanente
  • Implementação: criação dentro
  • Exemplo: Motor → Carro

Pergunta-Chave

"O objeto parte pode existir sem o objeto todo?"

  • SIM → Use Associação
  • NÃO → Use Composição

Implementação

  • ☐ Sei criar associações bidirecionais

Aplicação Prática

  • ☐ Consigo identificar relações em sistemas reais
  • ☐ Consigo modelar sistemas usando associação e composição
  • ☐ Consigo criar métodos para gerenciar relações
  • ☐ Consigo resolver exercícios práticos

Boas Práticas

  • ✅ Sempre faça a pergunta-chave antes de decidir o tipo de relação
  • ✅ Use composição quando o objeto parte não faz sentido sozinho
  • ✅ Use associação quando os objetos podem existir independentemente
  • ✅ Crie métodos para gerenciar relações (não acesse diretamente)
  • ✅ Mantenha relações bidirecionais sincronizadas
  • ✅ Documente as relações no código
