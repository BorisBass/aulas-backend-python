BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Tipos de Associação

Associação simples, múltipla e bidirecional

1. Associação Simples (1 para 1)

Um objeto se associa a um único objeto de outro tipo.

Exemplo: Aluno tem um Curso

class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.curso = None  # 1 para 1

aluno = Aluno("João")
aluno.curso = Curso("Python")  # Um aluno, um curso

2. Associação Múltipla (1 para Muitos)

Um objeto se associa a múltiplos objetos de outro tipo.

Exemplo: Professor leciona várias Disciplinas

class Professor:
    def __init__(self, nome):
        self.nome = nome
        self.disciplinas = []  # 1 para muitos

professor = Professor("Maria")
professor.disciplinas.append(Disciplina("Python"))
professor.disciplinas.append(Disciplina("Java"))
# Um professor, várias disciplinas

3. Associação Múltipla (Muitos para Muitos)

Múltiplos objetos se associam a múltiplos objetos.

Exemplo: Alunos podem estar em vários Cursos, e Cursos têm vários Alunos

class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.cursos = []  # Muitos cursos

class Curso:
    def __init__(self, nome):
        self.nome = nome
        self.alunos = []  # Muitos alunos

aluno1 = Aluno("João")
aluno2 = Aluno("Maria")
curso1 = Curso("Python")
curso2 = Curso("Java")

# Aluno em múltiplos cursos
aluno1.cursos.append(curso1)
aluno1.cursos.append(curso2)

# Curso com múltiplos alunos
curso1.alunos.append(aluno1)
curso1.alunos.append(aluno2)

4. Associação Bidirecional

Ambos os objetos mantêm referência um ao outro.

Exemplo: Aluno conhece seu Curso, e Curso conhece seus Alunos

class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.curso = None
    
    def matricular(self, curso):
        self.curso = curso
        curso.alunos.append(self)  # Bidirecional!

class Curso:
    def __init__(self, nome):
        self.nome = nome
        self.alunos = []  # Conhece seus alunos

aluno = Aluno("João")
curso = Curso("Python")
aluno.matricular(curso)

# Agora:
# aluno.curso aponta para curso
# curso.alunos contém aluno

Exemplo Completo: Associação Múltipla Bidirecional

class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.cursos = []  # Múltiplos cursos
    
    def matricular(self, curso):
        if curso not in self.cursos:
            self.cursos.append(curso)
            curso.adicionar_aluno(self)  # Bidirecional
    
    def desmatricular(self, curso):
        if curso in self.cursos:
            self.cursos.remove(curso)
            curso.remover_aluno(self)  # Bidirecional

class Curso:
    def __init__(self, nome):
        self.nome = nome
        self.alunos = []  # Múltiplos alunos
    
    def adicionar_aluno(self, aluno):
        if aluno not in self.alunos:
            self.alunos.append(aluno)
    
    def remover_aluno(self, aluno):
        if aluno in self.alunos:
            self.alunos.remove(aluno)

# Uso
aluno1 = Aluno("João")
aluno2 = Aluno("Maria")
curso1 = Curso("Python")
curso2 = Curso("Java")

aluno1.matricular(curso1)  # João em Python
aluno1.matricular(curso2)  # João em Java
aluno2.matricular(curso1)  # Maria em Python

# Relações bidirecionais mantidas automaticamente!
