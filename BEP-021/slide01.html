BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

Introdução: Relações entre Objetos

Por que objetos precisam se relacionar?

O Problema

No mundo real, objetos não existem isoladamente. Eles se relacionam, interagem e dependem uns dos outros.

Exemplos do mundo real:
  • Um Aluno está matriculado em um Curso
  • Um Carro possui um Motor
  • Uma Biblioteca contém vários Livros
  • Um Professor leciona várias Disciplinas

Na Programação

Em POO, precisamos modelar essas relações entre objetos para criar sistemas que reflitam a realidade.

Benefícios:
  • ✅ Modelagem mais realista
  • ✅ Código mais organizado
  • ✅ Reutilização de objetos
  • ✅ Sistemas mais complexos

Exemplo: Objetos Isolados (Problema)

Sem relações, objetos não podem interagir:

class Aluno:
    def __init__(self, nome):
        self.nome = nome

class Curso:
    def __init__(self, nome):
        self.nome = nome

# Problema: Como relacionar aluno e curso?
aluno = Aluno("João")
curso = Curso("Python")
# Não há conexão entre eles!

Exemplo: Objetos Relacionados (Solução)

Com relações, objetos podem interagir:

class Aluno:
    def __init__(self, nome):
        self.nome = nome
        self.curso = None  # Relação com Curso
    
    def matricular(self, curso):
        self.curso = curso  # Associação!

class Curso:
    def __init__(self, nome):
        self.nome = nome

# Agora podemos relacionar!
aluno = Aluno("João")
curso = Curso("Python")
aluno.matricular(curso)  # ✅ Relação criada!

Tipos de Relações

Nesta aula, vamos aprender dois tipos principais:

Associação

Objetos se relacionam, mas são independentes.

Exemplo: Aluno ↔ Curso

O aluno pode existir sem o curso e vice-versa.

Composição

Um objeto é parte de outro objeto.

Exemplo: Motor → Carro

O motor não existe sem o carro.
