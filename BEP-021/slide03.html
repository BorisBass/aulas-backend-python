BEP-021: Composição e Associação entre Objetos

Criando relações entre objetos para modelar sistemas complexos

O que é Composição?

Conceito e características da composição

Definição

Composição é um relacionamento onde um objeto é parte de outro objeto. O objeto "parte" não pode existir sem o objeto "todo".

É uma relação de "tem um" onde o objeto parte é criado e destruído junto com o objeto todo.

Características da Composição

1. Dependência Forte

O objeto "parte" não pode existir sem o objeto "todo". Se o objeto todo é destruído, a parte também é.

2. Criação Conjunta

O objeto parte é geralmente criado dentro do construtor do objeto todo, ou recebido como parâmetro obrigatório.

3. Relação "Parte de"

Expressa como "é parte de" ou "compõe". Exemplo: "Motor é parte de Carro" ou "Página compõe Livro".

4. Propriedade

O objeto todo é dono do objeto parte. A parte não pode ser compartilhada entre múltiplos objetos todo.

Analogia do Mundo Real

Exemplo 1: Carro e Motor

  • Um Motor é parte de um Carro
  • O motor não existe sem o carro
  • Se o carro é destruído, o motor também é
  • É uma relação forte

Exemplo 2: Livro e Páginas

  • Páginas compõem um Livro
  • As páginas não existem sem o livro
  • Se o livro é destruído, as páginas também são
  • É uma relação permanente

Implementação em Python

Composição é implementada criando o objeto parte dentro do objeto todo:

class Motor:
    def __init__(self, potencia):
        self.potencia = potencia
    
    def ligar(self):
        return f"Motor {self.potencia}CV ligado!"

class Carro:
    def __init__(self, marca, modelo, potencia_motor):
        self.marca = marca
        self.modelo = modelo
        # Composição: Motor é criado DENTRO do Carro
        self.motor = Motor(potencia_motor)  # Motor não existe sem Carro!
    
    def ligar(self):
        return self.motor.ligar()

# Criar carro (motor é criado automaticamente)
carro = Carro("Toyota", "Corolla", 150)
print(carro.ligar())  # Motor 150CV ligado!

# O motor não pode existir separadamente
# Se o carro for destruído, o motor também é

Importante: Composição vs Associação

Pergunta-chave: O objeto parte pode existir sem o objeto todo?

  • NÃO → É Composição (Motor não existe sem Carro)
  • SIM → É Associação (Aluno pode existir sem Curso)
