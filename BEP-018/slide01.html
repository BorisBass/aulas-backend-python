BEP-018: Criando e Instanciando Classes

Implementar e utilizar classes em Python

Definição de Classes

Entendendo a sintaxe e estrutura básica de uma classe

Sintaxe Básica

Uma classe em Python é definida usando a palavra-chave class:

class NomeDaClasse:
    # atributos e métodos aqui
    pass
  • Começa com class
  • Nome em PascalCase (primeira letra maiúscula)
  • Dois pontos (:) após o nome
  • Conteúdo indentado

Exemplo Simples

class Pessoa:
    pass

# Classe vazia (ainda sem funcionalidade)
p1 = Pessoa()
print(type(p1))  #

Mesmo sem atributos ou métodos, já podemos criar objetos (instâncias) da classe.

Por que usar classes?

  • Organização: Agrupa dados e comportamentos relacionados
  • Reutilização: Cria múltiplos objetos com a mesma estrutura
  • Abstração: Representa entidades do mundo real no código
  • Manutenção: Facilita a organização e modificação do código
