Classe completa com construtor e métodos

Classe Estudante - Exemplo Completo

class Estudante:
    def __init__(self, nome, matricula, curso):
        self.nome = nome
        self.matricula = matricula
        self.curso = curso
        self.notas = []  # Lista vazia inicialmente
    
    def adicionar_nota(self, nota):
        self.notas.append(float(nota))
    
    def calcular_media(self):
        if len(self.notas) > 0:
            return sum(self.notas) / len(self.notas)
        return 0.0
    
    def situacao(self):
        media = self.calcular_media()
        if media >= 7.0:
            return "Aprovado"
        elif media >= 5.0:
            return "Recuperação"
        else:
            return "Reprovado"

# Criando e usando objetos
est1 = Estudante("Ana", "2025A001", "Python")
est1.adicionar_nota(8.5)
est1.adicionar_nota(7.0)
est1.adicionar_nota(9.0)

print(f"{est1.nome}: Média {est1.calcular_media():.1f} - {est1.situacao()}")

Análise do Código

  • __init__: Inicializa os atributos nome, matricula, curso e notas (lista vazia)
  • adicionar_nota(): Método que adiciona notas à lista
  • calcular_media(): Método que calcula e retorna a média das notas
  • situacao(): Método que usa a média para determinar a situação do estudante
  • Instanciação: Criamos um objeto e usamos métodos para manipular seus dados
