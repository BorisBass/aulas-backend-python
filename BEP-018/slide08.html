BEP-018: Criando e Instanciando Classes

Implementar e utilizar classes em Python

Checklist de Revisão

Confirme seu domínio dos conceitos

Você consegue:

  • Definir uma classe usando a palavra-chave class
  • Explicar o que é o método __init__ e sua função
  • Entender o significado do parâmetro self
  • Criar atributos de instância dentro do __init__
  • Instanciar objetos a partir de uma classe
  • Criar múltiplos objetos da mesma classe com valores diferentes
  • Definir métodos que utilizam os atributos do objeto
  • Diferenciar entre atributos e métodos
  • Criar classes com múltiplos atributos
  • Implementar métodos que modificam o estado do objeto

Próximos Passos

Após dominar estes conceitos, você estará pronto para:

  • Encapsulamento e modificadores de acesso
  • Herança entre classes
  • Polimorfismo
  • Métodos especiais (magic methods)
  • Propriedades e decoradores

Dica de Estudo

Pratique criando classes para entidades do seu dia a dia: animais, veículos, dispositivos eletrônicos, etc. Quanto mais você praticar, mais natural se tornará o pensamento orientado a objetos!
