Criação de classes: Retangulo, Livro e Aluno

1) Classe Retangulo

  1. Crie a classe Retangulo com atributos largura e altura.
  2. Adicione o método area() que retorna a área do retângulo.
  3. Adicione o método perimetro() que retorna o perímetro.
  4. Crie dois objetos e compare as áreas.
class Retangulo:
    def __init__(self, largura, altura):
        self.largura = float(largura)
        self.altura = float(altura)
    
    def area(self):
        return self.largura * self.altura
    
    def perimetro(self):
        return 2 * (self.largura + self.altura)

r1 = Retangulo(5, 3)
r2 = Retangulo(4, 4)
print(f"Área r1: {r1.area()}, Perímetro: {r1.perimetro()}")
print(f"Área r2: {r2.area()}, Perímetro: {r2.perimetro()}")

2) Classe Livro

  1. Crie a classe Livro com atributos titulo, autor e paginas.
  2. Adicione o método descricao() que retorna uma string formatada.
  3. Crie três objetos de livros diferentes.
class Livro:

        self.titulo = titulo
        self.autor = autor
        self.paginas = int(paginas)
    
    def descricao(self):

3) Classe Aluno

  1. Crie a classe Aluno com atributos nome e notas (lista).
  2. Adicione o método media() que calcula a média das notas.
  3. Adicione o método situacao() que retorna "Aprovado" se média >= 6, senão "Reprovado".
class Aluno:
    def __init__(self, nome, notas):
        self.nome = nome
        self.notas = [float(n) for n in notas]
    
    def media(self):
        return sum(self.notas) / len(self.notas)
    
    def situacao(self):
        media = self.media()
        return "Aprovado" if media >= 6 else "Reprovado"

a1 = Aluno("Ana", [7, 8, 6, 9])
a2 = Aluno("Bruno", [5, 4, 6, 5])
print(f"{a1.nome}: Média {a1.media():.1f} - {a1.situacao()}")
print(f"{a2.nome}: Média {a2.media():.1f} - {a2.situacao()}")
