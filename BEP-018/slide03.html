BEP-018: Criando e Instanciando Classes

Implementar e utilizar classes em Python

Instanciação de Objetos

Criando objetos a partir de classes

Como Instanciar

Para criar um objeto, chamamos a classe como se fosse uma função:

class Aluno:
    def __init__(self, nome, matricula):
        self.nome = nome
        self.matricula = matricula

# Instanciação (criação do objeto)
aluno1 = Aluno("Ana", "2025A001")
aluno2 = Aluno("Bruno", "2025A002")

print(aluno1.nome)  # Ana
print(aluno2.nome)  # Bruno

Cada chamada cria um novo objeto independente.

Múltiplas Instâncias

Podemos criar quantos objetos quisermos da mesma classe:

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = preco

# Criando vários produtos
p1 = Produto("Caderno", 20.00)
p2 = Produto("Caneta", 2.50)
p3 = Produto("Borracha", 1.00)

# Cada um é um objeto diferente
print(p1.nome, p2.nome, p3.nome)

Todos compartilham a mesma estrutura, mas têm valores diferentes.

Passo a Passo da Instanciação

  1. Python cria um novo objeto vazio
  2. Chama automaticamente o método __init__
  3. Os parâmetros passados são atribuídos aos atributos do objeto
  4. O objeto é retornado e pode ser armazenado em uma variável
