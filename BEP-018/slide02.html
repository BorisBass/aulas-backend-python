BEP-018: Criando e Instanciando Classes

Implementar e utilizar classes em Python

Método Construtor __init__

Inicializando objetos com atributos

O que é __init__?

O método __init__ é chamado automaticamente quando criamos um objeto.

class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self.idade = idade

p = Pessoa("Ana", 25)
# __init__ é chamado automaticamente
  • self representa o objeto sendo criado
  • Parâmetros após self são obrigatórios na criação
  • Atributos são definidos com self.atributo

Atributos de Instância

Atributos definidos no __init__ pertencem a cada objeto:

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self.preco = float(preco)

p1 = Produto("Caderno", 20.00)
p2 = Produto("Caneta", 2.50)

print(p1.nome, p1.preco)  # Caderno 20.0
print(p2.nome, p2.preco)  # Caneta 2.5

Cada objeto tem seus próprios valores para os atributos.

Importante sobre __init__

  • Não retorna valor: __init__ não deve retornar nada (ou retornar None)
  • Obrigatório self: O primeiro parâmetro sempre é self
  • Chamado automaticamente: Não chamamos __init__ diretamente
  • Valores padrão: Podemos usar valores padrão nos parâmetros
