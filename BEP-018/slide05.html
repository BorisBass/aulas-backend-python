Implementar e utilizar classes em Python

Prática com múltiplos atributos e métodos

Classe Funcionario - Múltiplos Atributos

class Funcionario:
    def __init__(self, nome, cargo, salario_base):
        self.nome = nome
        self.cargo = cargo
        self.salario_base = float(salario_base)
        self.horas_extras = 0  # Atributo inicializado com zero
    
    def adicionar_horas_extras(self, horas):
        self.horas_extras += horas
    
    def calcular_salario_total(self):
        valor_hora_extra = self.salario_base / 160 * 1.5
        return self.salario_base + (self.horas_extras * valor_hora_extra)
    
    def resumo(self):
        return f"{self.nome} ({self.cargo}): R$ {self.calcular_salario_total():.2f}"

# Criando múltiplos objetos
func1 = Funcionario("Maria", "Desenvolvedora", 5000)
func2 = Funcionario("João", "Analista", 4000)

func1.adicionar_horas_extras(10)
func2.adicionar_horas_extras(5)

print(func1.resumo())
print(func2.resumo())

Pontos Importantes

  • Atributos no __init__: Podemos definir atributos com valores padrão
  • Múltiplos atributos: A classe pode ter quantos atributos forem necessários
  • Métodos modificadores: Métodos podem alterar o estado do objeto
  • Métodos informativos: Métodos podem retornar informações sobre o objeto
