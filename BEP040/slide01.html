BEP-040: Autenticação e Autorização

Implementar sistemas de autenticação de usuários

Sistema de Autenticação do Django

Django possui um sistema completo de autenticação embutido.

O que é autenticação?

Autenticação: Verificar quem é o usuário (login).

Autorização: Verificar o que o usuário pode fazer (permissões).

Django fornece ambos os sistemas prontos para uso.

Modelo User

# Django já fornece um modelo User padrão
from django.contrib.auth.models import User

# Campos principais:
# - username (obrigatório, único)
# - email
# - password (criptografado)
# - first_name, last_name
# - is_active, is_staff, is_superuser
# - date_joined

User: Modelo padrão do Django para usuários.

is_active: Se o usuário está ativo (pode fazer login).

is_staff: Se o usuário pode acessar o admin.

is_superuser: Se o usuário tem todas as permissões.

Configuração

# meu_projeto/settings.py
INSTALLED_APPS = [
    'django.contrib.auth',      # sistema de autenticação
    'django.contrib.contenttypes',
    # ... outros apps
]

# URLs de autenticação (já incluídas por padrão)
# django.contrib.auth.urls fornece:
# - /login/
# - /logout/
# - /password_change/
# - etc.

django.contrib.auth: App de autenticação do Django (já incluído por padrão).

As URLs de autenticação podem ser incluídas no projeto usando include('django.contrib.auth.urls').

Criar Usuário

# No shell do Django (python manage.py shell)
from django.contrib.auth.models import User

# Criar usuário comum
user = User.objects.create_user(
    username='joao',
    email='joao@email.com',
    password='senha123'
)

# Criar superusuário
admin = User.objects.create_superuser(
    username='admin',
    email='admin@email.com',
    password='admin123'
)

create_user(): Cria usuário comum com senha criptografada.

create_superuser(): Cria superusuário (pode acessar admin).

Nota: A senha é automaticamente criptografada (não salva em texto plano).
