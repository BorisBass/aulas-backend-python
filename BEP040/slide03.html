BEP-040: Autenticação e Autorização

Implementar sistemas de autenticação de usuários

Restrição de Acesso

Protegendo views para usuários autenticados.

Decorator @login_required

@login_required: Decorator que redireciona usuários não autenticados para a página de login.

Se o usuário não estiver logado, será redirecionado automaticamente.

Usando @login_required

# core/views.py
from django.contrib.auth.decorators import login_required
from django.shortcuts import render
from .models import Tarefa

@login_required  # protege a view
def lista_tarefas(request):
    tarefas = Tarefa.objects.filter(usuario=request.user)
    return render(request, 'lista.html', {'tarefas': tarefas})

@login_required
def criar_tarefa(request):
    if request.method == 'POST':
        # ... criar tarefa ...
        pass
    return render(request, 'criar.html')

@login_required: Garante que apenas usuários autenticados acessem a view.

Se não autenticado, redireciona para /accounts/login/ (padrão).

Configurar URL de Login

# meu_projeto/settings.py
LOGIN_URL = '/login/'  # URL para redirecionar usuários não autenticados
LOGIN_REDIRECT_URL = '/'  # URL após login bem-sucedido
LOGOUT_REDIRECT_URL = '/login/'  # URL após logout

LOGIN_URL: Onde redirecionar usuários não autenticados.

LOGIN_REDIRECT_URL: Onde redirecionar após login.

LOGOUT_REDIRECT_URL: Onde redirecionar após logout.

Verificar no Template


{% if user.is_authenticated %}
    <p>Olá, {{ user.username }}!</p>
    <a href="{% url 'core:logout' %}">Sair</a>
{% else %}
    <a href="{% url 'core:login' %}">Entrar</a>
{% endif %}

user: Variável disponível em todos os templates (equivalente a request.user).

Use {% if user.is_authenticated %} para mostrar conteúdo apenas para usuários logados.

Verificar Permissões

# core/views.py
from django.contrib.auth.decorators import login_required, permission_required

@login_required
@permission_required('core.add_tarefa', raise_exception=True)
def criar_tarefa_admin(request):
    # apenas usuários com permissão 'core.add_tarefa'
    return render(request, 'criar_admin.html')

# Ou verificar manualmente
@login_required
def minha_view(request):
    if request.user.has_perm('core.add_tarefa'):
        # usuário tem permissão
        pass
    else:
        # usuário não tem permissão
        return redirect('core:sem_permissao')

@permission_required: Verifica se o usuário tem uma permissão específica.

has_perm(): Verifica permissão manualmente.
