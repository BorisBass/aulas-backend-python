BEP-040: Autenticação e Autorização

Implementar sistemas de autenticação de usuários

Exercícios Práticos

Pratique os conceitos aprendidos nesta aula.

Exercícios Propostos

  1. Criar Usuário: Crie usuários usando o shell do Django
  2. Login: Implemente view e template de login
  3. Logout: Implemente view de logout
  4. Proteger View: Use @login_required para proteger uma view
  5. Perfil: Crie modelo Perfil com campos extras

Materiais

📘 Ver Exercícios  |  ✅ Ver Soluções

Dicas

  • Sempre use authenticate() antes de login()
  • Use @login_required para proteger views sensíveis
  • Configure LOGIN_URL no settings.py
  • Use request.user.is_authenticated para verificar login
  • Para campos extras, prefira modelo Perfil com OneToOne
