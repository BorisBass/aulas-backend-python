🎯 Exercício 1: Calculadora de IMC

Calcule o IMC e classifique o resultado.

peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))
imc = peso / (altura ** 2)
print(f"IMC: {imc:.2f}")
if imc < 18.5:
    print("Abaixo do peso")
elif imc < 25:
    print("Peso normal")
elif imc < 30:
    print("Sobrepeso")
else:
    print("Obesidade")

🎯 Exercício 2: Sistema de Notas

Calcule a média e determine se foi aprovado.

nota1 = float(input("Nota 1: "))
nota2 = float(input("Nota 2: "))
nota3 = float(input("Nota 3: "))

media = (nota1 + nota2 + nota3) / 3

print(f"Média: {media:.2f}")

if media >= 9.0:
    print("Conceito: A - Excelente!")
elif media >= 8.0:
    print("Conceito: B - Muito bom!")
elif media >= 7.0:
    print("Conceito: C - Aprovado!")
elif media >= 6.0:
    print("Conceito: D - Recuperação!")
else:
    print("Conceito: F - Reprovado!")
