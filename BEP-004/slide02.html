BEP-004: Estruturas Condicionais

if, elif, else em Python

Estrutura if Básica

🔍 Sintaxe do if

A estrutura if executa um bloco de código apenas se a condição for verdadeira:

# Sintaxe básica do if
if condição:
    # código executado se condição for True
    print("Condição verdadeira!")

📝 Exemplo Prático

# Verificação de idade
idade = int(input("Digite sua idade: "))

if idade >= 18:
    print("Você é maior de idade!")
    print("Pode votar e dirigir!")

print("Programa continuou...")

⚠️ Regras Importantes

  • Dois pontos (:): Sempre após a condição
  • Indentação: 4 espaços ou 1 tab
  • Bloco: Todo código indentado pertence ao if
💡 Exemplo: Verificação de Nota
nota = float(input("Digite sua nota: "))

if nota >= 7.0:
    print("Parabéns! Você foi aprovado!")
    print("Continue assim!")

print("Fim do programa")

Cuidado!

Não esqueça os dois pontos (:) após a condição e a indentação correta!
