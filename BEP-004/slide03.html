if, elif, else em Python

Estrutura if-else

🔄 Duas Opções

O if-else executa um bloco se a condição for verdadeira, outro se for falsa:

# Sintaxe do if-else
if condição:
    # código se condição for True
    print("Condição verdadeira!")
else:
    # código se condição for False
    print("Condição falsa!")

📝 Exemplo Prático

# Verificação de aprovação
nota = float(input("Digite sua nota: "))

if nota >= 7.0:
    print("Aprovado! Parabéns!")
else:
    print("Reprovado. Estude mais!")

print("Fim do programa")

🎯 Mais Exemplos

# Verificação de idade
idade = int(input("Sua idade: "))

if idade >= 18:
    print("Maior de idade")
    print("Pode votar")
else:
    print("Menor de idade")
    print("Não pode votar")

# Verificação de número par/ímpar
numero = int(input("Digite um número: "))

if numero % 2 == 0:
    print(f"{numero} é par")
else:
    print(f"{numero} é ímpar")

Dica

Use if-else quando tiver exatamente duas situações possíveis!
