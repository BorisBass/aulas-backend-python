BEP-004: Estruturas Condicionais

if, elif, else em Python

Introdução às Estruturas Condicionais

🎯 Objetivo da Aula

Aprender a usar estruturas condicionais (if, elif, else) para tomar decisões e controlar o fluxo de execução dos programas.

📚 O que você vai aprender:

  • Estrutura if: Execução condicional
  • Estrutura elif: Múltiplas condições
  • Estrutura else: Caso padrão
  • Aninhamento: Condições dentro de condições
  • Exercícios práticos: Aplicação em problemas reais

Por que usar condicionais?

  • Decisões: O programa escolhe o que fazer
  • Validação: Verificar dados de entrada
  • Fluxo: Controlar o caminho do código
  • Interatividade: Respostas diferentes para situações diferentes
💡 Analogia: Semáforo

Imagine um semáforo no trânsito:

  • Vermelho: Pare (if cor == "vermelho")
  • Amarelo: Atenção (elif cor == "amarelo")
  • Verde: Siga (else)

As condicionais funcionam assim: verificam uma situação e decidem o que fazer!

  • Operadores relacionais (BEP-003)
  • Operadores lógicos (BEP-003)
  • Variáveis e tipos de dados (BEP-001, BEP-002)

Dica Importante

As condicionais são fundamentais para criar programas inteligentes que respondem a diferentes situações!
