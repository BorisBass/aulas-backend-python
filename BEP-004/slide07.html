BEP-004: Estruturas Condicionais

if, elif, else em Python

Resumo e Próximos Passos

🎯 Você aprendeu:

  • if: Execução condicional simples
  • if-else: Duas opções possíveis
  • if-elif-else: Múltiplas condições
  • Aninhamento: Condicionais dentro de condicionais

🔧 Conceitos Importantes

  • Dois pontos (:): Sempre após a condição
  • Indentação: 4 espaços ou 1 tab
  • Ordem: if → elif → else
  • Primeiro verdadeiro: Apenas um bloco é executado
