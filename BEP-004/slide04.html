if, elif, else em Python

Estrutura if-elif-else

🔀 Múltiplas Condições

O if-elif-else permite verificar várias condições em sequência:

# Sintaxe do if-elif-else if condição1: # código se condição1 for True print("Primeira condição!") elif condição2: # código se condição2 for True print("Segunda condição!") elif condição3: # código se condição3 for True print("Terceira condição!") else: # código se todas forem False print("Nenhuma condição!")

📝 Exemplo: Sistema de Notas

# Sistema de classificação nota = float(input("Digite sua nota: ")) if nota >= 9.0: print("Excelente! Nota A") elif nota >= 8.0: print("Muito bom! Nota B") elif nota >= 7.0: print("Bom! Nota C") elif nota >= 6.0: print("Regular! Nota D") else: print("Precisa melhorar! Nota F")

🎯 Exemplo: Verificação de Idade

# Categorias de idade idade = int(input("Digite sua idade: ")) if idade < 12: print("Criança") elif idade < 18: print("Adolescente") elif idade < 60: print("Adulto") else: print("Idoso")

Atenção!

Python executa apenas o PRIMEIRO bloco verdadeiro. Os demais são ignorados!
