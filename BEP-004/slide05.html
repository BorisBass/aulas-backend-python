BEP-004: Estruturas Condicionais

if, elif, else em Python

Condicionais Aninhadas

🏗️ Estruturas Dentro de Estruturas

Podemos colocar condicionais dentro de outras condicionais:

# Exemplo de aninhamento idade = int(input("Sua idade: ")) if idade >= 18: print("Maior de idade") # Condicional aninhada if idade >= 65: print("Pode se aposentar") else: print("Ainda não pode se aposentar") else: print("Menor de idade") # Outra condicional aninhada if idade >= 16: print("Pode trabalhar com autorização") else: print("Não pode trabalhar")

📝 Exemplo: Sistema de Login

# Sistema de acesso usuario = input("Usuário: ") senha = input("Senha: ") if usuario == "admin": if senha == "123456": print("Login realizado com sucesso!") print("Bem-vindo, administrador!") else: print("Senha incorreta!") else: print("Usuário não encontrado!")

🎯 Exemplo: Calculadora de Desconto

# Sistema de desconto valor = float(input("Valor da compra: ")) categoria = input("Categoria (A, B, C): ").upper() if categoria == "A": if valor >= 1000: desconto = valor * 0.15 else: desconto = valor * 0.10 elif categoria == "B": if valor >= 500: desconto = valor * 0.10 else: desconto = valor * 0.05 else: desconto = 0 valor_final = valor - desconto print(f"Desconto: R$ {desconto:.2f}") print(f"Valor final: R$ {valor_final:.2f}")

Dica

Use aninhamento com moderação. Muitos níveis podem tornar o código difícil de entender!
