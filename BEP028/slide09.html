BEP-028: Introdução ao MVC

Model-View-Controller: Organizando código e separando responsabilidades

Comparação: Sem MVC vs Com MVC

Vantagens e diferenças práticas

Comparação Geral

Aspecto ❌ Sem MVC ✅ Com MVC
Organização Tudo em um arquivo/classe Separado em Model, View, Controller
Manutenção Difícil encontrar código Fácil localizar funcionalidades
Testes Difícil testar partes isoladas Fácil testar cada componente
Reutilização Código duplicado Componentes reutilizáveis
Escalabilidade Difícil adicionar features Fácil adicionar funcionalidades
Trabalho em Equipe Conflitos frequentes Poucos conflitos

Exemplo: Código Sem MVC

# ❌ Tudo misturado em uma classe
class SistemaAlunos:
    def __init__(self):
        self.alunos = []  # Dados
        self.db = sqlite3.connect('alunos.db')  # Banco
    
    def cadastrar(self):
        # Interface
        nome = input("Nome: ")
        idade = input("Idade: ")
        
        # Validação
        if not nome:
            print("Erro!")
            return
        
        # Lógica de negócio
        if int(idade) < 0:
            print("Erro!")
            return
        
        # Persistência
        cursor = self.db.cursor()
        cursor.execute("INSERT INTO...")
        self.db.commit()
        
        # Exibição
        print("Cadastrado!")
    
    def listar(self):
        # Consulta
        cursor = self.db.cursor()
        cursor.execute("SELECT * FROM...")
        alunos = cursor.fetchall()
        
        # Formatação
        for aluno in alunos:
            print(f"{aluno[0]} - {aluno[1]}")
        
        # Tudo junto = difícil manter!

Exemplo: Código Com MVC

# ✅ Separado em componentes

# Model: models.py
class Aluno:
    def __init__(self, nome, idade):
        self._nome = None
        self._idade = None
        self.nome = nome  # Validação aqui
        self.idade = idade

# View: views.py
class AlunoView:
    def solicitar_dados(self):
        nome = input("Nome: ")
        idade = input("Idade: ")
        return nome, idade
    
    def exibir_mensagem(self, msg):
        print(msg)

# Controller: controllers.py
class AlunoController:
    def __init__(self, repository, view):
        self.repository = repository
        self.view = view
    
    def cadastrar(self):
        nome, idade = self.view.solicitar_dados()
        aluno = Aluno(nome, idade)  # Validação no Model
        self.repository.salvar(aluno)
        self.view.exibir_mensagem("Cadastrado!")

# Cada parte tem responsabilidade única!

Comparação: Manutenção

❌ Sem MVC

Cenário: Mudar formato de exibição

  • Precisa encontrar código no meio de tudo
  • Risco de quebrar lógica de negócio
  • Difícil testar mudança isoladamente
  • Tempo: ⏱️ Alto

✅ Com MVC

Cenário: Mudar formato de exibição

  • Muda apenas na View
  • Model e Controller não são afetados
  • Fácil testar mudança isoladamente
  • Tempo: ⚡ Baixo

Comparação: Trabalho em Equipe

❌ Sem MVC

  • Conflitos no mesmo arquivo
  • Dificulta trabalho paralelo
  • Risco de sobrescrever código
  • Revisão de código complexa

✅ Com MVC

  • Arquivos separados = menos conflitos
  • Trabalho paralelo facilitado
  • Um no Model, outro na View
  • Revisão de código mais simples

Quando Usar MVC?

✅ Use MVC quando:

  • Projeto tem interface de usuário
  • Projeto será mantido/evoluído
  • Múltiplas formas de visualização
  • Trabalho em equipe
  • Projeto médio/grande

⚠️ Pode não precisar quando:

  • Scripts muito simples
  • Projetos de aprendizado
  • Protótipos rápidos
  • Aplicações sem interface
