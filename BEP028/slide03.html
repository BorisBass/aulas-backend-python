Model-View-Controller: Organizando código e separando responsabilidades

Componente View

Responsabilidades e características da View

O que é a View?

A View (Visão) é responsável por:

  • 🖥️ Apresentação: Exibir dados ao usuário
  • 🎨 Formatação: Como os dados são mostrados
  • 📝 Interface: Coletar entrada do usuário
  • 🔄 Atualização: Refletir mudanças nos dados

Responsabilidades da View

Deve Fazer:

  • Exibir dados do Model
  • Formatar saída para o usuário
  • Coletar entrada do usuário
  • Mostrar mensagens e erros
  • Atualizar quando dados mudam

NÃO Deve Fazer:

  • Processar lógica de negócio
  • Validar dados complexos
  • Acessar banco de dados diretamente
  • Decidir qual ação tomar
  • Manter estado de negócio

Exemplo: View de Aluno (Console)

# View: view.py
class AlunoView:
    """View - Responsável pela apresentação"""
    
    def exibir_menu(self):
        """Exibe o menu principal"""
        print("\n" + "="*50)
        print("🎓 SISTEMA DE GERENCIAMENTO DE ALUNOS")
        print("="*50)
        print("1. 📝 Cadastrar novo aluno")
        print("2. 📋 Listar todos os alunos")
        print("3. 🔍 Buscar aluno por nome")
        print("4. ✏️ Atualizar dados do aluno")
        print("5. 🗑️ Remover aluno")
        print("0. 🚪 Sair")
        print("="*50)
    
    def solicitar_dados_aluno(self):
        """Coleta dados do usuário"""
        nome = input("Nome completo: ").strip()
        idade = input("Idade: ").strip()
        curso = input("Curso: ").strip()
        nota = input("Nota (0-10): ").strip()
        return nome, idade, curso, nota
    
    def exibir_aluno(self, aluno):
        """Exibe um aluno formatado"""
        print(f"\n📋 Dados do Aluno:")
        print(f"   Nome: {aluno.nome}")
        print(f"   Idade: {aluno.idade}")
        print(f"   Curso: {aluno.curso}")
        if aluno.nota:
            print(f"   Nota: {aluno.nota:.1f}")
    
    def exibir_lista(self, alunos):
        """Exibe lista de alunos"""
        if not alunos:
            print("📭 Nenhum aluno cadastrado!")
            return
        print(f"\n📋 LISTA DE ALUNOS ({len(alunos)} cadastrados)")
        for aluno in alunos:
            self.exibir_aluno(aluno)
    
    def exibir_mensagem(self, mensagem, tipo="info"):
        """Exibe mensagens ao usuário"""
        if tipo == "erro":
            print(f"❌ {mensagem}")
        elif tipo == "sucesso":
            print(f"✅ {mensagem}")
        else:
            print(f"ℹ️ {mensagem}")
Características da View:
  • ✅ Apenas formatação e exibição
  • ✅ Não contém lógica de negócio
  • ✅ Pode ser trocada sem afetar Model
  • ✅ Pode ter múltiplas Views para o mesmo Model

Tipos de View

Console/CLI

Interface de linha de comando (texto)

Exemplo: Menu com print() e input()

Web

Interface web (HTML, CSS, JavaScript)

Exemplo: Páginas HTML renderizadas

Desktop

Interface gráfica (GUI)

Exemplo: Tkinter, PyQt, etc.

Mobile

Interface para dispositivos móveis

Exemplo: Apps Android/iOS

Princípios da View

  • ✅ Passividade: Não processa lógica complexa
  • ✅ Reutilização: Pode usar o mesmo Model
  • ✅ Substituibilidade: Fácil trocar uma View por outra
  • ✅ Simplicidade: Foca apenas em apresentação
  • ✅ Observação: Pode observar mudanças no Model
