Model-View-Controller: Organizando código e separando responsabilidades

Exercícios Práticos

Identificar e aplicar MVC em projetos pequenos

Exercício 1: Identificar Componentes

Objetivo: Analisar código existente e identificar Model, View e Controller.

Tarefa:

  1. Abra o arquivo BEP-016/crud_sistema_v2/sistema.py
  2. Identifique quais partes são Model, View e Controller
  3. Liste as responsabilidades de cada componente
  4. Identifique o que poderia ser melhorado para seguir MVC
💡 Dica: Procure por:
  • Model: Classes que representam dados e regras de negócio
  • View: Código que exibe informações (print, input)
  • Controller: Código que coordena Model e View

Exercício 2: Sistema de Livros

Objetivo: Criar um sistema simples de gerenciamento de livros usando MVC.

Requisitos:

  • Cadastrar livro (título, autor, ano, ISBN)
  • Listar todos os livros
  • Buscar livro por título
  • Marcar livro como lido

Tarefa:

  1. Crie a estrutura de pastas: models/, views/, controllers/
  2. Implemente o Model Livro com validações
  3. Implemente a View LivroView para exibição e entrada
  4. Implemente o Controller LivroController para coordenação
  5. Crie um main.py para iniciar o sistema
💡 Dica: Use o exemplo do slide 07 como referência!

Exercício 3: Refatorar Código Existente

Objetivo: Refatorar um código procedural para usar MVC.

Código a refatorar:

# sistema_procedural.py
alunos = []

def cadastrar():
    nome = input("Nome: ")
    idade = int(input("Idade: "))
    alunos.append({"nome": nome, "idade": idade})
    print("Cadastrado!")

def listar():
    for aluno in alunos:
        print(f"{aluno['nome']} - {aluno['idade']}")

while True:
    print("1. Cadastrar 2. Listar 0. Sair")
    op = input("Opção: ")
    if op == '1':
        cadastrar()
    elif op == '2':
        listar()
    elif op == '0':
        break

Tarefa:

  1. Identifique o que é Model, View e Controller
  2. Separe o código em arquivos apropriados
  3. Adicione validações no Model
  4. Melhore a View com formatação
  5. Implemente o Controller para coordenação

Exercício 4: Múltiplas Views

Objetivo: Criar múltiplas Views para o mesmo Model.

Tarefa:

  1. Use o Model Aluno do CRUD v2
  2. Crie AlunoViewConsole (interface texto)
  3. Crie AlunoViewHTML (gera HTML simples)
  4. Modifique o Controller para usar qualquer View
  5. Demonstre que o mesmo Model funciona com ambas Views
💡 Dica: Isso demonstra o poder do MVC - mesmo Model, diferentes apresentações!

Exercício 5: Sistema de Contatos

Objetivo: Criar um sistema completo de agenda de contatos usando MVC.

Requisitos:

  • Cadastrar contato (nome, telefone, email)
  • Listar contatos
  • Buscar contato por nome
  • Atualizar contato
  • Remover contato
  • Salvar em arquivo JSON (persistência simples)

Tarefa:

  1. Implemente Model Contato com validações (email válido, telefone)
  2. Implemente Repository para salvar/carregar JSON
  3. Implemente View completa com menu e formatação
  4. Implemente Controller com todas as operações
  5. Teste o sistema completo

Checklist de Avaliação

Use este checklist para avaliar seus exercícios:

  • ✅ Model contém apenas dados e lógica de negócio?
  • ✅ View contém apenas código de apresentação?
  • ✅ Controller coordena Model e View?
  • ✅ View não acessa Model diretamente?
  • ✅ Model não chama View diretamente?
  • ✅ Código está organizado em arquivos/pastas apropriadas?
  • ✅ Cada componente tem responsabilidade única?
  • ✅ Código está testável e manutenível?
