Aplicando MVC no CRUD

Refatorando o sistema CRUD usando MVC

Mapeamento: CRUD v2 → MVC

Como o CRUD v2 se relaciona com MVC:

📦 Model

  • models.py → Aluno
  • repository.py → AlunoRepository
  • database.py → DatabaseManager

🖥️ View

  • menu.py → Menu
  • Métodos de exibição
  • Coleta de entrada

🎮 Controller

  • sistema.py → SistemaAlunos
  • Coordena Model e View
  • Gerencia fluxo

  • ✅ models.py contém apenas a classe Aluno
  • ✅ Lógica de negócio (validação) está no Model

Controller: Refatorar Sistema

# controllers/aluno_controller.py
from models.aluno import Aluno
from repositories.aluno_repository import AlunoRepository
from views.aluno_view import AlunoView

class AlunoController:
    """Controller - Coordena Model e View"""
    
    def __init__(self, repository):
        self.repository = repository
        self.view = AlunoView()
    
    def iniciar(self):
        """Inicia o sistema"""
        while True:
            self.view.exibir_menu()
            opcao = input("👉 Escolha uma opção: ").strip()
            
            if opcao == '1':
                self.cadastrar_aluno()
            elif opcao == '2':
                self.listar_alunos()
            elif opcao == '3':
                self.buscar_aluno()
            elif opcao == '4':
                self.atualizar_aluno()
            elif opcao == '5':
                self.remover_aluno()
            elif opcao == '0':
                self.view.exibir_mensagem("Até logo!", "sucesso")
                break
            else:
                self.view.exibir_mensagem("Opção inválida!", "erro")
    
    def cadastrar_aluno(self):
        """Processa cadastro"""
        try:
            # View coleta dados
            nome, idade, curso, nota = self.view.solicitar_dados_aluno()
            
            # Cria Model (validação no Model)
            aluno = Aluno(
                nome, 
                int(idade) if idade else None,
                curso,
                float(nota) if nota else None
            )
            
            # Repository salva
            self.repository.salvar(aluno)
            
            # View exibe resultado
            self.view.exibir_mensagem(f"Aluno '{nome}' cadastrado!", "sucesso")
        except ValueError as e:
            self.view.exibir_mensagem(str(e), "erro")
        except Exception as e:
            self.view.exibir_mensagem(f"Erro: {e}", "erro")
    
    def listar_alunos(self):
        """Lista todos os alunos"""
        alunos = self.repository.listar_todos()
        self.view.exibir_lista(alunos)

Benefícios da Refatoração

  • ✅ Separação Clara: Cada componente tem responsabilidade única
  • ✅ Testabilidade: Fácil testar cada parte isoladamente
  • ✅ Manutenção: Mudanças isoladas em cada componente
  • ✅ Reutilização: View pode ser trocada (web, desktop, etc.)
  • ✅ Escalabilidade: Fácil adicionar novas funcionalidades
