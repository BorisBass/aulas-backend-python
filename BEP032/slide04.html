BEP-032: Autenticação e Autorização

Conceitos de segurança em APIs: autenticação e autorização

JWT (JSON Web Tokens)

Padrão moderno de autenticação

O que é JWT?

JWT é um token assinado que carrega dados do usuário e expiração.

  • ✅ Compacto e autocontido
  • ✅ Assinado (integridade)
  • ✅ Muito usado em APIs REST

JWT em FastAPI

# pip install python-jose[cryptography]
from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import OAuth2PasswordBearer
from jose import jwt, JWTError
from datetime import datetime, timedelta

SECRET_KEY = "segredo"
ALGORITHM = "HS256"

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/login")

app = FastAPI()

def criar_token(payload: dict, exp_minutos: int = 30):
    dados = payload.copy()
    exp = datetime.utcnow() + timedelta(minutes=exp_minutos)
    dados.update({"exp": exp})
    return jwt.encode(dados, SECRET_KEY, algorithm=ALGORITHM)

@app.get("/protegido")
def protegido(token: str = Depends(oauth2_scheme)):
    try:
        dados = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])
    except JWTError:
        raise HTTPException(status_code=401, detail="Token inválido")
    return {"usuario": dados.get("sub")}

Vantagens

  • ✅ Stateless (sem sessão no servidor)
  • ✅ Escalável
  • ✅ Contém dados do usuário
