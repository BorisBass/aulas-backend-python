BEP-032: Autenticação e Autorização

Conceitos de segurança em APIs: autenticação e autorização

JWT (JSON Web Tokens)

Padrão moderno de autenticação

O que é JWT?

JWT é um token assinado que carrega dados do usuário e expiração.

  • ✅ Compacto e autocontido
  • ✅ Assinado (integridade)
  • ✅ Muito usado em APIs REST

JWT em FastAPI (comentado)

# pip install python-jose[cryptography]
from fastapi import Body, Depends, FastAPI, HTTPException  # imports principais
from fastapi.security import OAuth2PasswordBearer  # extrai token do header
from jose import jwt, JWTError  # cria e valida JWT
from datetime import datetime, timedelta  # expiração do token

SECRET_KEY = "segredo"  # chave usada para assinar o JWT
ALGORITHM = "HS256"  # algoritmo de assinatura

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="/login")  # rota que gera token

app = FastAPI()  # cria a aplicacao

def criar_token(payload: dict, exp_minutos: int = 30):
    dados = payload.copy()  # copia os dados
    exp = datetime.utcnow() + timedelta(minutes=exp_minutos)  # expira em 30 min
    dados.update({"exp": exp})  # adiciona expiracao
    return jwt.encode(dados, SECRET_KEY, algorithm=ALGORITHM)  # assina o token

@app.post("/login")  # rota de login
def login(dados: dict = Body(...)):
    usuario = dados.get("usuario")
    senha = dados.get("senha")
    if usuario != "admin" or senha != "123":
        raise HTTPException(status_code=401, detail="Credenciais invalidas")
    token = criar_token({"sub": usuario})  # sub = subject (usuario)
    return {"token": token}

@app.get("/protegido")  # rota protegida
def protegido(token: str = Depends(oauth2_scheme)):
    try:
        dados = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])  # valida token
    except JWTError:
        raise HTTPException(status_code=401, detail="Token invalido")
    return {"usuario": dados.get("sub")}

Testando com Insomnia

  1. POST http://localhost:8000/login
  2. Body → JSON: {"usuario":"admin","senha":"123"}
  3. Copie o token da resposta
  4. GET http://localhost:8000/protegido
  5. Auth → Bearer → cole o token

Testando com Python (requests)

import requests

# 1) login
login = requests.post("http://localhost:8000/login", json={
    "usuario": "admin",
    "senha": "123"
})
token = login.json().get("token")

# 2) acesso protegido
headers = {"Authorization": f"Bearer {token}"}
resp = requests.get("http://localhost:8000/protegido", headers=headers)
print(resp.status_code)
print(resp.json())

Vantagens

  • ✅ Stateless (sem sessão no servidor)
  • ✅ Escalável
  • ✅ Contém dados do usuário
