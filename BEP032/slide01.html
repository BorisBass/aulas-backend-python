BEP-032: Autenticação e Autorização

Conceitos de segurança em APIs: autenticação e autorização

Autenticação vs Autorização

Diferença entre os conceitos fundamentais de segurança

Autenticação (Authentication)

O que é?

Autenticação é o processo de verificar a identidade de um usuário. Responde à pergunta: "Quem é você?"

  • ✅ Verifica se o usuário é quem diz ser
  • ✅ Usa credenciais (usuário/senha, tokens, etc.)
  • ✅ É o primeiro passo de segurança
// Exemplo: Login
POST /api/login
{
  "usuario": "joao",
  "senha": "senha123"
}

// Resposta: Token de autenticação
{
  "token": "abc123xyz..."
}

Autorização (Authorization)

O que é?

Autorização é o processo de verificar permissões de um usuário autenticado. Responde à pergunta: "O que você pode fazer?"

  • ✅ Verifica o que o usuário pode acessar
  • ✅ Baseado em roles/permissões
  • ✅ Vem depois da autenticação
// Exemplo: Verificar permissão
GET /api/admin/usuarios
Header: Authorization: Bearer abc123xyz...

// Resposta se autorizado: 200 OK
// Resposta se não autorizado: 403 Forbidden

Comparação

Autenticação

  • Pergunta: "Quem é você?"
  • Verifica: Identidade
  • Usa: Credenciais
  • Exemplo: Login
  • Status: 401 Unauthorized

Autorização

  • Pergunta: "O que pode fazer?"
  • Verifica: Permissões
  • Usa: Roles/Permissões
  • Exemplo: Acesso admin
  • Status: 403 Forbidden

Fluxo Completo

  1. Cliente faz requisição → Sem autenticação
  2. Servidor verifica autenticação → 401 se não autenticado
  3. Cliente envia credenciais → Login
  4. Servidor autentica → Retorna token
  5. Cliente faz requisição com token → Header Authorization
  6. Servidor verifica autorização → 403 se sem permissão
  7. Servidor processa requisição → 200 OK

Analogia do Mundo Real

Autenticação

É como mostrar seu RG na entrada de um prédio. O porteiro verifica se você é realmente quem diz ser.

Autorização

É como ter a chave para entrar em um quarto específico. Mesmo autenticado, você só pode acessar o que tem permissão.

Por que é Importante?

  • 🔒 Proteção de dados: Apenas usuários autorizados acessam recursos
  • 🛡️ Segurança: Previne acesso não autorizado
  • 👥 Controle de acesso: Diferentes níveis de permissão
  • 📊 Auditoria: Rastreia quem acessou o quê
  • ⚖️ Conformidade: Atende requisitos legais (LGPD, GDPR)
