BEP-032: Autenticação e Autorização

Conceitos de segurança em APIs: autenticação e autorização

Basic Authentication

Método básico de autenticação HTTP

O que é Basic Auth?

Basic Authentication envia usuário e senha codificados em Base64 no header HTTP.

  • ✅ Simples de implementar
  • ⚠️ Base64 não é criptografia
  • ✅ Deve usar HTTPS

Implementação em FastAPI

from fastapi import FastAPI, Depends, HTTPException
from fastapi.security import HTTPBasic, HTTPBasicCredentials

app = FastAPI()
security = HTTPBasic()

@app.get("/usuarios")
def listar_usuarios(credentials: HTTPBasicCredentials = Depends(security)):
    if credentials.username != "admin" or credentials.password != "123":
        raise HTTPException(status_code=401, detail="Credenciais inválidas")
    return [{"id": 1, "nome": "João"}]

Testando com curl

curl -u admin:123 http://localhost:8000/usuarios

Segurança

  • ⚠️ Não use em APIs públicas sem HTTPS
  • ⚠️ Não adequado para produção em larga escala
  • ✅ Útil para testes e APIs internas
