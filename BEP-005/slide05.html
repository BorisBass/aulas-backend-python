Loops Aninhados

🏗️ Loops Dentro de Loops

Podemos colocar loops dentro de outros loops:

# Exemplo: Tabuada completa
for i in range(1, 6):  # Loop externo
    print(f"
Tabuada do {i}:")
    for j in range(1, 11):  # Loop interno
        resultado = i * j
        print(f"{i} x {j} = {resultado}")

📝 Exemplo: Padrão de Asteriscos

# Desenhar um retângulo de asteriscos
linhas = int(input("Número de linhas: "))
colunas = int(input("Número de colunas: "))

for i in range(linhas):
    for j in range(colunas):
        print("*", end="")
    print()  # Nova linha

🎯 Exemplo: Triângulo de Números

# Triângulo de números
altura = int(input("Altura do triângulo: "))

for i in range(1, altura + 1):
    for j in range(1, i + 1):
        print(j, end=" ")
    print()  # Nova linha

🔍 Exemplo: Busca em Matriz

# Buscar um número em uma matriz
matriz = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]

numero_busca = int(input("Digite um número para buscar: "))
encontrado = False

for i in range(len(matriz)):
    for j in range(len(matriz[i])):
        if matriz[i][j] == numero_busca:
            print(f"Número {numero_busca} encontrado na posição ({i}, {j})")
            encontrado = True
            break
    if encontrado:
        break

if not encontrado:
    print(f"Número {numero_busca} não encontrado!")

Atenção!

Loops aninhados podem ser lentos! Use com moderação e sempre teste com valores pequenos primeiro.
