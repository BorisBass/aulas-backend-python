Função range()

O que é a função range()?

A função range() gera uma sequência de números inteiros, muito útil para criar loops com um número específico de iterações.

Sintaxe Descrição
range(stop) Gera números de 0 até stop-1
range(start, stop) Gera números de start até stop-1
range(start, stop, step) Gera números de start até stop-1, incrementando de step em step

Exemplos:

# Exemplo 1: range com um argumento
for i in range(5):
    print(i, end=" ")
0 1 2 3 4
# Exemplo 2: range com início e fim
for i in range(2, 8):
    print(i, end=" ")
2 3 4 5 6 7
