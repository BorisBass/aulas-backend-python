Loop for com range

🔄 Sintaxe do for

O loop for repete um bloco de código um número específico de vezes:

# Sintaxe básica do for for variavel in range(inicio, fim, passo): # código repetido print(f"Iteração: {variavel}")

📝 Exemplos com range

# Contar de 0 a 4 for i in range(5): print(f"Número: {i}") # Contar de 1 a 5 for i in range(1, 6): print(f"Número: {i}") # Contar de 2 em 2 (pares) for i in range(0, 11, 2): print(f"Par: {i}") # Contar de trás para frente for i in range(10, 0, -1): print(f"Contagem: {i}")

🎯 Exemplo Prático: Tabuada

# Tabuada do 5 numero = 5 print(f"Tabuada do {numero}:") for i in range(1, 11): resultado = numero * i print(f"{numero} x {i} = {resultado}")

Dica

range(inicio, fim) vai de inicio até fim-1. Use range(1, 6) para contar de 1 a 5!
