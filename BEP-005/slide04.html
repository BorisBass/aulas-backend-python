for e while em Python

Controle de Loops

🛑 break e continue

Podemos controlar o fluxo dos loops com break e continue:

# break: para o loop completamente for i in range(10): if i == 5: break # Para aqui print(f"Número: {i}") # continue: pula para a próxima iteração for i in range(10): if i % 2 == 0: continue # Pula números pares print(f"Ímpar: {i}")

📝 Exemplo: Busca de Número

# Buscar um número específico numeros = [1, 3, 5, 7, 9, 11, 13, 15] numero_busca = int(input("Digite um número para buscar: ")) encontrado = False for num in numeros: if num == numero_busca: print(f"Número {numero_busca} encontrado!") encontrado = True break # Para a busca if not encontrado: print(f"Número {numero_busca} não encontrado!")

🎯 Exemplo: Números Ímpares

# Mostrar apenas números ímpares print("Números ímpares de 1 a 20:") for i in range(1, 21): if i % 2 == 0: continue # Pula números pares print(f"Ímpar: {i}")

🔍 Exemplo: Validação com Limite

# Tentativas limitadas de login tentativas = 0 max_tentativas = 3 while tentativas < max_tentativas: senha = input("Digite a senha: ") if senha == "123456": print("Login realizado!") break else: tentativas += 1 if tentativas < max_tentativas: print(f"Senha incorreta! Tentativas restantes: {max_tentativas - tentativas}") else: print("Conta bloqueada!")

Dica

Use break para sair de loops quando encontrar o que procura. Use continue para pular iterações desnecessárias!
