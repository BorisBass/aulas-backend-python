for e while em Python

Introdução às Estruturas de Repetição

🎯 Objetivo da Aula

Aprender a usar estruturas de repetição (for e while) para automatizar tarefas e processar dados de forma eficiente.

📚 O que você vai aprender:

  • Loop for: Repetição com contador
  • Loop while: Repetição com condição
  • Função range: Gerar sequências de números
  • Controle de loops: break e continue
  • Exercícios práticos: Aplicação em problemas reais

Por que usar repetições?

  • Automação: Executar tarefas repetitivas
  • Eficiência: Processar muitos dados
  • Interatividade: Menus e validações
  • Simulação: Modelar processos repetitivos
💡 Analogia: Máquina de Lavar

Imagine uma máquina de lavar:

  • For: Lava 3 ciclos (contador fixo)
  • While: Continua até a roupa ficar limpa (condição)
  • Break: Para se detectar problema
  • Continue: Pula para o próximo ciclo

As repetições funcionam assim: executam uma tarefa várias vezes!

🔧 Pré-requisitos

  • Estruturas condicionais (BEP-004)
  • Operadores (BEP-003)
  • Variáveis e tipos (BEP-001, BEP-002)

Dica Importante

As repetições são essenciais para criar programas que processam dados e automatizam tarefas!
