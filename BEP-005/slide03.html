Loop while

🔄 Sintaxe do while

O loop while repete um bloco enquanto uma condição for verdadeira:

# Sintaxe básica do while
while condição:
    # código repetido
    print("Executando...")
    # IMPORTANTE: modificar a condição para evitar loop infinito

📝 Exemplos Práticos

# Contador simples
contador = 1
while contador <= 5:
    print(f"Contagem: {contador}")
    contador += 1  # Incrementa o contador
# Validação de entrada
senha = ""
while senha != "123456":
    senha = input("Digite a senha: ")
    if senha != "123456":
        print("Senha incorreta! Tente novamente.")
print("Acesso liberado!")

🎯 Exemplo: Menu Interativo

# Menu de opções
opcao = 0
while opcao != 4:
    print("
=== MENU ===")
    print("1. Calcular soma")
    print("2. Calcular produto")
    print("3. Verificar par/ímpar")
    print("4. Sair")
    
    opcao = int(input("Escolha uma opção: "))
    
    if opcao == 1:
        a = int(input("Número 1: "))
        b = int(input("Número 2: "))
        print(f"Soma: {a + b}")
    elif opcao == 2:
        a = int(input("Número 1: "))
        b = int(input("Número 2: "))
        print(f"Produto: {a * b}")
    elif opcao == 3:
        num = int(input("Número: "))
        if num % 2 == 0:
            print(f"{num} é par")
        else:
            print(f"{num} é ímpar")
