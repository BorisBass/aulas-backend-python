Exemplo Prático: Singleton

Implementando o padrão Singleton em Python

O que é Singleton?

O padrão Singleton garante que uma classe tenha apenas uma instância e fornece um ponto global de acesso a ela.

Quando usar:
  • Conexões com banco de dados
  • Loggers (sistemas de log)
  • Configurações globais
  • Cache compartilhado

Implementação Básica

class Singleton:
    _instancia = None
    
    def __new__(cls):
        if cls._instancia is None:
            cls._instancia = super().__new__(cls)
        return cls._instancia

# Teste
s1 = Singleton()
s2 = Singleton()
print(s1 is s2)  # True - mesma instância!

Exemplo Completo: Logger Singleton

class Logger:
    _instancia = None
    _logs = []
    
    def __new__(cls):
        if cls._instancia is None:
            cls._instancia = super().__new__(cls)
        return cls._instancia
    
    def __init__(self):
        if not hasattr(self, 'inicializado'):
            self.inicializado = True
            self._logs = []
    
    def log(self, mensagem):
        self._logs.append(mensagem)
        print(f"[LOG] {mensagem}")
    
    def obter_logs(self):
        return self._logs.copy()

# Uso
logger1 = Logger()
logger1.log("Primeira mensagem")

logger2 = Logger()  # Mesma instância!
logger2.log("Segunda mensagem")

print(logger1 is logger2)  # True
print(logger1.obter_logs())  # Ambas as mensagens
Vantagem: Garante que todos os logs vão para o mesmo lugar, independente de onde o Logger é criado.

Exemplo: Conexão com Banco de Dados

import sqlite3

class DatabaseConnection:
    _instancia = None
    _conexao = None
    
    def __new__(cls):
        if cls._instancia is None:
            cls._instancia = super().__new__(cls)
        return cls._instancia
    
    def conectar(self, database="app.db"):
        if self._conexao is None:
            self._conexao = sqlite3.connect(database)
            print("✅ Conexão estabelecida")
        return self._conexao
    
    def fechar(self):
        if self._conexao:
            self._conexao.close()
            self._conexao = None
            print("🔒 Conexão fechada")

# Uso - sempre a mesma conexão
db1 = DatabaseConnection()
db1.conectar()

db2 = DatabaseConnection()  # Mesma instância!
conn = db2.conectar()  # Reutiliza conexão existente

Cuidados com Singleton

⚠️ Problemas potenciais:
  • Dificulta testes unitários (dependência global)
  • Pode esconder dependências
  • Pode causar problemas em ambientes multi-thread
  • Pode ser um "code smell" se usado demais
✅ Use quando: Realmente precisa de uma única instância global (ex: configurações, conexões, loggers).
