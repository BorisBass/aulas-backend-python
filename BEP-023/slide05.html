BEP-023: Introdução aos Padrões de Projeto

Organizando código e promovendo reutilização através de padrões comprovados

Classificação: Padrões Comportamentais

Padrões que definem comunicação entre objetos

O que são Padrões Comportamentais?

Padrões Comportamentais estão preocupados com algoritmos e responsabilidades entre objetos, focando em como objetos interagem e se comunicam.

Objetivo: Definir padrões de comunicação entre objetos, tornando a comunicação mais flexível e permitindo que objetos trabalhem juntos de forma eficiente.

Principais Padrões Comportamentais

Observer

Notifica mudanças a múltiplos objetos.

Uso: Eventos, notificações, MVC.

Strategy

Define família de algoritmos intercambiáveis.

Uso: Diferentes formas de processar dados.

Command

Encapsula requisições como objetos.

Uso: Filas, undo/redo, macros.

Chain of Responsibility

Passa requisições por uma cadeia de handlers.

Uso: Middleware, validações, tratamento de erros.

Template Method

Define esqueleto de algoritmo em classe base.

Uso: Algoritmos com passos comuns.

Mediator

Centraliza comunicação entre objetos.

Uso: Reduzir acoplamento entre componentes.

Exemplo: Observer

Cenário: Sistema de notificações quando um evento ocorre.

# Padrão Observer
class Subject:
    def __init__(self):
        self._observers = []
    
    def adicionar_observer(self, observer):
        self._observers.append(observer)
    
    def notificar(self, evento):
        for observer in self._observers:
            observer.atualizar(evento)

class Observer:
    def atualizar(self, evento):
        print(f"Observer recebeu: {evento}")

# Uso
subject = Subject()
observer1 = Observer()
observer2 = Observer()

subject.adicionar_observer(observer1)
subject.adicionar_observer(observer2)
subject.notificar("Evento importante!")
Vantagem: Objetos são notificados automaticamente quando algo muda, sem acoplamento direto.

Exemplo: Strategy

Cenário: Diferentes formas de calcular desconto.

# Padrão Strategy
class DescontoStrategy:
    def calcular(self, valor):
        pass

class DescontoFixo(DescontoStrategy):
    def calcular(self, valor):
        return valor * 0.1  # 10%

class DescontoPercentual(DescontoStrategy):
    def __init__(self, percentual):
        self.percentual = percentual
    
    def calcular(self, valor):
        return valor * (self.percentual / 100)

class Venda:
    def __init__(self, estrategia):
        self.estrategia = estrategia
    
    def calcular_desconto(self, valor):
        return self.estrategia.calcular(valor)

# Uso
venda = Venda(DescontoPercentual(15))
desconto = venda.calcular_desconto(100)  # 15
Vantagem: Algoritmos podem ser trocados em tempo de execução, sem modificar código cliente.

Quando Usar Padrões Comportamentais?

  • ✅ Quando precisa notificar múltiplos objetos (Observer)
  • ✅ Quando tem algoritmos intercambiáveis (Strategy)
  • ✅ Quando precisa encapsular operações (Command)
  • ✅ Quando precisa processar requisições em cadeia (Chain)
  • ✅ Quando quer reduzir acoplamento entre objetos (Mediator)
