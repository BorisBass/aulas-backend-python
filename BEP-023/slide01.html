Introdução: O que são Design Patterns?

Conceito, origem e importância dos padrões de projeto

Definição

Design Patterns (Padrões de Projeto) são soluções reutilizáveis para problemas comuns que ocorrem durante o desenvolvimento de software.

Analogia: Assim como receitas de culinária descrevem como preparar pratos específicos, design patterns descrevem como resolver problemas específicos de programação.

Origem

O conceito foi popularizado pelo livro "Design Patterns: Elements of Reusable Object-Oriented Software" (Gang of Four - GoF), publicado em 1994.

Os 4 autores (GoF):
  • Erich Gamma
  • Richard Helm
  • Ralph Johnson
  • John Vlissides

Características

Design Patterns são:

  • ✅ Soluções testadas: Já foram usadas e validadas
  • ✅ Reutilizáveis: Aplicáveis em diferentes contextos
  • ✅ Documentadas: Têm nomes e descrições claras
  • ✅ Linguagem-agnósticos: Funcionam em várias linguagens

Exemplo: Problema Comum

Situação: Você precisa garantir que uma classe tenha apenas uma instância (ex: conexão com banco de dados).

# ❌ Sem padrão - pode criar múltiplas instâncias
class DatabaseConnection:
    def __init__(self):
        self.connection = "Conectado"

# Problema: cada vez que criar, será uma nova instância
db1 = DatabaseConnection()
db2 = DatabaseConnection()
# db1 e db2 são objetos diferentes!
Solução com Design Pattern: Usar o padrão Singleton para garantir apenas uma instância. Veremos isso em detalhes nos próximos slides!

O que Design Patterns NÃO são

❌ Não são:

  • Bibliotecas ou frameworks
  • Código pronto para copiar
  • Soluções para todos os problemas
  • Regras obrigatórias

✅ São:

  • Guias de design
  • Templates de solução
  • Boas práticas documentadas
  • Ferramentas para pensar

Importância dos Design Patterns

  • ✅ Comunicação: Nomes comuns facilitam discussão entre desenvolvedores
  • ✅ Documentação: Padrões documentam intenções de design
  • ✅ Reutilização: Soluções comprovadas economizam tempo
  • ✅ Manutenção: Código mais organizado e fácil de manter
  • ✅ Qualidade: Aplicação de soluções testadas e validadas
