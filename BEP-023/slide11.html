Exercícios Práticos

Aplicando padrões em situações reais

Exercício 1: Singleton para Logger

Desafio: Crie uma classe Logger usando o padrão Singleton que:

  • Permite apenas uma instância
  • Armazena logs em uma lista
  • Possui método log(mensagem, nivel) onde nível pode ser "INFO", "WARNING", "ERROR"
  • Possui método obter_logs() que retorna todos os logs
  • Possui método limpar_logs() que limpa a lista
💡 Dica: Use __new__ para garantir uma única instância. Verifique se já foi inicializado antes de criar a lista de logs.

Exercício 2: Factory de Formas Geométricas

Desafio: Crie um sistema usando Factory Pattern que:

  • Cria diferentes formas geométricas (Círculo, Retângulo, Triângulo)
  • Cada forma tem método calcular_area()
  • Factory recebe tipo e parâmetros necessários
  • Factory valida se tipo é suportado

Exemplo de uso:

forma1 = FormaFactory.criar("circulo", raio=5)
forma2 = FormaFactory.criar("retangulo", largura=10, altura=5)
print(forma1.calcular_area())  # ~78.54
print(forma2.calcular_area())  # 50

Exercício 3: Observer para Sistema de Notificações

Desafio: Implemente um sistema de notificações usando Observer Pattern:

  • Classe NotificacaoSubject que gerencia observers
  • Métodos: adicionar_observer(), remover_observer(), notificar()
  • Diferentes tipos de observers: EmailObserver, SMSObserver, PushObserver
  • Cada observer implementa método atualizar(mensagem)

Exemplo de uso:

sistema = NotificacaoSubject()
sistema.adicionar_observer(EmailObserver())
sistema.adicionar_observer(SMSObserver())
sistema.notificar("Nova mensagem recebida!")

Exercício 4: Identificar Padrões

Desafio: Analise os seguintes cenários e identifique qual padrão seria mais adequado:

  1. Sistema precisa garantir apenas uma conexão com banco de dados
  2. Precisa criar diferentes tipos de documentos (PDF, Word, HTML) dinamicamente
  3. Múltiplos componentes precisam ser notificados quando um arquivo é salvo
  4. Precisa adaptar uma API antiga para trabalhar com código novo
  5. Quer adicionar funcionalidades (cache, logging) a métodos sem modificar classes
💡 Dica: Revise os slides anteriores para identificar os padrões adequados!

Exercício 5: Refatoração

Desafio: Refatore o código abaixo usando um padrão apropriado:

# Código atual (sem padrão)
def processar_pagamento(tipo, valor):
    if tipo == "credito":
        # lógica para cartão de crédito
        print(f"Processando pagamento crédito: R$ {valor}")
    elif tipo == "debito":
        # lógica para débito
        print(f"Processando pagamento débito: R$ {valor}")
    elif tipo == "pix":
        # lógica para PIX
        print(f"Processando pagamento PIX: R$ {valor}")
    elif tipo == "boleto":
        # lógica para boleto
        print(f"Processando pagamento boleto: R$ {valor}")
    else:
        print("Tipo inválido")
