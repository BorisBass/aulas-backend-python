BEP-026: Padrão Observer

Comunicação desacoplada entre objetos

Exemplo Prático: Observer

Implementando o padrão Observer em Python

O que é Observer?

O padrão Observer define uma dependência um-para-muitos entre objetos, de modo que quando um objeto muda de estado, todos os seus dependentes são notificados e atualizados automaticamente.

Quando usar:
  • Sistemas de eventos
  • Notificações em tempo real
  • Arquitetura MVC (Model-View-Controller)
  • Atualizações de interface

Antes do padrão: tudo acoplado no produto

Vamos usar o mesmo exemplo de mudança de preço, mas sem Observer.

def notificar_clientes(produto, antigo, novo):
    print(f"🎉 Clientes: {produto} mudou de preço!")

def atualizar_estoque(produto, antigo, novo):
    print(f"📊 Estoque: atualizando preço de {produto}")

class ProdutoSimples:
    def __init__(self, nome, preco):
        self.nome = nome
        self._preco = preco
    
    @property
    def preco(self):
        return self._preco
    
    @preco.setter
    def preco(self, novo_preco):
        if novo_preco != self._preco:
            antigo = self._preco
            self._preco = novo_preco
            # Chamadas diretas (acoplamento forte)
            notificar_clientes(self.nome, antigo, novo_preco)
            atualizar_estoque(self.nome, antigo, novo_preco)
Problema: a classe ProdutoSimples conhece diretamente todas as funções que precisam ser chamadas. Se surgir um novo tipo de notificação, o código da classe terá que ser alterado.

Com Observer: produto avisa, observers reagem

class Subject:
    def __init__(self):
        self._observers = []
    
    def adicionar(self, observer):
        self._observers.append(observer)
    
    def remover(self, observer):
        self._observers.remove(observer)
    
    def notificar(self, evento):
        for observer in self._observers:
            observer.atualizar(evento)

class Observer:
    def atualizar(self, evento):
        print(f"Observer recebeu: {evento}")

# Uso
subject = Subject()
observer1 = Observer()
observer2 = Observer()

subject.adicionar(observer1)
subject.adicionar(observer2)
subject.notificar("Evento importante!")

Exemplo Completo: Sistema de Notificações

# Subject (Observado)
class Produto:
    def __init__(self, nome, preco):
        self.nome = nome
        self._preco = preco
        self._observers = []
    
    def adicionar_observer(self, observer):
        self._observers.append(observer)
    
    def remover_observer(self, observer):
        self._observers.remove(observer)
    
    @property
    def preco(self):
        return self._preco
    
    @preco.setter
    def preco(self, novo_preco):
        if novo_preco != self._preco:
            antigo_preco = self._preco
            self._preco = novo_preco
            self._notificar_mudanca_preco(antigo_preco, novo_preco)
    
    def _notificar_mudanca_preco(self, antigo, novo):
        for observer in self._observers:
            observer.preco_mudou(self, antigo, novo)

# Observers
class ClienteObserver:
    def __init__(self, nome):
        self.nome = nome
    
    def preco_mudou(self, produto, antigo, novo):
        if novo < antigo:
            print(f"🎉 {self.nome}: {produto.nome} está mais barato!")
            print(f"   De R$ {antigo:.2f} para R$ {novo:.2f}")
        else:
            print(f"📢 {self.nome}: {produto.nome} aumentou de preço")
            print(f"   De R$ {antigo:.2f} para R$ {novo:.2f}")

class EstoqueObserver:
    def preco_mudou(self, produto, antigo, novo):
        print(f"📊 [ESTOQUE] Preço de {produto.nome} atualizado no sistema")

# Uso
produto = Produto("Notebook", 3000.00)

cliente1 = ClienteObserver("João")
cliente2 = ClienteObserver("Maria")
estoque = EstoqueObserver()

produto.adicionar_observer(cliente1)
produto.adicionar_observer(cliente2)
produto.adicionar_observer(estoque)

# Mudança de preço notifica todos
produto.preco = 2500.00  # Desconto!
Resultado: Todos os observers são notificados automaticamente quando o preço muda, sem acoplamento direto.

Exemplo: Sistema de Eventos

class EventManager:
    def __init__(self):
        self._listeners = {}
    
    def on(self, evento, callback):
        if evento not in self._listeners:
            self._listeners[evento] = []
        self._listeners[evento].append(callback)
    
    def emit(self, evento, dados=None):
        if evento in self._listeners:
            for callback in self._listeners[evento]:
                callback(dados)

# Uso
eventos = EventManager()

# Registrar listeners
eventos.on("usuario_login", lambda d: print(f"✅ Login: {d}"))
eventos.on("usuario_login", lambda d: print(f"📧 Email enviado para {d}"))
eventos.on("compra_realizada", lambda d: print(f"💰 Compra: R$ {d}"))

# Emitir eventos
eventos.emit("usuario_login", "joao@email.com")
eventos.emit("compra_realizada", 150.00)

Vantagens do Observer

  • ✅ Desacoplamento: Subject e Observers são independentes
  • ✅ Extensibilidade: Fácil adicionar novos observers
  • ✅ Comunicação: Notificações automáticas e eficientes
  • ✅ Flexibilidade: Observers podem ser adicionados/removidos dinamicamente
