Resumo dos Conceitos

📚 O que Aprendemos

  • Design Patterns são soluções reutilizáveis para problemas comuns
  • Foram popularizados pelo livro Gang of Four (GoF)
  • São guias de design, não código pronto
  • Ajudam na comunicação e organização do código

📊 Classificações

  • Criacionais: Criação de objetos (Singleton, Factory)
  • Estruturais: Estrutura de classes (Adapter, Decorator)
  • Comportamentais: Comunicação (Observer, Strategy)

Conceitos-Chave

Conceito Definição
Design Pattern Solução reutilizável para problema comum
Singleton Garante uma única instância de classe
Factory Cria objetos sem especificar classe exata
Observer Notifica mudanças a múltiplos objetos
Anti-padrão Solução comum que é ineficaz

Lembrete Final

"Design Patterns são ferramentas, não regras. Use quando fizer sentido, não apenas porque são 'bonitos'. O objetivo é código mais limpo, organizado e manutenível."
