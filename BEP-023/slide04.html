BEP-023: Introdução aos Padrões de Projeto

Organizando código e promovendo reutilização através de padrões comprovados

Classificação: Padrões Estruturais

Padrões que organizam a estrutura de classes e objetos

O que são Padrões Estruturais?

Padrões Estruturais explicam como compor objetos e classes para formar estruturas maiores, mantendo flexibilidade e eficiência.

Objetivo: Facilitar o design identificando maneiras simples de relacionar entidades, permitindo que partes do sistema trabalhem juntas de forma eficiente.

Principais Padrões Estruturais

Adapter

Adapta interfaces incompatíveis para trabalharem juntas.

Uso: Integrar sistemas legados, APIs diferentes.

Decorator

Adiciona funcionalidades a objetos dinamicamente.

Uso: Adicionar features sem modificar classe base.

Facade

Simplifica interface de um subsistema complexo.

Uso: Esconder complexidade, criar APIs simples.

Proxy

Controla acesso a um objeto através de um intermediário.

Uso: Lazy loading, cache, controle de acesso.

Composite

Compor objetos em estruturas de árvore.

Uso: Hierarquias, estruturas recursivas.

Bridge

Separa abstração da implementação.

Uso: Plataformas diferentes, múltiplas implementações.

Exemplo: Adapter

Cenário: Integrar um sistema antigo com interface diferente.

# Sistema antigo (interface incompatível)
class SistemaAntigo:
    def processar_dados_antigo(self, dados):
        return f"Processado: {dados}"

# Nova interface esperada
class Adapter:
    def __init__(self, sistema_antigo):
        self.sistema = sistema_antigo
    
    def processar(self, dados):  # Nova interface
        return self.sistema.processar_dados_antigo(dados)

# Uso
antigo = SistemaAntigo()
adapter = Adapter(antigo)
resultado = adapter.processar("dados")  # Interface compatível!
Vantagem: Permite usar código legado sem modificá-lo, apenas adaptando a interface.

Exemplo: Decorator

Cenário: Adicionar funcionalidades a um objeto sem modificar sua classe.

# Classe base
class Cafe:
    def custo(self):
        return 5.0

# Decorator para adicionar leite
class CafeComLeite:
    def __init__(self, cafe):
        self.cafe = cafe
    
    def custo(self):
        return self.cafe.custo() + 2.0

# Uso
cafe = Cafe()
cafe_leite = CafeComLeite(cafe)
print(cafe_leite.custo())  # 7.0
Vantagem: Adiciona funcionalidades dinamicamente, sem modificar código existente.

Quando Usar Padrões Estruturais?

  • ✅ Quando precisa integrar sistemas com interfaces diferentes (Adapter)
  • ✅ Quando quer adicionar funcionalidades sem modificar classes (Decorator)
  • ✅ Quando precisa simplificar interfaces complexas (Facade)
  • ✅ Quando precisa controlar acesso a objetos (Proxy)
  • ✅ Quando trabalha com hierarquias de objetos (Composite)
