BEP-023: Introdução aos Padrões de Projeto

Organizando código e promovendo reutilização através de padrões comprovados

Classificação: Padrões Criacionais

Padrões que lidam com a criação de objetos

O que são Padrões Criacionais?

Padrões Criacionais fornecem mecanismos para criar objetos de forma que aumentem a flexibilidade e reutilização do código existente.

Objetivo: Abstrair o processo de criação de objetos, tornando o sistema independente de como seus objetos são criados, compostos e representados.

Principais Padrões Criacionais

Singleton

Garante uma única instância de uma classe.

Uso: Conexões de banco, loggers, configurações globais.

Factory Method

Cria objetos sem especificar a classe exata.

Uso: Criar diferentes tipos de objetos relacionados.

Abstract Factory

Cria famílias de objetos relacionados.

Uso: Interfaces de usuário, temas, sistemas operacionais.

Builder

Constrói objetos complexos passo a passo.

Uso: Objetos com muitos parâmetros opcionais.

Prototype

Copia objetos existentes em vez de criar novos.

Uso: Quando criação é custosa ou complexa.

Exemplo: Factory Method

Cenário: Sistema que precisa criar diferentes tipos de veículos.

# Padrão Factory Method
class VeiculoFactory:
    @staticmethod
    def criar_veiculo(tipo):
        if tipo == "carro":
            return Carro()
        elif tipo == "moto":
            return Moto()
        elif tipo == "bicicleta":
            return Bicicleta()
        else:
            raise ValueError(f"Tipo {tipo} não suportado")

# Uso
veiculo = VeiculoFactory.criar_veiculo("carro")
veiculo.acelerar()
Vantagem: Código cliente não precisa saber como criar cada tipo de veículo. Fácil adicionar novos tipos sem modificar código existente.

Quando Usar Padrões Criacionais?

  • ✅ Quando o sistema precisa ser independente de como objetos são criados
  • ✅ Quando você quer reutilizar código de criação
  • ✅ Quando a criação de objetos é complexa ou custosa
  • ✅ Quando você precisa controlar o número de instâncias (Singleton)
  • ✅ Quando precisa criar famílias de objetos relacionados

Resumo dos Padrões Criacionais

Padrão Problema Resolve Quando Usar
Singleton Múltiplas instâncias Recursos compartilhados
Factory Criação complexa Diferentes tipos relacionados
Builder Objetos com muitos parâmetros Construtores complexos
Prototype Criação custosa Clonar objetos existentes
