Exceções Comuns em Python

🔍 Principais Tipos de Exceções

Conheça as exceções mais comuns e quando elas ocorrem:

# 1. ValueError - Valor inválido try: numero = int("abc") # Erro! except ValueError: print("Erro: Valor inválido para conversão") # 2. TypeError - Tipo incorreto try: resultado = "texto" + 5 # Erro! except TypeError: print("Erro: Não é possível somar string com número") # 3. ZeroDivisionError - Divisão por zero try: resultado = 10 / 0 # Erro! except ZeroDivisionError: print("Erro: Divisão por zero") # 4. IndexError - Índice fora do range try: lista = [1, 2, 3] elemento = lista[10] # Erro! except IndexError: print("Erro: Índice fora do range") # 5. KeyError - Chave não encontrada try: dicionario = {"nome": "João"} valor = dicionario["idade"] # Erro! except KeyError: print("Erro: Chave não encontrada no dicionário")

Dica de Boa Prática

Sempre capture exceções específicas antes das genéricas. Use Exception apenas como último recurso!
