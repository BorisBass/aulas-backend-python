# BEP-010: Tratamento de Exceções em Python

## 📚 Visão Geral

Este módulo ensina tratamento de exceções em Python, focando em try, except, finally, raise e tipos comuns de exceções.

## 🎯 Objetivos de Aprendizagem

- ✅ Compreender o que são exceções
- ✅ Utilizar try-except para tratar erros
- ✅ Aplicar finally para limpeza de recursos
- ✅ Lançar exceções customizadas
- ✅ Conhecer tipos comuns de exceções
- ✅ Implementar boas práticas
