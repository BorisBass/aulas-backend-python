# Plano de Aula: Tratamento de Exceções em Python (BEP-010)

## Informações Gerais

- **Disciplina:** Back End com Python
- **Aula:** BEP-010
- **Tema:** Tratamento de Exceções
- **Duração:** 3 horas
- **Público-alvo:** Estudantes de programação com conhecimentos básicos em Python

## Objetivo Geral

Aprender a lidar com erros e exceções em Python de forma profissional, utilizando try, except, finally, raise e conhecendo os principais tipos de exceções.

## Objetivos Específicos

1. Compreender o que são exceções e por que acontecem
2. Utilizar try-except para capturar e tratar erros
3. Aplicar finally para garantir limpeza de recursos
4. Lançar exceções customizadas com raise
5. Conhecer os tipos mais comuns de exceções
6. Implementar boas práticas de tratamento de erros
