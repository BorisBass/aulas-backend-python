Torne seus programas mais robustos e confiáveis

Finally - Limpeza e Finalização

🔍 Bloco Finally

O bloco finally sempre é executado, com ou sem exceção:

# Sintaxe com finally
try:
    arquivo = open("dados.txt", "r")
    conteudo = arquivo.read()
    print("Arquivo lido com sucesso!")
except FileNotFoundError:
    print("Erro: Arquivo não encontrado!")
except Exception as e:
    print(f"Erro inesperado: {e}")
finally:
    arquivo.close()  # Sempre fecha o arquivo
    print("Limpeza realizada!")

📝 Quando Usar Finally

Casos de Uso do Finally

  • Fechar arquivos: Garantir que recursos sejam liberados
  • Limpar recursos: Liberar memória, conexões
  • Registro de logs: Sempre registrar o que aconteceu
  • Limpeza de dados: Resetar variáveis temporárias

🔧 Exemplos Práticos

# 1. Gerenciamento de arquivos
try:
    arquivo = open("dados.txt", "w")
    arquivo.write("Dados importantes")
except IOError:
    print("Erro ao escrever arquivo")
finally:
    if 'arquivo' in locals():
        arquivo.close()
    print("Arquivo fechado com segurança")

# 2. Conexão com banco de dados
try:
    conexao = conectar_banco()
    dados = buscar_dados(conexao)
    print("Dados carregados!")
except DatabaseError:
    print("Erro no banco de dados")
finally:
    if 'conexao' in locals():
        conexao.close()
    print("Conexão encerrada")

# 3. Processamento com limpeza
try:
    lista_temporaria = []
    for item in dados:
        lista_temporaria.append(processar(item))
    print("Processamento concluído!")
except Exception as e:
    print(f"Erro no processamento: {e}")
finally:
    lista_temporaria.clear()  # Limpa a lista
    print("Memória liberada")

Dica Importante

O finally é executado sempre, mesmo se houver return no bloco try ou except!
