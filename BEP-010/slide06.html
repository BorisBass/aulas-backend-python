BEP-010: Tratamento de Exceções

Torne seus programas mais robustos e confiáveis

Raise - Lançando Exceções

🔍 O que é Raise?

Use raise para lançar exceções manualmente:

# Lançar exceção def dividir(a, b): if b == 0: raise ZeroDivisionError("Não pode dividir por zero!") return a / b try: resultado = dividir(10, 0) except ZeroDivisionError as e: print(f"Erro: {e}")

📝 Exemplos Práticos

# Validação de idade def validar_idade(idade): if idade < 0: raise ValueError("Idade não pode ser negativa!") if idade > 150: raise ValueError("Idade inválida!") return True try: validar_idade(-5) except ValueError as e: print(f"Erro: {e}")
