Raise - Lançando Exceções

🔍 O que é Raise?

Use raise para criar e lançar exceções manualmente quando algo não está correto:

Por que usar raise?

  • Validação: Verificar se dados estão corretos
  • Controle: Forçar parada em condições específicas
  • Clareza: Mensagens de erro personalizadas
  • Robustez: Evitar comportamentos inesperados

📝 Sintaxe do Raise

# Sintaxe básica raise TipoExcecao("Mensagem de erro") # Exemplo simples def dividir(a, b): if b == 0: raise ZeroDivisionError("Não pode dividir por zero!") return a / b try: resultado = dividir(10, 0) except ZeroDivisionError as e: print(f"Erro: {e}")

🔧 Exemplos Práticos

# 1. Validação de idade def validar_idade(idade): if idade < 0: raise ValueError("Idade não pode ser negativa!") if idade > 150: raise ValueError("Idade inválida!") return True # 2. Validação de email def validar_email(email): if "@" not in email: raise ValueError("Email deve conter @") if "." not in email: raise ValueError("Email deve conter domínio") return True # 3. Validação de arquivo def abrir_arquivo(nome): if not nome.endswith('.txt'): raise ValueError("Apenas arquivos .txt são permitidos!") return open(nome, 'r')

Dica Importante

raise é usado para criar exceções, enquanto try-except é usado para capturar exceções!
