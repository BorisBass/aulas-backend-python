BEP-010: Tratamento de Exceções

Torne seus programas mais robustos e confiáveis

O que são Exceções?

🔍 Definição

Exceções são erros que ocorrem durante a execução de um programa. Quando uma exceção acontece, o programa para abruptamente, a menos que o erro seja tratado.

# Exemplo de erro não tratado
numero = int("abc")  # ValueError: invalid literal for int()

📝 Exemplos de Exceções Comuns

# 1. ValueError - Valor inválido
idade = int("vinte")  # Erro: não é um número

# 2. ZeroDivisionError - Divisão por zero
resultado = 10 / 0  # Erro: divisão por zero

# 3. TypeError - Tipo incompatível
resultado = "5" + 3  # Erro: não pode somar string com int

# 4. IndexError - Índice fora do range
lista = [1, 2, 3]
elemento = lista[10]  # Erro: índice não existe

# 5. KeyError - Chave não encontrada
dicionario = {"nome": "Ana"}
idade = dicionario["idade"]  # Erro: chave não existe

# 6. FileNotFoundError - Arquivo não encontrado
arquivo = open("arquivo_inexistente.txt")  # Erro: arquivo não existe

🎯 Por que Exceções Acontecem?

  • Entrada do usuário: Dados inválidos ou inesperados
  • Recursos externos: Arquivos, banco de dados, rede
  • Lógica de programação: Erros no código
  • Limites do sistema: Memória, processamento

Sem Tratamento

Quando uma exceção não é tratada, o programa para completamente e mostra uma mensagem de erro técnica que pode confundir o usuário.

Com Tratamento

Com tratamento adequado, o programa pode:

  • Continuar executando normalmente
  • Mostrar mensagens amigáveis ao usuário
  • Registrar o erro para análise posterior
  • Tomar ações corretivas
