BEP-010: Tratamento de Exceções

Torne seus programas mais robustos e confiáveis

Try-Except-Else

🔍 Bloco Else

O bloco else é executado apenas se não houver exceção:

# Sintaxe com else try: numero = int(input("Digite um número: ")) except ValueError: print("Erro: Número inválido!") else: print(f"Número válido: {numero}") print("Executando código adicional...")

📝 Exemplo Prático

# Sistema de login try: usuario = input("Usuário: ") senha = input("Senha: ") if not usuario or not senha: raise ValueError("Campos obrigatórios!") except ValueError as e: print(f"Erro: {e}") else: print("Login realizado com sucesso!") print(f"Bem-vindo, {usuario}!")
