# BEP-007: Tuplas e Dicionários em Python

## 📖 Descrição

Material didático completo sobre **Tuplas e Dicionários** em Python, desenvolvido para estudantes iniciantes. Este módulo faz parte do curso de programação Python do IFBA CEPEDI e aborda duas estruturas de dados fundamentais da linguagem.

## 🎯 Objetivos

### Objetivo Geral
Conhecer outras estruturas de dados fundamentais em Python, especificamente tuplas e dicionários, desenvolvendo competências para escolher e utilizar a estrutura mais adequada para cada situação.

### Objetivos Específicos
- Compreender o conceito de tuplas e suas características
- Diferenciar tuplas de listas em Python
- Aprender a criar e manipular tuplas
- Entender o conceito de dicionários e sua estrutura
- Dominar a criação e manipulação de dicionários
- Aplicar tuplas e dicionários em situações práticas

## 📚 Conteúdo Programático

### Tuplas (Slides 1-7)
1. **Introdução às Tuplas** - Conceito e características
2. **Características das Tuplas** - Imutabilidade e performance
3. **Diferenças: Tuplas vs Listas** - Comparação detalhada
4. **Criação e Acesso** - Sintaxe e manipulação
5. **Métodos de Tuplas** - count(), index() e operações

### Dicionários (Slides 8-15)
6. **O que são Dicionários** - Estrutura chave-valor
7. **Estrutura de Dicionários** - Anatomia e tipos
8. **Criação de Dicionários** - Métodos e comprehension
9. **Acesso a Dicionários** - Métodos seguros
10. **Adição e Modificação** - CRUD operations
11. **Remoção de Elementos** - del, pop(), clear()
12. **Métodos de Dicionários** - keys(), values(), items()
13. **Funções Built-in** - len(), max(), min(), sum()

### Exercícios Práticos (Slides 16-19)
14. **Exercícios - Tuplas** - Prática direcionada
15. **Exercícios - Dicionários** - Aplicações reais
16. **Exercícios Combinados** - Integração das estruturas
17. **Resumo e Próximos Passos** - Consolidação

## 🚀 Como Usar

### 1. Navegação pelos Slides
- Abra `index.html` em um navegador
- Clique em qualquer slide para abrir
- Use as setas do teclado para navegar
- Pressione `Esc` para ver o índice

### 2. Exercícios Práticos
- Abra `exercicios_tuplas_dicionarios_colab.py` no Google Colab
- Execute os exercícios sequencialmente
- Modifique e experimente o código

### 3. Plano de Aula
- Consulte `plano_aula_tuplas_dicionarios.md` para orientações pedagógicas
- Siga o cronograma sugerido
- Adapte conforme necessário
