Método pop()

O que faz o pop()?

O método pop() remove e retorna o elemento de uma posição específica da lista. Se nenhum índice for fornecido, remove o último elemento.

Sintaxe

elemento = lista.pop(índice) # Remove elemento do índice
elemento = lista.pop() # Remove último elemento

Exemplos Práticos

frutas = ["maçã", "banana", "laranja", "uva"]

# Removendo o último elemento
ultima = frutas.pop()
print(f"Removido: {ultima}") # "Removido: uva"
print(frutas) # ["maçã", "banana", "laranja"]

# Removendo elemento específico
segunda = frutas.pop(1)
print(f"Removido: {segunda}") # "Removido: banana"
print(frutas) # ["maçã", "laranja"]
Vantagem: O pop() retorna o elemento removido, permitindo que você o use em outras operações.
