Método remove()

O que faz o remove()?

O método remove() remove a primeira ocorrência de um elemento específico da lista. Se o elemento não existir, gera um erro.

Sintaxe

lista.remove(elemento)

Exemplos Práticos

frutas = ["maçã", "banana", "laranja", "banana"]

# Removendo "banana" (primeira ocorrência)
frutas.remove("banana")
print(frutas) # ["maçã", "laranja", "banana"]

# Removendo "laranja"
frutas.remove("laranja")
print(frutas) # ["maçã", "banana"]

# Tentando remover elemento inexistente
# frutas.remove("uva") # Erro: ValueError

Verificando antes de remover

frutas = ["maçã", "banana", "laranja"]

if "uva" in frutas:
    frutas.remove("uva")
else:
    print("Elemento não encontrado!")
Atenção: O remove() remove apenas a primeira ocorrência. Para remover todas as ocorrências, use um laço ou list comprehension.
