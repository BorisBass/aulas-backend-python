## Objetivos de Aprendizagem

### Conceitos Fundamentais
- Compreender o que são listas em Python
- Entender as características das listas (ordenadas, mutáveis, indexadas)
- Aprender a criar e acessar elementos de listas

### Métodos Principais
- **append()**: Adicionar elementos no final
- **insert()**: Inserir elementos em posições específicas
- **remove()**: Remover primeira ocorrência de elementos

### Técnicas Avançadas
- Fatiamento (slicing) de listas
- Índices positivos e negativos
- Manipulação de listas com diferentes tipos de dados

## Conteúdo dos Exercícios

### Exercícios Básicos
1. Lista de compras com append()
2. Inserção no meio com insert()
3. Remoção de elementos com remove()
4. Fatiamento básico

### Exercícios Intermediários
1. Cálculo de média e adição à lista
2. Inserção no início da lista
3. Fatiamento avançado (números pares)
4. Inversão de lista

### Exercícios Avançados
1. Manipulação completa de lista
2. Análise de lista (primeiro, último, tamanho)
3. Combinação de métodos
4. Resolução de problemas práticos
