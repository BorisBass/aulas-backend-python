# Plano de Aula: Trabalhando com Listas em Python

## Informações Gerais
- **Disciplina**: Programação Python
- **Tema**: Trabalhando com Listas
- **Duração**: 2 horas (120 minutos)
- **Nível**: Iniciante
- **Objetivo Geral**: Manipular coleções de dados em listas

## Objetivos Específicos
Ao final da aula, o aluno será capaz de:
1. Compreender o conceito de listas e sua importância na programação
2. Aprender a criar e acessar elementos de listas em Python
3. Dominar o uso dos métodos append(), insert() e remove()
4. Entender e aplicar o fatiamento (slicing) de listas
5. Praticar a manipulação de listas através de exercícios práticos
6. Desenvolver habilidades para resolver problemas usando listas

## Conteúdo Programático

### 1. Introdução às Listas (20 minutos)
- **Conceito**: O que são listas em Python
- **Características**: Ordenadas, mutáveis, indexadas, heterogêneas
- **Sintaxe básica**: Criação de listas com [] e list()
- **Exemplos práticos**: Diferentes tipos de listas

### 2. Criação e Acesso a Listas (25 minutos)
- **Criação de listas**: Vazias e com elementos
- **Acesso por índice**: Positivo e negativo
- **Demonstração prática**: Manipulação básica
- **Exercícios guiados**: Criação e acesso

### 3. Métodos de Manipulação (45 minutos)

#### 3.1 Método append() (15 minutos)
- **Funcionalidade**: Adicionar elemento no final
- **Sintaxe**: lista.append(elemento)
- **Exemplos práticos**: Lista de compras, notas
- **Exercícios**: Adição de elementos

#### 3.2 Método insert() (15 minutos)
- **Funcionalidade**: Inserir elemento em posição específica
- **Sintaxe**: lista.insert(índice, elemento)
- **Exemplos práticos**: Inserção no início, meio e final
- **Exercícios**: Inserção em diferentes posições

#### 3.3 Método remove() (15 minutos)
- **Funcionalidade**: Remover primeira ocorrência
- **Sintaxe**: lista.remove(elemento)
- **Tratamento de erros**: Verificação de existência
- **Exercícios**: Remoção de elementos

### 4. Fatiamento de Listas (20 minutos)
- **Conceito**: Extração de partes da lista
- **Sintaxe**: lista[início:fim:passo]
- **Exemplos**: Fatiamento básico e avançado
- **Casos especiais**: Inversão, passo negativo
- **Exercícios**: Diferentes tipos de fatiamento

### 5. Exercícios Práticos (30 minutos)
- **Lista de compras**: Uso do append()
- **Inserção no meio**: Uso do insert()
- **Remoção seletiva**: Uso do remove()
- **Fatiamento**: Extração de elementos
- **Problemas complexos**: Combinação de métodos
