O que são Listas?

Definição

Uma lista é uma coleção ordenada e mutável de elementos que podem ser de diferentes tipos de dados. Em Python, as listas são representadas por colchetes [].

Características Principais

• Ordenadas: Os elementos têm uma posição definida
• Mutáveis: Podem ser modificadas após a criação
• Indexadas: Acessadas por índices (começando em 0)
• Heterogêneas: Podem conter diferentes tipos de dados
• Duplicadas: Permitem elementos repetidos

Exemplo de lista:
frutas = ["maçã", "banana", "laranja", "uva"]
numeros = [1, 2, 3, 4, 5]
misturada = ["texto", 42, 3.14, True]
