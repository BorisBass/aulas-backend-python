Método extend()

O que faz o extend()?

O método extend() adiciona todos os elementos de uma sequência (lista, tupla, string) ao final da lista atual.

Sintaxe

lista.extend(sequência)

Exemplos Práticos

# Lista original
frutas = ["maçã", "banana"]
print("Original:", frutas)

# Estendendo com outra lista
novas_frutas = ["laranja", "uva", "morango"]
frutas.extend(novas_frutas)
print("Após extend:", frutas)
# ["maçã", "banana", "laranja", "uva", "morango"]

# Estendendo com string
frutas.extend("kiwi")
print("Com string:", frutas)
# ["maçã", "banana", "laranja", "uva", "morango", "k", "i", "w", "i"]

# Estendendo com tupla
numeros = [1, 2, 3]
numeros.extend((4, 5, 6))
print("Com tupla:", numeros) # [1, 2, 3, 4, 5, 6]
Diferença: extend() adiciona elementos individuais, enquanto append() adiciona a sequência como um único elemento.
