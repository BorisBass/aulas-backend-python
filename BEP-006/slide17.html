Funções Úteis para Listas

Funções de Tamanho e Verificação

len() - Retorna o número de elementos
in - Verifica se elemento existe na lista

Funções de Valor

max() - Retorna o maior elemento
min() - Retorna o menor elemento
sum() - Soma todos os elementos numéricos

Exemplos Práticos

numeros = [5, 2, 8, 1, 9, 3]
frutas = ["maçã", "banana", "laranja"]

# Tamanho e verificação
print("Tamanho:", len(numeros)) # 6
print("8 está na lista:", 8 in numeros) # True

# Valores extremos
print("Maior número:", max(numeros)) # 9
print("Menor número:", min(numeros)) # 1
print("Soma total:", sum(numeros)) # 28

# Com strings (ordem alfabética)
print("Maior fruta:", max(frutas)) # "maçã"
print("Menor fruta:", min(frutas)) # "banana"

# Aplicações práticas
if len(numeros) > 0:
    media = sum(numeros) / len(numeros)
    print(f"Média: {media:.2f}")

if 5 in numeros:
    print("Número 5 encontrado!")
Dica: max() e min() funcionam com números e strings. Para strings, usa ordem alfabética.
