Método append()

O que faz o append()?

O método append() adiciona um elemento ao final da lista. É uma das formas mais comuns de adicionar elementos a uma lista existente.

Sintaxe

lista.append(elemento)

Exemplos Práticos

# Criando uma lista vazia
frutas = []

# Adicionando elementos
frutas.append("maçã")
frutas.append("banana")
frutas.append("laranja")

print(frutas) # ["maçã", "banana", "laranja"]

# Adicionando um número
numeros = [1, 2, 3]
numeros.append(4)
print(numeros) # [1, 2, 3, 4]
Características: O append() sempre adiciona o elemento no final da lista e modifica a lista original (não retorna uma nova lista).
