Exercícios com Métodos Avançados

1. Gerenciamento de Lista

Crie uma lista com 5 números, ordene-a, remova o último elemento e conte quantas vezes o número 5 aparece.

numeros = [3, 5, 1, 5, 2]
# Ordene, remova último e conte 5s

2. Busca e Remoção

Dada uma lista de nomes, verifique se "Ana" existe, encontre sua posição e remova-a usando pop().

nomes = ["João", "Maria", "Ana", "Pedro"]
# Verifique, encontre posição e remova

3. Combinação de Listas

Crie duas listas, combine-as usando extend(), inverta a ordem e faça uma cópia da lista resultante.

lista1 = [1, 2, 3]
lista2 = [4, 5, 6]
# Combine, inverta e copie

4. Análise Completa

Crie uma lista com números duplicados, ordene-a, remova duplicatas e mostre o tamanho final.

numeros = [3, 1, 4, 1, 5, 9, 2, 6, 5]
# Ordene, remova duplicatas, mostre tamanho
