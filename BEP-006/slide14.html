Métodos count() e index()

Método count()

O método count() retorna o número de ocorrências de um elemento na lista.

Método index()

O método index() retorna o índice da primeira ocorrência de um elemento na lista.

Exemplos Práticos

numeros = [1, 2, 3, 2, 4, 2, 5]

# Contando ocorrências
print(numeros.count(2)) # 3
print(numeros.count(7)) # 0

# Encontrando índices
print(numeros.index(2)) # 1 (primeira ocorrência)
print(numeros.index(4)) # 4

# Busca a partir de uma posição
print(numeros.index(2, 2)) # 3 (busca a partir do índice 2)

# Tratamento de erro
if 7 in numeros:
    print(numeros.index(7))
else:
    print("Elemento não encontrado!")
Atenção: O index() gera erro se o elemento não for encontrado. Use 'in' para verificar antes.
