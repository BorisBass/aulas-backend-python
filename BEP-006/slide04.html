Criação e Acesso a Listas

Criando Listas

# Lista vazia
lista_vazia = []

# Lista com elementos
frutas = ["maçã", "banana", "laranja"]

# Lista com diferentes tipos
misturada = [1, "texto", 3.14, True]

# Usando list()
numeros = list(range(1, 6)) # [1, 2, 3, 4, 5]

Acessando Elementos

frutas = ["maçã", "banana", "laranja", "uva"]

# Acesso por índice (começa em 0)
print(frutas[0]) # "maçã"
print(frutas[2]) # "laranja"

# Índice negativo (do final para o início)
print(frutas[-1]) # "uva"
print(frutas[-2]) # "laranja"
Importante: O primeiro elemento tem índice 0, o segundo tem índice 1, e assim por diante. Índices negativos contam do final para o início.
