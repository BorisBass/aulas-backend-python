Operações com Listas

🔗 Concatenação e Repetição

# Concatenação (+) lista1 = [1, 2, 3] lista2 = [4, 5, 6] lista_combinada = lista1 + lista2 print(f"Concatenação: {lista_combinada}") # [1, 2, 3, 4, 5, 6] # Repetição (*) lista_repetida = [1, 2] * 3 print(f"Repetição: {lista_repetida}") # [1, 2, 1, 2, 1, 2] # Adicionar lista a outra lista1.extend(lista2) print(f"Lista1 após extend: {lista1}") # [1, 2, 3, 4, 5, 6]

📊 Funções Úteis

# len(): tamanho da lista lista = [1, 2, 3, 4, 5] print(f"Tamanho: {len(lista)}") # 5 # max() e min(): maior e menor valor numeros = [3, 1, 4, 1, 5, 9, 2] print(f"Maior: {max(numeros)}") # 9 print(f"Menor: {min(numeros)}") # 1 print(f"Soma: {sum(numeros)}") # 25 # in: verificar se elemento existe lista = ["a", "b", "c"] print(f"'b' está na lista: {'b' in lista}") # True print(f"'d' está na lista: {'d' in lista}") # False

🔄 Iterando sobre Listas

# Usando for frutas = ["maçã", "banana", "laranja"] print("Frutas disponíveis:") for fruta in frutas: print(f"- {fruta}") # Usando enumerate (índice + valor) print(" Frutas com índice:") for i, fruta in enumerate(frutas): print(f"{i}: {fruta}") # Usando range com len print(" Frutas com range:") for i in range(len(frutas)): print(f"{i}: {frutas[i]}")
💡 Exemplo Prático: Lista de Notas
# Sistema de notas notas = [] print("Digite as notas (digite -1 para parar):") while True: nota = float(input("Nota: ")) if nota == -1: break notas.append(nota) if notas: print(f" Notas: {notas}") print(f"Quantidade: {len(notas)}") print(f"Maior nota: {max(notas)}") print(f"Menor nota: {min(notas)}") print(f"Média: {sum(notas)/len(notas):.2f}") else: print("Nenhuma nota foi digitada!")

Dica

Use enumerate() quando precisar do índice e do valor ao mesmo tempo!
