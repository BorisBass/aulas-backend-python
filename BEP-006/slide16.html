Métodos clear() e copy()

Método clear()

O método clear() remove todos os elementos da lista, deixando-a vazia.

Método copy()

O método copy() cria uma cópia superficial da lista (nova lista com os mesmos elementos).

Exemplos Práticos

# Método clear()
lista = [1, 2, 3, 4, 5]
print("Antes:", lista)

lista.clear()
print("Após clear:", lista) # []
print("Tamanho:", len(lista)) # 0

# Método copy()
original = ["a", "b", "c"]
copia = original.copy()

print("Original:", original)
print("Cópia:", copia)

# Modificando a cópia
copia.append("d")
print("Original:", original) # ["a", "b", "c"]
print("Cópia:", copia) # ["a", "b", "c", "d"]
Importante: copy() cria uma nova lista independente. Mudanças na cópia não afetam a original.
