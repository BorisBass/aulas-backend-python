Método insert()

O que faz o insert()?

O método insert() adiciona um elemento em uma posição específica da lista, deslocando os elementos existentes para a direita.

Sintaxe

lista.insert(índice, elemento)

Exemplos Práticos

frutas = ["maçã", "banana", "laranja"]

# Inserindo no início (índice 0)
frutas.insert(0, "uva")
print(frutas) # ["uva", "maçã", "banana", "laranja"]

# Inserindo no meio (índice 2)
frutas.insert(2, "morango")
print(frutas) # ["uva", "maçã", "morango", "banana", "laranja"]

# Inserindo no final
frutas.insert(len(frutas), "abacaxi")
print(frutas) # ["uva", "maçã", "morango", "banana", "laranja", "abacaxi"]
Dica: Use insert(0, elemento) para adicionar no início e insert(len(lista), elemento) para adicionar no final (equivalente ao append()).
