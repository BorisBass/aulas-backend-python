Métodos sort() e reverse()

Método sort()

O método sort() ordena os elementos da lista in-place (modifica a lista original).

Método reverse()

O método reverse() inverte a ordem dos elementos da lista in-place.

Exemplos Práticos

# Ordenação
numeros = [3, 1, 4, 1, 5, 9, 2]
print("Original:", numeros)

numeros.sort()
print("Ordenado:", numeros) # [1, 1, 2, 3, 4, 5, 9]

# Ordenação decrescente
numeros.sort(reverse=True)
print("Decrescente:", numeros) # [9, 5, 4, 3, 2, 1, 1]

# Inversão
frutas = ["maçã", "banana", "laranja"]
frutas.reverse()
print("Invertido:", frutas) # ["laranja", "banana", "maçã"]
Importante: Ambos os métodos modificam a lista original e não retornam uma nova lista.
