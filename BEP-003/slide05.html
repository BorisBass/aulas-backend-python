Precedência de Operadores

📋 Ordem de Execução

Python executa operadores em uma ordem específica (precedência):

# Exemplo de precedência resultado = 2 + 3 * 4 # = 14 (não 20!) print(f"2 + 3 * 4 = {resultado}") # Use parênteses para controlar a ordem resultado = (2 + 3) * 4 # = 20 print(f"(2 + 3) * 4 = {resultado}")

💡 Exemplo Prático
# Cálculo de média ponderada nota1 = 8.5 nota2 = 7.0 peso1 = 2 peso2 = 3 # Sem parênteses (incorreto) media_errada = nota1 * peso1 + nota2 * peso2 / peso1 + peso2 # Com parênteses (correto) media_correta = (nota1 * peso1 + nota2 * peso2) / (peso1 + peso2) print(f"Média correta: {media_correta:.2f}")

Dica

Quando em dúvida, use parênteses! Torna o código mais claro e evita erros.
