BEP-003: Operadores em Python

Aritméticos, Relacionais e Lógicos

Resumo e Próximos Passos

🎯 Você aprendeu:

  • Operadores Aritméticos: +, -, *, /, //, %, **
  • Operadores Relacionais: ==, !=, <, >, <=, >=
  • Operadores Lógicos: and, or, not
  • Precedência: Ordem de execução dos operadores

🔧 Conceitos Importantes

  • Divisão: / (decimal) vs // (inteira)
  • Comparação: == (igual) vs = (atribuição)
  • Lógica: and, or, not combinam condições
  • Parênteses: Controlam a ordem de execução

🚀 Próxima aula (BEP-004)

  • Estruturas condicionais: if, elif, else
  • Tomada de decisões no código
  • Validação de dados
  • Fluxo de controle
💡 Dica Final

Pratique com exercícios variados. Os operadores são a base para toda lógica de programação!
