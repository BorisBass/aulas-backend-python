Operadores Lógicos

🧠 Combinando Condições

Os operadores lógicos combinam condições para formar expressões mais complexas:

# Operadores lógicos idade = 20 salario = 5000 # AND: ambas condições devem ser verdadeiras print(f"Maior de idade E salário alto: {idade >= 18 and salario > 3000}") # OR: pelo menos uma condição deve ser verdadeira print(f"Menor de idade OU salário baixo: {idade < 18 or salario < 3000}") # NOT: inverte o resultado print(f"NÃO é menor de idade: {not (idade < 18)}")
