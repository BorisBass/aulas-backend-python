Operadores Aritméticos

🧮 Operadores Básicos

Os operadores aritméticos realizam cálculos matemáticos:

# Operadores aritméticos básicos
a = 10
b = 3

print(f"Soma: {a} + {b} = {a + b}")        # 13
print(f"Subtração: {a} - {b} = {a - b}")   # 7
print(f"Multiplicação: {a} * {b} = {a * b}") # 30
print(f"Divisão: {a} / {b} = {a / b}")     # 3.333...

🔢 Operadores Avançados

# Divisão inteira e resto
print(f"Divisão inteira: {a} // {b} = {a // b}")  # 3
print(f"Resto da divisão: {a} % {b} = {a % b}")   # 1
print(f"Potência: {a} ** {b} = {a ** b}")         # 1000

💡 Exemplo Prático: Calculadora
# Calculadora simples
num1 = float(input("Primeiro número: "))
num2 = float(input("Segundo número: "))

print(f"Soma: {num1 + num2}")
print(f"Subtração: {num1 - num2}")
print(f"Multiplicação: {num1 * num2}")
print(f"Divisão: {num1 / num2}")

Cuidado!

Divisão por zero causa erro! Sempre valide os dados antes de dividir.
