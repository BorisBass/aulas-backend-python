BEP-003: Operadores em Python

Aritméticos, Relacionais e Lógicos

Introdução aos Operadores

🎯 Objetivo da Aula

Dominar os operadores aritméticos, relacionais e lógicos em Python para realizar cálculos e comparações em programas.

📚 O que você vai aprender:

  • Operadores Aritméticos: +, -, *, /, //, %, **
  • Operadores Relacionais: ==, !=, <, >, <=, >=
  • Operadores Lógicos: and, or, not
  • Precedência: Ordem de execução dos operadores
  • Exercícios práticos: Aplicação em problemas reais

Por que estudar operadores?

  • Cálculos: Realizar operações matemáticas
  • Comparações: Tomar decisões no código
  • Lógica: Combinar condições complexas
  • Eficiência: Escrever código mais limpo
💡 Analogia: Operadores como Ferramentas

Imagine operadores como ferramentas de uma caixa:

  • Martelo (+): Junta coisas
  • Serra (-): Separa coisas
  • Furadeira (*): Multiplica esforço
  • Fita métrica (==): Compara tamanhos

Cada operador tem sua função específica!

🔧 Pré-requisitos

  • Conhecimento básico de matemática
  • Variáveis em Python (BEP-001)
  • Tipos de dados (BEP-002)

Dica Importante

Os operadores são a base para toda lógica de programação. Domine-os bem para avançar com confiança!
