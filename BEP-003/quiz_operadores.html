🐍 Quiz: Operadores em Python

1. Qual é o resultado da expressão: 10 + 3 * 2?

A) 26
B) 16
C) 13
D) 20
Resposta correta: B) 16
Devido à precedência de operadores, a multiplicação é executada antes da adição: 3 * 2 = 6, depois 10 + 6 = 16.

2. Qual operador é usado para verificar se dois valores são iguais?

A) =
B) ==
C) !=
D) ===
Resposta correta: B) ==
O operador == é usado para comparação de igualdade, enquanto = é usado para atribuição.

3. Qual é o resultado da expressão: 17 % 5?

A) 3
B) 2
C) 3.4
D) 12
Resposta correta: B) 2
O operador % (módulo) retorna o resto da divisão. 17 ÷ 5 = 3 com resto 2.

4. Qual é o resultado da expressão: True and False or True?

A) True
B) False
C) None
D) Error
Resposta correta: A) True
Devido à precedência, and é avaliado antes de or: (True and False) or True = False or True = True.

5. Qual operador é usado para exponenciação em Python?

A) ^
B) **
C) pow
D) exp
Resposta correta: B) **
O operador ** é usado para exponenciação em Python. Por exemplo: 2 ** 3 = 8.

6. Qual é o resultado da expressão: not (5 > 3 and 2 < 4)?

A) True
B) False
C) None
D) Error
Resposta correta: B) False
5 > 3 é True, 2 < 4 é True, então True and True = True. O not inverte o resultado: not True = False.

7. Qual é o resultado da divisão inteira: 15 // 4?

A) 3.75
B) 3
C) 4
D) 3.0
Resposta correta: B) 3
O operador // realiza divisão inteira, retornando apenas a parte inteira do resultado: 15 ÷ 4 = 3.75, mas 15 // 4 = 3.

8. Qual é o resultado da expressão: 10 >= 10?

A) True
B) False
C) 10
D) Error
Resposta correta: A) True
O operador >= verifica se o valor à esquerda é maior ou igual ao valor à direita. 10 é igual a 10, então o resultado é True.
