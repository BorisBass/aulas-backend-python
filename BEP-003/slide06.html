🎯 Exercício 1: Calculadora Avançada

Calcule a média de 3 notas com pesos diferentes.

nota1 = float(input("Nota 1: "))
nota2 = float(input("Nota 2: "))
nota3 = float(input("Nota 3: "))

# Média simples
media_simples = (nota1 + nota2 + nota3) / 3

# Média ponderada (pesos: 2, 3, 5)
media_ponderada = (nota1 * 2 + nota2 * 3 + nota3 * 5) / 10

print(f"Média simples: {media_simples:.2f}")
print(f"Média ponderada: {media_ponderada:.2f}")

🎯 Exercício 2: Verificação de Aprovação

Verifique se um aluno foi aprovado (média >= 7.0).

nota1 = float(input("Nota 1: "))
nota2 = float(input("Nota 2: "))
nota3 = float(input("Nota 3: "))

media = (nota1 + nota2 + nota3) / 3

if media >= 7.0:
    print(f"Aprovado! Média: {media:.2f}")
else:
    print(f"Reprovado! Média: {media:.2f}")

🎯 Exercício 3: Calculadora de IMC

Calcule o Índice de Massa Corporal.

peso = float(input("Peso (kg): "))
altura = float(input("Altura (m): "))
imc = peso / (altura ** 2)
print(f"IMC: {imc:.2f}")
if imc < 18.5:
    print("Abaixo do peso")
elif imc < 25:
    print("Peso normal")
elif imc < 30:
    print("Sobrepeso")
else:
    print("Obesidade")
