Protegendo dados e criando métodos para manipulação de objetos

Exercícios Práticos

Prática com classes encapsuladas

1) Classe Aluno Encapsulada

  1. Crie a classe Aluno com atributo privado __nota.
  2. Implemente getter get_nota() e setter set_nota() com validação (0-10).
  3. Adicione método aprovado() que retorna True se nota >= 6.
class Aluno:
    def __init__(self, nome, nota):
        self.nome = nome
        self.__nota = 0
        self.set_nota(nota)
    
    def get_nota(self):
        return self.__nota
    
    def set_nota(self, nota):
        if 0 <= nota <= 10:
            self.__nota = nota
        else:
            raise ValueError("Nota deve estar entre 0 e 10")
    
    def aprovado(self):
        return self.__nota >= 6

a = Aluno("Ana", 7.5)
print(a.get_nota(), a.aprovado())

2) Classe Produto Encapsulada

  1. Crie a classe Produto com __preco e __estoque privados.
  2. Implemente getters e setters para ambos os atributos.
  3. Valide: preço > 0 e estoque >= 0.
  4. Adicione método vender(quantidade) que reduz estoque.
class Produto:
    def __init__(self, nome, preco, estoque):
        self.nome = nome
        self.__preco = 0
        self.__estoque = 0
        self.set_preco(preco)
        self.set_estoque(estoque)
    
    def get_preco(self):
        return self.__preco
    
    def set_preco(self, preco):
        if preco > 0:
            self.__preco = float(preco)
        else:
            raise ValueError("Preço deve ser maior que zero")
    
    def get_estoque(self):
        return self.__estoque
    
    def set_estoque(self, estoque):
        if estoque >= 0:
            self.__estoque = int(estoque)
        else:
            raise ValueError("Estoque não pode ser negativo")
    
    def vender(self, quantidade):
        if quantidade > 0 and quantidade <= self.__estoque:
            self.__estoque -= quantidade
            return f"Venda de {quantidade} unidade(s) realizada."
        return "Estoque insuficiente."

p = Produto("Notebook", 2500, 10)
print(p.get_preco(), p.get_estoque())
p.vender(3)
print(p.get_estoque())

3) Classe Pessoa com Idade Protegida

  1. Crie a classe Pessoa com _idade (protected).
  2. Implemente getter e setter com validação (idade >= 0).
  3. Adicione método fazer_aniversario() que incrementa a idade.
class Pessoa:
    def __init__(self, nome, idade):
        self.nome = nome
        self._idade = 0
        self.set_idade(idade)
    
    def get_idade(self):
        return self._idade
    
    def set_idade(self, idade):
        if idade >= 0:
            self._idade = int(idade)
        else:
            raise ValueError("Idade não pode ser negativa")
    
    def fazer_aniversario(self):
        self._idade += 1
        return f"{self.nome} fez aniversário! Agora tem {self._idade} anos."

p = Pessoa("Ana", 25)
print(p.get_idade())
print(p.fazer_aniversario())
