BEP-019: Encapsulamento e Métodos de Instância

Protegendo dados e criando métodos para manipulação de objetos

Modificadores de Acesso

Public, private e protected em Python

Public (Público)

Atributos e métodos acessíveis de qualquer lugar:

class Pessoa:
    def __init__(self, nome):
        self.nome = nome  # Público

p = Pessoa("Ana")
print(p.nome)  # ✅ Acesso direto permitido

Em Python, por padrão, tudo é público (sem prefixo).

Private (Privado)

Atributos e métodos acessíveis apenas dentro da classe:

class Pessoa:
    def __init__(self, nome):
        self.__nome = nome  # Privado (__)

p = Pessoa("Ana")
print(p.__nome)  # ❌ Erro! Acesso negado

Usa prefixo __ (dois underscores).

Protected (Protegido)

Atributos e métodos acessíveis na classe e subclasses:

class Pessoa:
    def __init__(self, nome):
        self._nome = nome  # Protegido (_)

p = Pessoa("Ana")
print(p._nome)  # ⚠️ Funciona, mas é convenção não acessar

Usa prefixo _ (um underscore). É uma convenção, não bloqueia acesso.

Resumo dos Modificadores

Modificador Prefix Acesso Exemplo
Public Nenhum Qualquer lugar self.nome
Protected _ Classe e subclasses self._nome
Private __ Apenas na classe self.__nome
