BEP-019: Encapsulamento e Métodos de Instância

Protegendo dados e criando métodos para manipulação de objetos

Métodos de Instância

Criando métodos para manipular atributos

O que são Métodos de Instância?

Métodos que operam sobre uma instância específica do objeto. Eles recebem self como primeiro parâmetro e podem acessar e modificar os atributos da instância.

Exemplo: Manipulando Atributos

class ContaBancaria:
    def __init__(self, titular, saldo_inicial=0):
        self.__saldo = saldo_inicial  # Privado
        self.titular = titular
    
    # Método para ler o saldo
    def obter_saldo(self):
        return self.__saldo
    
    # Método para modificar o saldo (com validação)
    def depositar(self, valor):
        if valor > 0:
            self.__saldo += valor
            return f"Depósito de R$ {valor:.2f} realizado."
        return "Valor inválido!"
    
    def sacar(self, valor):
        if valor > 0 and valor <= self.__saldo:
            self.__saldo -= valor
            return f"Saque de R$ {valor:.2f} realizado."
        return "Saldo insuficiente!"

conta = ContaBancaria("Ana", 1000)
print(conta.obter_saldo())  # ✅ Via método
print(conta.depositar(500))
print(conta.sacar(200))
print(conta.obter_saldo())

Vantagens

  • Controle: Validação antes de modificar atributos
  • Segurança: Atributos privados não são acessados diretamente
  • Flexibilidade: Pode mudar implementação sem afetar quem usa
  • Manutenibilidade: Lógica centralizada nos métodos
