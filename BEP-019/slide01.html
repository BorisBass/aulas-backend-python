BEP-019: Encapsulamento e Métodos de Instância

Protegendo dados e criando métodos para manipulação de objetos

O que é Encapsulamento?

Definição e importância do encapsulamento

Definição

Encapsulamento é o princípio de ocultar os detalhes internos de implementação de uma classe e expor apenas o que é necessário através de uma interface controlada.

  • Protege dados sensíveis
  • Controla como os dados são acessados
  • Facilita manutenção do código
  • Previne modificações indevidas

Problema sem Encapsulamento

class ContaBancaria:
    def __init__(self, titular, saldo):
        self.titular = titular
        self.saldo = saldo  # Acesso direto!

conta = ContaBancaria("Ana", 1000)
conta.saldo = -500  # ❌ Problema! Saldo negativo
conta.saldo = "erro"  # ❌ Problema! Tipo errado

Sem proteção, qualquer um pode modificar os dados de forma incorreta.

Benefícios do Encapsulamento

  • Segurança: Dados protegidos contra acesso indevido
  • Validação: Controle sobre valores aceitos
  • Flexibilidade: Pode mudar implementação interna sem afetar quem usa
  • Manutenibilidade: Código mais organizado e fácil de manter
