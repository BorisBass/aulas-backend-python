BEP-019: Encapsulamento e Métodos de Instância

Protegendo dados e criando métodos para manipulação de objetos

Atributos Privados

Usando _ e __ para proteger atributos

Protected (_)

Convenção para indicar "não acesse diretamente":

class ContaBancaria:
    def __init__(self, titular):
        self._saldo = 0  # Protected
        self.titular = titular

conta = ContaBancaria("Ana")
print(conta._saldo)  # ⚠️ Funciona, mas não é recomendado

É uma convenção, não bloqueia o acesso.

Private (__)

Bloqueia acesso direto (name mangling):

class ContaBancaria:
    def __init__(self, titular):
        self.__saldo = 0  # Private
        self.titular = titular

conta = ContaBancaria("Ana")
print(conta.__saldo)  # ❌ AttributeError
# Python renomeia para _ContaBancaria__saldo

Python renomeia internamente para evitar acesso direto.

Exemplo Prático

class Produto:
    def __init__(self, nome, preco):
        self.nome = nome  # Público
        self._preco = preco  # Protected
        self.__estoque = 0  # Private
    
    def ver_estoque(self):
        return self.__estoque  # Acesso interno OK

p = Produto("Notebook", 2500)
print(p.nome)  # ✅ OK
print(p._preco)  # ⚠️ Funciona, mas não recomendado
print(p.__estoque)  # ❌ Erro!
print(p.ver_estoque())  # ✅ OK (via método)
