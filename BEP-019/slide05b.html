BEP-019: Encapsulamento e Métodos de Instância

Protegendo dados e criando métodos para manipulação de objetos

@property: Forma Pythônica

Decorador elegante para getters e setters

O que é @property?

@property é um decorador que permite acessar métodos como se fossem atributos.

  • Forma elegante e pythônica
  • Mantém encapsulamento
  • Sintaxe mais limpa
  • Usa atributos como se fossem públicos

Por que usar @property?

Em vez de:

pessoa.get_nome()

Você pode usar:

pessoa.nome

Mas ainda mantém validação e controle!

Comparação: Métodos vs @property

❌ Forma Tradicional (getters/setters)

class Produto:
    def __init__(self, preco):
        self.__preco = preco
    
    def get_preco(self):
        return self.__preco
    
    def set_preco(self, valor):
        if valor > 0:
            self.__preco = valor
        else:
            raise ValueError("Preço inválido")

p = Produto(100)
print(p.get_preco())  # Precisa usar get_()
p.set_preco(150)      # Precisa usar set_()

✅ Forma Pythônica (@property)

class Produto:
    def __init__(self, preco):
        self.__preco = preco
    
    @property
    def preco(self):
        return self.__preco
    
    @preco.setter
    def preco(self, valor):
        if valor > 0:
            self.__preco = valor
        else:
            raise ValueError("Preço inválido")

p = Produto(100)
print(p.preco)  # Acesso direto como atributo!
p.preco = 150   # Atribuição direta como atributo!

Como Funciona

  • @property: Transforma um método em um "getter" (leitura)
  • @atributo.setter: Transforma um método em um "setter" (escrita)
  • Sintaxe: Use o mesmo nome para getter e setter
  • Uso: Acesse como atributo normal, mas com validação por trás

Exemplo Completo com @property

class Pessoa:
    def __init__(self, nome, idade):
        self.__nome = nome
        self.__idade = 0
        self.idade = idade  # Usa o setter na inicialização
    
    @property
    def nome(self):
        return self.__nome
    
    @nome.setter
    def nome(self, valor):
        if isinstance(valor, str) and len(valor) > 0:
            self.__nome = valor
        else:
            raise ValueError("Nome deve ser uma string não vazia")
    
    @property
    def idade(self):
        return self.__idade
    
    @idade.setter
    def idade(self, valor):
        if isinstance(valor, int) and valor >= 0:
            self.__idade = valor
        else:
            raise ValueError("Idade deve ser um inteiro não negativo")

# Uso elegante!
p = Pessoa("Ana", 25)
print(p.nome)    # Acesso direto
print(p.idade)   # Acesso direto
p.idade = 26     # Atribuição direta (com validação)
p.nome = "Ana Silva"  # Atribuição direta (com validação)
